# Block 36: [황궁 탈환전: 대도의 심판]

[핵심 전략]
황궁의 결계를 힘으로 부수고 정전에 난입. 옥좌 뒤에 숨은 환관들을 도의 풍압으로 끌어내고, 덤벼드는 키메라들을 단순하고 묵직한 '내려치기'로 하나씩 터뜨려버림.

[상황/맥락]
후방의 불안 요소를 제거하기 위해, 마교와 내통한 황실을 정화하고자 정예병을 이끌고 입궐.

[적대자/위기]
황제를 허수아비로 만들고 중원을 마교에 넘기려 한 매국노 환관들과, 황궁 지하에 숨겨둔 마교의 키메라 병기들.

[해결/전투]
황궁의 결계를 힘으로 부수고 정전에 난입. 옥좌 뒤에 숨은 환관들을 도의 풍압으로 끌어내고, 덤벼드는 키메라들을 단순하고 묵직한 '내려치기'로 하나씩 터뜨려버림.
