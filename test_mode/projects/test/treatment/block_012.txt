# Block 12: [아버지의 어깨: 오대세가 회의]

[핵심 전략]
호위로 동행한 무진이 나서는 대신, 아버지의 뒤에 산처럼 버티고 서서 가주들이 뿜어내는 기세를 자신의 '무게'로 지워버림. 무진의 보필을 받은 팽철산이 위축되지 않고 당당하게 팽가의 지분을 요구하며 호통침.

[상황/맥락]
팽가의 위상이 급상승하자, 견제와 탐색을 위해 오대세가 가주들이 모이는 정기 회의가 소집됨.

[적대자/위기]
전생에 팽철산(아버지)을 '근육만 있는 촌부'라 무시했던 남궁과 모용의 가주들. 회의장에서 은근한 기세 싸움으로 팽철산을 망신 주려 함.

[해결/전투]
호위로 동행한 무진이 나서는 대신, 아버지의 뒤에 산처럼 버티고 서서 가주들이 뿜어내는 기세를 자신의 '무게'로 지워버림. 무진의 보필을 받은 팽철산이 위축되지 않고 당당하게 팽가의 지분을 요구하며 호통침.
