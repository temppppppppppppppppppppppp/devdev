# Block 44: [아버지의 방패: 팽철산의 투혼]

[핵심 전략]
쓰러진 아버지를 뒤로하고 분노한 무진이 돌격. 아버지의 희생이 헛되지 않도록 냉정함을 유지하며 천마의 1차 공세를 도의 '면'으로 받아냄.

[상황/맥락]
천마신궁 내부. 천마가 옥좌에 앉아 압도적인 마기를 뿜어냄.

[적대자/위기]
천마가 손가락 하나를 튕겨 날린 '탄지공'이 무진의 심장을 노리고 날아옴. 무진이 반응하기 전, 아버지 팽철산이 뛰어들어 온몸으로 공격을 막아내고 중상을 입음.

[해결/전투]
쓰러진 아버지를 뒤로하고 분노한 무진이 돌격. 아버지의 희생이 헛되지 않도록 냉정함을 유지하며 천마의 1차 공세를 도의 '면'으로 받아냄.
