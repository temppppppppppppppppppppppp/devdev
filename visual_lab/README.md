# Visual Lab

Standalone image-production lab at workspace root.

Purpose:

- keep illustration / cover R&D outside the main `projects/` app flow
- separate typography experiments from illustration-generation experiments
- preserve reusable prompts, job configs, outputs, and automatic judging

Current areas:

- `cover_pipeline/`
  - title-integrated cover experiments
- `illustration_pipeline/`
  - text-free illustration generation and ranking

This folder is intentionally isolated from the main Geuldobi runtime.
