# 회차 간 연결 패턴(Episode Transition Pattern) 분석 보고서

**분석 대상**: 투자/재벌 장르 웹소설 3작품, 총 75화(72개 전환점)
**분석 일자**: 2026-03-17

---

## 1부: 작품별 전환점 상세 분석

---

### 작품 A: 투자물_금수저생활백서 (24개 전환점)

#### A-01: ep01 → ep02
- **ep01 마지막 문장**: "본능적으로 머리를 부여잡고 바닥을 구른 재성은 자신이 아닌 다른 사람의 기억이 밀려들어 오는 것을 느끼고 경악했다."
- **ep02 첫 문장**: "이거 정말 실화야……?"
- **연결 유형**: 시간 점프 + 반응 시작형
- **시간 간격**: 하룻밤 경과 (다른 몸으로 깨어남)
- **이월 정보**: 기억 이식이라는 초자연적 사건, 경악의 감정
- **신규 정보**: 새로운 몸(재벌 막내아들), 새로운 공간(넓은 방)
- **매끄러움**: ★★★★★ (전화의 결과를 독자가 즉시 확인)

#### A-02: ep02 → ep03
- **ep02 마지막 문장**: "성난 황소처럼 뒤에서 그르렁 그르렁거리는 엔진 소리를 들으며 그는 처음으로 게임을 실행하길 잘했다고 생각했다."
- **ep03 첫 문장**: "거친 엔진 소리를 울리면서 한강 고수부지에 들어선 재성은 가야르도 차문을 열고 내렸다."
- **연결 유형**: 직접 연속형
- **시간 간격**: 즉시 연속 (드라이브 도중 → 도착)
- **이월 정보**: 람보르기니 드라이브라는 동일 행위, 엔진 소리 묘사 연결
- **신규 정보**: 한강 고수부지라는 새로운 장소
- **매끄러움**: ★★★★★ ("엔진 소리" 키워드가 양쪽에 등장하며 자연스럽게 이어짐)

#### A-03: ep03 → ep04
- **ep03 마지막 문장**: "아니야. 성급하게 믿기에는 아직 이르지."
- **ep04 첫 문장**: "서울 마포 공덕 오거리."
- **연결 유형**: 장소 전환 + 시간 점프형
- **시간 간격**: 시간 점프 (가족 모임 후 → 출근)
- **이월 정보**: 회장의 의심이라는 긴장감
- **신규 정보**: 제일 그룹 본사 사옥, 업무 환경
- **매끄러움**: ★★★☆☆ (장소 묘사로 새 장면 설정, 약간의 단절감)

#### A-04: ep04 → ep05
- **ep04 마지막 문장**: "그것도 10시간 동안."
- **ep05 첫 문장**: "절제되고 심플한 디자인을 강조하는 것이 핵심입니다."
- **연결 유형**: 직접 연속형 (동일 회의 연속)
- **시간 간격**: 즉시 연속 (마라톤 회의 계속)
- **이월 정보**: 광고 컨셉 회의라는 동일 사건
- **신규 정보**: 결정된 컨셉 내용
- **매끄러움**: ★★★★★ (10시간 회의의 결과가 바로 이어짐)

#### A-05: ep05 → ep06
- **ep05 마지막 문장**: "불과 일주일 전과 비교해 봐도 확연하게 다른 반응이었다."
- **ep06 첫 문장**: "재성이 먼저 회의실을 나간 뒤. 남은 팀원들은 각자 자리를 정리하며 잡담을 하기 시작했다."
- **연결 유형**: 시점 전환형 (재성 → 팀원들)
- **시간 간격**: 즉시 연속 (같은 회의 직후)
- **이월 정보**: 보너스 약속, 팀원들의 반응
- **신규 정보**: 팀원들의 사적 대화, 재성 부재 시의 분위기
- **매끄러움**: ★★★★☆ (시점만 바뀌고 시공간 동일)

#### A-06: ep06 → ep07
- **ep06 마지막 문장**: "권혁재 대리는 성급하게 입을 놀린 과거의 자신을 원망하며 작게 한숨을 내쉬었다."
- **ep07 첫 문장**: "회의실에 앉은 재성은 읽고 있던 서류를 내려놓았다."
- **연결 유형**: 시간 점프 + 시점 복귀형
- **시간 간격**: 시간 점프 (광고 제작 기간 경과)
- **이월 정보**: 광고 프로젝트 진행
- **신규 정보**: 광고 성과 보고 상황
- **매끄러움**: ★★★☆☆ (시간 경과가 명시적이지 않음)

#### A-07: ep07 → ep08
- **ep07 마지막 문장**: "뒤늦게 말뜻을 알아차린 황창민 부장의 눈이 휘둥그레졌다."
- **ep08 첫 문장**: "난데없이 찾아온 막내아들의 당돌한 요구에 박경수 회장의 미간에 주름이 잡혔다."
- **연결 유형**: 직접 연속형 + 장소 전환
- **시간 간격**: 짧은 시간 점프 (회장실 도착)
- **이월 정보**: 성과금 요구라는 목표
- **신규 정보**: 회장의 반응, 회장실 상황
- **매끄러움**: ★★★★★ (클리프행어 → 즉시 다음 장면)

#### A-08: ep08 → ep09
- **ep08 마지막 문장**: "원하던 대답이 나오자 재성의 입가에 미소가 지어졌다."
- **ep09 첫 문장**: "퇴근 시간이 되자 재성은 보고 있던 서류를 내려놓았다."
- **연결 유형**: 일상 리셋형
- **시간 간격**: 시간 점프 (업무 마무리 후 퇴근)
- **이월 정보**: 후속 제품 기획이라는 업무 맥락
- **신규 정보**: 퇴근 후 일상, 새로운 퀘스트 가능성
- **매끄러움**: ★★★☆☆ (성취 후 소강 상태로 전환)

#### A-09: ep09 → ep10
- **ep09 마지막 문장**: "보상 내용을 확인한 그는 자신도 모르게 한쪽 주먹을 꽉 움켜쥐었다."
- **ep10 첫 문장**: "'이거 완전 대박이잖아!'"
- **연결 유형**: 직접 연속형 (감정 연속)
- **시간 간격**: 즉시 연속
- **이월 정보**: 퀘스트 보상 내용, 흥분 감정
- **신규 정보**: 보상 분석에 대한 구체적 내심
- **매끄러움**: ★★★★★ (감정이 직접 이어짐)

#### A-10: ep10 → ep11
- **ep10 마지막 문장**: "나도 나름 사활을 걸고 있거든. 그런 사람 둘이 손잡으면 뭘 못 하겠어."
- **ep11 첫 문장**: "답지 않게 아주 솔직한 대답이었다."
- **연결 유형**: 시점 전환형 (재성 → 재경)
- **시간 간격**: 즉시 연속
- **이월 정보**: 재성의 대사, 누나와의 협력 제안
- **신규 정보**: 재경의 내면 심리, 동생에 대한 재평가
- **매끄러움**: ★★★★★ (대사 직후 상대방 반응)

#### A-11: ep11 → ep12
- **ep11 마지막 문장**: "그쪽에서 어떤 조건을 제시했는지 모르겠지만 저희가 해드릴 수 있는 최상의 대우입니다."
- **ep12 첫 문장**: "아르노 회장이 눈썹을 찌푸리고는 맞은편에 있는 재경을 봤다."
- **연결 유형**: 직접 연속형 (동일 협상 장면)
- **시간 간격**: 즉시 연속
- **이월 정보**: 협상 긴장감, 재경의 발언
- **신규 정보**: 아르노 회장의 반응
- **매끄러움**: ★★★★★ (대화가 그대로 이어짐)

#### A-12: ep12 → ep13
- **ep12 마지막 문장**: "말 그대로 우수수 쏟아져 내리는 보상에 입이 함지박만 하게 벌어졌다."
- **ep13 첫 문장**: "'놀랄 노 자로군.'"
- **연결 유형**: 시간 점프 + 장소 전환형
- **시간 간격**: 시간 점프 (계약 후 → 회장 보고)
- **이월 정보**: 파르네세 계약 성사
- **신규 정보**: 박경수 회장의 반응 장면
- **매끄러움**: ★★★★☆ (성과 보고라는 자연스러운 후속)

#### A-13: ep13 → ep14
- **ep13 마지막 문장**: "재성의 목소리는 확신에 가득 차 있었다."
- **ep14 첫 문장**: "그러면 전제적인 UI는 명품 브랜드 고유의 이미지를 살릴 수 있도록 파르네세 측에 디자인을 맡기는 걸로 정리하죠."
- **연결 유형**: 시간 점프형 (프로젝트 진행)
- **시간 간격**: 시간 점프 (기획 → 실무 회의)
- **이월 정보**: 명품폰 프로젝트
- **신규 정보**: UI 디자인 실무 논의
- **매끄러움**: ★★★☆☆ (업무 진행의 자연스러운 흐름)

#### A-14: ep14 → ep15
- **ep14 마지막 문장**: "사람이 기껏 감사 인사를 하는데. 하여간 제멋대로라니까."
- **ep15 첫 문장**: "인천 국제공항. 국제선 청사에 도착하자 먼저 나와 있던 권혁재 대리와 장하나가 그를 발견하곤 바로 다가왔다."
- **연결 유형**: 시간 점프 + 장소 전환형
- **시간 간격**: 시간 점프 (서울 → 공항)
- **이월 정보**: 파르네세 프로젝트 진행 맥락
- **신규 정보**: 해외 출장, 공항 장면
- **매끄러움**: ★★★☆☆ (목적지 변경이 다소 갑작스러움)

#### A-15: ep15 → ep16
- **ep15 마지막 문장**: "아르노 회장의 대답을 들으며 재성은 입가에 미소를 지었다."
- **ep16 첫 문장**: "스페셜 에디션 출시는 파르네세 입장에서도 이득이 되는 일이었기에 어렵지 않게 계약이 이루어졌다."
- **연결 유형**: 요약 전진형
- **시간 간격**: 시간 점프 (협상 성사 → 요약 후 파티)
- **이월 정보**: 스페셜 에디션 계약 성사
- **신규 정보**: VIP 파티 초대
- **매끄러움**: ★★★★☆ (요약 문장으로 자연스럽게 넘어감)

#### A-16: ep16 → ep17
- **ep16 마지막 문장**: "꺅, 하면서 장하나가 허리를 끌어안자 권혁재 대리의 얼굴이 헤벌쭉하게 벌어졌다."
- **ep17 첫 문장**: "실제로 장하나의 아이디어는 꽤 쓸 만했다."
- **연결 유형**: 반응-확장형 (아이디어 → 실행)
- **시간 간격**: 즉시 연속
- **이월 정보**: 장하나의 마케팅 아이디어
- **신규 정보**: 브래드 피트/안젤리나 졸리 활용 구체화
- **매끄러움**: ★★★★☆

#### A-17: ep17 → ep18
- **ep17 마지막 문장**: "……!"
- **ep18 첫 문장**: "난데없는 지시에 놀란 기색을 감추지 못한 채 되물었다."
- **연결 유형**: 직접 연속형 (클리프행어 해소)
- **시간 간격**: 즉시 연속
- **이월 정보**: 회장의 핸드볼 후원 지시
- **신규 정보**: 재성의 놀란 반응과 구체적 질문
- **매끄러움**: ★★★★★ (놀람 → 반응이 즉시 연결)

#### A-18: ep18 → ep19
- **ep18 마지막 문장**: "이거 해도 해도 너무한 거 아닙니까!"
- **ep19 첫 문장**: "사무실 안으로 들어가자 태극기 마크가 선명하게 박힌 국가대표 트레이닝복을 입은 사내가 살집이 두툼한 중년인과 말다툼을 벌이고 있었다."
- **연결 유형**: 직접 연속형 (문을 열며 목격한 장면)
- **시간 간격**: 즉시 연속
- **이월 정보**: 고함소리의 주인공 확인
- **신규 정보**: 감독과 협회 간 갈등, 열악한 지원 실태
- **매끄러움**: ★★★★★ (고함 → 상황 설명이 자연스럽게 연결)

#### A-19: ep19 → ep20
- **ep19 마지막 문장**: "재성은 문득 떠오른 과거를 털어내며 의욕을 끌어올렸다."
- **ep20 첫 문장**: "넓은 집무실 안. 박경수 회장은 푹신한 가죽 소파에 앉은 채 막내아들 녀석이 갑자기 가져온 기획안을 읽고 있었다."
- **연결 유형**: 시간 점프 + 시점 전환형
- **시간 간격**: 시간 점프 (기획안 작성 → 회장 보고)
- **이월 정보**: 기획안 준비 의욕
- **신규 정보**: 회장의 관점, 기획안 내용
- **매끄러움**: ★★★★☆ (기획안 작성 → 보고 결과의 자연스러운 전개)

#### A-20: ep20 → ep21
- **ep20 마지막 문장**: "'먼저 걸리적거리지 않게 기생충 같은 놈들부터 싹 다 치워 버려야겠지.'"
- **ep21 첫 문장**: "협회 사무실로 올라가자 실내 체육관에서 있었던 일을 전해 들었는지 손경식 부장이 불편한 기색을 내보였다."
- **연결 유형**: 의지-실행형 (결심 → 행동)
- **시간 간격**: 짧은 시간 점프
- **이월 정보**: 협회 비리 척결 의지
- **신규 정보**: 손경식 부장과의 대면, 갈등 본격화
- **매끄러움**: ★★★★★ (결심 직후 행동으로 전환)

#### A-21: ep21 → ep22
- **ep21 마지막 문장**: "살짝 머리를 숙인 재성은 결재판을 챙겨 들고 자리에서 일어났다."
- **ep22 첫 문장**: "새삼스러운 눈빛으로 문을 닫고 나가는 막내아들을 물끄러미 쳐다보던 박경수 회장은 이내 두 측근에게 시선을 돌렸다."
- **연결 유형**: 시점 전환형 (재성 → 회장)
- **시간 간격**: 즉시 연속 (재성 퇴장 직후)
- **이월 정보**: 재성의 보고 내용, 회장의 결재
- **신규 정보**: 회장과 측근들의 평가
- **매끄러움**: ★★★★★ (동일 장면의 시점만 전환)

#### A-22: ep22 → ep23
- **ep22 마지막 문장**: "술잔을 부딪치는 두 사람 주위로 다른 손님들의 목소리가 떠들썩하게 울렸다."

## 2부: 패턴 분류 체계 (Pattern Taxonomy)

### 패턴 1: 직접 연속형 (直接 連續型)

**정의**: 이전 화의 마지막 장면이 다음 화의 첫 장면과 시간적/공간적으로 끊김 없이 이어지는 패턴. 동일한 대화, 동일한 행동, 동일한 장소가 화 경계를 넘어 지속된다.

**매끄러움**: ★★★★★

**대표 사례**:
- A-02 (금수저생활백서 ep02→03): "엔진 소리" 키워드가 양쪽에 등장하며 드라이브가 그대로 이어짐

### 핵심 인사이트

**1. "직접 연속 + 시간 점프"가 전체의 65%를 차지한다.**
이 두 패턴이 웹소설 회차 전환의 기본 문법이다. 직접 연속은 몰입감을, 시간 점프는 서사 속도를 담당한다.

**2. 재벌/투자물 장르의 고유 패턴: "직접 반복형"과 "외부 사건 도입형"**
뉴스 기사, 금융 데이터, 역사적 사건 등 "외부 텍스트"가 회차 전환의 매개체로 활용되는 것은 이 장르의 특징이다. 판타지나 로맨스에서는 보기 어려운 패턴이다.

**3. 시점 전환은 "회장의 반응"을 보여줄 때 집중적으로 사용된다.**
세 작품 모두 주인공이 퇴장한 직후 회장/가족/상대방의 시점으로 전환하는 패턴을 반복한다. 이는 "주인공이 인정받고 있다"는 독자 만족감을 간접적으로 전달하는 효과가 있다.

**4. 일상 리셋은 최소화된다.**
72개 전환 중 단 2개만이 일상 리셋형이다. 투자/재벌 장르는 성공의 연속이 핵심이므로, 긴장-이완의 리듬보다 상승-상승의 리듬을 선호한다.

**5. "……!" 클리프행어는 정형화되어 있다.**
한국 웹소설에서 말줄임표+느낌표 조합("……!")은 놀라움의 클리프행어를 위한 사실상의 표준 문법이다. 다음 화 첫 줄은 반드시 그 놀람의 구체적 내용을 서술한다.

**6. 키워드 브릿지 기법**
가장 매끄러운 전환들은 동일 키워드가 양 화에 걸쳐 나타난다: "엔진 소리"(A-02), "정체"(B-19), "외환위기"(C-09), "75억 달러"(C-22) 등. 이를 "키워드 브릿지"라 명명할 수 있다.

## 4부: 글도비 AI 시스템을 위한 구현 제안

### 전환 패턴 선택 로직

```
IF 이전_화_마지막_장면 == 대화_도중 OR 행동_진행중:
    → 직접 연속형 (35% 기본 확률)
ELIF 이전_화_마지막 == 결심/계획/야망:
    → 의지-실행형 (높은 우선순위)
ELIF 이전_화_마지막 == "……!" 클리프행어:
    → 클리프행어 해소형 (필수)
ELIF 이전_화_마지막 == 뉴스/기사/속보:
    → 직접 반복형 (장르 특화)
ELIF 시간_경과_필요:
    → 시간 점프형 (명시적 시간 지표 포함)
ELIF 타인_반응_필요:
    → 시점 전환형
ELSE:
    → 시간 점프형 (기본값)
```

### 키워드 브릿지 규칙
