# gatekeeper_heir Domain Map

Title: 사람값이 보이는 후계자
Status: bootstrap domain map

## 1. Domain Core

- genre operating surface: 현대판타지 기업 경영 + 제조 현장 + 공급망/표준/금융 관문 전쟁
- opening battlefield: 후공정 검사 7공정, 고객 인증, 계열사 구조조정 직전 현장
- scaling path: 후공정 장비/검사 -> 소재/기판 -> 자동화/MES/제어 -> 물류/통관/보험 -> 전력/냉각/유틸리티 -> 금융/리스/팩토링 -> 표준/인증/해외 JV -> 지주/IR/지배구조

## 2. Required Domain Truth

- 고객 인증과 재심은 실제 공정, 결함, 검사 절차를 타야 한다.
- 소재와 기판 전쟁은 단순 원가 싸움이 아니라 오염, 납기, 듀얼소싱, 공동개발 구조를 보여줘야 한다.
- 자동화와 MES는 마법 버튼이 아니라 데이터 수집, 라인 보정, 현장 반발, 표준화 과정을 거쳐야 한다.
- 물류와 보험은 배달 문제가 아니라 통관 분류, 선적 규격, 보험 조건, 항만 실무가 있어야 한다.
- 전력과 냉각은 추상 인프라가 아니라 계약 전력, 냉각 설계, 설비 승인 병목으로 나타나야 한다.
- 금융은 리스, 팩토링, 서비스 계약이 고객과 계열사를 락인하는 구조로 보여야 한다.
- 지배구조 전쟁은 감정 싸움이 아니라 권한, 결재, 배치, 은퇴 명분, 이사회 언어로 전개돼야 한다.

## 4. Bottleneck Map

- 첫 병목: 후공정 검사 7공정의 미세균열과 잘못된 인력 배치
- 첫 죽은 자산: 세원정밀, X-ray 검사장비, 결함 라이브러리, 좌천 인력
- 첫 해결 인력: 윤태석, 민경호, 오서윤
- 첫 보상 구조: 세원정밀 6개월 지휘권, 인사 이동권 3명, 회장 직보권

## 5. Domain Guardrails

- 공신 세대의 존엄은 절대 손상시키지 않는다.
- 현장 절차가 비면 감정과 카리스마로 때우지 않는다.
- 제조/공급망/금융/표준의 병목은 각각 다른 언어와 테이블을 가져야 한다.
