## 2. Pitch Truth

- one-line premise:
  - 오너 일가에서 밀려 그룹 전략금융실 말석에 박힌 재벌 3세가, 각 부서가 따로 보고하는 보험·물류·원가 숫자를 한 줄의 손실선으로 먼저 읽고, 회사 안 권한과 시장 바깥 수익을 함께 쥔다.
- why now:
  - 도성그룹 배터리 계열사가 글로벌 공급망 재편기에 들어서며 보험·물류·원가 리스크가 동시다발로 쌓이고 있다. 각 부서는 자기 숫자만 보고하고 연쇄를 못 본다. 주인공은 전략금융실 말석에서 세 숫자를 동시에 보는 유일한 자리에 있으며, 이 자리에서 손실선을 먼저 읽는 감각으로 회사 안팎의 기회를 선점한다.
- theme statement:
  - 정보는 모두에게 공개돼 있지만, 연결을 먼저 읽는 사람이 판을 쥔다.
- protagonist position:
  - 도진우(28)는 도성그룹 지주사 전략금융실 대리다. 명목상 재벌 3세지만 오너 일가 내 정치에서 밀려 결재선 밖 말석에 박혀 있다. 만기표, 보험표, 자금 스케줄 정리만 떠안는 자리. 본가 식탁에서는 `숫자놀이 좋아하는 애`, 회사에서는 `리스크 표 만드는 도련님`으로 소비된다. 가진 것은 각 부서 보고서가 모이는 말석 자리, 그리고 개별 숫자를 하나의 손실선으로 묶어 읽는 감각뿐이다. 시세 예측 능력이 아니라, 자리의 정보 우위와 연결을 읽는 감각의 조합이다.
- long-term goal:
  - 도성그룹 리스크 위원회 의결권과 회장 직보 라인을 확보하고, 내부 손실 방어와 외부 공개 신호 기반 포지션을 동시에 운용해 회사 안팎에서 `이 사람의 설명을 먼저 들어야 한다`는 구조를 만든다.
- short-term goal:
  - 전략금융실 확대 리스크 회의에서 보험·스크랩률·슬롯 취소를 하나의 손실선으로 묶어 18일 뒤 배터리 계열사 마진 붕괴를 먼저 선언하고, 사촌 형의 낙관 보고를 뒤집어 리스크 회의 정식 배석권·대시보드 열람권·긴급 헤지 공동 서명권·회장 직보 주간 메모 라인을 얻는다.
- information gap:
  - 도진우만이 안다: 보험 갱신표, 클레임 준비금, 선적 지연, 고객사 실사 경보를 동시에 보면 개별 뉴스로는 보이지 않는 손실 연쇄(`보험 → 물류 → 원가 → 리콜 → 실적 쇼크`)가 보인다는 것. CFO도 보험표와 물류표를 따로 본다. 각 부서장도 자기 숫자만 들고 나간다. 도진우는 말석이라 세 숫자를 다 듣고 나갈 데가 없다 — 그래서 연결을 봤다.
- competence process:
  - 각 부서 보고서의 개별 숫자를 손실선 하나로 묶어 읽기 → 사촌 형의 낙관 보고를 회의실에서 뒤집기 → 손실 방어안(헤지·선매입·실사 대응)을 먼저 올리기 → 공개 성과(손실 회피 실적)로 증명 → 배석권·서명권·열람권·직보 라인·위원회 의결석 회수.
- core engine:
  - 각 부서가 따로 들고 있는 숫자를 한 줄의 손실선으로 묶어 읽고, 내부에서는 손실 방어와 권한 회수로, 외부에서는 공개 신호 기반 포지션으로 환전하는 dual-lane 투자물 엔진. 내부표로 외부 포지션을 잡는 구조는 금지다.
- dual-lane separation:
  - 내부 레인: 회사 안 데이터(보험 갱신표, 클레임 준비금, 선적 보고, 실사 공문)는 회사 안 손실 방어와 권한 회수에만 쓴다.
  - 외부 레인: 회사 밖 포지션은 공개 신호(공개 보험시장 지표, 공개 해운 지표, 공개 공급망 뉴스, 공개 섹터 연쇄)만으로 설계한다.
  - 두 레인은 같은 현상을 다루지만 근거 데이터 출처가 반드시 분리된다.
- major materials:
  - 보험 (해상보험 갱신률, 클레임 준비금, 로이즈 인덱스, 공개 손해율 통계)
  - 물류 (선적 지연, 중국 항만 슬롯 취소율, 공개 해운 지표)
  - 원가 (분리막 스크랩률, 배터리 원자재, 공급망 병목)
  - 실사 (고객사 긴급 실사, 원가 연쇄 방어)
  - 리스크 회의 (배석권, 서명권, 열람권, 의결권)
  - 포지션 (공개 섹터 연쇄, 환헤지, 롱/숏 — 공개 신호 기반만)
- repeatable loop:
  - 각 부서 보고서에서 개별 이상 신호 감지 → 손실선 하나로 묶기 → 회의실에서 사촌 형/기존 보고의 낙관을 뒤집기 → 내부 손실 방어안 실행 + 공개 신호 기반 외부 포지션 설계 → 손실 회피·수익 실현 증명 → 평가 수정 → 권한(배석권/서명권/열람권/의결권) 회수 → 다음 위기 읽기 입장권 확보.
- promise to reader:
  - 오너 일가에서 밀려 리스크 표만 만들던 재벌 3세가, 남들이 각자 숫자를 들고 나갈 때 나갈 데가 없어서 연결을 봤고, 그 연결로 손실선을 먼저 읽어 회사 안 권한과 시장 바깥 수익을 함께 독식하는 dual-lane 투자물. 시세 예측이 아니라 연결을 읽는 감각이 무기다.
- contamination guard:
  - 내부 데이터를 근거로 외부 포지션을 잡는 장면은 절대 불가 (insider-trading 구조 금지)
  - 내부 레인과 외부 레인의 데이터 출처를 섞지 않는다 (dual-lane 혼선 금지)
  - 자산 수치를 reward 첫 문장에 놓지 않는다 (asset-first reward narration 금지)
  - `평가 수정 → 권한 → 자본` 순서를 절대 뒤집지 않는다
  - 퇴사 판타지 오프닝 금지
  - 자기연민, 자기반성, 회개 서사 금지
  - 특정 종목, 특정 회사, 특정 수치 복제 금지
  - exact app or cheat UI 금지
  - 순수 퇴사물·자산자랑물·회개물로 둔갑시키지 않는다
  - 사촌 형(도현석)을 무능/탐욕 캐리커처로 만들지 않는다 — 세 숫자를 따로 봤기 때문에 연결을 못 본 사람이다
  - 적대자는 이전 시대의 정답을 믿은 사람들이다

## 3. Early Conversion

- trigger set A:
  - 분리막 스크랩률 상승
  - 해상보험 갱신률 급등
  - 중국 항만 슬롯 취소율 증가
- opening spike:
  - 1화: 월요일 전략금융실 확대 리스크 회의. 보험 담당 임원이 해상보험 인상률을, 구매실장이 분리막 스크랩률을, 생산관리 상무가 중국 항만 슬롯 취소율을 보고한다. 사촌 형 도현석이 `배터리 라인은 가동률 유지 중이고 마진 리스크는 관리 범위입니다`라고 정리한다. 회의실이 고개를 끄덕이는 순간, 도진우가 trigger set A 숫자 세 개를 한 장 표로 묶어 `사촌 형이 말한 관리 범위는 18일 뒤에 무너집니다`라고 선을 긋는다. 사촌 형이 반박하려다 숫자를 다시 보고 입을 다문다.
- episodes 1 to 3 impact:
  - 1화: trigger set A 숫자 세 개를 묶어 손실선을 먼저 그음 → 사촌 형의 낙관 보고가 침묵으로 철회됨 → CFO `이건 보고가 아니라 손실선을 먼저 그린 거네` → 회장 `이번 건은 네 선에서 먼저 잡아`.
  - 2화: 18일 카운트다운 시작. 도진우가 긴급 헤지안과 원재료 선매입안을 올린다. 사촌 형이 뒤늦게 자기 보고를 수정하려 하지만 이미 회장 직보 메모 라인에 도진우의 이름이 먼저 올라가 있다.
  - 3화: 배터리 계열사 마진이 실제로 꺾인다. 도진우의 선매입안 덕에 분기 손실이 묶인다. 리스크 회의 정식 배석권, 보험 대시보드 열람권, 긴급 헤지 공동 서명권이 붙는다. `리스크 표 만드는 도련님`이 `손실선을 먼저 읽는 놈`으로 평가가 바뀌는 첫 영수증.
- first block problem:
  - 사촌 형 도현석의 낙관 보고가 그룹 의사결정의 기본값이다. 도진우가 손실선을 증명하지 못하면 18일 뒤 배터리 계열사 마진이 무너지고, 도진우는 리스크 표만 만드는 말석 도련님으로 영원히 굳는다.
- first block reward:
  - 순서는 절대다. `평가 수정 → 권한 → 자본.`
    - 평가 수정: `리스크 표 만드는 도련님` → `손실선을 먼저 읽는 놈`
    - 권한: 리스크 회의 정식 배석권, 보험 갱신안·클레임 준비금 대시보드 열람권, 긴급 헤지 실행 공동 서명권, 회장 직보 주간 메모 라인
    - 자본(하위): 전략금융실 산하 파일럿 운용금 50억
  - 핵심: 첫 보상은 돈이 아니라 `이제는 네 설명을 먼저 듣는다`는 평가 전환과 접근 권한이다.
- early antagonist shape:
  - 사촌 형 도현석: 도성그룹 전략기획실 과장. 도진우보다 한 직급 위이며 그룹 내 발언권이 강하다. 무능한 것이 아니라 세 숫자를 따로 봤기 때문에 연결을 못 본 사람이다. 도진우의 손실선이 증명된 뒤 경계 모드로 전환한다.
  - CFO 강태호: 보험표와 물류표를 따로 보는 사람. 도진우의 연결을 인정하면 자기 기존 보고 체계가 흔들리므로 처음에는 견제하지만, 숫자 앞에서 계산을 바꾼다.
  - 보험 담당 임원 임재훈: 갱신안을 올렸는데 도진우에게 공개 데이터로 오류를 찍힌다. 자존심은 상하지만 숫자가 맞으니 입을 다문다.
- proof scene:
  - 사촌 형이 `관리 범위입니다`라고 올린 숫자 세 개를 도진우가 한 장 표로 뒤집어, 18일 뒤 손실선을 먼저 그은 장면. 회의실 전체의 도진우 해석이 `리스크 표 만드는 도련님`에서 `손실선을 먼저 읽는 놈`으로 이동하는 바로 그 장면이다.
