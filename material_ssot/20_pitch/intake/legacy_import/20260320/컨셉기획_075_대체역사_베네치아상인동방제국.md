# 컨셉 기획안 — 베네치아 상인의 동방 제국

> 작성일: 2026-03-20
> 장르: 대체역사 · 해양상업 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-WLD-05

## 1. 로그라인

**2025년 부산 해운회사 대리 최민재가 1200년 베네치아 공화국의 10대 상인 가문 서자로 빙의한다. 제4차 십자군 전쟁 직전 — 지중해 무역의 패권이 결정되는 순간, 현대 물류·금융 지식으로 베네치아를 세계 최초의 해상 제국으로 만드는 상업 대체역사.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 부산 감만부두 사무실.
 → 최민재 대리. 한진해운 후속사의 물류 관리. 야근 중 과로로 쓰러진다.
 → "컨테이너 327번 트래킹 업데이트해… 아, 잠깐만…"
 → 의식이 사라진다.

1화: 1200년, 베네치아 리알토 다리.
 → 눈을 뜬다. 운하의 냄새. 나무 다리(아직 돌다리가 아닌).
 → 거울에 비친 얼굴 — 서양인. 갈색 머리. 10대 후반.
 → "마르코! 아버지가 부르신다. 향신료 선적 확인해야 한다고!"
 → 마르코 — 베네치아 무역 가문 콘타리니의 서자.
 → 최민재는 안다: 1200년, 제4차 십자군이 콘스탄티노플을 약탈하기
   4년 전. 이 사건으로 베네치아는 지중해 패권을 잡는다.
 → 그리고 최민재에게는 800년 후의 물류·금융·보험 지식이 있다.
 → 1화 마지막 줄: "이 운하 하나로 세계를 지배할 수 있어."
```

**후킹 구조**: 부산 해운 대리(친숙) → 베네치아 서자(반전) → 십자군(역사적 스케일) → 세계 지배(야심). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **빙의 방식** | 의식 전이. 2025→1200, 825년 역행. 베네치아 상인 가문 서자에 빙의 |
| **기억 유지** | 현대 물류·해운·금융·보험 지식 완전 보존. 중세 유럽사 세부는 점진적으로 흐려짐 |
| **빙의 제약** | 서자 신분의 사회적 제약. 현대 금융 시스템은 중세 인프라에서 구현 불가 |
| **빙의 증거** | 현대 상업 용어, 복식부기(아직 발명 안 됨) 사용 실수, 미래 사건 예언 |
