# 컨셉 기획안 — 방산물 B: 「대한민국 최초의 무기 딜러」

> 장르: 현대판타지 · 방산물 · 능력물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)

---

## 1. 로그라인

**군 장비의 성능 데이터가 숫자로 보이는 능력을 가진 前 육군 정비병이, 중고 군용 장비 브로커에서 시작해 글로벌 방산 수출 기업을 세운다. 단, 그가 파는 무기가 전쟁에 쓰일 때마다 능력이 보여주는 건 — 사상자 수.**

## 2. 1화 후킹

> _경기도 포천, 폐기 대기 중인 K-9 자주포 앞. 전역한 지 3개월, 통장 잔고 47만 원. 그런데 눈앞의 고철 위에 숫자가 떠올랐다. 「잔존 수명: 12,400시간 / 정비 후 성능: 원래 대비 94% / 예상 수출가: 85억 원」_
> → "이거… 팔 수 있잖아?"

## 3. 세계관 & 장르 설정

| 항목            | 설정                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **판타지 능력** | 군사 장비를 보면 성능·수명·가격이 숫자로 보임. 단, **그 장비가 실전 투입되면 사상자 수도 보임** (moral_dilemma 자연 유발) |
| **능력 제약**   | 민간 장비에는 작동 안 함. 군용으로 만들어진 것에만 반응                                                                   |
| **초기 자본**   | 47만 원 → 중고 군장비 매매 → 정비 후 수출 → 독자 개발                                                                     |
| **기업 배경**   | 1인 브로커 → 주식회사 아이언힐 (방산 스타트업)                                                                            |
