# 컨셉 기획안 — 고려 상인이 실크로드를 정복하다

> 작성일: 2026-03-20
> 장르: 대체역사 · 상업/경제물 · 해양모험
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-KOR-07 (BATCH 07)

---

## 1. 로그라인

**2026년, 삼성물산 해외영업 팀장 윤태호(37세)가 고려 충렬왕 시대(1280년대) 개경 상인 '윤보(尹寶)'로 빙의한다. 고려 — 세계 유일의 '코리아' 이름의 원조이자, 아라비아 상인들이 드나들던 국제 무역국. 그러나 원나라의 간섭기, 고려는 속국이나 다름없다. 윤보는 원의 교역 네트워크를 역이용해, 개경에서 벽란도, 벽란도에서 대도(북경), 대도에서 사마르칸트, 사마르칸트에서 바그다드까지 — 실크로드를 잇는 고려 상단을 세운다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2026년, 삼성물산 서울 본사.
 → 윤태호 팀장. 중앙아시아 프로젝트 수주 건 해외 출장 준비.
 → "고려가 '코리아'의 어원이라는 거, 아라비아 상인들이 불렀대."
 → 고려청자 레플리카를 만지다 쓰러진다.

1화: 1281년(충렬왕 7년), 개경 시전거리.
 → 눈을 뜬다. 비단 두루마기. 개경의 번잡한 시장.
 → 아비(아버지)가 말한다: "보야, 벽란도에서 아라비아 상선이 들어온다 하더라."
 → 태호(윤보)는 안다: 지금이 원 간섭기이고, 고려는 원의 부마국이라는 걸.
 → 그리고 안다: 이 시대 원나라가 세계 최대 교역 네트워크를 가지고 있다는 걸.
 → 원의 속국이라는 약점이, 실크로드 접근이라는 기회가 된다.
 → 1화 마지막 줄: "아비, 벽란도가 아니라… 더 먼 곳까지 가보고 싶습니다."
```

**후킹 구조**: 현대 무역맨(전문성) → 원 간섭기 고려(역사적 아이러니) → 실크로드 접근 기회(반전) → 세계를 향한 선언(포부). 4단 임팩트.

1. **고려 = 코리아의 원조** — 세계에 이름을 알린 나라의 로맨스
