# 컨셉 기획안 051 — 건축수선전(建築修仙傳)

> 작성일: 2026-03-20
> 코드: MAR-FUS-01
> 장르: 무협 · 선협/수선/퓨전
> 플랫폼 타겟: 문피아 (1순위)
> 핵심 공식: ~수선전 네이밍 + "너무 쉽다" + 현대 시스템 융합

---

## 1. 로그라인

**현대 건축학과 졸업생 노건우가 선협 세계로 전이하여, 건물을 설계하고 건축할수록 수선 경지가 오르는 '건도(建道)' 체질을 각성한다. 기초를 다지면 단전이 열리고, 기둥을 세우면 경맥이 뚫리며, 지붕을 올리면 경지가 돌파된다 — 선계에서 가장 쉬운 수선은 집을 짓는 것이었다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 현대, 건축학과 졸업 후 취업 실패.
 → 노건우(27세), 100번째 불합격 통보를 받고 한강 다리 위에 선다.
 → "4년 동안 배운 게 이 세상에선 쓸모없다는 거냐…"
 → 다리 난간에 기대는 순간, 발밑의 강이 빛난다.
 → 의식이 암전.

1화: 천무대륙(天武大陸), 이름 없는 산골 폐촌.
 → 눈을 뜬다. 몸은 막 쫓겨난 종파의 잡역 소년 '노건(勞建)'.
 → 머릿속에 현대 건축학 지식이 고스란히 남아 있다.
 → 폐촌의 무너진 토담집을 보며 "기초부터 다시 해야 하는데…"라고 중얼거린다.
 → 흙을 다지고 기초를 놓는 순간, 단전에서 뜨거운 기운이 솟구친다.
 → 머릿속에 투명한 창이 뜬다: [건도 경지: 연기 1층 — 기초공사 완료]
 → 1화 마지막 줄: "…집을 지으면 경지가 오른다고?"
```

**후킹 구조**: 현실 좌절(공감) → 전이(반전) → 건축=수선 경지 상승(호기심) → 시스템 창(장르 시그널). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **전이 방식** | 현대→천무대륙 의식 전이. 원래 몸의 주인 '노건'은 종파에서 쫓겨난 직후 사망, 빈 몸에 의식 이입 |
| **건도(建道) 체질** | 건물을 설계·시공할수록 천지영기를 자연 흡수하여 수선 경지가 상승하는 유일무이한 도(道) |
| **건축 시스템** | 머릿속에 현대식 '건축 시스템 인터페이스'가 구현됨 — 설계도, 구조 계산, 재료 분석, 경지 게이지 표시 |
| **건축→경지 전환 법칙** | 기초공사=단전 개방, 골조=경맥 확장, 마감=경지 안정화, 진법 각인=경지 돌파 |
| **제약** | ① 같은 유형의 건물 반복 시 경지 상승률 급감 ② 건물이 파괴되면 해당 경지의 기반이 흔들림 ③ 대형 건축물일수록 영기 소모가 커서 재료에 영석(靈石) 필요 |
| **현대 지식 활용** | 구조역학, 재료공학, 도시설계 등 현대 건축 지식이 선계에서 파격적 효율을 냄 — "너무 쉽다" 요소 |

### 3.2 배경 타임라인 (천무대륙 역사 활용)

| 시기 | 선계 사건 | 작중 활용 |
|------|-----------|-----------|
| 전이 직후 | 폐촌 발견 | **1화 기폭제** — 첫 건축으로 연기 경지 각성 |
| 1~2년차 | 청풍종 하산 파벌 추방사건 | 추방된 제자들을 위한 거점 건설 → 세력 형성 |
| 3~4년차 | 마도 부활의 징조 | 방어 성채 건축 수요 폭발 → 명성 확대 |
| 5~6년차 | 선마대전(仙魔大戰) 조짐 | 각 종파에 방어 진법 건축 납품 → 정파 핵심 인물로 부상 |
| 7~8년차 | 고대 선인 유적 발견 | 고대 건축술과 현대 건축학 융합 → 원신(元神) 돌파 |
| 9~10년차 | 선마대전 본격 발발 | 전장 요새 건축 → 전쟁의 향방을 바꿈 |
| 11~12년차 | 선계-마계 경계 붕괴 위기 | 차원 봉인 건축물 "천관(天關)" 건설 → 최종 프로젝트 |
| 13~14년차 | 승천(昇天) 기회 | 선계의 문(仙門)을 직접 건축하여 등선 — 최종 경지 |

### 3.3 주인공 그룹 (건도문 · 建道門)

| 항목 | 설명 |
|------|------|
| **문파명** | 건도문(建道門) — 주인공이 직접 창설 |
| **초기 상태** | 폐촌 하나, 구성원 0명 |
| **주력** | 건축 수선, 진법 각인, 영재(靈材) 가공 |
| **최종 규모** | 정파 6대 종파급 — 건축 의뢰로 모든 종파와 연결된 허브 조직 |
| **수입원** | 종파/세가의 건축 의뢰, 진법 건축 라이선싱, 영재 거래 |

## 6. 경지 성장 곡선 설계

### 6.1 핵심 규칙
- 초기 경지: **무(無)** — 영근(靈根)조차 없는 잡역 소년
- 최종 목표: **대승선인(大乘仙人)** — 등선(登仙) 직전 경지
- **최소 7블록에서 경지 정체 또는 역행** 필수
- 경지 상승은 건축물 완공과 연동: 더 크고, 더 복잡하고, 더 혁신적인 건축이 필요
- 같은 유형 건축 반복 시 경지 상승 급감 (다양한 건축 강제)

### 6.2 경지 체계

```
연기(鍊氣) → 축기(築基) → 금단(金丹) → 원영(元嬰) → 화신(化神) →
연허(鍊虛) → 합체(合體) → 도겁(渡劫) → 대승(大乘) → 등선(登仙)
※ 각 경지 3단계(초기/중기/후기)
```

### 6.3 경지 곡선 개요 (70블록)

```
대단원 1 (Block 1~10): 개안기 — "집을 지으면 강해진다"
  시작: 무(無) → 종료: 축기 후기
  건축: 토담집→석조가옥→마을 전체→소형 수련동→방어벽
  패턴: 기초 건축으로 빠른 경지 상승 → "너무 쉽다" 체감
  패배 블록: Block 4 (첫 건축물 파괴 → 경지 역행)
            Block 8 (천공각의 재료 차단 → 건축 불가 → 경지 정체)

대단원 2 (Block 11~20): 정립기 — "건축이 곧 도(道)다"
  시작: 축기 후기 → 종료: 금단 후기
  건축: 종파 본산→수련탑→연단각→진법 성채
  패턴: 건도문 창설 + 의뢰 건축 시작 → 안정적 성장
  패배 블록: Block 14 (의뢰 건축물 붕괴 사고 → 명성 추락 + 경지 불안정)

대단원 3 (Block 21~30): 도약기 — "대륙이 나를 부른다"
  시작: 금단 후기 → 종료: 화신 초기
  건축: 도시 방어 성벽→공중 부교→영맥 정화탑→선계 등대
  패턴: 대형 건축 프로젝트 → 경지 대폭 상승 + 명성 확대
  패배 블록: Block 26 (마기 침식된 재료 사용 → 건축물 폭주 → 화신 돌파 실패)

대단원 4 (Block 31~40): 시련기 — "파괴는 건축보다 쉽다"
  시작: 화신 초기 → 종료: 화신 후기 (정체 대단원)
  건축: 전장 요새→지하 피난처→이동식 진법 전차
  패턴: 마도 침공으로 건축물 연쇄 파괴 → 경지 기반 흔들림
  패배 블록: Block 33 (본산 습격 → 건도문 본전 반파), Block 37 (핵심 건축물 3개 동시 파괴 → 경지 역행)

대단원 5 (Block 41~50): 재건기 — "무너진 것을 다시 세운다"
  시작: 화신 후기 → 종료: 합체 초기
```
