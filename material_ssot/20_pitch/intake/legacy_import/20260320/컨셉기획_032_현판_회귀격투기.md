# 컨셉 기획안 032 — 회귀 격투기: 은퇴한 파이터의 두 번째 라운드

> 작성일: 2026-03-20
> 장르: 현대판타지 · 스포츠 · 격투기 · 회귀물

---

## 1. 로그라인

**UFC 미들급 챔피언에 도전했으나 판정패 후 부상으로 은퇴한 격투기 선수 오정훈(38). 체육관 사장으로 근근이 살던 어느 날, 심장마비로 쓰러진 후 20살의 자신으로 회귀한다. 18년 치 경험과 기술, 미래의 기억을 가진 20대의 몸 — 이번엔 반드시 UFC 챔피언 벨트를 건다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 2044년, 서울 외곽 소규모 MMA 체육관.
 → 오정훈(38), 관원생 셋에게 기초 기술을 가르치고 있다.
 → TV에서 UFC 미들급 타이틀전 중계. 후배 선수가 챔피언에 도전.
 → 관원생: "관장님도 UFC 나가셨죠?" 정훈: "...오래전 얘기야."
 → 밤, 빈 체육관에서 샌드백을 친다. 왼쪽 무릎이 삐걱.
 → 허리를 짚는다. 목, 어깨, 손목 — 전부 망가진 몸.
 → "한 번만 더... 20대 때로 돌아갈 수 있다면."
 → 가슴을 쥔다. 심장마비. 쓰러진다.

1화: 2026년 3월, 서울 모 대학 레슬링부 숙소.
 → 눈을 뜬다. 거울 속에 20살의 얼굴.
 → 몸이 가볍다. 무릎이 안 아프다. 목이 돌아간다.
 → 휴대폰 날짜: 2026년 3월 15일.
 → 정훈은 안다: 올해 레슬링에서 MMA로 전향하고,
   2년 뒤 첫 아마추어 대회, 5년 뒤 프로 데뷔,
   12년 뒤 UFC 타이틀전 — 그리고 패배.
 → 체육관으로 뛰어간다. 샌드백 앞에 선다.
 → 20살의 몸에 38살의 기술을 실어 왼쪽 훅을 날린다.
 → 샌드백이 천장 고리째 흔들린다.
 → 1화 마지막 줄: "이번엔 진다는 선택지가 없다."
```

**후킹 구조**: 은퇴한 파이터의 아픔(공감) → 심장마비(위기) → 20대로 회귀(반전) → 18년 경험+20대 몸의 첫 펀치(쾌감). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **회귀 방식** | 심장마비 후 의식 전이. 2044→2026으로 18년 역행 |
| **기억 유지** | 미래 기억 완전 보존. 18년 치 격투 기술·전술·상대 분석 모두 보유 |
| **회귀 제약** | ① 기술 기억은 있으나 20대 몸에 재적응 필요(근육 기억 재구축) ② 미래를 바꿀수록 대전 상대·대회 일정 등 기억과 현실 괴리 ③ 25블록 이후 세부 기억 퇴색 시작 |
| **회귀 증거** | regression_hint — 전생에서 맞았던 기술이 데자뷔로 발현. slip_up은 "아직 배우지 않은 기술을 쓰는 실수" |

## 5. 적대자 변천사 (3세력+)

### Phase 1 (대단원 1~2): 국내 격투기 기득권

| 항목 | 설명 |
|------|------|
| **적대자** | 체육회 최영수 + 레슬링 국가대표팀 감독 + 국내 MMA 프로모터(불공정 매칭) |
| **목표** | 정훈의 MMA 전향 방해. "레슬링 국대 유망주가 싸움판으로?" 압박 |
| **방법** | 레슬링 국가대표 선발전 출전 강요, MMA 체육관 신고 방해, 불리한 심판 판정 |
| **약점** | 정훈이 아마추어 대회에서 압도적 성적을 내면 막을 수 없음 |
| **퇴장** | Block 18에서 국내 프로 5연속 KO승 후 체육회 입장 변화 |

### Phase 2 (대단원 3~4): 해외 MMA 장벽 + 인종 편견

| 항목 | 설명 |
|------|------|
| **적대자** | 호르헤 에르난데스(ONE 챔피언) + 미국 훈련캠프 내부 경쟁 + UFC 매치메이커(불리한 매칭) |
| **목표** | 아시안 파이터의 상위 랭킹 진입 차단. "아시안은 타격이 약하다" 편견 |
| **방법** | 스파링에서 과도한 가격, 불리한 대전 카드 배정, 미디어 무시 |
| **약점** | 옥타곤 안에서 KO로 증명하면 뒤집힘 |
| **전환** | Block 35에서 UFC 메인카드 발탁, Block 40에서 타이틀 도전권 획득 |

### Phase 3 (대단원 5~7): UFC 정상 + 전생의 적

| 항목 | 설명 |
|------|------|
| **적대자** | 빅터 안토노프(전생 챔피언/최종 보스) + UFC 정치(챔피언 보호 매칭) + 도핑 의혹 |
| **목표** | 안토노프 — 타이틀 방어. UFC — 흥행 카드 조절. 도핑 세력 — 정훈의 급성장 의심 |

| **최종** | Block 67~70 UFC 미들급 타이틀전 5라운드 풀매치 |

- 초기 지표: **대학 레슬링 선수** (전적 0승 0패, 세계 랭킹 없음, 연봉 0원)
- 최종 목표: **UFC 미들급 챔피언** (전적 30승+, 파운드 포 파운드 Top 3, 파이트 머니 $5M+)
