## 1. 로그라인

**탑 내부 층간 물자와 편지를 배달하는 F급 비전투 우체부 헌터가, 배달할수록 각 층의 비밀 정보가 축적되는 '정보 시스템'을 각성한다. 모든 층의 비밀을 아는 남자 — 정보가 무기고, 배달이 성장이다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 탑 3층, 레이드 파티.
 → 주인공 안지훈(27), F급 헌터. 탑 내부 물류 배달원.
 → 레이드 파티가 지나간다. 지훈은 길 옆에서 배달 상자를 나른다.
 → S급 헌터: "야, 길 비켜. 배달부."
 → 지훈이 묵묵히 비킨다. 하루 배달량 50건.
 → "탑에서 가장 쓸모없는 직업이 뭔지 알아? 우체부야."

1화: 탑 1층→5층 배달 중.
 → 지훈이 3층 길드 거점에 소포를 배달한다.
 → 배달 완료 순간, 머릿속에 정보가 흘러든다.
 → [정보 시스템 활성화]
 → [배달 완료: 3층 '블레이드' 길드 거점]
 → [정보 획득: 길드원 15명, 보스 공략 진행도 43%, 내부 불화: 길드장 vs 부장]
 → [정보 등급: D급]
 → 지훈이 멈춘다. "…뭐야 이건?"
 → 4층 개인 헌터에게 편지를 배달한다.
 → [정보 획득: A급 헌터 '이강윤', 비밀: 5층 보스 약점을 알지만 숨기고 있음]
 → 지훈의 머릿속에 탑의 비밀이 쌓이기 시작한다.
 → 1화 마지막 줄: "…이 정보, 팔면 얼마지?"
```

**후킹 구조**: 최하급 배달부(좌절) → 정보 시스템 각성(반전) → 층별 비밀 축적(스릴) → "팔면 얼마?"(경제 기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **정보 시스템** | 배달 완료 시 해당 위치·인물의 비밀 정보 자동 축적. 배달 횟수 비례 정보 정밀도 상승 |
| **성장 축** | 정보 데이터베이스 규모 + 정보 정밀도(D→SSS) + 정보 네트워크(협력자 수) |
| **정보 등급** | 배달 1회=D급 정보, 10회=C급, 50회=B급, 200회=A급, 1000회=S급, 5000회=SSS급 |
| **제약** | ① F급 전투력(영구) ② 배달 완료해야만 정보 획득(우편 안 열어봄으로 직접 확인 불가) ③ 정보 판매 시 출처 노출 위험 ④ 1일 배달 한도(체력 제한) |
| **정보 거래** | 정보 = 탑 내 화폐. 길드·헌터·정부에 정보 판매로 수익 |
