# 컨셉기획 088 — 우주무협

- **코드**: XGN-EXP-08
- **장르**: 크로스장르 (무협 + SF)
- **타겟 플랫폼**: 문피아 / 카카오페이지 양면
- **BATCH**: 09 크로스장르 블루오션 실험

---

## 1. 로그라인

**2077년, 지구의 마지막 무림인이었던 주인공이 우주 정거장 '천관(天關)'에서 눈을 뜬다. 무중력 환경에서 내공 수련법을 재구축하고, 진공의 검법과 무중력 경공을 창시하며, 은하 곳곳의 세력 다툼 속에서 '우주무림'을 개창해 나가는 SF 무협 서사.**

## 2. 1화 후킹 시퀀스

```
[시퀀스 1] 지구 최후의 밤 — 2077년, 환경 붕괴로 멸망 직전의 지구.
           마지막 무림인 '엽무한'이 쿤룬산 동굴에서 홀로 수련 중,
           UN 우주이민선의 강제 탑승 명령을 받는다.
           "지구에 남으면 죽습니다." "죽어도 무림을 지킨다."
           — 그러나 동굴이 붕괴하며 기절.

[시퀀스 2] 우주의 첫 호흡 — 눈을 뜨니 우주 정거장 '천관' 의료실.
           중력 0.3G. 몸이 붕 뜬다. 내공을 운기하자 기(氣)가
           무중력에서 사방으로 흩어진다.
           "내공이… 모이지 않는다?"

[시퀀스 3] 무중력의 주먹 — 정거장 치안대원이 '원시인 깨어났다'며
           조롱. 주인공이 반사적으로 주먹을 날리지만, 무중력에서
           반동으로 자기가 날아간다. 웃음거리가 된다.

[시퀀스 4] 첫 번째 깨달음 — 의료실에 홀로 남은 주인공.
           무중력에서 떠다니는 물방울을 보며 깨닫는다.
           "기(氣)도 물과 같다면… 흩어지는 것이 아니라 사방으로 퍼지는 것이다."
           물방울을 손끝의 기로 조종. 공중에서 구체로 만든다.
           "무중력 내공… 이것이 새로운 무(武)의 시작이다."
```

**후킹 구조**: 멸망(지구 상실) → 이질 환경(무협인의 우주 부적응) → 굴욕(먼치킨 불가 선언) → 즉각 돌파(새로운 무공 체계 착상). 1화 안에 '익숙한 무협이 전혀 새로운 공간에서 리부트된다'는 핵심 매력 확정.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 요소 | 설명 |
|------|------|
| 내공/기(氣) | 실재하는 에너지. 지구에서는 중력장과 결합해 체내 순환. 우주에서는 새로운 순환법 필요 |
| 무중력 무공 | 기존 무공을 0G~저G 환경에 맞게 재창조. 경공 → 무중력 비행, 장풍 → 진공파 등 |
| 기공 과학 융합 | 내공의 정체가 SF적으로 '암흑에너지 조작 능력'으로 재해석됨 (중반 이후 밝혀짐) |
| 무림 시스템 | 우주 각 구역(정거장·행성·함선)마다 문파 형성. 무공 유파가 환경에 따라 분화 |

### 3.2 배경 타임라인

| 시기 | 설정 |
|------|------|
| 2077년 | 지구 환경 붕괴. 인류 우주 이민 시작. 주인공 강제 이송 |
| 2077~2082년 (작중) | 우주 정거장 '천관' → 화성 → 목성 궤도 → 외행성계로 확장 |
| 우주 정치 구도 | 3대 세력: UN우주연합(관료), 기업연합체(재벌), 프리 콜로니(해적/자유민) |
| 무림 부재 | 지구에서 무림은 이미 소멸. 주인공이 유일한 계승자 |
| 종료 시점 | '우주무림' 개창. 은하 전역에 무공 수련자 탄생. 새로운 강호(江湖) 형성 |

| 지표 | 등급 체계 | 설명 |
|------|-----------|------|
| 무공 경지 | 후천 → 선천 → 화경 → 현경 → 탈태환골 → 우주경(창시) | 전통 경지 + 우주 환경 특화 최종 경지 |

## 11. 세계관 전용 설정 (SF + 무협 융합)

| 항목 | 설정 |
|------|------|
| 내공 × 우주 | 내공(기)은 암흑에너지 조작 능력. 중력장 영향을 받아 지구에서는 체내 순환, 우주에서는 확산형 순환 |
| 무중력 경공 | '허공답보' — 기를 분사하여 3차원 자유 이동. 지구 경공의 우주 버전 |

| 중력별 무공 분화 | 화성(0.38G) = 유연한 권법, 목성 정거장(가변G) = 적응형 무공, 소행성(미중력) = 순수 기공 |
| 내공 전송 | 기를 전자파처럼 원거리 전송하는 기술 (후반 개발). 은하 규모 무공 네트워크의 기초 |

## 13. 킬링포인트 요약

1. **무중력 무공의 신선함** — 기존 무협의 모든 초식이 우주에서 리부트. 경공이 비행이 되고, 장풍이 진공파가 되는 쾌감
2. **SF × 무협 본격 융합** — 내공 = 암흑에너지라는 설정이 중반에 폭로되며 두 장르가 완전 결합. "무림인이 우주에서 가장 강한 종족"
3. **구도자의 서사** — 먼치킨이 아닌 '재적응'. 지구 최강이었던 주인공이 우주에서 맨바닥부터 다시 시작하는 성장 쾌감
4. **우주무림 개창** — 혼자의 무공에서 문파 → 유파 → 무림으로 확장. 강호(江湖)가 은하가 되는 스케일
5. **지구 상실의 감정** — 멸망한 고향, 사라진 무림. 노스탤지어와 새 시대 개척의 이중 감정이 작품 전체를 관통
