## 1. 로그라인

**39세, 퇴직금 전액을 투자한 치킨 프랜차이즈가 3개월 만에 폐업하고 빚 1억 5천만 원에 이혼 위기까지 몰린 남자. 마지막으로 딸에게 튀겨준 치킨이 10년 묵은 만성 아토피를 하룻밤에 고쳐버렸다. 손끝에 깃든 기적의 요리 — 먹은 사람의 병이 낫는다. 치킨집 폐업 사장에서 미슐랭 셰프, 프랜차이즈 제국, 글로벌 F&B 재벌까지. 자영업자의 역전 서사가 시작된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 폐업 당일 밤, 간판 내린 치킨집.
 → 주인공 백도현(39), 빈 매장에 앉아 마지막 치킨을 튀긴다.
 → 아내에게서 온 문자: "이번 달 안에 안 갚으면 진짜 끝이야."
 → 통장 잔고 -1억 5천만. 신용불량 D등급.
 → 딸 백수아(9)가 매장으로 뛰어 들어온다.
   "아빠, 나 배고파. 아빠 치킨 먹고 싶어."
 → 도현이 딸에게 마지막 치킨을 건넨다. 팔뚝에 빼곡한 아토피 각질.
 → 수아가 치킨을 한 입 베어 물고 눈이 커진다. "아빠, 이거 왜 이렇게 맛있어..."
 → 다음 날 아침.
 → 수아의 팔뚝이 매끈하다. 10년 묵은 만성 아토피가 사라졌다.
 → 아내 정윤서가 수아의 피부를 만지며 경악한다.
 → 도현이 자기 손을 내려다본다. 손바닥에 미세한 온기가 남아 있다.
 → 1화 마지막 줄: "이 손으로 한 번만 더 튀겨보자."
```

**후킹 구조**: 폐업(절망) → 딸의 등장(감정) → 치킨 한 조각(기적) → 아토피 완치(충격 반전) → 재기 의지(희망). 5단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소 — 치유 요리 규칙

| 항목 | 설정 |
|------|------|
| **발동 조건** | 주인공이 직접 재료 손질부터 플레이팅까지 전 과정을 조리해야 발동. 타인이 중간 과정에 개입하면 치유력 상실 |
| **재료 법칙** | 재료의 신선도와 품질이 치유력에 정비례. 산지 직송 유기농 > 일반 마트 > 냉동. 최상급 재료일수록 난치병 치유 가능 |
| **성장 단계** | 초기: 피부병/감기/소화불량 → 중기: 당뇨/고혈압/만성통증 → 후기: 암/난치성 자가면역질환/장기부전 |
| **반복 제약** | 같은 사람에게 같은 메뉴는 효과 50% 반감 (2회째), 75% 반감 (3회째), 4회째 효과 소멸. 메뉴 다양화 강제 |
| **체력 소모** | 치유 요리 후 주인공에게 피로·탈진 발생. 고난도 치유일수록 심함. 과사용 시 머리카락 백화, 시력 저하, 수명 단축 암시 |
| **치유 증거** | 치유 대상의 혈색 변화, 미세한 빛(주인공만 보임), 요리에서 나는 비현실적 향 — 일반인은 "맛이 유독 좋다" 정도로 인식 |

## 11. 능력 각성 전용 설정 — 치유 요리 시스템

### 11.1 발동 조건 상세

| 필드 | 설정 |
|------|------|
| **awakening_type** | 치유 요리 (잠재 유전 능력의 후천적 각성) |
| **trigger** | 극한의 감정 상태(절망+사랑)에서 조리 행위가 방아쇠. 첫 각성은 딸을 위한 마지막 치킨 |
| **activation_rule** | 전 과정 직접 조리 + 치유 의도 집중 + 재료 품질 최소 기준 충족 |
| **sensory_cue** | 조리 중 손바닥의 온기, 재료가 미세하게 빛남(주인공만 인지), 완성 요리에서 비현실적 향 |

### 11.2 성장 단계

| 단계 | 블록 범위 | 치유 가능 범위 | 재료 요구 | 체력 소모 | 제약 |
|------|-----------|---------------|-----------|-----------|------|
