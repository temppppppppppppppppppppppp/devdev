# 컨셉 기획안 — 해고당한 길드 회계사의 SSS급 감정안: 숫자로 세계를 읽다

> 작성일: 2026-03-20
> 장르: 현대판타지 · 헌터물 · 경제/감정사
> 플랫폼 타겟: 카카오페이지 (1순위), 문피아 (2순위)
> 배치: BATCH 01 / #006 / FAN-HNT-06

---

## 1. 로그라인

**대형 길드에서 횡령 누명으로 해고당한 D급 회계사 헌터가, 아이템·스킬·인간의 숨겨진 가치를 정확한 수치로 보는 'SSS급 감정안'을 각성한다. 버려진 E급 아이템이 실은 SSS급, 해고한 길드장의 숨겨진 약점은 3,847 — 숫자가 무기다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 대형 길드 '크로노스' 본부.
 → 주인공 윤시준(33), D급 헌터, 회계사.
 → 길드장: "윤 회계사, 3억 횡령 건 해명해."
 → 시준: "저는 횡령하지 않았습니다. 장부를 확인하시면—"
 → 길드장: "넌 해고야. 다시는 이 업계에서 일 못 할 줄 알아."
 → 보안팀이 시준을 끌어낸다. 짐 박스 하나.
 → 헌터 업계 블랙리스트 등재. 어디서도 고용하지 않는다.

1화: 노점 아이템 시장.
 → 해고 후 3개월. 시준은 E급 헌터 아르바이트로 연명 중.
 → 노점에서 500원짜리 E급 단검을 본다.
 → 갑자기 시야가 변한다. 단검 위에 숫자가 떠오른다.
 → [SSS급 감정안 각성]
 → [대상: 낡은 단검(표시 등급: E)]
 → [실제 가치: 47,000,000원]
 → [숨겨진 속성: 마나 증폭 ×3 (봉인 상태)]
 → [봉인 해제 조건: A급 이상 마나 주입]
 → 시준이 500원에 산다. 봉인 해제 의뢰를 맡기면 4,700만 원.
 → 1화 마지막 줄: "…길드장, 당신의 숨겨진 가치도 보이더라."
```

**후킹 구조**: 횡령 누명 해고(분노) → 감정안 각성(반전) → 500원→4700만 원(경제 쾌감) → 길드장 약점 암시(복수 기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **SSS급 감정안** | 아이템·스킬·인간의 숨겨진 가치를 정확한 수치로 시각화 |
| **감정 대상** | 아이템(실제 등급·봉인 속성·시세), 스킬(숨겨진 효과·한계치), 인간(전투력·약점·거짓말 감지) |
| **성장 축** | 감정 정밀도(소수점 이하 자릿수) + 감정 범위(접촉→시야→구역) + 동시 감정 수 |
| **제약** | ① 감정은 '볼 수만' 있고 직접 전투력 상승 없음 ② 과다 사용 시 두통·실명 위험 ③ 인간 감정 시 상대가 '감정당하는 느낌' 인지(적의) ④ D급 전투력 고정 |
| **경제 원리** | 감정 정보 = 돈. 아이템 실제 가치 파악 → 차익 거래 → 경제적 성장 |

### 3.2 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 아이템 시장 정보 비대칭 심각 | 시준의 감정안이 게임 체인저 |
| 3개월 후 | 숨겨진 SSS급 아이템 연속 발굴 | 업계 주목 |
| 1년 후 | 감정사 직업군 인정 | 신직업 창설 |
| 3년 후 | 글로벌 아이템 거래소 | 국제 감정 표준 |
| 5년 후 | 차원 아이템 출현 | 최종 감정 |

### 3.3 주인공 그룹

| 항목 | 설명 |
|------|------|
| **상호** | '시준 감정소' (1인) → '밸류아이(VALUE-I) 감정 길드' |
| **주력** | 아이템 감정·거래·컨설팅 |
| **자산** | 초기 -3억(횡령 배상금) → 최종 5조+ |
