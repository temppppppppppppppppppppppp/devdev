## 1. 로그라인

**10년차 무명 웹툰 작가 한시율은 연재 종료 통보를 받은 날, 자신이 그린 캐릭터가 스케치북에서 뛰어나온다. 그림의 완성도가 소환수의 등급을 결정하고, 연재 순위가 소환 가능 슬롯 수를 좌우한다 — 살아남으려면 그려야 하고, 그리려면 살아남아야 한다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 서울 한복판, 정체불명의 괴수가 출현한다.
 → 헌터들이 전멸 직전, 한 남자가 스케치북을 펼친다.
 → 남자가 펜을 한 획 긋자 스케치북에서 거대한 용사가 튀어나온다.
 → 괴수 격멸. "작가님, 다음 화 마감은요?" 편집자 전화.
 → 3개월 전으로 되돌아간다.

1화: 서울 관악구 반지하 원룸.
 → 한시율(32세), 10년차 웹툰 작가. 조회수 200의 바닥 인생.
 → 편집자에게 연재 종료 통보를 받는다. "시율 씨, 이번 달로 컷입니다."
 → 자포자기로 마지막 원고를 그린다 — 자신의 첫 캐릭터 '카론'.
 → 새벽 4시, 완성된 카론의 눈이 빛난다. 종이를 찢고 30cm 피규어 크기의 검사가 책상 위에 선다.
 → 1화 마지막 줄: "…작가님, 저를 부르셨습니까?"
```

**후킹 구조**: 프롤로그 스케일 전투(시각 충격) → 3개월 전 바닥 인생(공감) → 연재 종료(위기) → 캐릭터 소환(판타지 반전). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **소환 방식** | 작가가 직접 그린 캐릭터만 소환 가능. 완성된 일러스트 1장 = 소환수 1체 |
| **소환 등급** | 그림 완성도(디테일·감정·세계관 깊이)에 비례 — 러프 스케치(F급) ~ 풀컬러 완결 일러스트(SSS급) |
| **소환 제약** | ① 동시 소환 수 = 연재 플랫폼 순위에 연동 (100위 밖: 1체, 50위: 3체, 10위: 5체, 1위: 7체) ② 소환수 파괴 시 원본 원고 소실, 재작화 필요 ③ 타인의 그림은 소환 불가 — 반드시 본인의 창작물이어야 함 |
| **소환 증거** | 소환수에게는 원본 원고의 잉크 냄새가 남. 파괴 시 종이가 재가 되며 흩어짐 |
| **능력 각성 계기** | 10년간 쏟아부은 창작 에너지가 임계점 돌파. 연재 종료라는 극한 감정이 트리거 |
