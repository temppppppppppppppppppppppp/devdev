# 컨셉 기획안 — 신라 화랑이 당나라에서 장원급제하다

> 작성일: 2026-03-20
> 장르: 대체역사 · 입신양명물 · 문무겸비
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)

## 1. 로그라인

**2026년, 외교부 중국 주재 서기관 정해민(29세)이 820년대 신라 하급 화랑 '정랑(鄭郞)'으로 빙의한다. 통일신라 말기, 왕위 쟁탈의 혼란 속에서 출세길이 막힌 6두품 청년. 그가 선택한 돌파구는 바다 건너 당나라 — 세계 최대 제국의 과거(科擧)에 도전한다. 검은머리 이방인으로 당 장안에서 장원급제하고, 당 조정을 움직이며, 최종적으로 신라를 구한다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2026년, 주중 한국대사관.
 → 서기관 정해민. 한중 외교 현안 보고서 작성 중.
 → "당나라 때 신라인 최치원이 빈공과에 급제했다는 거, 그게 역대 최연소였대."
 → 당대 한중 관계 사료를 읽다 쓰러진다.

1화: 821년(헌덕왕 13년), 경주 남산 기슭.
 → 눈을 뜬다. 화랑도 수련장. 손에 검.
 → 선배 화랑이 말한다: "정랑, 6두품 주제에 무엇이 되겠다고 이리 발악이냐."
 → 해민(정랑)은 안다: 골품제 — 이 나라에서 6두품은 아찬(6등급)까지만 오를 수 있다.
 → 그리고 안다: 당나라에는 빈공과(賓貢科)가 있다.
   외국인도 과거에 응시할 수 있는 시험이.
 → 최치원이 12세에 당에 건너가 18세에 급제한 역사를 안다.
   지금이 821년이면, 최치원은 아직 태어나지도 않았다.
 → 1화 마지막 줄: "형님, 저 당나라에 가려 합니다. 과거를 보러."
```

**후킹 구조**: 현대 외교관(전문성) → 골품제 한계(좌절) → 당나라 과거(돌파구) → 최치원보다 먼저(야심). 4단 임팩트.
