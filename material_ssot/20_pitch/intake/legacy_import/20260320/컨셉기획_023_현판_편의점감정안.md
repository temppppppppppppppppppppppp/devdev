## 1. 로그라인

**서울 변두리 편의점 야간 알바생 강시율(24). 부모 없이 자란 극한 흙수저가 어느 날 상품을 만지면 '숨겨진 진짜 가치'가 수치로 보이는 감정안을 각성한다. 편의점 진열대에서 시작해 중고거래, 경매, 부동산, 유통 사업을 거쳐 글로벌 유통 재벌로 올라서는 0원짜리 역전극.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 새벽 3시, 서울 구로구 골목 편의점.
 → 강시율(24), 야간 알바 48시간째. 눈 아래 다크서클.
 → 점주한테 전화: "이번 달 알바비 좀만 늦게 줘도 되지?"
 → 시율이 대답하기도 전에 끊김. 잔고 확인: 12,340원.
 → 유통기한 임박 삼각김밥으로 끼니 해결.

1화: 새벽 4시, 택배 상하차 검수 중.
 → 쏟아지는 택배 박스를 정리하다 손이 찢어짐. 피가 묻은 손으로
   박스를 만지는 순간 — 시야에 숫자가 뜬다.
 → [일반 컵라면] 시장가: 1,200원 | 실제 가치: 1,200원
 → "뭐야 이거..." 눈을 비비고 다시 본다.
 → 진열대 구석에 쌓인 반품 대기 상품 하나를 집는다.
 → [단종 예정 한정판 스낵] 시장가: 1,500원 | 실제 가치: 38,000원
 → 시율의 눈이 커진다.
 → 1화 마지막 줄: "이거... 내가 사도 되는 거 맞지?"
```

**후킹 구조**: 극한 빈곤(공감) → 부상 각성(각성 트리거) → 가치 괴리 발견(호기심) → 첫 기회 포착(욕망). 4단 임팩트.
