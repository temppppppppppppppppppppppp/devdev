# 컨셉기획 081 — 야근 시작, 회사가 던전으로 변한다

- **코드**: XGN-EXP-01
- **장르**: 호러 + 직장물 (크로스장르 블루오션)
- **타겟 플랫폼**: 문피아 / 카카오페이지 양면
- **분량 목표**: 7대단원 × 10블록 = 70블록 (블록당 약 7~10화, 총 490~700화)
- **기획일**: 2026-03-20

---

## 1. 로그라인

**오후 6시, 퇴근 버튼을 누르지 못한 순간 — 사무실이 괴담 던전으로 변한다. 야근 시간이 길어질수록 던전 난이도는 올라가고, 살아서 퇴근하려면 괴담을 클리어해야 한다. 만년 대리 서진혁은 '야근 생존자'로 각성하며, 회사 전체를 지배하는 저주의 정체를 파헤친다.**

## 5. 적대자 변천사

### Phase 1: 괴담 개체들 (B01~B25)

| 항목 | 내용 |
|------|------|
| 정체 | 각 층·구역에 귀속된 개별 괴담 개체. 과로사·원한·비리에서 탄생 |
| 등급 | E~A급. 초반에는 탕비실 괴담, 복사실 귀신 등 직장 밀착형 |
| 위협 방식 | 퀘스트 실패 시 사망. 오답 유도, 심리 공포, 시간 압박 |
| 약점 | 각 괴담에 고유 규칙 존재 → 규칙 파악 시 클리어 가능 |
| 대표 개체 | 복사실의 분신(B05), 서버실의 데이터 귀신(B12), 옥상의 투신자(B18) |

### Phase 2: 관리자 세력 — 야근 시스템 수호자 (B20~B50)

| 항목 | 내용 |
|------|------|
| 정체 | 야근 던전을 "경영 도구"로 활용하는 경영진 비밀 조직 |
| 구성 | 오경태 상무(실행), 이사회 3인(의사결정), 외부 주술사(기술지원) |
| 목적 | 던전의 저주 에너지를 흡수해 기업 경쟁력으로 전환. 직원 사망 = 연료 |
| 위협 방식 | 생존자 추적, 던전 난이도 인위적 조작, 내부 배신자 침투 |
| 약점 | 시스템에 대한 이해가 불완전. 핵심 괴담(지하 봉인)을 통제 못함 |

### Phase 3: 근원 — 한강그룹 창립자의 저주 (B45~B70)

| 항목 | 내용 |
|------|------|
| 정체 | 한강그룹 창립자 한태수의 잔류 의지. 형장터 원혼과 융합하여 건물 자체가 된 존재 |
| 목적 | 영원한 노동 = 영원한 생명. 모든 직원을 던전에 가두어 영속적 에너지원으로 삼음 |
| 위협 방식 | 건물 자체를 변형, 괴담 무한 생성, 시간 왜곡(야근 무한 루프) |
| 규모 | 전국 자회사 건물로 확산 시도 → 최종 단계에서 도시 전체 위협 |
| 약점 | 창립 당시 봉인된 '근무 종료 종(鐘)' → 고산이 보유한 봉인 열쇠로 타종 시 약화 |

## 13. 킬링포인트 요약

1. **야근 = 던전** — 모든 직장인이 공감하는 '야근 지옥'을 리터럴하게 던전화. "퇴근하려면 클리어하세요"의 직관적 후킹.
2. **층별 괴담 퀘스트** — 각 층·구역마다 고유한 한국형 직장 괴담. 추리+호러+서바이벌의 삼중 재미.
3. **직급 승진 = 레벨업** — 만년 대리가 괴담 클리어로 승진. 현실 직장 판타지와 이세계 성장물의 결합.
4. **경영진이 진짜 악당** — 직원 사망을 연료로 쓰는 경영진. 사회 풍자 + 카타르시스 이중 구조.
5. **한국형 오피스 호러** — 복사실 귀신, 탕비실 저주, 야근 괴담 등 K-직장 특화 호러. 기존에 없던 장르 결합.
