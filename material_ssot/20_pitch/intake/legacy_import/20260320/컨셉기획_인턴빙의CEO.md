## 1. 로그라인

**대한민국 시가총액 1위 기업을 말아먹은 CEO가, 13년 전 같은 회사의 첫날 인턴으로 빙의했다. 회사의 모든 비밀을 알지만 직급은 인턴 — 듣는 사람이 없다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2040년, 한라테크 본사 56층 회장실.
 → 뉴스 속보: "한라테크, 반도체 사업 전량 손실… 시총 90조 증발"
 → 이수혁 CEO, 빈 회장실에 홀로 앉아 있다.
 → 비서: "대표님, 채권단이…" / 수혁: "알아."
 → 창밖을 본다. 13년 전 인턴 시절이 떠오른다.
 → "그때로 돌아갈 수 있다면, 단 하나만 바꾸겠다."
 → 의식이 사라진다.

1화: 2027년 3월 2일(월), 한라테크 강남 사옥 1층 로비.
 → 눈을 뜬다. 손에 든 건 '신입 인턴 교육 안내문'.
 → 옆에 같이 줄 선 2000년생 인턴들. 수혁은 자기 손을 본다 — 22살.
 → 인사팀 김 과장: "자, 신입 인턴 여러분, 자기소개 시간입니다."
 → 수혁이 일어선다. 시선이 엘리베이터로 간다.
   56층에서 내려오는 사람 — 정태준 부사장.
   전생에서 수혁을 CEO로 만들어주고, 결국 배신한 남자.
 → 정태준이 인턴들을 스치며 지나간다. 눈도 안 마주친다.
 → 수혁의 독백: "부사장님, 13년 뒤에 당신이 나를 버리는 건 알고 있습니다."
 → 1화 마지막 줄: "하지만 이번엔 내가 먼저입니다."
```

**후킹 구조**: CEO 몰락(공감) → 인턴 빙의(갭 모에) → 배신자와의 재회(복수 기대) → "이번엔 내가 먼저"(사이다 예고). 직장인 카타르시스 극대화.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목            | 설정                                                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **빙의 방식**   | 의식 전이. 2040년 CEO → 2027년 인턴의 몸. 동일 인물의 과거 자아에 덮어씌워짐                                                                   |
| **기억 유지**   | 13년간의 경영 경험·인맥·기밀 완전 보존                                                                                                         |
| **빙의 제약**   | ① 인턴 직급이므로 의사결정권 零 ② 전생 기억 중 **자신이 내린 결정**만 선명, 타인의 행동은 흐릿 ③ 전생에서 모르던 부서(연구소 등)의 정보는 없음 |
| **핵심 딜레마** | 전생에서 **자신이 내린 결정들**이 회사를 망하게 했으므로, 자기 판단 자체를 의심해야 함                                                         |

### 3.2 기업 배경 (한라테크)

| 항목            | 설명                                                           |
| --------------- | -------------------------------------------------------------- |
| **기업명**      | 한라테크 (HANLA TECH)                                          |
| **사업**        | 반도체 소재·장비 → AI 데이터센터 → 전기차 배터리 (사업 다각화) |
| **규모**        | 2027년 기준 시총 15조, 임직원 1.2만 명                         |
| **지배구조**    | 창업주 가문(한가) 지분 31%, 외국인 투자자 28%, 국민연금 9%     |
| **숨겨진 문제** | 반도체 R&D 과잉 투자, 내부 파벌 투쟁, 2세 경영 승계 갈등       |

### 3.3 "인턴"이라는 제약이 만드는 서사 구조

전통 재벌물과의 핵심 차이: **주인공이 올바른 답을 알아도 직급이 막는다.**

| 일반 재벌 빙의물                   | 이 작품                                |
| ---------------------------------- | -------------------------------------- |
| 재벌 2세 몸에 빙의 → 즉시 의사결정 | 인턴 → 아무 권한 없음                  |
| "이 주식을 사라" → 비서가 실행     | "이 주식을 사세요" → "인턴이 뭘 알아?" |
| 정보 + 권한 = 즉시 실행            | 정보 + 0 권한 = 우회 전략 필수         |

**매 블록의 핵심 긴장**: "맞는 답을 어떻게 권한 없이 실현시키는가?"

## 11. regression_ext 설계 (빙의 전용)

| 필드                 | 설정                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `regression_type`    | 빙의                                                                                                                |
| `is_regressor`       | true (전 블록 고정)                                                                                                 |
| `regression_hint`    | "전생에서 본 이사회 장면이 겹쳐 보인다" 류의 데자뷔. 서사적 한국어                                                  |
| `slip_up`            | "아직 발표 안 된 기술 사양을 아는 듯한 발언" 등 — 최소 10종, 에스컬레이션                                           |
| `execution_doctrine` | 진화 흐름: "간접 제안(인턴)" → "데이터 기반 설득(사원~대리)" → "직접 의사결정(차장~이사)" → "조직 설계(부사장~CEO)" |
| `death_flag`         | 전생의 CEO 파산 타임라인 접근 시, 동일한 결정 상황이 반복됨                                                         |

### death_flag 에스컬레이션 (전생에서 내린 잘못된 결정들)

| 대단원 | death_flag 유형                                                          |
| ------ | ------------------------------------------------------------------------ |
| 1~2    | 전생에서 무시했던 소규모 리스크가 다시 눈앞에 나타남                     |
| 3~4    | 전생에서 내린 핵심 투자 결정과 동일한 상황 도래 — 같은 실수를 할 것인가? |
| 5      | 전생에서 해고한 장현우를 다시 해고해야 할 상황                           |
| 6~7    | 전생의 파산 직전 결정과 완전히 동일한 보드 구성 → "이번엔 다르게"        |

### slip_up 에스컬레이션

| 단계       | 빈도        | 예시                                            |
| ---------- | ----------- | ----------------------------------------------- |
| 대단원 1~2 | 5블록당 1회 | "이 제품 수율 문제… 아, 아직 양산 안 했죠?"     |
| 대단원 3~4 | 3블록당 1회 | "사라 밀러가 올 겁니다" (아직 한국 진출 미발표) |
| 대단원 5~7 | 2블록당 1회 | 누군가(한예린)가 패턴을 인지하기 시작           |
