# 컨셉 기획안 — 동로마 최후의 황제가 콘스탄티노플을 지킴

> 작성일: 2026-03-20
> 장르: 대체역사 · 제국방어 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-WLD-08

---

## 1. 로그라인

**2025년 군사사학과 교수 한재민이 1449년 동로마(비잔틴) 제국 마지막 황제 콘스탄티노스 11세에 빙의한다. 오스만 메흐메트 2세의 콘스탄티노플 공성전까지 4년 — 1,100년 로마의 역사를 끊지 않기 위해, 현대 군사학으로 난공불락의 성벽을 지키는 최후의 황제.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 이스탄불 아야소피아 앞.
 → 한재민 교수가 비잔틴 제국 멸망 학술 발표 중이다.
 → "1453년 5월 29일. 테오도시우스 성벽이 무너지고,
    1,100년 로마가 끝났습니다. 콘스탄티노스 11세는 성벽 위에서
    전사했고, 시신조차 찾지 못했습니다."
 → 아야소피아의 벽에 손을 대는 순간, 세계가 뒤집힌다.

1화: 1449년, 콘스탄티노플 블라케르나이 궁전.
 → 눈을 뜬다. 황금 모자이크 천장. 보라색 예복.
 → 거울에 비친 얼굴 — 중년 남성. 수염. 왕관.
 → "폐하, 즉위식 준비가 되었습니다."
 → 한재민은 안다: 콘스탄티노스 11세 팔라이올로고스.
   동로마 제국의 마지막 황제. 4년 후 성벽 위에서 죽는 사람.
 → 창밖으로 콘스탄티노플이 보인다. 테오도시우스 성벽.
   1,100년간 외적을 막아낸 삼중 성벽.
 → 그리고 4년 후, 저 성벽이 무너진다. 오스만의 거대 대포에.
 → 1화 마지막 줄: "이 성벽을 지킨다. 1,100년의 로마를 끝내지 않는다."
```

**후킹 구조**: 아야소피아(역사적 비극) → 마지막 황제 빙의(운명적 반전) → 4년 시한(긴박) → "끝내지 않는다"(결의). 4단 임팩트.

## 6. 자본/성장 곡선 설계

### 6.1 핵심 규칙
- 초기 지위: **황제** (최고 지위이나 자원 0에 가까움)
- 최종 목표: **제국 생존 + 재건** — 콘스탄티노플을 지키고 제국을 살림
- 성장 지표: 병력 + 재정 + 동맹국 + 성벽 강도 + 영토
- **최소 7블록에서 후퇴** 필수
