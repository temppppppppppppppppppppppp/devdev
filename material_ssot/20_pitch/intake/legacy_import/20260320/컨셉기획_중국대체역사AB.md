# 컨셉 기획안 — 중국 대체역사 A: 「삼국지의 제갈량이 통일했다면」

> 장르: 대체역사물 · 중국 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)

---

## 1. 로그라인

**전략 컨설턴트가 제갈량 사후(234년)의 강유에 빙의한다. 제갈량의 북벌 실패를 이어받는 것이 아니라 — 촉한이 위를 멸하고 천하를 통일하는 if 역사를 쓴다.**

## 2. 1화 후킹

> _오장원. 제갈량의 장막 안. "후사를 부탁하오, 백약…" 승상이 눈을 감는다. 눈물을 흘리는 강유(姜維)의 의식이 끊어지고, 서울 강남 컨설팅펌 전략이사 노재현의 기억이 덮어씌워진다._
> → "삼국지? … 여기가 그 삼국지? 그리고 내가 강유?"
> → 장막 밖에서 양의(楊儀)가 소리친다: "강유! 위군이 추격한다! 퇴각해야 한다!"
> → 노재현(강유)은 생각한다: '제갈량은 죽었다. 하지만 촉한의 군대 10만은 아직 여기 있다.'

## 3. 세계관 & 장르 설정

| 항목               | 설정                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **빙의 대상**      | 강유(姜維), 촉한 대장군. 제갈량의 후계자                                                 |
| **시대**           | 234년 (위·촉·오 삼국) ~ 260년대                                                          |
| **분기점**         | 강유가 제갈량 사후 단순 북벌이 아닌 경제·외교·기술 혁신 병행                             |
| **현대 지식 활용** | 경영 전략(M&A = 오나라 합병), 물류 혁신(촉도 개선), 정보전(첩보망), 농업 기술(식량 자급) |
| **핵심 딜레마**    | 역사 속 촉한의 멸망을 아는 자가, 그 운명을 바꿀 수 있는가?                               |

| 2 (대단원 3~5) | 위의 사마의·사마사·사마소 3부자                         |
| 3 (대단원 6~7) | 오나라의 배반 + 위의 총공세 (역사적 멸촉 시나리오 방어) |

# 컨셉 기획안 — 중국 대체역사 B: 「명을 삼킨 환관」

> 장르: 대체역사물 · 중국 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 네이버시리즈 (2순위)

---

## 1. 로그라인

**역사학 대학원생이 명나라 정화(鄭和)에 빙의한다. 환관이라는 극한의 제약 속에서 대항해를 이끌고, 유럽보다 100년 먼저 세계를 장악하는 대명제국을 건설한다.**

## 2. 1화 후킹

> _1405년, 남경(南京) 용강선소. 길이 120미터, 폭 50미터의 보물선(寶船) 62척이 출항을 기다린다. 이 세계 최대의 함대를 이끄는 자가 — 환관? 내가?_
> → "삼보태감 정화, 영락황제의 칙명이오. 서양으로 출항하시오."
> → 역사학도 신동현은 안다: 이 함대가 28년간 7회 항해를 하고, 그 뒤 영원히 바다에서 사라진다는 것을. "이번에는 사라지지 않는다."

## 3. 세계관 & 장르 설정

| 항목                | 설정                                                             |
| ------------------- | ---------------------------------------------------------------- |
| **빙의 대상**       | 정화(鄭和), 명 영락제의 환관 대항해가                            |
| **시대**            | 1405년 ~ 1435년대                                                |
| **분기점**          | 정화 함대가 귀환·해체되지 않고 **항구적 해상 거점을 구축**       |
| **핵심 변화**       | 명의 해금(海禁) 정책 → 해양 제국 전환. 유럽 대항해시대 선제      |
| **환관이라는 제약** | 정치적 권한 극히 제한, 문관 사대부의 적대, 후계자를 남길 수 없음 |

### 적대자 3단계

| Phase          | 적대자                                          |
| -------------- | ----------------------------------------------- |
| 1 (대단원 1~2) | 사대부 보수파 (해금 주장, 정화 견제)            |
| 2 (대단원 3~5) | 영락제 사후 홍희·선덕제의 내향 정책 + 환관 배척 |
| 3 (대단원 6~7) | 포르투갈·아랍 해상 세력 + 명 내부 쿠데타        |

### NPC 12명 / 복선 8개 / 패배 10개

### 자본 곡선 (함대 규모 + 해상 거점 수 + 무역 수입)

```
대단원 1~2: 62척 → 80척, 거점 0 → 말라카·칼리컷 2곳
  패배: Block 4 (해적 습격 피해), Block 8 (선원 반란)
대단원 3~4: 100척, 거점 5곳 (동남아+인도+아프리카)
  패배: Block 26 (영락제 승하, 함대 해체 명령), Block 33 (사대부 탄핵)
대단원 5~6: 150척, 거점 10곳 (아프리카+아라비아+유럽 접근)
  패배: Block 44 (포르투갈 함대 충돌), Block 55 (명 국내 반환관 운동)
대단원 7: 200척, 세계 해상 패권 or 선택의 결말
  패배: Block 65 (명 본국과의 최종 대결)
```

## 4. 3-Pass 감리 — **PASS** (P0 ✅ P1 ✅ P2 ✅)
