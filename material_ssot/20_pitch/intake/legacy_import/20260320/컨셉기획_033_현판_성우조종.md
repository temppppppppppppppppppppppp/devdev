# 컨셉 기획안 — 폐성우의 목소리가 너무 위험하다

> 작성일: 2026-03-20
> 장르: 현대판타지 · 연예계 · 초능력
> 플랫폼 타겟: 카카오페이지 (1순위)

---

## 1. 로그라인

**20년 무명 성우 출신, 40대 백현우는 성대결절 수술 후 목소리로 타인의 감정과 행동을 조종하는 능력에 각성한다. 업계에서 버림받은 남자가 목소리 하나로 애니메이션·더빙·광고·드라마·영화까지 연예계를 삼키며, 자신을 짓밟았던 세력에 복수한다. 단, 능력을 쓸수록 자신의 진짜 목소리는 사라져 간다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 녹음실. 40대 남자가 마이크 앞에 서 있다.
 → 디렉터: "백 선생님, 죄송한데 이 캐릭터는 좀 더 젊은 느낌이…"
 → 스태프가 속삭인다: "저 아저씨 아직도 해? 20년째 단역인데."
 → 백현우가 녹음실을 나온다. 핸드폰에 문자: "다음 달부터 계약 갱신 없습니다."
 → 집에 돌아오면 이혼 서류가 식탁 위에.

1화: 성대결절 수술 당일, 마취에서 깨어난 병실.
 → 의사: "수술은 잘 됐는데, 음성이 이전과 약간 달라질 수 있습니다."
 → 백현우가 처음 말을 꺼낸다: "물 좀…"
 → 간호사가 멈칫한다. 눈이 풀리며 벌떡 일어나 물을 가져온다.
 → 병실 동료 환자에게 "조용히 해주세요"라고 말하자, 환자가 석상처럼 입을 닫는다.
 → 퇴원 후, 거리에서 시비 건 양아치에게 "무릎 꿇어"라고 말한다.
   양아치가 무릎을 꿇는다.
 → 1화 마지막 줄: "…이 목소리로, 다시 시작할 수 있을까."
```

**후킹 구조**: 프롤로그 해고+이혼(공감+분노) → 수술 후 각성(반전) → 능력 확인(쾌감) → 복귀 암시(기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **능력 방식** | 성대결절 수술 중 성대에 알 수 없는 변이 발생. 목소리에 초자연적 공명 주파수가 실림 |
| **능력 범위** | Lv1: 감정 유도(기쁨·슬픔·공포) → Lv2: 행동 암시(단순 명령) → Lv3: 인격 덮어쓰기(일시) → Lv4: 다중 조종(방송 매체를 통한 대중 조종) → Lv5: 목소리의 잔상(녹음본으로도 효과 발동) |
| **능력 제약** | ① 사용할수록 본래 목소리(음색·감정)가 소실 — 최종적으로 "진심을 담은 말"을 할 수 없게 됨 ② 상대의 의지력이 강하면 저항 가능 ③ 귀마개/이어폰 차단 시 무력화 ④ 1일 사용 횟수 제한 (초과 시 성대 출혈) |
| **능력 감지** | 일부 청각이 예민한 인물(음악가, 절대음감 보유자)이 "뭔가 이상한 주파수"를 감지할 수 있음 |
