# 09. 연예/배우 — 「20년 엑스트라가 주연을 꿰찼다」

> 장르 가드: `actor_guard`
> 대상 독자: 5060 남성
> 키워드: 회귀 + 연기 달인 + 업계 장악 + 지각된 천재

---

## 컨셉 한 줄

20년간 엑스트라만 하다 교통사고로 죽은 55세 배우가 35세로 돌아갔다. 촬영장의 모든 감독, 모든 배우의 습관과 약점을 안다. 이번엔 주연이다.

## 주인공

- **이름**: 장무영 (55 → 35세로 회귀)
- **유형**: 회귀자
- **성격**: 관찰력의 괴물, 자기중심적. "20년 동안 뒤에 서서 앞사람을 봤다. 이제 앞에 설 차례다."
- **우위**: 20년간 현장에서 본 감독별 연출 스타일 + 배우별 NG 패턴 + 작품별 흥행 공식. 연기력 자체보다 "현장을 읽는 능력"이 비정상적.
- **결핍**: 전생에서 실력은 있었으나 인맥·외모·학벌에 밀려 기회 0 → 이번엔 기회를 뺏는다

## 핵심 갈등

- **적대자**: 톱스타(주인공의 부상을 질투) + 대형 기획사 대표(통제 불능 배우를 싫어함) + 편성 권한 가진 방송국 국장
- **구조**: 엑스트라 → 조연 → 주연 → 대상 → 글로벌 스타. 연기 실력으로 밟고 올라간다.

## 성장 자원

- 화제성 (buzz_score): 무명 → 화제 → 톱급 → 글로벌
- 캐스팅 등급 (casting_tier): 엑스트라 → 조연 → 주연 → 원톱
- IP 가치 (ip_value): 출연료 → 제작사 설립 → 콘텐츠 IP 소유

## 대리만족 포인트

1. **오디션에서 "엑스트라 출신이 왜 여기에" → 즉석 연기 한 번에 심사위원 침묵하는 장면**
2. **톱스타와 같은 씬에서 톱스타가 연기에 밀려 NG 내는 장면**
3. **시상식에서 "20년 엑스트라, 오늘 대상" 소감 → 업계 기립박수 장면**
4. **대형 기획사 대표가 계약 제안 → "내 조건은 이거다. 싫으면 말고" 갑을 역전 장면**

## 금지 사항

- "연기는 관객에게 감동을 주는 것" 같은 예술론 금지. 연기는 권력 수단.
- 후배 배우 멘토링 금지. 경쟁자다.
- 슬럼프에 빠져서 방황하는 전개 금지.

## 아크 구조 (7아크 × 10블록)

| Arc | 핵심 | 등급 | 위치 |
|-----|------|------|------|
| 1 | 회귀 + 단역 오디션 합격 + 첫 존재감 | 단역 | 무명 |
| 2 | 조연 발탁 + 화제의 장면 + SNS 바이럴 | 조연 | 떠오르는 신인(?) |
| 3 | 첫 주연 + 시청률 30% + 톱스타 1차 충돌 | 주연 | 톱급 진입 |
| 4 | 영화 데뷔 + 영화제 수상 + 기획사 갈등 | 원톱 | 업계 A급 |
| 5 | 독립 기획사 설립 + 제작자 겸업 | 제작자 겸 배우 | 업계 권력자 |
| 6 | 해외 진출 + 넷플릭스/할리우드 + 글로벌 인지도 | 글로벌 스타 | 국제급 |
| 7 | 대상 + 콘텐츠 제국 + "엑스트라 출신 전설" | 레전드 | 업계 지배 |

## 톤

관찰자적 1인칭. 다른 사람의 미세한 표정·행동을 읽어내는 묘사가 핵심.
"감독이 입꼬리를 올렸다. 저건 만족한 게 아니라 참는 거다. 한 번 더 해야 돼."
