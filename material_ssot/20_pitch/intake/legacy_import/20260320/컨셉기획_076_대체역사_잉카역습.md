# 컨셉 기획안 — 남미 잉카의 역습

> 작성일: 2026-03-20
> 장르: 대체역사 · 제국방어 · 빙의물
> 플랫폼 타겟: 문피아 (1순위)
> 코드: ALT-WLD-06

## 1. 로그라인

**2025년 감염내과 전문의 김서진이 1527년 잉카 제국 황태자 아타우알파의 몸에 빙의한다. 스페인 피사로의 정복군이 도착하기 5년 전 — 역사에서 천연두로 멸망한 제국을, 현대 의학과 방역 지식으로 살려내고 스페인을 역전시키는 잉카 제국 생존기.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 서울아산병원 감염내과.
 → 김서진 전문의가 코로나 7차 변이 대응 브리핑 중이다.
 → "격리 프로토콜을 지키지 않으면 한 도시가 무너집니다."
 → 야근 후 의자에서 쓰러진다.

1화: 1527년, 잉카 제국 수도 쿠스코.
 → 눈을 뜬다. 황금 장식의 방. 석조 궁전.
 → 거울에 비친 얼굴 — 구릿빛 피부, 검은 머리. 잉카인의 얼굴.
 → "아타우알파 왕자님, 와이나 카팍 폐하께서 부르십니다."
 → 서진은 안다: 아타우알파. 잉카 제국의 마지막 황제.
   3년 후 천연두가 제국을 덮치고, 아버지 와이나 카팍이 죽고,
   형제끼리 내전이 벌어지고, 그 틈에 피사로가 온다.
 → 그리고 서진에게는 감염내과 전문의의 지식이 있다.
   천연두를 막을 수 있다. 제국을 지킬 수 있다.
 → 1화 마지막 줄: "아버지, 급히 드릴 말씀이 있습니다. 전염병에 대해서요."
```

**후킹 구조**: 감염내과(전문성) → 잉카 황태자(극적 반전) → 천연두 임박(긴박) → 전염병 저지(서사 목표). 4단 임팩트.

## 6. 자본/성장 곡선 설계

### 6.1 핵심 규칙
- 초기 지위: **황태자** (높은 출발이나, 권한 제한)
- 최종 목표: **사파 잉카(황제)** — 잉카 제국을 멸망에서 구한 군주
- 성장 지표: 방역 성공률 + 군사력 + 외교 동맹 + 기술 도입률
- **최소 7블록에서 후퇴** 필수

## 11. 빙의 전용 설정 (regression_ext)

| 필드 | 설정 |
|------|------|
| `regression_type` | 빙의 (의식 전이) |
| `is_regressor` | true (전 블록 고정) |
| `regression_hint` | 서울아산병원 감염병동의 기억이 잉카 격리 시설과 겹침. "PPE가 없으니 마스크라도…" |
| `slip_up` | 의학 용어("면역", "잠복기", "R0"), 현대 위생 개념, 미래 사건 예언 등. 최소 10종 |
| `execution_doctrine` | 20블록마다 변화: "방역 지식 직접 적용" → "군사 전략 수립" → "기술 도입 가속" → "외교적 해결" |
| `death_flag` | 역사 속 아타우알파 처형 장면이 반복적으로 꿈에 나타남 |

### death_flag 에스컬레이션

| 대단원 | death_flag 유형 |
|--------|----------------|
| 1~2 | 천연두 — 역사대로 제국 인구 90% 사망할 뻔한 공포 |
| 3~4 | 카하마르카 — 역사 속 아타우알파 생포·처형 장면의 데자뷔 |
| 5 | 화기 격차 — "기술이 없으면 결국 당한다" |
| 6~7 | 유럽 전체가 적 — 스페인이 아니라 유럽 식민 체제와의 싸움 |
