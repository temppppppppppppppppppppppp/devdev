# 컨셉 기획안 — 오스만의 검은머리 대재상

> 작성일: 2026-03-20
> 장르: 대체역사 · 제국경영 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-WLD-01

## 1. 로그라인

**2025년 외교부 3등 서기관 강태윤이 1520년 오스만 제국의 고려인 노예 소년으로 빙의한다. 데브시르메(소년 징집제)로 끌려온 검은머리 이방인이 술레이만 대제의 신임을 얻어 대재상(사드라잠)에 오르기까지 — 이슬람 제국의 심장에서 펼치는 한국인의 제국 경영.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 이스탄불 한국 대사관.
 → 강태윤 3등 서기관이 터키 외교 현안 브리핑 중 쓰러진다.
 → 눈을 뜬다. 쇠사슬에 묶인 채 마차 위.
 → 주변에 아랍어와 터키어. 소년의 몸. 거울에 비친 검은 머리.
 → "데브시르메 수집이다. 새 소년병을 모아라."
 → 태윤은 안다 — 1520년, 셀림 1세가 죽고 술레이만이 즉위하는 해.
   오스만 제국의 황금기가 시작되는 바로 그 순간.

1화: 이스탄불 톱카프 궁전 인근, 데브시르메 훈련소.
 → 검은 머리의 소년은 이름을 받는다: "카라바쉬(Karabaş, 검은머리)."
 → 훈련소에서 아랍어·터키어·코란을 배운다. 다른 소년들은 발칸 출신.
 → 유일한 동양인. "저놈은 어디서 왔냐" — 따돌림.
 → 그러나 태윤에게는 500년 후의 외교관 지식이 있다.
 → 훈련관이 묻는다: "제국의 적은 누구냐?"
 → 태윤이 답한다: "밖의 적보다 안의 적이 위험합니다."
 → 훈련관의 눈이 빛난다.
 → 1화 마지막 줄: "이 소년… 파샤(Pasha)감이군."
```

**후킹 구조**: 현대 외교관(공감) → 오스만 노예(충격) → 데브시르메 시스템(역사적 흥미) → 지식의 힘(기대감). 4단 임팩트.

## 6. 자본/성장 곡선 설계

### 6.1 핵심 규칙
- 초기 지위: **노예 소년** (데브시르메 최하층) → 사회적 자본 0
- 최종 목표: **대재상(사드라잠)** — 술탄 다음의 실질 2인자
- 성장 지표: 관직 등급 + 군사 공적 + 영지 규모 + 외교 네트워크
- **최소 7블록에서 지위/권력 감소** 필수
- 성장률 3블록 연속 동일 금지
