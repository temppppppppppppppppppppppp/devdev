## 1. 로그라인

**D-Day, 전 세계에 균열이 열리고 괴수가 쏟아진다. 각성자들은 괴수를 사냥하지만, 52세 퇴직 소방관 박정수는 각성에 실패한다. 그러나 30년간 불 속에서 사람을 꺼내온 남자에게 전투만이 생존은 아니다 — 폐소방서 하나로 시작한 대피소가, 이 망한 세상의 마지막 도시가 된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 서울 은평구, 새벽 3시.
 → 잠에서 깬 박정수(52). 식탁 위에 퇴직 기념 시계와 이혼 서류.
 → TV를 켠다. 모든 채널이 같은 화면 — 서울 상공에 벌어진 붉은 균열.
 → "긴급속보: 전 세계 동시다발 이상 현상. 시민 여러분은 대피—"
 → 방송이 끊긴다. 창밖, 괴수의 포효.

1화: 균열 발생 6시간 후.
 → 아파트 복도에서 비명. 정수는 반사적으로 뛴다 — 30년의 습관.
 → 주민 7명을 계단통으로 유도. 괴수가 추격한다.
 → 젊은 각성자가 나타나 괴수를 처리하지만, 부상자를 보고 당황한다.
   "피가 너무 많이 나는데... 어떻게 해요?"
 → 정수가 무릎을 꿇고 지혈한다. 침착하게. 손이 기억하는 대로.
 → 각성자가 묻는다: "아저씨도 각성자예요?"
 → 정수, 대답 없이 부상자를 업는다.
 → 1화 마지막 줄: "이 동네 소방서가 아직 남아 있을 거다. 일단 거기로 간다."
```

**후킹 구조**: 퇴직+이혼의 바닥(감정) → 아포칼립스 발생(충격) → 비각성자의 구조 행동(반전) → 소방서 거점화 선언(기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 아포칼립스 규칙

| 항목 | 설정 |
|------|------|
| **균열(Crack)** | 전 세계 동시다발 발생. 등급 E~SSS. 균열에서 괴수 출현, 일정 시간 후 자연 소멸하거나 고정화(영구 균열) |
| **괴수** | 균열 등급에 비례한 위험도. E급(개 크기)~SSS급(빌딩 크기). 사체에서 "코어" 획득 가능 — 핵심 자원 |
| **각성자(헌터)** | 균열 발생 후 인류 1~2%가 초자연적 능력 각성. 전투 특화. 비각성자는 일반인 |
| **사회 붕괴 단계** | 1단계(1~2주): 군·경찰 대응 → 2단계(1~3개월): 군 붕괴, 무법 지대화 → 3단계(3개월~): 자생 세력 등장, 영역화 |
| **자원 경제** | 화폐 무효화. 물·식량·의약품·코어가 교환 기준. 전기/통신은 거점에서만 제한 가동 |

## 6. 자원/인구/영향력 성장 곡선 설계

### 6.1 핵심 규칙
- 초기 인구: **10명** (정수 포함 은평소방서 생존자) → 최종 인구: **1만명+**
- 영향력 범위: **소방서 1동** → **은평구** → **서울 서북권** → **수도권** → **한반도 연합**
- 자원 등급: 결핍(D) → 부족(C) → 균형(B) → 풍족(A) → 잉여(S)
- **최소 7블록에서 인구 감소 또는 자원 하락** 필수
- 3블록 연속 동일 성장률 금지

## 11. 대피소 시스템 설정

### 11.1 시설 업그레이드 트리

```
[방어 계열]
 L1: 임시 바리케이드 (가구/차량) → L2: 콘크리트 방벽 + 감시탑
 → L3: 전기 철조망 + 경보 시스템 → L4: 자동 방어 포대 (코어 동력)
 → L5: 균열 감지 레이더 + 대피소 방어막 (SSS급 코어 필요)

[의료 계열]
 L1: 응급 처치소 (소방서 장비) → L2: 야전 진료소 (간호사 배치)
 → L3: 야전 병원 (수술 가능) → L4: 종합 병원 (전문의 확보)
 → L5: 의학 연구소 (괴수 독/질병 연구)

[식량 계열]
 L1: 비상식량 배급 → L2: 옥상/공터 텃밭
 → L3: 수경재배 시설 → L4: 대규모 농업 단지 (학교 운동장 전환)
 → L5: 식품 가공/저장 공장

[에너지 계열]
 L1: 비상 발전기 (연료 의존) → L2: 태양광 패널
 → L3: 코어 동력 발전기 → L4: 소규모 발전소
 → L5: 영구균열 에너지 변환 (실험적)

[행정 계열]
 L1: 리더 1인 지시 체계 → L2: 부서별 책임자 임명
 → L3: 주민 자치 위원회 → L4: 선출직 행정부 + 사법 체계
 → L5: 연합 행정 기구 (다수 거점 통합)
```

### 11.2 인구 관리

| 항목 | 설명 |
|------|------|
| **배급 체계** | 기여도 기반 차등 배급. 노동 불능자(노약자/아동)는 기본 배급 보장 — 정수의 원칙 |
| **직업 배정** | 능력 기반 자율 지원 + 필요 시 요청. 강제 노동 금지 (까마귀단과의 차별점) |
| **갈등 관리** | 각성자 vs 비각성자 갈등이 핵심. 정수는 "전투만이 기여가 아니다"는 원칙 관철 |
| **사기(morale)** | 이벤트/뉴스/생활 수준에 따라 변동. 사기 하락 시 이탈·범죄·반란 위험 증가 |
| **인구 유입** | 구조 작전, 타 대피소 합류, 난민 수용. 유입 시 검역+면담+적응 기간 필수 |

### 11.3 자원 체계

| 자원 | 획득 방법 | 용도 |
|------|-----------|------|
| **식량** | 채집, 농업, 교역, 수렵 | 배급, 사기 유지 |
| **의약품** | 약국/병원 수색, 제조, 교역 | 치료, 전염병 대응 |
| **건축 자재** | 폐건물 해체, 생산, 교역 | 시설 건설/보수 |
| **연료** | 주유소 수색, 바이오연료 제조 | 발전, 차량, 난방 |
| **코어** | 괴수 사체에서 추출 (각성자 전담) | 고급 장비 동력, 교역 화폐, 연구 |
| **무기/장비** | 군/경 시설 수색, 제작, 교역 | 방어, 탐사 |
| **정보** | 정찰, 통신, 교역 네트워크 | 의사 결정, 외교 |

### 11.4 방어 시스템

| 단계 | 위협 등급 | 대응 방식 |
|------|-----------|-----------|
| **녹색(평시)** | E~D급 괴수 산발 | 순찰조 대응. 주민 생활 정상 |
| **황색(경계)** | C~B급 괴수 또는 소규모 적대 세력 | 방어조 배치. 외부 활동 제한 |
