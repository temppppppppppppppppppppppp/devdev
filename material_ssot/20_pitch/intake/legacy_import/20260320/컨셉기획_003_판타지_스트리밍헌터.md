# 컨셉 기획안 — 스트리밍으로 각성하는 E급 헌터: 구독자 수가 전투력입니다

> 작성일: 2026-03-20
> 장르: 현대판타지 · 헌터물 · 스트리밍
> 플랫폼 타겟: 카카오페이지 (1순위)
> 배치: BATCH 01 / #003 / FAN-HNT-03

---

## 1. 로그라인

**E급 헌터 최하위, 던전 안에서 죽을 뻔하다 우연히 스마트폰 라이브 방송을 켰더니 시청자 수에 정비례해 스킬이 강화되는 '스트리밍 시스템'이 각성됐다. 구독자 0명이면 E급, 100만이면 S급 — 방송이 곧 전투다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: E급 던전 내부.
 → 주인공 류현수(28), E급 헌터. 솔로 공략 중 덫에 걸림.
 → HP 10%. 구원 요청 불가. 죽음 직전.
 → 주머니에서 스마트폰이 떨어진다. 실수로 라이브 앱 켜짐.
 → "어… 방송 중인가?" 시청자 0명.

1화: 던전 내부, 라이브 ON.
 → 류현수가 자조적으로 중얼거린다. "여기서 죽는 E급 헌터 보실 분?"
 → 시청자 1명 접속. 시스템창이 뜬다.
 → [스트리밍 시스템 활성화]
 → [현재 시청자: 1명 → 기본 스킬 해금: 마나 부스트(E급)]
 → 몸에 마나가 흐른다. 함정에서 빠져나온다.
 → 채팅: "ㅋㅋㅋ 이거 뭐냐" "E급이 갑자기 강해짐?" "구독 박았다"
 → 시청자 5명 → 10명 → 50명.
 → [시청자 50명 도달: 스킬 강화 — 마나 부스트(D급)]
 → 류현수가 보스 몬스터와 맞닥뜨린다.
 → 1화 마지막 줄: "…구독 좀 눌러주세요. 진짜로 살려야 합니다."
```

**후킹 구조**: 죽음 직전(절박) → 우연한 방송(반전) → 시청자=전투력(놀라움) → "구독 눌러주세요"(유머+긴박). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **스트리밍 시스템** | 실시간 시청자 수에 비례해 전투력 상승. 방송 종료 시 전투력 원점 회귀 |
| **구독자 효과** | 구독자 수 = 기본 바닥 전투력. 시청자는 추가 버프 |
| **등급 환산** | 0~99명 E급, 100~999명 D급, 1K~9.9K C급, 10K~99K B급, 100K~999K A급, 1M+ S급 |
| **제약** | ① 방송 OFF 시 E급 복귀 ② 시청자 이탈 시 실시간 약화 ③ 통신 두절=사망 ④ 채팅 미션 거부 시 디버프 |
| **채팅 미션** | 시청자가 도네이션으로 미션 부여 → 성공 시 특수 스킬 일시 해금 |

### 3.2 헌터 세계 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 헌터 스트리밍 초기 시대 | 류현수가 선구자 |
| 3개월 후 | 헌터 스트리밍 법안 통과 | 합법화, 경쟁자 출현 |
| 1년 후 | 스트리밍 헌터 붐 | 모방 헌터 대량 출현, 경쟁 격화 |
| 3년 후 | 글로벌 스트리밍 대전 | 국가 대항 헌터 스트리밍 |
| 5년 후 | SSS급 게이트 출현 | 최종 결전 생중계 |

## 11. 각성 전용 설정
