# 컨셉 기획안 — 바이킹 여전사가 아메리카를 발견

> 작성일: 2026-03-20
> 장르: 대체역사 · 해양모험 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-WLD-04

---

## 1. 로그라인

**2025년 해양고고학과 여성 교수 서윤아가 1000년경 바이킹 여전사 프레이디스의 몸에 빙의한다. 레이프 에릭손의 빈란드(아메리카) 탐험 직전 — 역사에서 잊힌 여전사가 콜럼버스보다 500년 먼저 신대륙을 정복하고, 바이킹 제국을 세우는 대서사.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 캐나다 뉴펀들랜드 란세오메도즈 유적.
 → 서윤아 교수가 바이킹 정착지 발굴 현장에서 룬문자 석판을 발견한다.
 → "이건… 프레이디스의 이름이야. 붉은 에릭의 딸."
 → 석판에 손을 대는 순간, 세계가 뒤집힌다.

1화: 1000년경, 그린란드 브라탈리드.
 → 눈을 뜬다. 모피 침대. 나무 천장.
 → 거울에 비친 얼굴 — 붉은 머리, 푸른 눈, 흉터가 있는 여전사의 몸.
 → "프레이디스! 레이프가 출항 준비를 마쳤다!"
 → 서윤아는 안다: 프레이디스 에릭스도티르. 붉은 에릭의 딸.
   역사에서는 빈란드에 갔다가 살인을 저지르고 돌아온 여자.
   그러나 아무도 모른다 — 바이킹이 정말로 아메리카에 닿았다는 것을.
 → 밖에서 드래곤 보트의 돛이 펼쳐진다. 서쪽 바다를 향해.
 → 1화 마지막 줄: "이번에는 돌아오지 않을 거야. 서쪽에 남는 거야."
```

**후킹 구조**: 고고학 발굴(학술적 흥미) → 바이킹 여전사 빙의(성별+시대 반전) → 신대륙 탐험(모험) → "남는다"(제국 건설 선언). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **빙의 방식** | 룬 석판 접촉 → 의식 전이. 2025→1000년, 1025년 역행 |
| **기억 유지** | 현대 해양고고학·항해술·역사학 완전 보존. 단, 세부 연도는 점진적으로 흐려짐 |
| **빙의 제약** | 바이킹 사회의 성별 제약(느슨하지만 존재). 기술 도입은 바이킹 자원 의존 |
| **빙의 증거** | 동양식 사고방식, 현대 항해 용어, 미래 지식 실수 |
