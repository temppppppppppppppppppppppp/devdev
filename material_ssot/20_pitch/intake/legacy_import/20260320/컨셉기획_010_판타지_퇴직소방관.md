## 1. 로그라인

**30년 근속 소방관이 정년퇴직 당일, 화재 현장에서 재앙급 화염 면역을 각성한다. 53세, 모든 불이 통하지 않는 남자 — 화염계 몬스터의 천적이 된 퇴직 아저씨의 늦깎이 헌터 생활.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 소방서 퇴임식.
 → 주인공 김병호(53), 30년 근속 소방관. 정년퇴직.

 → 시스템창이 뜬다.
 → [재앙급 화염 면역 각성]
 → [화염 속성 데미지: 0]
 → [화염 흡수: 활성화 — 화염을 흡수할수록 신체 강화]

```
