## 1. 로그라인

**선협 세계에 '천하비무리그'가 열렸다. 영상전송진(映像傳送陣)으로 억만 수선자가 실시간 관전하는 e스포츠형 비무대회. 무명 외단기(外丹期) 산적 출신이 팀을 꾸려 최하위 리그에서 시작해 천하제일의 자리에 오른다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 천하비무리그 결승전 중계석.
 → 해설자: "제7시즌 결승! 천하 10억 수선자가 지켜보고 있습니다!"
 → 거대한 비무장(比武場) 위, 두 팀이 대치.
 → 한쪽은 화려한 법보(法寶)를 두른 명문종파 엘리트.
 → 반대편은 너덜너덜한 법의(法衣)의 5인조.
 → 해설자: "잡초들의 기적? 아니면 여기까지인가?"
 → 화면 멈춤. 시간 역행.

1화: 6개월 전, 천운산 폐광.
 → 주인공 노현(盧玄), 외단기 2층. 도적단에서 쫓겨난 전과자.
 → 손에 든 건 구겨진 전단지: [천하비무리그 제7시즌 — 하부 리그 참가자 모집]
 → [참가 조건: 금단기 이하, 5인 팀, 등록비 영석 100개]
 → 노현의 전재산: 영석 12개.
 → 1화 마지막 줄: "팀원 4명 구하고, 영석 88개 벌면 되는 거잖아. 쉽네."
```

**후킹 구조**: 결승전 플래시포워드(스케일) → 시간 역행(궁금증) → 바닥 인생 주인공(감정이입) → 불가능한 도전(기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **수선 체계** | 연기(煉氣) → 축기(築基) → 금단(金丹) → 원영(元嬰) → 화신(化神) → 대승(大乘) → 도겁(渡劫) |
| **천하비무리그** | 선협 세계 최대 비무 대회. 영상전송진으로 전 천하에 실시간 중계. 5인 팀전 + 1:1 개인전 병행 |
| **영상전송진** | 고대 유적에서 발견된 영상 전송 법진. 비무 장면을 만리 밖 선계 곳곳으로 동시 전송 |
| **리그 시스템** | 하부 리그(축기~금단) → 중부 리그(금단~원영) → 상부 리그(원영+) → 챔피언스 리그(무제한) |
| **팬덤/후원** | 관중이 영석을 보내면 선수에게 '기운'으로 전달. 팬덤 = 실질적 전력 보너스 (약 5~10%) |

### 3.2 배경 타임라인

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 500년 전 | 영상전송진 유적 발견 | 천하비무리그 탄생의 기원 |
| 100년 전 | 제1시즌 개막 | 리그 역사의 전설적 시즌 |

| 현재 | 제7시즌 개막 | **1화 기점** |
| 시즌 중반 | 마계(魔界) 침공 징조와 리그의 관계 의혹 | 대단원 4~5 |
| 시즌 종료 | 결승전 + 마계 위기 동시 발생 | 대단원 7 |

### 3.3 주인공 그룹 (팀 잡초(雜草))

| 항목 | 설명 |
|------|------|
| **팀명** | 잡초(雜草) — 명문 종파 출신 없음. 전원 비주류·전과자·탈락자 |
