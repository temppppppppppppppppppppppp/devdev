# 컨셉 기획안 — 조선 대체역사 A: 「세종이 죽지 않았더라면」

> 장르: 대체역사물 · 조선 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 네이버시리즈 (2순위)

---

## 1. 로그라인

**과학사 교수가 세종 28년(1446년)의 장영실에 빙의한다. 훈민정음 반포 직후 쓰러지는 세종을 현대 의학 지식으로 살린다. 세종이 10년 더 살면 조선은 어떻게 달라지는가?**

## 2. 1화 후킹

> _경복궁 경회루. 세종이 쓸데없는 문자를 만든다며 최만리가 상소를 올리는 그 순간, '장영실'의 몸으로 눈이 떠졌다. 세종이 기침을 한다. 눈가의 부종, 다리의 부기, 잦은 야뇨 — 당뇨합병증이다. "전하, 어의의 처방을 바꾸셔야 합니다."_

## 3. 세계관 & 장르 설정

| 항목                | 설정                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| **빙의 대상**       | 장영실 (노비 출신 발명가, 세종의 총신)                                    |
| **시대**            | 1446년 (세종 28년) ~ 1470년대                                             |
| **대체역사 분기점** | 세종이 1450년에 죽지 않고 1460년까지 생존                                 |
| **핵심 변화**       | 세종 생존 → 수양대군 왕위 찬탈 불가 → 단종 안정 즉위 → 조선 과학 르네상스 |
| **주인공 지식**     | 현대 과학사·기술사·의학 상식. 단, **구현 수단은 15세기 수준**             |

### 적대자 3단계

| Phase          | 적대자                                      |
| -------------- | ------------------------------------------- |
| 1 (대단원 1~2) | 최만리 + 집현전 보수파 (훈민정음/과학 반대) |
| 2 (대단원 3~5) | 수양대군 + 무인 세력 (왕위 야심)            |
| 3 (대단원 6~7) | 명나라 조공 체제 + 여진족 위협 (대외 갈등)  |

### NPC 12명 / 복선 8개 / 패배 10개 / 자본 곡선 (조선 관직·영향력 기반)

```
대단원 1~2: 종6품 상의원별좌 → 정3품 과학감 설치
  패배: Block 4 (노비 출신 탄핵), Block 8 (발명품 실패 폭발 사고)
대단원 3~4: 과학감 → 정2품 판서급 영향력
  패배: Block 26 (수양대군 암살 시도), Block 33 (명나라 사신 압박)
대단원 5~6: 조선 과학원 설립 + 화포 혁신 + 활판인쇄 보급
  패배: Block 44 (세종 건강 재악화), Block 55 (여진 침공)
대단원 7: 조선 과학 르네상스 또는 — 역사의 반격?
  패배: Block 65 (세종 서거, 후계 갈등 재점화)
```

## 4. 3-Pass 감리 — **PASS** (P0 ✅ P1 ✅ P2 ✅)

# 컨셉 기획안 — 조선 대체역사 B: 「이순신이 살아왔다」

> 장르: 대체역사물 · 조선 · 회귀물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)

---

## 1. 로그라인

**노량해전에서 전사한 이순신이 1년 전(1597년)으로 회귀한다. 백의종군 시점, 12척의 배도 아직 없다. 이번에는 살아남아, 전쟁 이후의 조선을 직접 바꾼다.**

## 2. 1화 후킹

> _"나를 죽이고 싶은 자가 적진에만 있는 것이 아니었다." 노량 앞바다, 총탄이 갑옷을 뚫는 순간, 눈앞이 하얘진다._
> → 1597년 7월. 오두막에서 눈을 뜬다. '삼도수군통제사'직을 박탈당하고 백의종군 명을 받은 그 날이다.

## 3. 세계관 & 장르 설정

| 항목          | 설정                                                                    |
| ------------- | ----------------------------------------------------------------------- |
| **회귀 시점** | 1598년 노량 → 1597년 7월 (약 1년 5개월 역행)                            |
| **분기점**    | 이순신 생존 → 임란 후 조선 군사·외교·정치 재편                          |
| **핵심 변화** | 이순신 생존 + 명량 이후 해군력 확대 → 일본 재침 억제 → 명나라 의존 탈피 |
| **회귀 제약** | 1년 5개월의 기억만 유효. 전쟁 이후는 미지                               |

### 적대자 3단계

| Phase          | 적대자                               |
| -------------- | ------------------------------------ |
| 1 (대단원 1~2) | 원균 일파 + 선조의 불신 (내부 정치)  |
| 2 (대단원 3~5) | 왜군 재침 세력 + 명나라 통제 시도    |
| 3 (대단원 6~7) | 광해군 즉위 후 권력 구도 + 후금 부상 |
