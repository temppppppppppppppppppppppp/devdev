## 1. 로그라인

> 현대 스페셜티 바리스타 **서진우**가 선협 세계의 떠돌이 낭인으로 전이한다. 커피를 내리면 영기(靈氣)가 깃들어 마시는 자의 경맥이 열리고, 막힌 심기(心氣)가 풀린다. 그는 검 대신 드리퍼를 들고 **'운무다방(雲霧茶房)'**을 열어, 선계 곳곳의 상처 입은 수선자·요수·귀선들의 사연을 한 잔의 커피로 치유한다. "싸우지 않아도 세상을 바꿀 수 있다"는 것을 증명하는, 선협 세계 최초의 카페 힐링 서사.

## 2. 1화 후킹 시퀀스

| 단계 | 내용 |
|------|------|
| **오프닝 훅** | 현대 서울, 스페셜티 커피 대회 결승. 서진우가 완벽한 에스프레소를 추출하는 순간, 찻잔에서 안개가 피어오르며 의식이 끊긴다. |
| **전이 각성** | 눈을 뜨니 황폐한 산길. 낡은 도포를 입은 낭인 신분. 품에는 현대에서 쓰던 핸드드리퍼가 하나 남아 있다. |
| **첫 번째 추출** | 산중 약초를 볶아 즉석 원두를 만들어 드리핑. 물줄기가 내려가는 순간 드리퍼에서 은은한 영광(靈光)이 발산된다. 한 모금 마시자 단전에서 미세한 영기가 순환하기 시작. |
| **첫 손님** | 독기에 중독된 채 쓰러진 떠돌이 검수(劍修) 소녀가 커피 향에 이끌려 기어온다. 서진우가 한 잔을 내리자, 소녀의 독맥이 정화되며 기사회생. |
| **클리프행어** | 소녀가 경악하며 묻는다. "이건… 상급 해독 영단보다 효과가 좋은데, 대체 어떤 단방(丹方)이오?" 서진우가 웃으며 답한다. "단방이 아니라 커피예요. 한 잔 더 드릴까요?" |

## 3. 세계관 & 장르 설정

### 판타지 요소

| 요소 | 설명 |
|------|------|
| **영기 커피** | 현대 바리스타 기술(추출 온도·분쇄도·물줄기 제어)에 선계 영기가 반응하여, 커피 한 잔마다 고유한 영기 효과가 깃든다. 원두(영초·영과 볶음) 종류와 추출법 조합으로 효과가 달라진다. |
| **운무다방(雲霧茶房)** | 주인공이 운영하는 이동식 → 고정식 카페. 손님이 한 잔을 마시면 경맥 소통, 심마 완화, 독기 정화 등의 효과를 받는다. 전투력 부여가 아닌 "치유와 회복"에 특화. |
| **수선 체계** | 선계는 연단(煉丹)·부록(符籙)·검수(劍修)·의수(醫修) 등 다양한 수선 길이 존재. 주인공은 어디에도 속하지 않는 **다도수(茶道修)** — 선계 최초의 다도 수선자. |
| **영초 농원** | 카페 뒤뜰에 현대 농업 지식(비료 배합·접목·수경재배 개념)을 적용한 영초 재배원. 선계 수선자들이 불가능하다고 여긴 영초 대량 재배를 실현. |

### 배경 타임라인 / 세계관 체계

| 층위 | 명칭 | 특징 |
|------|------|------|
| **하계(下界)** | 인간계 무림 | 무공·내공 체계. 선계와 단절된 지 300년. |
| **중계(中界)** | 선계 구주(九州) | 9개 대륙으로 나뉜 수선 문파 세계. 영기 농도 보통. |
| **상계(上界)** | 천선영역(天仙領域) | 비승(飛升)한 천선들의 영역. 영기 극농. |
| **이계** | 요계(妖界) · 귀계(鬼界) | 요수·귀수가 사는 차원. 선계와 간헐적 통로 존재. |

- **시대**: 선계 역법 태화(太和) 3127년. 현대 지구 시간과 1:1 대응하지 않음.
- **핵심 갈등**: 300년 전 "영기 대고갈" 이후 선계 영기가 서서히 쇠퇴 중. 영기 커피가 이 쇠퇴를 역전시킬 열쇠가 될 수 있다는 것이 장기 떡밥.

## 6. 경지 성장 곡선

> 주인공은 전투 수선자가 아니므로, "다도수(茶道修)" 고유 경지 체계를 사용한다. 커피 추출의 깊이와 영기 제어력으로 경지를 표현.

| 블록 | 경지 | 추출 수준 | 영기 효과 |
|------|------|-----------|-----------|
| B01-B05 | **초미(初味)** — 첫 맛을 아는 단계 | 기본 드리핑. 영기가 불안정하게 깃듦. | 경미한 피로 회복, 경맥 미세 소통 |
| B06-B10 | **지향(知香)** — 향을 아는 단계 | 원두별 특성 파악. 영기 안정화. | 독기 정화, 심마(心魔) 일시 완화 |
| B11-B20 | **관류(灌流)** — 물줄기를 다스리는 단계 | 물줄기 궤적으로 영기 문양을 새김. | 경맥 전면 소통, 내상 치유 |
| B21-B30 | **온운(蘊韻)** — 여운을 품는 단계 | 추출 후에도 영기가 잔에 남아 지속 효과. | 수선 정체 돌파 보조, 심마 근본 치유 |
| B31-B40 | **융향(融香)** — 향이 하나 되는 단계 | 복수 원두 블렌딩으로 복합 영기 효과. | 복합 치유(신체+정신+영혼 동시) |
| B41-B50 | **무형추(無形抽)** — 형태 없는 추출 | 도구 없이 의념만으로 추출 가능. | 공간 정화, 영기 결계 생성 |
| B51-B60 | **천향(天香)** — 하늘의 향 | 추출한 커피의 향이 수십 리에 퍼져 영기 순환을 촉진. | 대규모 영기 회복, 영기 고갈 지역 재생 |
| B61-B70 | **도다(道茶)** — 다도가 곧 도(道) | 한 잔의 커피에 도(道)의 이치가 담김. 마시는 자가 깨달음을 얻음. | 만물 치유, 영기 대고갈 역전 |

## 11. 전이/빙의 전용 설정

| 항목 | 설정 |
|------|------|
| **전이 방식** | 현대 커피 대회 결승전에서 추출 중 의식 소실 → 선계 운주 변방에서 깨어남. 몸은 선계 낭인의 몸이 아닌 **자기 자신의 몸** 그대로 전이. |

| **귀환 가능성** | 초반에는 귀환 불가. 영기 대고갈 역전 시 선계-현대 간 통로가 열릴 가능성 암시. 최종적으로 양쪽을 오갈 수 있게 됨. |
| **현대 지식 활용** | 커피 추출 과학(수온·추출 시간·분쇄 입도), 농업 지식(비료·접목·병충해 관리), 경영 마인드(고객 관리·마케팅 개념). 전투 기술은 전무. |
| **언어** | 전이 시 자동 언어 적응(드리퍼의 법기 기능). 선계 문자는 서서히 학습. |
| **정체 노출 리스크** | "이계인"은 선계에서 불길한 징조로 여겨짐. 천기각이 이계인을 감시·포획하는 전담 조직. 정체를 숨기며 살아야 하는 긴장감. |
