## 1. 로그라인

**29세 직장인 강도현은 전 재산과 대출금 5억을 코인에 올인했다가 거래소 해킹으로 전액 잃고 옥상 난간에 선다. 뛰어내리는 순간, 시간이 5분 전으로 되감긴다. 하루 3회, 딱 5분만 되감을 수 있는 이 능력으로 — 코인 단타부터 선물옵션, 카지노, 부동산, 기업 인수까지, 금융시장을 씹어먹는 남자의 역전극이 시작된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2026년 3월, 서울 마포구 원룸 옥상.
 → 강도현(29), 핸드폰 화면에 뜬 잔고: 0원.
 → 12시간 전만 해도 5억 2천만 원이었다. 전 재산 + 신용대출 + 카드론.
 → "XX거래소 해킹 피해… 고객 자산 전액 유출."
 → 문자 47통. 대출 독촉. 카드사. 어머니.
 → 난간에 선다. 바람이 분다. 서울이 작다.
 → 눈을 감는다. 발을 뗀다.

1화: 같은 옥상. 5분 전.
 → 눈을 뜬다. 난간 안쪽에 서 있다.
 → 핸드폰을 본다. 시간: 23:51. 5분 전이다.
 → 잔고: 5억 2천만 원. 아직 해킹 전.
 → 심장이 터질 것 같다. 손이 떨린다.
 → 출금 버튼을 누른다. 한도 초과 — 1회 출금 한도 1천만 원.
 → 5분 안에 5억을 뺄 수 없다.
 → 23:56. 해킹 발생. 잔고가 0이 된다.
 → "안 돼—" 순간, 또 되감긴다.
 → 23:51. 세 번째 5분이 시작된다.
 → 이번엔 다르게 한다. 코인을 전량 매도. 테더(USDT)로 전환. 다른 거래소로 전송.
 → 23:55. 전송 완료 30초 전. 블록체인 컨펌 대기.
 → 23:55:45. 컨펌 완료.
 → 23:56. 해킹 발생. XX거래소 잔고 0원.
 → 도현의 다른 거래소 잔고: 5억 1,800만 원.
 → 1화 마지막 줄: "5분. 나한테는 5분이면 충분하다."
```

**후킹 구조**: 전액 손실(절망) → 투신(충격) → 5분 전으로 되감김(반전) → 첫 시도 실패(긴장) → 두 번째 되감기로 자산 구출 성공(쾌감). 5단 임팩트. 1화 안에 능력의 규칙(5분, 기억 유지, 반복 가능)과 한계(5분 밖 사건은 못 바꿈)를 자연스럽게 시연.

### 3.1 5분 루프 능력 규칙

| 항목 | 설정 |
|------|------|
| **능력명** | 5분 리와인드 (Five-Minute Rewind) |
| **발동 방식** | 의식적 발동. "되감아"라고 의지하면 현재 시점에서 정확히 5분 전으로 의식이 돌아감 |
| **시간 범위** | 5분 고정 (절대 불변). 4분도, 6분도 불가 |
| **일일 횟수** | 초기 하루 3회 → 성장에 따라 점진적 증가 (상세: 섹션 11) |
| **기억 유지** | 되감기 전의 기억 완전 보존. 물리적 변화(부상, 위치 이동 등)는 리셋 |
| **부작용** | 연속 사용 시 두통 → 코피 → 기억 혼선(현재와 되감기 전 기억이 뒤섞임) → 일시적 시력 상실 |
| **핵심 제약** | "5분 안에 일어나지 않는 사건은 예측 불가." 5분 뒤의 주가, 5분 뒤의 뉴스는 되감아 봐야 알 수 없음. 오직 "5분 안에 확인 가능한 정보"만 활용 가능 |
| **타인 인지** | 타인은 되감기를 인지하지 못함. 도현만 5분 후의 기억을 가짐 |
| **중첩 불가** | 되감긴 5분 안에서 또 되감기 불가. 5분이 완전히 흘러야 다음 발동 가능 |

## 11. 타임루프 전용 설정 (5분 루프 규칙 상세)

### 11.1 기본 규칙

| 필드 | 설정 |
|------|------|
| **loop_type** | 5분 리와인드 (Five-Minute Rewind) |
| **trigger** | 의식적 발동. 강한 의지로 "되감기"를 원하면 발동 |
| **duration** | 정확히 5분 전으로 회귀 (±0초, 절대 불변) |
| **daily_limit** | 초기 3회/일 → 성장에 따라 증가 (아래 성장 단계 참조) |
| **cooldown** | 되감긴 5분이 완전히 경과해야 다음 발동 가능 (중첩 불가) |
| **memory** | 되감기 전 5분간의 기억 완전 보존. 누적됨 |
| **physical_reset** | 되감기 시 신체는 5분 전 상태로 복귀 (부상 치유, 위치 리셋) |
| **external_reset** | 외부 세계도 5분 전으로 완전 리셋. 타인 기억 없음 |

### 11.2 제약 사항

| 제약 | 설명 | 서사적 기능 |
|------|------|------------|
| **5분 한계** | 5분 이전은 절대 불가. 6분 전에 일어난 사건은 되돌릴 수 없음 | 긴박감 유지. "5분 안에 해결해야 한다"는 시한 구조 |
| **정보 한계** | 5분 안에 확인 불가능한 정보(예: 봉인된 서류, 미도착 택배)는 루프로도 얻을 수 없음 | 먼치킨 제어. 모든 정보를 알 수 없음 |
| **중첩 불가** | 되감긴 5분 안에서 다시 되감기 불가 | 무한 루프 방지 |
| **물리적 한계** | 되감기로 5분 전 위치로 돌아감 → 5분 안에 이동 가능한 거리 내에서만 행동 가능 | 공간적 제약 |
| **타인 불인지** | 루프 사실을 타인에게 증명할 방법 없음 (되감기면 증거도 사라짐) | 고독감, 비밀 유지 긴장 |

### 11.3 부작용 에스컬레이션

| 단계 | 발생 시기 | 부작용 | 서사적 활용 |
|------|-----------|--------|------------|
| 1단계 | 하루 2~3회 사용 | 경미한 두통, 피로감 | 일상 묘사 |
| 2단계 | 하루 4~5회 사용 | 심한 두통 + 코피 | 사용 횟수 선택의 긴장 |
| 3단계 | 하루 6~7회 사용 | 기억 혼선 (현재와 되감기 전 기억이 뒤섞임) | 판단 오류 유발 → 패배 원인 |
| 4단계 | 하루 8회+ 사용 | 일시적 시력 상실 (수 분~수 시간) | 치명적 위기 상황 |
| 5단계 | 극한 사용 | 의식 상실 + 기억 영구 소실 위험 | 대단원 7 클라이맥스 |

## 13. 킬링포인트 요약 (마케팅 컷)

1. **"5분이면 충분하다"** — 코인 5분봉 하나로 인생을 바꾸는 남자. 문피아 코인 트렌드 직격
2. **5분의 한계가 만드는 긴장** — 만능 치트가 아닌 "5분 안에 해결해야 하는" 시한부 서스펜스. 매 거래가 타임어택
3. **코인→카지노→부동산→주식→기업인수→글로벌** — 투자 유형 14종. 매번 새로운 판에서 새로운 룰로 싸움
4. **능력자 대결** — 5분 루프 vs 30초 루프. "더 긴 시간을 되감는 자가 이기는 게 아니다"
5. **12번의 패배, 12번의 손실** — 되감아도 지는 싸움이 있다. 5분 밖의 세계는 치트로도 못 바꾼다
