# 컨셉기획 — 058. 게임 속 선협 서버에 갇힘

- **코드**: MAR-FUS-08
- **장르**: 무협 · 선협/수선/퓨전 · 게임 판타지
- **타겟 플랫폼**: 문피아 1순위
- **핵심 공식**: 수선전 네이밍 + "너무 쉽다" + 현대 시스템 융합
- **구조**: 7대단원 × 10블록 = 70블록
- **차별화 한줄**: 게임+선협. 게임 시스템(퀘스트/인벤토리/스킬트리)과 선협 수선 체계의 결합. 블루오션. 세대를 넘는 "게임 세계에 갇힌 아들을 걱정하는 아버지" 정서로 5060 타겟 확장 [P3 수정]

## 1. 로그라인

> 게임 폐인 대학생 **한시율**이 신작 VRMMO **"선계Online"** 선협 서버에 최초 접속하는 순간, 서버가 현실화되어 로그아웃이 불가능해진다. 게임 시스템(스테이터스 창, 퀘스트 로그, 인벤토리, 스킬트리)은 살아 있지만 NPC들은 자아를 가진 진짜 수선자가 되었고, 죽으면 진짜로 죽는다. 한시율은 **클로즈 베타 테스터**로서 아무도 모르는 히든 퀘스트·버그·미구현 콘텐츠 지식을 무기 삼아, "너무 쉽다"는 소리를 들으며 선협 세계를 공략해 나간다. 게임의 최종 보스를 쓰러뜨려야 로그아웃할 수 있다 — 하지만 최종 보스는 게임 개발자가 "절대 클리어 불가"로 설계한 존재다.

## 3. 세계관 & 장르 설정

### 판타지 요소

| 요소 | 설명 |
|------|------|
| **게임 시스템 잔존** | 스테이터스 창, 인벤토리, 스킬트리, 퀘스트 로그, 미니맵 등 게임 UI가 시율에게만 보인다. 세계가 현실화되었지만 시스템은 "게임의 껍데기"로 남아 작동. |
| **수선 체계 = 스킬트리** | 선계 수선자의 경지가 게임의 레벨·스킬트리와 대응. 시율만 이 대응 관계를 알고 있어 성장 루트를 최적화할 수 있다. |
| **NPC 자아 각성** | 게임 NPC가 자아를 가진 존재로 변화. 퀘스트를 "의뢰"로 인식하고, 선계의 역사와 감정을 가짐. 시율은 이들을 "NPC"로 볼 것인가 "사람"으로 볼 것인가의 윤리적 갈등. |
| **버그 = 세계의 틈** | 클베 때 발견한 버그들이 현실화된 세계에서 "시공간 균열"로 나타남. 버그를 이용하면 숏컷이 가능하지만, 세계 붕괴를 가속시킨다. |

### 배경 타임라인 / 세계관 체계

| 층위 | 게임 명칭 | 현실화 후 | 특징 |
|------|----------|----------|------|
| **초심자 영역** | Lv.1-30 존 | 하선계(下仙界) | 연기(靈氣) 희박. 초급 수선자·요수 서식. |
| **중급 영역** | Lv.31-70 존 | 중선계(中仙界) | 영기 보통. 중급 문파·도시 소재. 주요 스토리 진행. |
| **상급 영역** | Lv.71-100 존 | 상선계(上仙界) | 영기 농후. 대문파·선부(仙府) 소재. |
| **레이드 존** | Lv.100+ 레이드 | 천선계(天仙界) | 최상급 영역. 천선급 보스 다수. |
| **히든 존** | 미구현 콘텐츠 | 혼돈계(混沌界) | 개발자가 미완성으로 남긴 영역. 최종 보스 "혼돈마신" 소재. 세계 붕괴의 근원. |

- **갇힌 유저**: 최초 접속 시점 동시 접속자 약 1만 명. 시간이 지나며 사망·탈진으로 감소.
- **시간 흐름**: 게임 내 1일 = 현실 1시간(클베 설정). 현실화 후에도 동일. 현실 세계에서는 시율의 몸이 VR 캡슐 안에서 생명유지 상태.

## 6. 경지 성장 곡선

## 11. 전이/빙의 전용 설정

| 항목 | 설정 |
|------|------|
| **전이 방식** | VR 풀다이브 캡슐로 "선계Online" 접속. 서버 현실화로 로그아웃 불가. 의식이 게임 세계에 갇힘. 현실의 몸은 VR 캡슐 안에서 생명유지 상태. |
| **아바타/신체** | 게임 캐릭터 생성 시 만든 아바타 = 선계에서의 몸. 현실 외모와 90% 유사하게 생성했으나 약간 이상화됨. |
| **게임 시스템 잔존** | 스테이터스 창, 인벤토리(공간저장), 스킬트리, 퀘스트 로그, 미니맵, 파티 시스템 — 시율에게만 보이는 UI로 잔존. NPC에게는 보이지 않음. |
| **현대 지식 활용** | 게임 클베 지식(맵·AI패턴·퀘스트·버그), 프로그래밍 사고(시스템 로직 분석), 현대 전략 게임 사고방식. |
| **로그아웃 조건** | 최종 히든 퀘스트 완료 = 혼돈마신 문제 해결. 단순 처치가 아닌 "공존"이 진정한 클리어. |
| **사망 페널티** | 게임 시 부활 시스템 → 현실화 후 **사망 = 진짜 사망(현실 육체도 사망)**. 부활 불가. |
| **귀환 후** | 로그아웃 시 현실 귀환 가능. 단, NPC들의 세계는 독립적 현실로 계속 존재. 재접속 가능. |
