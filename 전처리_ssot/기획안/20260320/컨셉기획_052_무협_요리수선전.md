## 1. 로그라인

**선협 세계 최하층 잡역 요리사 백찬(白饌)이 우연히 '선주방(仙廚房)' 체질을 각성한다. 요리할수록 체내에 선단(仙丹)이 자연 응축되고, 그가 만든 음식을 먹은 자는 경지가 오른다 — 칼을 잡지 않아도 등선할 수 있는 가장 맛있는 수선이 시작된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 천운종(天雲宗) 주방, 새벽 4시.
 → 백찬(17세), 300명분 아침 식사 준비 중.
 → 외문 제자에게도 못 끼는 잡역 요리사, 영근(靈根)도 없는 범인(凡人).
 → "나한테 검을 쥐라고? 이 칼이면 충분해." (식칼을 들며)
 → 10년째 같은 주방. 수선자들이 먹다 남긴 영수(靈獸) 고기로
   겨우 국물을 끓이는 처지.

1화: 잔반 처리 중 사건.
 → 연단(鍊丹) 실패로 버려진 약재 찌꺼기를 국에 넣어본다.
 → "어차피 버릴 건데… 맛이라도 보자."
 → 끓이는 순간, 국에서 영롱한 빛이 피어오른다.
 → 한 모금 마신 백찬의 단전에서 따뜻한 기운이 돈다.
 → 머릿속에 투명한 창이 뜬다:
   [선주방 각성 — 요리 등급: 범품(凡品) | 선단 응축률: 0.3% | 경지: 연기 1층]
 → 1화 마지막 줄: "…국을 끓였을 뿐인데, 영기가 도는 거야?"
```

**후킹 구조**: 밑바닥 처지(공감) → 잔반+폐약재(비천한 시작) → 요리=수선(반전) → 시스템 창(장르 시그널). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **각성 방식** | 선계 토종 잡역 요리사가 폐약재 요리 중 돌연변이적 체질 각성 — 전이/회귀 아님 |
| **선주방(仙廚房) 체질** | 요리할수록 체내에 선단(仙丹)이 자연 응축되어 경지 상승. 더 높은 등급의 재료와 기법을 쓸수록 상승폭 증가 |
| **요리 시스템** | 머릿속에 '선주방 인터페이스' 구현 — 레시피 도감, 재료 감정, 선단 응축률 게이지, 요리 등급 판정 |
| **요리→경지 전환 법칙** | 재료 손질=경맥 정화, 조리=영기 순환, 완성=선단 응축, 먹는 자에게도 부분적 영기 전달 |
| **제약** | ① 같은 레시피 반복 시 응축률 급감 ② 실패 요리(독요리) 시 역류로 내상 ③ 고급 요리일수록 희귀 재료 필요 ④ 본인 전투력은 낮음 — 경지는 높지만 전투 기법 부재 |
| **비전투 수선의 핵심** | 요리로 타인의 경지를 올려주는 '선식(仙食)' 능력이 진짜 무기 — 동맹자를 강하게 만드는 지원형 |

### 3.2 배경 타임라인 (천운대륙 역사 활용)

| 시기 | 선계 사건 | 작중 활용 |
|------|-----------|-----------|
| 각성 직후 | 천운종 내부 약재 도난 사건 | **1화 기폭제** — 폐약재로 첫 요리, 체질 각성 |
| 1~2년차 | 천운종 문파 대항전 | 선식(仙食)으로 제자들 강화 → 이변적 성과, 명성 시작 |
| 3~4년차 | 영수(靈獸) 대발생 | 영수 식재료 대량 확보 기회 → 요리 등급 대폭 상승 |
| 5~6년차 | 선단사(仙丹師) 길드의 독점 논쟁 | 선식이 선단을 대체 가능? → 연단 세력과 정면 충돌 |
| 7~8년차 | 선계 오미대회(五味大會) 개최 | 대륙 최고의 요리 대회 → 명성의 정점 |
| 9~10년차 | 기근+마도 침공 | 대규모 선식 공급으로 정파 전력 유지 — 전쟁의 핵심 보급책 |
| 11~12년차 | 천도연(天道宴) 전설 발견 | 고대에 등선한 선인의 마지막 만찬 레시피 추적 |
| 13~14년차 | 등선 기회 | '천도연' 완성 → 요리로 등선하는 최초의 수선자 |

### 3.3 주인공 그룹 (선미각 · 仙味閣)

| 항목 | 설명 |
|------|------|
| **조직명** | 선미각(仙味閣) — 백찬이 독립 후 창설한 요리 수선 문파 |
| **초기 상태** | 천운종 주방 잡역 1인 |
| **주력** | 선식(仙食) 제조, 영수 식재료 가공, 선단급 요리 납품 |
| **최종 규모** | 대륙 유일의 요리 수선 종파 — 모든 종파가 의존하는 보급 허브 |
| **수입원** | 선식 납품, 연회 의뢰, 레시피 라이선싱, 식재료 거래 |

## 6. 경지 성장 곡선 설계

### 6.1 핵심 규칙
- 초기 경지: **무(無)** — 영근 없는 범인(凡人)
- 최종 목표: **대승선인(大乘仙人)** — 등선 직전
- **최소 7블록에서 경지 정체 또는 역행** 필수
- 경지 상승은 요리 완성과 연동: 더 희귀한 재료, 더 복잡한 기법, 더 혁신적인 레시피 필요
- 같은 레시피 반복 시 선단 응축률 급감 (레시피 다양화 강제)
- 요리 등급 체계: 범품(凡品) → 영품(靈品) → 선품(仙品) → 신품(神品) → 천품(天品)

### 6.2 경지 체계

```
연기(鍊氣) → 축기(築基) → 금단(金丹) → 원영(元嬰) → 화신(化神) →
연허(鍊虛) → 합체(合體) → 도겁(渡劫) → 대승(大乘) → 등선(登仙)
※ 각 경지 3단계(초기/중기/후기)
```

### 6.3 경지 곡선 개요 (70블록)

```
대단원 1 (Block 1~10): 각성기 — "국을 끓였을 뿐인데"
  시작: 무(無) → 종료: 축기 후기
  요리: 잡곡죽→약초탕→영수구이→선과(仙菓)
  패턴: 잡역 요리에서 점차 선식(仙食) 영역으로 → "너무 쉽다" 체감
  패배 블록: Block 4 (실패 요리로 내상, 경지 역행)
            Block 8 (재료 횡령 누명 → 주방 추방, 요리 불가)

대단원 2 (Block 11~20): 인정기 — "이 음식, 보통이 아니다"
  시작: 축기 후기 → 종료: 금단 후기
  요리: 영수정찬→약선(藥膳)→영과주(靈果酒)→선차(仙茶)
  패턴: 선식 효과 입소문 → 종파 인정 → 독립 준비
  패배 블록: Block 14 (독요리 사고 — 재료 오판으로 제자 중독)

대단원 3 (Block 21~30): 도약기 — "선단보다 맛있다"
  시작: 금단 후기 → 종료: 화신 초기
  요리: 선단급 선식→영수 만한전석→비전 약선→부활선식
  패턴: 선미각 창설 + 선단사 길드와 경쟁 → 명성 급상승
  패배 블록: Block 26 (선단사 길드 약재 전면 차단 → 핵심 레시피 제조 불가)

대단원 4 (Block 31~40): 시련기 — "음식으로 사람을 죽일 수도 있다"
  시작: 화신 초기 → 종료: 화신 후기 (정체 대단원)
  요리: 전장 군량선식→해독선식→비상 구황식
```
