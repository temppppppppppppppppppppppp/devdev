## 1. 로그라인

**42세, 아내의 외도로 이혼하고 전 재산을 잃은 중견기업 부장이 도피하듯 시골 폐교를 헐값에 매입한다. 그런데 운동장 지하에서 자원형 던전을 발견 — 던전 자원으로 폐교를 리모델링하고 죽어가는 마을을 살리며, 이혼남의 인생 2막이 시작된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 서울 가정법원.
 → "원고 측 주장을 인정합니다. 위자료 2억, 재산분할 70:30."
 → 법원 밖, 전처 옆에 서 있는 낯익은 남자 — 같은 회사 전무.
 → 주인공(오태산), 담배도 안 피우는 남자가 법원 화단 벤치에 앉아 하늘을 본다.
 → "18년이 이렇게 끝나는구나."

1화: 경북 ○○군, 폐교 앞.
 → 부동산 중개인이 건넨 서류. '○○초등학교(폐교) — 대지 1,200평, 건물 260평. 매각가 4,800만 원.'
 → 잡초가 허리까지 올라온 운동장, 깨진 유리창, 녹슨 철봉.
 → 태산이 교실 바닥에 이불을 깔고 첫 밤을 보낸다.
 → 새벽, 운동장 한가운데가 은은하게 빛난다. 삽으로 파보니 계단이 나온다.
 → 계단 끝, 동굴 입구에 떠오르는 반투명 문자: [자원 던전 · 1층 — 입장하시겠습니까?]
 → 1화 마지막 줄: "…미친, 이게 뭐야."
```

**후킹 구조**: 이혼 법정(공감·분노) → 폐교 매입(전환) → 첫 밤의 고독(감정) → 던전 발견(반전). 4단 임팩트. 카카오 "이혼 트리거" + 문피아 "사표내고 폐가를 샀더니 돈벼락" 공식의 결합.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소 — 던전 규칙

| 항목 | 설정 |
|------|------|
| **던전 위치** | 폐교 운동장 지하에만 존재하는 **개인 던전**. 타인에게 양도·이전 불가. 소유자(등기 명의인)만 입장 가능, 동행자는 소유자와 함께 입장 시 허용 |
| **던전 유형** | 전투형이 아닌 **자원형 던전**. 채집·채광·채취가 핵심. 몬스터는 자원 수호자로 등장 |
| **층수 구조** | 총 100층. 1~10층 일반 약초/농산물, 11~30층 희귀 약재/광물, 31~60층 마법 금속/보석, 61~100층 초희귀 자원(세계 유일) |
| **위험도** | 층수가 깊어질수록 수호 몬스터 강화. 10층마다 보스급 수호자 배치. 사망 시 1층으로 귀환(24시간 입장 불가) |
| **시간 규칙** | 던전 내부 시간 = 현실 시간 × 0.1 (던전 10시간 = 현실 1시간). 자원 채집 효율의 핵심 |
| **자원 반출** | 채집한 자원은 현실 세계로 반출 가능. 단, 1일 반출 한도 존재 → 층수 개방 시 한도 상향 |
| **폐교 연동** | 폐교를 리모델링(투자)하면 던전이 확장됨. 교실 수리 → 던전 내 휴식 공간 생성, 운동장 정비 → 던전 입구 확대, 급식실 복원 → 던전 내 조리/가공 기능 해금 |
| **성장 시스템** | 전투 레벨이 아닌 **채집 숙련도** 시스템. 약초학·광물학·재배학·가공학 4개 트리. 숙련도가 오르면 희귀 자원 식별·채집 가능 |
| **던전 비밀** | 던전은 전국에 잠재적으로 더 존재함 (폐교/폐광/폐공장 등 버려진 장소 아래). 주인공이 최초 발견자 |
