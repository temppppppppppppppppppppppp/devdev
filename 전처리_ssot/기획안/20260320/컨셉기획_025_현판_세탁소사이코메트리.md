## 1. 로그라인

**오하이오 깡촌에서 20년째 빨래만 돌리는 45세 한인 세탁소 주인 박정수. 어느 날 고객의 빈티지 재킷을 세탁하다 옷에 깃든 기억 — 1967년 우드스톡, 지미 헨드릭스의 무대 뒤 — 이 눈앞에 펼쳐진다. 빨래할수록 선명해지는 사이코메트리 능력. 남들에겐 헌옷이지만 그에게는 역사가 보인다. 세탁소에서 시작해 글로벌 아트딜러가 되기까지, 물건의 기억을 읽는 남자의 경제 역전극.**

## 3. 세계관 & 장르 설정

### 3.1 사이코메트리 능력 규칙

| 항목 | 설정 |
|------|------|
| **발동 조건** | 세탁(물+세제+마찰)의 3요소가 충족될 때만 발동. 단순 만지기로는 불가 |
| **대상 확장** | ① 의류(초기) → ② 직물/소품(대단원 2~) → ③ 가구/목재(대단원 3~) → ④ 금속/보석(대단원 4~) → ⑤ 건축물/부동산(대단원 6~) |
| **세탁 방식 확장** | 드라이클리닝 → 손빨래 → 스팀클리닝 → 초음파세척 → 산업용 세정. 각 방식별 읽히는 기억 계층이 다름 |
| **기억 선명도** | 물건의 역사적/경제적 가치에 비례. 값싼 양산품 = 흐릿한 잔상 / 역사적 명품 = HD급 풀컬러 영상+음향+냄새 |
| **시간 깊이** | 초기: 최근 50년만 / 성장 후: 200년 → 500년 → 1,000년+ |
| **부작용** | ① 두통 (초기) ② 타인의 기억 침식 — 물건 주인의 감정에 공감, 자아 경계 흐려짐 ③ 과다 사용 시 "기억 중독" — 현실과 환각 구분 불가 ④ 물건의 트라우마 기억(살인, 전쟁) 강제 체험 |

## 13. 킬링포인트 요약 (5개)

1. **"빨래하면 보인다" — 세탁소 사이코메트리** : 세탁이라는 가장 일상적 행위가 초능력 트리거. 매 회 "오늘 뭘 빨래할까"가 곧 사건의 시작. 문피아 "능력 숨김" 패턴의 극한 — 세탁소 아저씨가 글로벌 아트딜러.

2. **미국 깡촌 45세 아저씨의 역전** : 오하이오 인구 3천 마을에서 시작. 이혼, 아들과 불화, 영어 서투른 이민자. 가장 밑바닥에서 시작하는 블루칼라 판타지. 문피아 "미국 깡촌" 트렌드 정조준.

3. **골동품 시장의 실제 생태계** : 에스테이트 세일 → 플리마켓 → 지역 경매 → 소더비/크리스티 → 프라이빗 딜. 실재하는 골동품 유통 단계를 따라 올라가는 리얼리즘. "감정가 대비 몇 배"의 숫자 쾌감.

4. **물건이 품은 역사 — 에피소드 무한 생성기** : 매 블록마다 새로운 물건 = 새로운 역사적 이야기. 남북전쟁 군복, 마릴린 먼로의 드레스, 조선 백자, 나치 약탈 회화. "역사 속 이야기" 자체가 콘텐츠.

5. **부자(父子) 관계 + 이민자 서사** : 45세 아버지와 22세 아들의 화해가 감정 축. "아버지가 20년간 빨래만 한 게 아니었다"는 깨달음. 이민자의 꿈과 현실, 세대 간 갈등이라는 보편적 감정.
