## 1. 로그라인

**게이트가 열린 세상, 몬스터에게 당한 상처는 일반 의학으로 고칠 수 없다. 대형병원에서 쫓겨난 외과 레지던트가 마나 메스를 각성하고, 죽어가는 S급 헌터들의 마지막 희망 — '헌터 전담 외과의'가 된다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 대형병원 응급실. 오전 3시.
 → A급 헌터가 실려 온다. 복부에 독사 몬스터의 독아가 박혀 있다.
 → 담당 교수: "이건 수술로 안 돼. 마나 오염이 장기까지 퍼졌어."
 → 레지던트 한시율이 말한다: "교수님, 제가 해보겠습니다."
 → 교수: "네가? 의사면허 반납할 셈이야?"
 → 무시당한 시율. 그런데 환자의 마나가 폭주하기 시작한다.
 → 병원 전체가 마나 잔류파로 흔들린다. 의료진 전원 대피.
 → 시율만 남는다. 맨손으로 독아를 잡는 순간 — 손끝에서 푸른 빛.
 → 마나 메스 각성. 독아를 절제한다. 환자 안정.
 → 1화 마지막 줄: "한시율 레지던트, 수술 무단 시행으로 즉시 사직 처리합니다."
 → 병원에서 쫓겨나는 시율. 주머니에서 울리는 전화.
 → "한시율 씨? 헌터협회 의료지원단입니다. 제안이 있습니다."
```

**후킹 구조**: 응급 상황(긴박) → 무시당하는 주인공(감정이입) → 각성(반전) → 성공했는데 해고(아이러니) → 새 제안(기대). 5단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **게이트 시스템** | 10년 전 세계 동시다발 게이트 출현. 몬스터 출몰이 일상화. 헌터 등급제(E~SSS) 운영 |
| **마나 의학** | 몬스터에 의한 부상은 마나 오염을 동반. 일반 의학으로는 마나 잔류독 제거 불가 |
| **마나 메스** | 주인공 고유 능력. 마나를 메스 형태로 응축하여 마나 오염 조직을 절제·치유 |
| **헌터 전담 의료** | 초기에는 힐러(마법 치유사)에 의존 → 주인공이 '마나 외과학'이라는 새 분야를 개척 |
| **제약 조건** | 마나 메스 사용 시 시술자의 체력·마나 대량 소모. 하루 대수술 2건이 한계. 과로 시 손떨림 발생 |

| 시기 | 사건 | 작중 활용 |
