## 1. 로그라인

**지방대 건축학과 졸업 후 국내 취업에 실패한 33세 건설 노동자가 캄보디아 앙코르와트 인근 공사현장에서 고대 유적의 기둥을 건드린 순간 "건축 시스템"을 각성한다. 직접 시공에 참여한 건물마다 초자연적 버프가 발동하는 능력 ― 일용직 막노동꾼에서 세계 유산급 건축가로 올라서는 블루칼라 역전 서사.**

## 3. 세계관 & 장르 설정

### 3.1 건축 시스템 능력 규칙

| 항목 | 설정 |
|------|------|
| **각성 방식** | 앙코르와트 인근 미발견 고대 신전의 주춧돌 접촉. 크메르 건축신 비슈바카르만의 축복 |
| **핵심 원리** | 건물을 직접 시공하면 건축 경험치 획득. 완성된 건물에 버프 부여 가능 |
| **등급 체계** | F(견습 석공) → E(도제) → D(장인) → C(명장) → B(대장인) → A(건축사) → S(신전 건축가) → SS(대건축가) → SSS(세계유산급) |
| **버프 종류** | 내구도 강화, 에너지 효율, 치유 효과, 행운, 방어, 자정(자체 수리), 풍수(재운), 결계(외부 침입 차단), 생명력(식물 성장 촉진) 등 |
| **히든 스킬** | 고대 건축 양식(크메르, 이집트, 그리스, 고려, 로마, 무굴)을 연구하면 해금 — 양식별 고유 버프 존재 |
| **제약 ①** | 본인이 직접 시공에 참여해야 함. 지시만으로는 버프 발동 불가 |
| **제약 ②** | 등급 이상의 건물 시도 시 건물 붕괴 위험 + 시공자 체력 역류 피해 |
| **제약 ③** | 버프 부여 건물 수 = 현재 등급에 비례 (F등급: 동시 1채, SSS등급: 동시 100채) |
| **제약 ④** | 파괴 목적의 건축 불가. 사람을 해치려는 의도로 지으면 시스템 경고 후 등급 강등 |
