## 1. 로그라인

**선협 세계 말단 잡역 수선자 '서진'이 어느 날 눈앞에 현대 쇼핑몰 UI의 상점창을 얻는다. 영약·법보·진법 재료를 시세보다 싸게 사들이고, 필요한 자에게 비싸게 되팔며 수선 경지를 올린다. 돈이 곧 도(道)인 세계에서, 장사가 너무 쉬운 남자의 선협 경제 정복기.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 천풍종(天風宗) 잡역 제자 서진, 3년째 연성로(練星爐) 불 때는 중.
 → 동기들은 이미 축기 3층. 서진은 축기 1층도 못 넘겼다.
 → "서진, 너 이번 달 영석(靈石) 배급도 절반이다. 실적이 바닥이니까."
 → 굶주린 채 폐광 동굴에서 혼자 수련하던 밤.
 → 눈앞에 반투명 파란 창이 뜬다. 검색창, 장바구니, 결제 버튼.
 → [상점 시스템 활성화. 보유 자산: 영석 3개. 열람 가능 상품: 237건]
 → 가장 싼 품목: [하품 축기단(築基丹)] — 가격: 영석 2개
   → 시장가: 영석 50개.
 → 서진이 떨리는 손으로 '구매'를 누른다.
 → 허공에서 옥병이 떨어진다. 뚜껑을 열자 영약 향이 동굴을 채운다.
 → 1화 마지막 줄: "이걸로… 축기를 넘을 수 있다?"
```

**후킹 구조**: 바닥 인생(공감) → 상점창 등장(반전) → 시장가 대비 초저가(경제적 쾌감) → 성장 가능성(기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **시스템 방식** | 현대 쇼핑몰 UI의 상점창이 시야에 투영됨. 음성·사념 조작 가능 |
| **상점 규칙** | ① 경지가 오를수록 상위 품목 해금 ② 판매도 가능(NPC에게 비싸게 파는 것보다 상점 매각이 즉시 현금화) ③ 거래량 누적 시 '등급' 상승 → 독점 품목·경매·도매 기능 해금 |
| **화폐 체계** | 영석(靈石) 기반. 상점 내부 통화는 '선폐(仙幣)'로 영석과 교환 가능 |
| **시스템 제약** | ① 1일 거래 횟수 제한 (초기 3회 → 등급별 증가) ② 본인 경지보다 2단계 이상 높은 물품 구매 불가 ③ 거래 수수료 존재 (등급 올리면 감소) ④ 상점창 존재를 타인이 알면 '시스템 경고' 발동 |

### 3.2 배경 세계관 체계

| 항목 | 설명 |
|------|------|
| **세계명** | 천현대륙(天玄大陸) — 수선자와 무인이 공존하는 대륙 |
| **수선 경지** | 축기→금단→원영→화신→도합→대승→도극(渡劫)→선인 |
| **경제 구조** | 영석 본위제. 대종파가 영맥(靈脈)을 독점, 산문 수선자는 영석 부족이 만성적 |
| **주요 세력** | 5대 종파 + 3대 상회 + 마도 연맹 + 요족(妖族) 부락 |
| **핵심 갈등** | 영석 자원의 불균형 → 부익부 빈익빈 → 서진의 상점창이 이 구조를 깨뜨림 |

## 6. 경지 성장 곡선 설계

### 6.1 핵심 규칙
- 초기 경지: **축기 1층 미만** (영근 각성 전) → 최종: **도극(渡劫) 완료, 선인 문턱**
- 핵심 자원: 영석 보유량 + 상점 등급
- **최소 7블록에서 성장 정체 또는 역행** 필수
- 성장률 3블록 연속 동일 금지
