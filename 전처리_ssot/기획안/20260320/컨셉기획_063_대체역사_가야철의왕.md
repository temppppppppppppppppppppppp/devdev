# 컨셉 기획안 — 가야 철의 왕: 대장장이가 세운 제국

> 작성일: 2026-03-20
> 장르: 대체역사 · 문명건설 · 전쟁/밀리터리
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-KOR-03 (BATCH 07)

---

## 1. 로그라인

**2026년, 포항제철 야금공학 연구원이 42년(가야 건국기) 금관가야의 대장장이로 빙의한다. 역사에서 지워진 나라 가야 — 철의 기술은 동아시아 최고였으나 통일 국가를 이루지 못해 신라에 흡수된 연맹. 현대 야금학과 역사 지식을 무기로, 가야 6국을 통합하고 철의 제국을 건설한다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2026년, 포항 포스코 기술연구소.
 → 야금공학 연구원 서진우(35세). 고대 제철 기술 복원 프로젝트 중.
 → 가야 철기 유물의 금속 조직을 분석하다 감탄: "1세기에 이 수준의 강철이라니."
 → 유물 조각을 잡는 순간, 의식이 사라진다.

1화: 42년, 김해 구지봉 인근.
 → 눈을 뜬다. 대장간의 화덕. 손에는 망치.
 → 늙은 대장장이가 말한다: "야로(冶爐)야, 그 쇳물을 빼라!"
 → 진우(야로)는 깨닫는다: 여기가 김해(금관가야)이고,
   지금이 수로왕 건국 무렵이라는 걸.
 → 그리고 알고 있다: 이 나라는 결국 532년에 신라에 투항한다는 걸.
 → 이유를 안다: 6개의 가야가 끝내 하나가 되지 못했기 때문.
 → 1화 마지막 줄: "이 쇳물로… 나라를 만들겠다."
```

**후킹 구조**: 현대 야금 전문가(전문성) → 가야 대장장이(비천한 신분) → 500년 뒤 멸망(비극) → 철로 나라를 세우겠다(각오). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **빙의 방식** | 유물 접촉 의식 전이. 2026→42년(가야 건국기) |
| **지식 유지** | 현대 야금학·제철 기술·역사 지식 보존. 화학 원소 지식, 합금 비율 등 |
| **빙의 제약** | 현대 기술을 구현하려면 재료·인프라가 필요. 시간과 자원의 물리적 한계 |
| **빙의 증거** | 기술적 slip_up — "탄소 함량 0.8%"라 말하다 "쇳물 맛이 다르다"로 수정 |

## 6. 자본/성장 곡선 설계

### 6.1 핵심 규칙
- 초기 상태: **대장장이 한 명. 대장간 1개. 천민 신분**
- 최종 목표: **통일 가야 제국. 동아시아 철 산업 패권. 한반도 4강**
- **최소 7블록에서 국력 감소** 필수

### 6.2 국력 곡선 개요 (70블록)

```
대단원 1 (Block 1~10): 기술 혁신기
  시작: 대장장이 1명, 대장간 1개
  종료: 혁신 철기 공방 5개, 기술자 50명, 수로왕의 후원 확보
  패턴: 강철 생산 → 무기 품질 혁신 → 수로왕 주목 → 왕실 대장장이 발탁
  패배 블록: Block 4 (기존 대장장이 길드의 방해 — 공방 파괴)
            Block 8 (토착 족장의 철광석 공급 차단)

대단원 2 (Block 11~20): 경제 패권기
  시작: 왕실 대장장이
  종료: 가야 철 교역 동아시아 1위, 왜국·낙랑 교역 확립
  패턴: 철 무기 수출 → 교역 이익 → 금관가야 경제 패권 → 연맹 내 영향력 확대
  패배 블록: Block 14 (왜국의 기술 탈취 시도 — 기술자 납치)

대단원 3 (Block 21~30): 연맹 통합기
  시작: 금관가야 경제 패권
  종료: 가야 6국 중 4국 통합
  패턴: 경제적 종속 → 정치적 통합 → 군제 통합 → 비화가야·아라가야 저항
  패배 블록: Block 26 (비화가야의 군사적 저항 — 통합 전쟁)

대단원 4 (Block 31~40): 외부 위협 — 신라
  시작: 가야 4국 통합
  종료: 가야 6국 완전 통합 (신라 위협이 통합 촉매)
  패턴: 신라 침공 → 위기 → 잔여 2국 합류 → 통합 가야 방어 성공
  패배 블록: Block 33 (신라 기습 — 낙동강 동안 상실), Block 37 (내부 반란 — 친신라파 봉기)

대단원 5 (Block 41~50): 제국 건설기
  시작: 통일 가야
  종료: 한반도 4강 체제 (가야·신라·백제·고구려)
  패턴: 국가 체제 정비 → 군사 강화 → 해양 진출 → 국제 외교
  패배 블록: Block 44 (고구려 광개토대왕 남정 — 가야 북부 침공)

대단원 6 (Block 51~60): 철의 제국
  시작: 한반도 4강
  종료: 동아시아 철 산업 패권 확립
  패턴: 제철소 대형화 → 무기 수출 → 조선업 → 해양 세력
  패배 블록: Block 55 (신라·백제 연합 공격 — 양면 전쟁)

대단원 7 (Block 61~70): 가야 천년의 꿈
  시작: 철의 패권
  종료: 가야 제국 확립 (또는 후계자 체제 구축)
  패턴: 고구려와의 최종 대결 → 4강 평화 → 해양 진출 → 제국 선언
  패배 블록: Block 65 (고구려의 최종 남정 — 전면전)
```
