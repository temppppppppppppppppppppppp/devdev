# 컨셉 기획안 — 조선 발명가 장영실이 산업혁명을 앞당기다

> 작성일: 2026-03-20
> 장르: 대체역사 · 문명건설 · 과학/기술물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-KOR-09 (BATCH 07)

## 1. 로그라인

**2026년, KAIST 기계공학과 교수 오현석(45세)이 1420년(세종 2년) 관노(官奴) 장영실(蔣英實)로 빙의한다. 천민 출신 천재 발명가 — 그러나 현실은 인간 취급도 못 받는 관노. 현대 공학 지식을 가진 남자가, 세종대왕의 후원 아래 조선에서 산업혁명을 일으킨다. 자격루를 넘어, 증기기관을 향해.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2026년, KAIST 기계공학과 실험실.
 → 오현석 교수. 조선시대 자격루 복원 프로젝트 진행 중.
 → "장영실이 현대 공학을 알았다면, 세종 시대에 산업혁명이 가능했을까?"
 → 자격루 복원 모형을 만지다 쓰러진다.

1화: 1420년(세종 2년), 동래현 관아.
 → 눈을 뜬다. 거친 마당. 대장간 열기. 노비 표식의 옷.
 → 주인(관리)이 말한다: "영실아, 세종대왕께서 네 재주를 들으시고
   한양으로 올리라 하신다."
 → 현석(영실)은 안다: 이것이 역사의 시작이다.
   세종이 장영실을 한양으로 불러올리는 1421년 직전.
 → 그리고 안다: 역사에서 장영실은 자격루·측우기·해시계를 만들고,
   1442년 가마 사건으로 파직되어 역사에서 사라진다.
 → 1화 마지막 줄: "폐하, 저는 시계보다 더 큰 것을 만들 수 있사옵니다."
```

**후킹 구조**: 현대 공학 교수(전문성) → 관노(최하층) → 세종의 부름(기회) → 산업혁명 선언(야심). 4단 임팩트.

```

  시작: 관노. 대장간 기술자
  종료: 면천(신분 해방). 궁중 기술자. 첫 발명품(개량 물시계)

  패턴: 자격루 설계 → 제작 → 완성 → 추가 발명(해시계·혼천의)

  시작: 종3품 대호군
  종료: 측우기·갑인자 완성 + 수력 기계 도입
  패턴: 측우기 → 갑인자 → 수력 방직기 → 초기 산업화 구상
  패배 블록: Block 26 (명나라 사신의 기술 탈취 시도 — 기밀 유출 위기)

  시작: 수력 기계 단계
  종료: 증기기관 원형 실험 성공. 그러나 정치적 위기
  패턴: 증기 원리 실험 → 보일러 시제품 → 증기 펌프 → 정치 반발
  패배 블록: Block 33 (증기 보일러 폭발 사고 — 부상자 발생)

대단원 5 (Block 41~50): 가마 사건과 위기
  시작: 증기기관 원형
  종료: 가마 사건 발생. 파직 위기. 세종의 최후 보호
  패턴: 가마 제작 → 파손 → 음모 밝혀짐 → 세종의 보호 → 위기 탈출
  패배 블록: Block 44 (가마 파손 사건 — 파직 명령)

  종료: 방직기·증기 펌프 실용화. 조선 초기 산업화
  패턴: 복직 → 증기기관 실용화 → 방직 공장 → 광산 배수 펌프

대단원 7 (Block 61~70): 조선 산업혁명

  종료: 조선 산업혁명 기반 확립 (또는 유산으로 남기기)

  패배 블록: Block 65 (세종 사후 정치 변동 — 기술 혁신 중단 위기)
```
