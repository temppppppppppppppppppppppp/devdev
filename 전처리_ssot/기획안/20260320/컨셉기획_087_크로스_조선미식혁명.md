# 컨셉기획 087 — 조선미식혁명

- **코드**: XGN-EXP-07
- **장르**: 크로스장르 (대체역사 + 요리)
- **타겟 플랫폼**: 문피아 / 카카오페이지 양면
- **BATCH**: 09 크로스장르 블루오션 실험

---

## 1. 로그라인

**조선 최고의 숙수였으나 역모 누명으로 죽임당한 주인공이, 10년 전 견습 시절로 회귀하여 서양·동남아·중화의 식재료와 조리법을 조선 궁중 요리에 접목, '미식 혁명'을 일으키며 왕의 수라상부터 조선의 외교·경제까지 바꿔 나가는 대체역사 요리 서사.**

## 2. 1화 후킹 시퀀스

```
[시퀀스 1] 사약 — 주인공 '서찬'은 대령숙수로서 왕의 수라를 책임지던 중,
           반대 세력이 수라에 독을 넣어 역모 누명을 씌운다.
           사약을 받아 마시는 순간, 혀끝에 느껴지는 마지막 맛 — 쓴 감초.

[시퀀스 2] 회귀 — 눈을 뜨니 10년 전, 사옹원(司饔院) 견습 숙수 시절.
           손에 쥔 것은 무를 깎는 칼 하나. 옆에서 선배가 호통친다.
           "이놈, 무 하나를 종일 깎고 있느냐!"

[시퀀스 3] 첫 번째 요리 — 견습 평가 시험에서, 전생의 기억으로
           '서양식 버터 풍미'를 떠올리며 소기름을 정제하여 무나물에 입힌다.
           심사관(내시)이 한 입 먹고 눈이 커진다.
           "이것이… 무나물이란 말이냐?"

[시퀀스 4] 떡밥 투하 — 심사관이 놀란 사이, 주인공 독백:
           "이번 생에서는 내가 수라상의 주인이 된다.
            그리고 나를 죽인 놈들, 반드시 혀끝으로 굴복시키겠다."
```

**후킹 구조**: 사약(죽음) → 회귀(두 번째 기회) → 압도적 요리(먼치킨 시그널) → 복수 선언(장기 목표 제시). 1화 안에 '왜 읽어야 하는가'를 네 박자로 확정.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 요소 | 설명 |
|------|------|
| 회귀 | 사약으로 죽은 뒤 10년 전 견습 시절로 돌아옴. 1회성 회귀 |
| 미각 각성 | 전생 기억과 함께 '절대미각' 발현 — 재료의 상태·산지·숙성도를 혀로 감별 |
| 요리 시스템 | 요리 완성 시 '맛의 경지' 시각화 (은은한 빛, 향기 묘사). 먹는 이에게 기력 회복·독 해독 등 부가 효과 (과장되지 않은 수준) |
| 레시피 해금 | 전생 기억이 단편적으로 떠오르는 방식. 특정 식재료를 접하면 관련 조리법 플래시백 |

### 3.2 배경 타임라인

| 시기 | 설정 |
|------|------|
| 본래 역사 | 조선 중기 (17세기 초, 광해군~인조 시대 모티브) |
| 대체역사 분기점 | 주인공이 서양·일본·동남아 식재료를 조선에 조기 도입하면서 무역·외교 노선이 바뀜 |
| 시작 시점 | 견습 숙수 (16세) — 사옹원 말단 |
| 종료 시점 | 어선별감 + 조선 미식 외교의 설계자 (약 15년 후) |
| 핵심 변화 | 조선이 쇄국 대신 '미식 외교'로 네덜란드·일본·청과 교류 → 경제·문화 강국화 |

### 3.3 주인공 그룹

| 이름 | 역할 | 핵심 특성 |
|------|------|-----------|
| 서찬(徐饌) | 주인공 / 회귀 숙수 | 절대미각, 전생 지식, 집요한 복수심 + 요리에 대한 순수한 열정 |
| 금이(錦伊) | 사옹원 비자(婢子) / 히로인 | 후각 천재, 양념·발효 전문. 전생에서 주인공을 도우다 함께 죽음 |
| 박치문 | 약재상 / 조력자 | 전국 물류망 보유. 이문에 밝지만 의리 있음. 식재료 수급 핵심 |
| 하연 | 역관(譯官) / 해외 루트 | 일본어·네덜란드어 가능. 해외 식재료 밀수입 → 공식 무역으로 전환 |

## 13. 킬링포인트 요약

1. **회귀 숙수의 먼치킨 요리** — 전생 대령숙수의 기술로 견습 시절부터 압도. 매 요리마다 "이것이 조선의 맛이냐?"라는 반응 양산
2. **문화 충돌 미식** — 조선 궁중 요리 × 서양 버터·치즈 × 일본 우마미 × 동남아 향신료. 이질적 조합이 만드는 새로운 맛의 쾌감
3. **수라상 정치극** — 요리 한 그릇이 곧 정치. 왕의 입맛을 사로잡는 것이 권력 투쟁의 무기
4. **스승의 죽음과 유산** — 윤상궁의 퇴장이 만드는 감정 폭발 + 봉인된 레시피 노트의 장기 복선
5. **대체역사 분기** — 미식 하나로 조선의 외교·경제가 바뀌는 거시적 쾌감. "요리사가 나라를 바꿨다"
