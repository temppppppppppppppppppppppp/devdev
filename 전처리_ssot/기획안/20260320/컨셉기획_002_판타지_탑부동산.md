# 컨셉 기획안 — 탑 내부 부동산 개발자: 층마다 짓고 임대합니다

> 작성일: 2026-03-20
> 장르: 현대판타지 · 헌터물 · 탑물 · 경영
> 플랫폼 타겟: 카카오페이지 (1순위), 문피아 (2순위)
> 배치: BATCH 01 / #002 / FAN-HNT-02

---

## 1. 로그라인

**D급 판정으로 전투는 포기한 전직 건축사 헌터가, 탑 내부에 건물을 짓고 헌터에게 임대하면 건물 등급에 비례해 버프가 걸리는 '건축 시스템'을 각성한다. 전투력 대신 부동산 가치가 성장 지표 — 탑의 모든 층은 그의 임차인이 된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 탑 5층 보스 레이드.
 → 주인공 한준혁(35), D급 서포터. 바리케이드 설치 담당.
 → 레이드 실패. 파티 전멸 직전 구조됨.
 → 길드장: "한 기사, 다음 레이드부턴 빠져. 전투는 무리야."
 → 해고. 건축사 자격증만 남았다.

1화: 탑 1층, 빈 공터.
 → 준혁이 자조하며 탑 1층을 배회한다.
 → 습관적으로 벽을 두드린다. "여기 구조적으로 허술한데…"
 → 시스템창이 뜬다.
 → [건축 시스템 활성화]
 → [이 층에 건축 가능한 부지: 3곳]
 → [건축물 종류: 휴식소(E급) / 무기 보관소(E급) / 식당(E급)]
 → 준혁이 주머니의 마나스톤 3개(전 재산)로 '휴식소'를 짓는다.
 → 허름한 오두막 하나. 그 안에 들어간 헌터의 HP가 회복되기 시작한다.
 → 지나가던 C급 헌터: "여기 뭐야? HP가 차는데?"
 → 준혁의 눈이 빛난다.
 → 1화 마지막 줄: "1박에 마나스톤 2개입니다."
```

**후킹 구조**: 레이드 해고(좌절) → 건축 시스템 발현(반전) → 버프 건물(놀라움) → "1박에 마나스톤 2개"(경제 쾌감). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **건축 시스템** | 탑 내부에 건물을 지으면 해당 건물의 기능이 실제 효과 발동. 건물 등급(E~SSS)에 따라 버프 강도 상승 |
| **성장 축** | 건축 등급(E~SSS) + 부동산 포트폴리오(보유 건물 수 × 등급 × 임대료) |
| **탑 구조** | 100층 탑. 10층마다 보스층. 현재 인류 최고 도달층: 50층 |
| **제약** | ① 건축에 마나스톤 필요(비용) ② 한 층에 최대 5동 ③ 건물 유지에 월 마나 비용 ④ 준혁 본인 전투력 D급 고정 |
| **경제** | 임대료 = 마나스톤. 층이 높을수록 임대료↑, 건축 비용도↑ |
