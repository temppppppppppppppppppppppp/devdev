# 컨셉기획 082 — 조선에서 라이브 중입니다

- **코드**: XGN-EXP-02
- **장르**: 대체역사 + 스트리밍 (크로스장르 블루오션)
- **타겟 플랫폼**: 문피아 / 카카오페이지 양면
- **분량 목표**: 7대단원 × 10블록 = 70블록 (블록당 약 7~10화, 총 490~700화)
- **기획일**: 2026-03-20

---

## 1. 로그라인

**구독자 300명의 망한 스트리머 한시율이 조선 중종 시대로 전이된다. 그런데 방송 장비가 작동한다 — 현대 시청자에게 조선시대를 실시간 송출. 구독자 수가 곧 권력이 되고, 채널 등급이 올라갈수록 역사를 바꿀 수 있는 '역사 개입 권한'이 열린다. 조선을 바꾸고, 역사를 뒤집고, 구독자 1000만을 찍어라.**

- 망한 스트리머 공감 → 이세계(조선) 전이 → 방송이 연결된다는 반전

## 5. 적대자 변천사

### Phase 1: 훈구파 — 남곤 세력 (B01~B40)

| 항목 | 내용 |
|------|------|
| 정체 | 조선 기득권 세력. 조광조의 사림파 개혁을 저지하려는 훈구 대신들 |
| 수장 | 남곤 (좌의정). 홍경주, 심정 등 훈구 핵심 |
| 위협 방식 | 시율을 '요승(妖僧)' '서양 간첩'으로 몰아 처형 시도, 사림파 탄압 |
| 시율과의 갈등 | 시율의 방송이 민심을 움직이자 → "괴이한 술법으로 민심을 현혹" 탄핵 |
| 약점 | 내부 분열(이익 다툼), 민심 이반, 중종의 신뢰 상실 |

### Phase 2: 외척 세력 — 김안로 일파 (B25~B55)

| 항목 | 내용 |
|------|------|
| 정체 | 훈구파 몰락 후 부상하는 외척 세력. 왕실 혼인으로 권력 장악 |
| 수장 | 김안로 (중종의 장인 측근) |
| 위협 방식 | 왕실 내부에서 시율 배제 공작, 방송 장비 탈취 시도, 암살 조직 동원 |
| 시율과의 갈등 | 시율이 키운 개혁 세력이 외척 이익을 침해 → 전면전 |
| 약점 | 민심에 기반이 없음. 시율의 방송력(여론)에 취약 |

### Phase 3: 시스템 자체 — 역사 보정력 & 현대 권력 (B45~B70)

| 항목 | 내용 |
|------|------|
| 정체 | 역사가 원래 궤도로 돌아가려는 '보정력' + 현대 정부의 시공 연결 통제 시도 |
| 역사 보정력 | 기묘사화를 막으면 다른 형태의 비극이 발생. 역사가 스스로 교정 시도 |
| 현대 권력 | 정부 기관이 시율의 방송을 국가안보 위협으로 판단, 차단/통제 시도 |
| 위협 방식 | 역사 보정 = 자연재해·역병·암살 등 '운명적 사건' 연쇄 발생 / 현대 = 방송 차단·채널 정지 위협 |
| 약점 | 보정력은 구독자(민심) 규모로 상쇄 가능. 현대 권력은 여론전으로 대응 |

## 6. 자본/성장 곡선

### 6.1 핵심 규칙

| 성장 지표 | 설명 |
|-----------|------|
| 구독자 수 = 영향력 | 구독자가 늘수록 조선 내 발언권·신뢰도 상승 (시스템이 '위광' 부여) |
| 채널 등급 = 권력 범위 | 동(마을) → 은(고을) → 금(한양) → 백금(전국) → 다이아(동아시아) → 마스터(세계) → 그랜드마스터(역사 자체) |
| 슈퍼챗 = 자금 | 현대 후원금 → 조선 화폐 전환. 경제력 기반 |
| 시청자 투표 = 역사 분기 | 중요 갈림길에서 시청자 투표 → 대체역사 방향 결정 |
| 콘텐츠 퀄리티 = 능력치 | 좋은 콘텐츠(조회수 높음) → 시율 신체/지식 버프 |

## 11. 회귀/빙의 전용 설정

본작은 **시공 전이(Temporal Transfer)** 메커니즘 사용.

| 항목 | 설명 |
|------|------|
| 전이 조건 | 조선 시대 정만조의 천문 관측 의식 + 시율의 방송 전파가 시공 공명 |
| 신체 | 시율 본인의 몸 그대로 전이 (빙의 아님). 현대인 외모 유지 |
| 장비 | 스마트폰, 보조 배터리, 이어폰 — 용맥 에너지로 무한 충전 |
| 귀환 조건 | 그랜드마스터 등급 달성 후 '귀환 선택권' 해금. 단, 조선 잔류도 가능 |
| 시간 동기화 | 조선 1일 = 현대 1일. 양쪽 세계 동시 진행 |
| 방송 제약 | 방송 범위는 채널 등급에 비례. 초반에는 음성+화면만, 후반에는 멀티캠·드론뷰 해금 |
| 사망 시 | 조선에서 사망 → 현대로 강제 귀환, 단 재전이 불가. 모든 것 종료 |

## 13. 킬링포인트 요약

1. **구독자 수 = 권력** — 현대 스트리밍 성장 서사와 조선 정치 권력 서사의 완벽한 결합. 구독자가 오를 때마다 조선에서의 위상이 상승하는 이중 쾌감.
2. **시청자 참여형 대체역사** — 독자가 시청자 입장에서 투표·후원하는 몰입 구조. "내가 역사를 바꾼다"는 참여감.
3. **조선 먹방·관광·체험 콘텐츠** — 스트리밍 특유의 다양한 콘텐츠 유형을 조선 배경으로. 긴장 사이의 유머와 힐링.
4. **기묘사화를 막아라** — 실제 역사의 비극을 막는 대체역사 카타르시스. 역사 팬 + 판타지 팬 양쪽 타겟.
5. **현대-조선 이중 세계 동시 진행** — 조선 사건이 현대에 실시간 영향, 현대 반응이 다시 조선에 영향. 양방향 서사의 신선함.
