## 1. 로그라인

**레벨 0, 스킬 0, 헌터 전용 던전 셔틀버스 기사가, 버스에 탑승한 헌터의 스킬을 하차 시까지 일시 복사하는 '카피 시스템'을 각성한다. 매회 다른 능력, 매회 다른 전투 — 승객이 곧 그의 스킬창이다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 던전 앞 주차장.
 → 주인공 문재영(38), 0레벨 무각성. 직업: 헌터 전용 셔틀버스 기사.
 → 매일 헌터를 던전 앞까지 태워다준다. 20인승 소형 버스.
 → S급 헌터가 탄다. "아저씨, 빨리 좀 갑시다."
 → 재영이 묵묵히 운전한다. 버스 안은 갑옷과 무기로 가득하다.
 → "이 일 10년째인데… 한 번도 던전에 들어가본 적이 없지."

1화: 버스 내부.
 → 갑자기 도로에 게이트가 열린다. 버스째 게이트 안으로 빨려 들어간다.
 → 승객 S급 헌터 3명, A급 5명, B급 12명.
 → 게이트 안은 A급 던전. 몬스터가 몰려온다.
 → 재영은 운전석에 웅크린다. 0레벨. 할 수 있는 게 없다.
 → 시스템창이 뜬다.
 → [카피 시스템 활성화]
 → [현재 탑승자 20명 — 스킬 복사 가능]
 → [복사 가능 스킬: S급 '절대검' / A급 '화염창' / B급 '치유' …총 47개]
 → [제한: 동시 활성 3개, 하차 시 소멸]
 → 재영이 '절대검'을 복사한다. 손에 검기가 피어오른다.
 → 1화 마지막 줄: "승객 여러분, 기사가 잠시 내립니다."
```

**후킹 구조**: 0레벨 버스기사(좌절) → 게이트 조난(절박) → 승객 스킬 복사(반전) → "기사가 내립니다"(유머+기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **카피 시스템** | 버스(차량) 탑승자의 스킬을 일시 복사. 승객이 하차하면 해당 스킬 소멸 |
| **복사 규칙** | ① 동시 활성 3개(초기)→5→7→10개 ② 복사 등급은 원본의 70%(S급→A+) ③ 탑승자 본인 동의 불필요 ④ 같은 승객 재탑승 시 새로 복사 가능 |
| **성장 축** | 동시 활성 슬롯 수 + 복사 정밀도(%) + 차량 등급(일반 버스→마나 버스→차원 버스) |
| **제약** | ① 0레벨 고정(본인 고유 스킬 없음) ② 승객 없으면 무능력 ③ 차량 파괴=시스템 비활성 ④ 복사 정밀도 70%(원본보다 약함) |
| **차량 업그레이드** | 버스 개조 → 마나 엔진 → 차원 이동 기능 |

### 3.2 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 헌터 셔틀 서비스 보편화 | 재영의 직업 배경 |
| 1개월 후 | 갑작스런 게이트 폭주 | 버스째 게이트 진입 빈도 증가 |
| 1년 후 | 카피 드라이버 인정 | 신직업 창설 |
| 3년 후 | 글로벌 원정 버스 | 해외 게이트 원정 |
| 5년 후 | 차원 버스 | 차원간 이동 가능한 최종 버스 |

### 3.3 주인공 그룹

| 항목 | 설명 |
|------|------|
| **상호** | '재영 셔틀' (1인) → '카피 드라이브' 길드 |
| **차량** | 초기: 20인승 소형 버스 → 최종: 50인승 마나 버스 |
| **승객** | 초기 20명 제한 → 최종 50명(=스킬 풀 150개+) |
