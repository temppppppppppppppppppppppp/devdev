# 컨셉 기획안 — 아공간 팩토리 노동자 회귀: 공장을 아는 자가 세계를 지배한다

> 작성일: 2026-03-20

## 1. 로그라인

**전생에서 아공간 팩토리의 노예 노동자로 10년을 착취당하다 과로사한 E급 헌터가, 아공간이 열리기 3년 전으로 회귀한다. 아무도 모르는 아공간 팩토리의 생산 시스템 지식 — 그것이 이번 생의 치트키다.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 아공간 팩토리, 전생.
 → 주인공 정태호(29), E급 헌터. 아공간 팩토리 생산라인 3번.
 → 하루 18시간 마나스톤 정제 노동. 10년째.
 → "태호야, 오늘 할당량 300개. 못 채우면 식사 없어."
 → 태호의 손이 떨린다. 마나 고갈. 시야가 흐려진다.
 → 쓰러진다. 과로사.
 → 마지막으로 본 건 팩토리 천장의 생산 시스템 배치도.

1화: 2023년, 서울 고시원.
 → 태호가 눈을 뜬다. 좁은 고시원 방.
 → 달력: 2023년 3월. 아공간 최초 출현 3년 전.
 → [회귀 확인: 2033→2023, 10년 역행]
 → 태호의 머릿속에 팩토리의 모든 것이 있다.
 → 생산 라인 배치, 마나스톤 정제법, 아이템 제작 공식, 아공간 확장법.
 → "이번엔 내가 노예가 아니라 주인이 된다."
 → 1화 마지막 줄: "3년 후, 아공간이 열린다. 그 전에 준비를 끝낸다."
```

**후킹 구조**: 팩토리 노예 과로사(충격) → 10년 회귀(반전) → 생산 지식 치트(기대) → 3년 준비 시한(긴박). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **회귀** | 2033→2023, 10년 역행. 아공간 출현 3년 전으로 |
| **기억 유지** | 전생 팩토리 10년 경험 완전 보존. 생산 시스템, 마나스톤 정제, 아이템 제작 공식 |
| **회귀 제약** | ① 미래 기억 중 팩토리 외 정보는 흐림(노예였으므로 바깥세상 정보 제한) ② 나비효과로 미래 변동 ③ 아공간 출현 시기는 고정이나 규모는 변동 가능 |
| **아공간 팩토리** | 전생에서 대형 길드가 운영하던 아공간 생산 시설. 마나스톤 정제, 아이템 제작, 포션 합성 등 |
| **성장 축** | 팩토리 효율(생산량/시간) + 생산 라인 수 + 아공간 규모 |
