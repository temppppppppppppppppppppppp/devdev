## 1. 로그라인

서울대 이론물리학 교수 박정우(42)는 국제 학술대회 논문 심사 도중 원인 불명의 차원 전이를 겪어 마법이 지배하는 이세계에 떨어진다. 마나 수치 '완전한 0'이라는 전대미문의 측정 결과에 조롱을 받지만, 열역학·전자기학·양자역학으로 마법의 본질을 해석해 내며 엘드리안 아카데미의 이론마법학 교수로 채용된다. 경험과 감각에만 의존하던 마법 체계를 수식으로 재구성하고, 마나 공학 장치를 설계해 '마나 없이 마법을 쓰는' 전무후무한 길을 개척한다. 비주류 제자들을 최강으로 키우고, 마법 전통파·마탑 연합의 탄압을 뚫고, 궁극적으로 차원 침략자에 맞서 물리+마법 융합 문명을 완성하는 이공계 먼치킨 아카데미물.

**핵심 공식**: 숨겨진 실력(다른 방식의 강함) + 아카데미
**차별화**: 과학과 마법의 결합. 문피아 "물리학을 숨김" 계열의 확장판으로, 단순 치트키가 아닌 '이론→실증→체계화'의 학술적 과정 자체를 서사로 풀어낸다.

## 2. 1화 후킹 시퀀스

**오프닝 장면 — "이 마법은 틀렸습니다."**

1. **프롤로그 (현대)**: 박정우는 서울대 연구실에서 초끈이론 관련 최종 논문을 교정 중이다. 동료 교수와 전화 통화 — "정우야, 네 논문이 PRL에 실리면 한국 이론물리학 역사가 바뀐다." 차분하게 웃는 정우. 그러나 모니터 화면에 원인 불명의 파형이 뜨고, 연구실 전체가 푸른빛에 휩싸인다.
2. **전이 직후**: 눈을 뜨면 중세풍 석조 광장. 하늘에 달이 두 개. 정우는 습관적으로 중력가속도를 체감 계산한다 — "9.8이 아니야… 9.2 정도?" 물리학자의 본능이 먼저 반응한다.
3. **첫 번째 마법 목격**: 광장에서 마법사 둘이 결투 중. 화염구가 날아간다. 정우의 눈에는 에너지 전환 과정이 보인다 — "열에너지 변환 효율이 30%도 안 되는데 저걸 '고위 마법'이라고?" 혼잣말이 주변 마법사들의 분노를 산다.
4. **마나 측정 사건**: 기사단에 끌려가 '마나 측정 수정구'에 손을 댄다. 수치: 0. 완전한 0. 측정 담당관이 고장인 줄 알고 수정구를 세 번 교체한다. 결과는 같다. "마나가 0이라니, 이런 존재는 기록에도 없다." 조롱과 동정이 뒤섞인 시선.
5. **반전 후킹**: 감옥에 갇힌 정우. 벽에 손을 댄다. 석재의 결정 구조를 손끝으로 느끼며 중얼거린다 — "이 세계 원자 구조는 우리 세계와 거의 동일해. 다만… 전자 궤도에 미지의 에너지장이 하나 더 있어. 그게 '마나'인 거지." 공중에 손가락으로 슈뢰딩거 방정식 변형을 쓰기 시작한다. 수식이 빛나며 감옥 벽이 진동한다. 간수가 경악 — "마, 마법?! 마나가 0인데 어떻게?!" 정우가 안경을 고쳐 쓰며 말한다. **"마법이 아닙니다. 물리학입니다."**

**1화 마지막 줄**: *그리고 이것이, 이 세계 마법의 역사를 송두리째 바꿔놓을 한 남자의 첫 수업이었다.*

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소 (표)

| 요소 | 설정 | 물리학 해석 |
|------|------|-------------|
| 마나 | 모든 생물과 자연에 존재하는 근원 에너지. 마나핵(인체 단전 유사 기관)에서 생성 | 전자 궤도 외부의 5번째 기본 상호작용. 정우는 이를 '마나장(Mana Field)'으로 정의하고 양자장론으로 기술 |
| 마법 | 마나를 의지로 조작해 현실에 영향을 미치는 행위. 주문·마법진이 촉매 | 마나장의 위상 변환. 주문은 '공명 주파수', 마법진은 '경계조건 설정 도구'. 정우는 수식으로 직접 경계조건 계산 |
| 마법 등급 | 1서클~9서클 (9가 최고). 10서클은 전설(신화급) | 마나장 조작의 자유도(차원 수). 1서클=1차원 조작, 9서클=9차원 동시 조작. 정우의 해석으로 '반정수 서클'도 가능해짐 |
| 마나핵 | 심장 옆에 위치한 에너지 기관. 선천적 크기가 재능 결정 | 마나장과 물질계를 잇는 '변환기(transducer)'. 정우에겐 없지만 외장형 변환기(마나 공학 장치)로 대체 |
| 마법 속성 | 화·수·풍·토·뇌·빛·암 7속성 | 마나장의 진동 모드(파동 함수의 고유 상태). 속성 간 전환은 모드 변환으로 가능 → 정우가 '무속성 마법' 개념 창시 |
| 소환마법 | 다른 차원의 존재를 불러오는 고위 마법 | 차원 간 양자 터널링. 소환진은 터널링 확률을 높이는 포텐셜 우물 설계 |
| 부여마법 | 물체에 마법적 속성을 각인 | 물체 원자 결정 격자에 마나장 정보를 인코딩(고체물리학). 정우가 이를 최적화해 부여 효율 300% 향상 |
| 결계 | 공간을 격리하는 방어 마법 | 마나장의 포텐셜 장벽 생성. 슈뢰딩거 방정식의 무한 포텐셜 우물과 동일 원리 |
| 치유마법 | 생체 손상 복구 | 세포 내 마나장 정보의 복원(양자 오류 정정 코드 적용). 정우가 치유 효율을 획기적으로 개선 |
| 신성마법 | 신의 권능을 빌리는 특수 마법 | 마나장의 거시적 결맞음(coherence) 상태. 개인이 아닌 집단 마나장의 동기화로 발현 |

## 6. 자본/성장 곡선 설계

### 6.1 핵심 규칙

1. **성장 지표 3축**:
   - **이론 혁신 지수(TII)**: 정우가 발견·정립한 마법 물리학 이론의 수와 영향력. 논문·발견 단위로 측정.
   - **마나 공학 세대(MEG)**: 마나 공학 장치의 기술 세대. 1세대(단순 마나 증폭기) → 7세대(차원 조작 엔진).
   - **제자 성장도(DSI)**: 제자들의 평균 서클 수 × 인원 수. 정우 자신이 싸우는 것이 아니라 제자들의 성장이 곧 전력.

2. **성장 제한 (밸런스)**:
   - 정우 자신은 끝까지 마나 0. 직접 전투력은 없음.
   - 마나 공학 장치는 '마나 연료'가 필요 → 제자나 마나석 공급이 끊기면 무력화.
   - 이론이 아무리 뛰어나도 '실험·실증'에 시간과 자원이 필요. 한 번에 모든 것을 해결하지 못함.
   - 이론 공개 시 적에게도 이용될 위험 → 기술 유출 딜레마.

3. **성장 패턴**:
   - **1~2대단원**: 느린 축적기. 이론 하나하나를 증명하는 과정 자체가 서사.
   - **3~4대단원**: 가속기. 제자들이 성장하며 실증 속도가 빨라짐. 동시에 적대 세력도 강화.
   - **5~6대단원**: 위기+도약. 마탑 연합 붕괴 → 차원 위기. 기존 이론의 한계 봉착 → 돌파.
   - **7대단원**: 수렴·완성. 모든 이론과 제자 성장이 하나로 결집.

4. **먼치킨 공식 준수**:
   - "약해 보이지만 사실은 강하다"의 변주 → "마나 0이라 약하지만, 그의 머릿속이 이 세계 최강의 무기."
   - 쾌감 포인트: 정우를 무시하던 자들이 그의 제자에게 패배 → 알고 보니 뒤에 정우의 이론이 있었음.

## 11. 회귀/빙의 전용 설정

본 작품은 **차원 전이물**로, 회귀·빙의가 아닌 '본인 그대로의 이세계 이동'이다. 다만 전이 장르 특유의 설정을 구체화한다.

| 항목 | 설정 |
|------|------|
| 전이 방식 | 차원 공명형 소환. 정우의 초끈이론 연구가 아르테미아 차원과 공명을 일으켜 물리적으로 이동. 소환자는 아르테미아 세계 의지(무의식적 자기보호 시스템) |
| 전이 시 변화 | 몸이 그대로 이동하나 원자 구조가 미세 변형(마나 감응 안테나화). 언어 동기화 발생. 마나핵은 생성되지 않음 |
| 지구 지식 활용 | 물리학 전 분야(역학, 열역학, 전자기학, 양자역학, 상대성이론, 통계역학, 고체물리학 등). 수학(미적분, 선형대수, 미분방정식, 군론 등). 공학 기초 지식 |
| 치트키 한계 | ① 지식은 있으나 마나 0이라 직접 실행 불가 ② 이론 검증에 실험 필요 → 시간+자원 소모 ③ 이세계 물리 상수가 지구와 미세하게 다름 → 모든 공식을 재보정해야 함 ④ 사회적 신뢰 0에서 시작 |
| 귀환 가능성 | 존재하나 조건이 까다로움: 차원 공명을 역으로 일으키려면 마나 물리학 통합 이론 완성 필요. 아이러니하게도 귀환 기술 연구가 보이드 대응 기술과 동일 |
| 지구 시간 경과 | 이세계와 비동기. 이세계에서 수년이 지나도 지구에서는 수초만 경과 (최종 밝혀짐) |
| 전이자 전례 | 500년 전 '고대 전이자' 1명 기록. 지구 출신 물리학자로 추정. 마법 문명 기초를 놓았으나 1차 보이드 침공 때 희생 |
| 언어 동기화 | 세계 의지의 개입으로 자동 부여. 정우는 읽기·듣기·말하기 즉시 가능. 다만 '쓰기'는 별도 학습 필요 (이세계 문자 체계가 다름) → 초반 수식을 아라비아 숫자로 쓰는 에피소드 |
| 외모/신체 | 동양인 외모가 이세계에서는 매우 희귀. "동쪽 먼 바다 너머의 사람?" 정도로 인식. 체력은 일반 중년 남성 수준으로 매우 약함 |
| 정신적 영향 | 전이 초기 극심한 고립감·향수. 지도를 펼칠 때마다 한국 지도를 떠올림. 제자들과의 유대가 심리적 안정의 핵심 |

## 13. 킬링포인트 요약 (5개)

**킬링포인트 1: "마법이 아닙니다. 물리학입니다."**
마나 0인 교수가 수식 하나로 수백 년 마법 체계를 뒤집는 순간의 쾌감. 정우가 칠판에 수식을 쓸 때마다 세계가 바뀐다. 독자는 물리학 공식이 마법으로 전환되는 과정에서 지적 흥분과 통쾌함을 동시에 느낀다. 핵심 장면: 학술 토론회에서 세라핀의 9서클 마법을 수식 3줄로 최적화해 보이는 장면.

**킬링포인트 2: 제자 성장의 대리 만족**
"교수님의 이론이 아니었으면 저는 낙제생으로 끝났을 겁니다." 비주류·낙제생·차별받던 제자들이 정우의 이론을 무기로 기존 엘리트를 압도하는 언더독 서사. 정우 자신이 싸우지 않지만, 제자들의 승리가 곧 정우의 승리. 핵심 장면: 토너먼트에서 엘라가 마나량 3배 차이의 상대를 열효율 최적화로 제압.

**킬링포인트 3: 과학자의 방식으로 세계를 구한다**
검도 마법도 아닌, 가설→실험→검증→이론 정립의 과정으로 위기를 돌파한다. "이 데이터에 오차가 있어"라는 한 마디가 세계를 구할 열쇠가 되는 이공계 먼치킨의 정수. 핵심 장면: 마나 보존 법칙의 0.03% 오차가 보이드 침공의 증거이자 대응 무기의 원리가 되는 복선 회수.

**킬링포인트 4: 적에서 동지로 — 인정의 서사**
세라핀, 마르쿠스, 레이놀드 등 정우를 멸시·탄압하던 이들이 그의 이론의 가치를 인정하고 동지가 되는 과정. 특히 마르쿠스의 유언 장면은 적대자 서사의 정점. 핵심 장면: 마르쿠스가 죽으며 "내 평생의 오만이었소. 당신의 학문을 부탁하오"라고 말하는 순간.

**킬링포인트 5: 귀환 vs 잔류 — 교수의 선택**
돌아갈 수 있는 기술이 완성되었을 때, 정우는 서울대 연구실이 아닌 엘드리안 아카데미를 선택한다. "내 논문은 여기서 더 많은 의미가 있으니까요." 42세 교수의 인생 선택이 주는 묵직한 감동. 핵심 장면: 차원문 앞에서 지구 쪽을 바라보다 안경을 고쳐 쓰고 돌아서는 정우.
