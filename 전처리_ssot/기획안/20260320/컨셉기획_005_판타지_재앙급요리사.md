# 컨셉 기획안 — 재앙급 요리사: 내 요리를 먹으면 S급이 됩니다

> 작성일: 2026-03-20
> 장르: 현대판타지 · 헌터물 · 요리/제작
> 플랫폼 타겟: 카카오페이지 (1순위)
> 배치: BATCH 01 / #005 / FAN-HNT-05

---

## 1. 로그라인

**무각성자 전직 요리사가, 몬스터 식재료로 요리하면 먹은 사람에게 각성·강화·치유를 부여하는 '요리 시스템'을 발현한다. 본인 전투력은 0이지만, 그의 한 끼가 S급을 양산한다 — 재앙급 요리사의 탄생.**

---

## 2. 1화 후킹 시퀀스

```
프롤로그: 헌터 전용 식당.
 → 주인공 백도윤(30), 요리사. 헌터 전용 식당에서 일한다.
 → 각성 측정: 무각성. "마나 반응 없음. 일반인입니다."
 → 식당 주인: "도윤아, 넌 요리나 잘해. 헌터는 무리야."
 → 도윤이 쓰레기통에서 버려진 C급 몬스터 고기를 줍는다.
 → "이거… 조리법만 바꾸면 먹을 수 있을 텐데."

1화: 식당 주방, 새벽.
 → 도윤이 C급 '스톤베어' 고기로 요리를 시작한다.
 → 마나 활성화를 위해 저온 숙성 → 고온 시어링 → 마나허브 소스.
 → 시스템창이 뜬다.
 → [요리 시스템 활성화]
 → [제조 완료: 스톤베어 스테이크 (C급)]
 → [효과: 음용 시 2시간 마나 총량 +30%, 방어력 +20%]
 → 도윤이 맛을 본다. 맛은 좋지만 본인에게 효과 없음(무각성).
 → 출근한 D급 헌터가 한 접시 먹는다.
 → "사장님… 저 갑자기 C급 느낌인데요?"
 → 도윤의 눈이 번뜩인다.
 → 1화 마지막 줄: "…코스요리 먹으면 어떻게 되는 거지?"
```

**후킹 구조**: 무각성 요리사(좌절) → 몬스터 식재료 조리(호기심) → 먹은 사람이 강해짐(반전) → "코스요리 먹으면?"(기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **요리 시스템** | 몬스터 식재료 조리 시 음식에 마나 효과 부여. 먹은 사람의 능력 일시/영구 강화 |
| **요리 등급** | E~SSS급. 식재료 등급 × 조리 기법 숙련도 × 레시피 희귀도 |
| **효과 유형** | 일시 버프(2~24시간), 영구 강화(SSS급 식재료+대종사 기법), 치유, 해독, 각성 촉진 |
| **제약** | ① 도윤 본인은 무각성(요리 효과 적용 불가) ② 같은 요리 반복 시 내성 ③ 조리 시간 필요 ④ 과식 시 마나 중독 |
| **코스요리** | 여러 요리 조합 시 시너지 효과. '풀코스'는 일시적 SSS급 버프 |

### 3.2 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 몬스터 식재료 = 폐기물 인식 | 도윤의 출발점 |
| 3개월 후 | 첫 번째 각성 촉진 요리 성공 | 업계 충격 |
| 1년 후 | 몬스터 미식 붐 | 수요 폭발, 경쟁 시작 |
| 3년 후 | 글로벌 미식 전쟁 | 국가 대항 미식 대회 |
| 5년 후 | 최종 식재료 | 차원 식재료로 최종 요리 |

### 3.3 주인공 그룹

| 항목 | 설명 |
|------|------|
| **상호** | '도윤 키친' (1인 식당) → '백도윤 미식연구소' → '그랑 미식 길드' |
| **메뉴** | 초기 C급 스테이크 → 최종 SSS급 풀코스 |
| **매출** | 초기 0원 → 최종 월 300억+ |

## 12. 장소/파트너 다양화

### 주요 장소 (8곳+)

서울 헌터 식당(초기), 강남 '도윤 키친' 본점, 부산 해산물 던전,
제주 몬스터 목장, 프랑스 파리 '르 몽스트르'(피에르 거점),
베트남 호찌민 몬스터 시장(탄 리엔 거점), 일본 도쿄 미슐랭 심사장,
미국 뉴욕 유엔 푸드 서밋, 이탈리아 토스카나 와이너리,
서울 미식연구소
