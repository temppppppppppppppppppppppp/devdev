## 1. 로그라인

**2035년, 아버지의 1조 2천억 부채와 자살 스캔들로 모든 것을 잃은 재벌 2세가 2008년 서브프라임 위기 직전으로 회귀한다. 미래를 아는 남자지만 현재 신용은 0 — 빚을 갚는 것부터가 생존이다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2035년, 파산 선고 법정.
 → "피고인 진서하, 대표이사 배임 혐의 유죄."
 → 법정 밖, 기자들 플래시. "진현태 前 회장 자살 후 아들까지—"
 → 서하가 법원 옥상에 선다. 발 아래 서울.
 → 눈을 감는다.

1화: 2008년 9월 14일(일), 서울 성북동 본가.
 → 눈을 뜬다. 손에 든 건 리먼 브라더스 파산 뉴스가 실린 아침 신문.
 → 아버지(진현태)가 살아있다. 식탁에서 "오늘 이사회 간다"고 한다.
 → 서하는 안다: 내일, 리먼이 터지고, 아버지의 무리한 해외 레버리지가
   그룹을 삼킬 것이라는 걸.
 → 1화 마지막 줄: "아버지, 이사회 전에 드릴 말씀이 있습니다."
```

**후킹 구조**: 프롤로그 파산(충격) → 회귀(반전) → 리먼 브라더스(긴박한 시한) → 아버지와의 대면(감정). 4단 임팩트.

## 11. regression_ext 설계 (회귀 전용)

| 필드                 | 설정                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| `regression_type`    | 회귀                                                                                   |
| `is_regressor`       | true (전 블록 고정)                                                                    |
| `regression_hint`    | 전생의 데자뷔 장면 (서사적 한국어), 블록당 1~2개                                       |
| `slip_up`            | "아직 일어나지 않은 일을 아는 듯한 발언 실수" — 최소 10종, 에스컬레이션                |
| `execution_doctrine` | 20블록마다 변화: "정보 우위 활용" → "방어적 포석" → "역발상 공세" → "직관과 경험 의존" |
| `death_flag`         | 전생의 파산/자살 타임라인 접근 시 유사 징후 반복 (대단원별 다른 유형)                  |

### death_flag 에스컬레이션

| 대단원 | death_flag 유형                                     |
| ------ | --------------------------------------------------- |
| 1~2    | 아버지의 건강 악화 징후 (전생과 동일 패턴)          |
| 3~4    | 전생에서 파산 시작된 거래와 유사한 딜 출현          |
| 5      | 전생에서 자살 시도한 장소를 우연히 방문             |
| 6~7    | 전생의 파산 판결 날짜가 다가옴 → 같은 날 무슨 일이? |
