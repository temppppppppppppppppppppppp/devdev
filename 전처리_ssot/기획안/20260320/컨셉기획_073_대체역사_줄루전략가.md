## 1. 로그라인

**2025년 육군사관학교 전술학 교수 이동건이 1816년 줄루 왕국의 젊은 전사로 빙의한다. 사카 줄루(위대한 줄루) — 아프리카 역사상 가장 강력한 군사 왕국을 세운 샤카 줄루의 시대에, 검은머리 전략가가 영국 대영제국의 아프리카 진출을 60년 앞서 저지하는 밀리터리 대체역사.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 육군사관학교 전술학 강의실.
 → 이동건 교수가 "이산들와나 전투"를 강의 중이다.
 → "1879년 1월 22일, 줄루 전사 2만이 영국군 1,700명을 전멸시켰습니다.
    대영제국이 아프리카에서 당한 최악의 패배."
 → "그러나 결국 줄루는 졌습니다. 기술의 격차를 용기로 메울 수 없었으니까."
 → 강의실을 나서다 쓰러진다.

1화: 1816년, 남아프리카 줄루란드.
 → 눈을 뜬다. 흙바닥. 원형 가옥(크라알).
 → 거울 대신 물에 비친 얼굴 — 검은 피부가 아니다. 동양인의 얼굴.
 → "은코시(지도자)! 새 전사가 눈을 떴습니다!"
 → 마을 사람들이 모여든다. "동쪽 바다에서 떠내려온 이방인."
 → 이동건은 안다: 1816년, 지금 줄루 부족은 작은 씨족에 불과하다.
   그러나 1년 후, 샤카 줄루가 족장이 되고, 역사상 최강의
   아프리카 군사 왕국이 탄생한다.
 → 그리고 63년 후, 영국이 모든 것을 부순다.
 → 1화 마지막 줄: "이번에는 다르게 할 수 있다."
```

**후킹 구조**: 이산들와나 전투(전쟁 로맨스) → 줄루 왕국(완전 신규 배경) → 검은머리 이방인(반전) → 역사 바꾸기(서사 목표). 4단 임팩트.

## 11. 빙의 전용 설정 (regression_ext)

| 필드 | 설정 |

| `regression_type` | 빙의 (표류민 설정, 동양인 외모 유지) |

| `death_flag` | 역사 속 줄루 왕국 멸망의 패턴이 반복적으로 나타남 |
