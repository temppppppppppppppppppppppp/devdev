# 컨셉 기획안 — 무굴 제국의 천재 엔지니어

> 작성일: 2026-03-20
> 장르: 대체역사 · 산업혁명 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)
> 코드: ALT-WLD-02

## 1. 로그라인

**2025년 포스코 제철소 수석 엔지니어 박준혁이 1556년 무굴 제국 3대 황제 악바르 대제의 즉위 직전, 델리의 고려인 대장장이 아들로 빙의한다. 인도 아대륙 최강 제국의 한가운데서, 현대 공학 지식으로 산업혁명을 250년 앞당기는 검은머리 기술자의 제국 건설.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, 포항 포스코 고로(高爐) 앞.
 → 박준혁 수석이 용광로 폭발 사고를 수습하다 쓰러진다.
 → "산소 공급 차단해! 3번 고로 긴급 정지!"
 → 의식이 사라진다.

1화: 1556년, 델리 외곽의 대장간.
 → 눈을 뜬다. 손에 쥐어진 건 조악한 망치.
 → 거울에 비친 얼굴 — 검은 머리, 10대의 몸.
 → 아버지라 불리는 남자: "준혁아, 주문받은 칼을 마저 때려라."
   고려에서 실크로드를 따라 인도까지 온 대장장이 가문.
 → 밖에서 말발굽 소리. "악바르 왕자가 후마윤 대제를 이어 즉위한다!"
 → 준혁은 안다: 악바르 대제. 인도 역사상 최고의 군주.
   지금부터 50년, 인도 아대륙의 황금기가 시작된다.
 → 그리고 이 시대의 철은 너무 조악하다. 현대 제철 지식이 있다면—
 → 1화 마지막 줄: "이 불의 온도가 너무 낮아. 코크스가 필요해."
```

**후킹 구조**: 제철소 엔지니어(전문성) → 무굴 대장장이(반전) → 악바르 즉위(역사적 기대) → 코크스 제철(기술 치트 예고). 4단 임팩트.
