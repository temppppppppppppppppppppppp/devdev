## 1. 로그라인

**2025년 SpaceX 한국인 추진공학 엔지니어 정하늘이 1962년 NASA 켄트 우주센터의 23세 한국계 미국인 엔지니어로 회귀한다. 아폴로 계획 7년 전 — 60년 후의 로켓 공학 지식으로 인류를 달에 보내고, 한국인 최초의 우주비행사가 되는 검은머리의 우주 개발사.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 2025년, SpaceX 텍사스 스타베이스.
 → 정하늘 엔지니어가 스타십 발사 시험 카운트다운을 지휘한다.
 → "T-10... 9... 8..."
 → 엔진 폭발. 사고. 화염 속에서 의식을 잃는다.

1화: 1962년 9월 12일, 라이스 대학교.
 → 눈을 뜬다. TV에서 케네디 대통령의 연설.
 → "We choose to go to the Moon—"
 → 거울에 비친 얼굴 — 검은 머리. 동양인. 23세의 청년.
 → 책상 위 NASA ID 카드: "David H. Jung, Propulsion Engineer,
   Marshall Space Flight Center"
 → 하늘은 안다: 아폴로 계획. 인류 최초의 달 착륙까지 7년.
   그리고 하늘에게는 60년 후의 로켓 공학 지식이 있다.
   새턴 V의 결함도, 아폴로 1호의 화재도, 아폴로 13호의 사고도 안다.
 → 1화 마지막 줄: "달에 갈 수 있다. 아니, 달 너머까지."
```

**후킹 구조**: 스타십 폭발(충격) → 1962년 NASA(시대 반전) → 케네디 연설(역사적 흥분) → "달 너머"(야심). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **회귀 방식** | 의식 전이. 2025→1962, 63년 역행. 한국계 미국인 엔지니어의 몸에 빙의 |
| **기억 유지** | 현대 로켓 공학·추진 기술 완전 보존. 우주 개발사 세부 일정 기억 |
| **회귀 제약** | 1960년대 기술·소재 한계. 현대 기술을 바로 구현 불가. 컴퓨터 성능 극히 제한 |
| **회귀 증거** | 현대 공학 용어, 아직 개발 안 된 소재 명칭, 미래 사고 예언 |

### 3.2 역사 배경 타임라인

| 시기 | 실제 사건 | 작중 활용 |
|------|-----------|-----------|
| 1962 | 케네디 달 연설 | **1화 기폭제** — 아폴로 계획 시작 |
| 1963 | 케네디 암살 | 정치적 위기. 우주 프로그램 예산 위기 |
| 1966 | 제미니 프로그램 | 우주 비행 기술 검증. 주인공 참여 |
| 1967 | 아폴로 1호 화재 (3명 사망) | 주인공이 사전 방지 시도 |
| 1968 | 아폴로 8호 달 궤도 | 주인공의 엔진 설계 기여 |
| 1969 | 아폴로 11호 달 착륙 | 핵심 전환점. 주인공의 역할 |
| 1970 | 아폴로 13호 사고 | 주인공이 사전 대비 |
| 1972~75 | 아폴로 종료 / 데탕트 | 달 너머 — 화성 프로그램 제안 |
| 1980s | 셔틀 시대 / 냉전 종식 | 최종 대단원. 한국인 우주비행사 |

|------|------|
