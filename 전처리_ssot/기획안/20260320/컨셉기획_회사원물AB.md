# 컨셉 기획안 — 회사원물 A: 「사직서는 내일 쓰겠습니다」

> 장르: 현대판타지 · 회사원물 · 회귀물
> 플랫폼 타겟: 카카오페이지 (1순위), 네이버시리즈 (2순위)

---

## 1. 로그라인

**20년간 회사에 충성했지만 구조조정으로 해고당한 54세 과장이 입사 첫날(24세)로 회귀한다. 이번 생에서는 회사를 위해 일하지 않는다 — 회사를 삼킨다.**

## 2. 1화 후킹

> _"김 과장, 내일부터 안 나와도 됩니다." 30년 만에 들은 해고 통보. 퇴사 박스를 들고 나오는데 비가 온다. 택시도 안 잡힌다._
> → 눈을 뜨니 2005년 3월. 한성건설 신입사원 OT. 인사팀장이 말한다: "신입 여러분, 앞으로 30년을 함께할 동료입니다."
> → 주인공 독백: "30년? 아뇨. 3년이면 충분합니다."

## 3. 세계관 & 장르 설정

| 항목            | 설정                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------ |
| **회귀 범위**   | 30년 (2035→2005). 한국 기업 문화의 변천을 관통                                                   |
| **기억 유지**   | 30년간 회사 내부 정보 + 인맥 + 부동산/주식 타이밍                                                |
| **회귀 제약**   | 전생에서 '순종적 과장'이었으므로 **경영 전략을 모름**. 현장 실무는 완벽하지만 이사회 정치는 처음 |
| **판타지 없음** | 순수 회귀물. regression_ext 활용, 판타지 능력 없음                                               |
| **기업 배경**   | 한성건설 (건설+부동산 개발, 시총 3조, 재계 40위)                                                 |

### 적대자 3단계

| Phase          | 적대자                        | 방법                                   |
| -------------- | ----------------------------- | -------------------------------------- |
| 1 (대단원 1~2) | 꼰대 상사 + 학연 파벌         | 업무 방해, 성과 가로채기, 인사 불이익  |
| 2 (대단원 3~5) | 오너 일가 2세 (무능한 후계자) | 경영 실책 은폐, 횡령, 내부 고발자 탄압 |
| 3 (대단원 6~7) | 사모펀드 + 오너 일가 분열     | 적대적 인수, 경영권 전쟁, 계열사 매각  |

### NPC 12명 / 복선 8개 / 패배 10개 / deal_type 13종 / 장소 15곳 / 해외 파트너 3곳

### 자본 곡선

```
대단원 1~2: 0원 → 30억 (부동산 투자 + 사내 승진 가속)
  패배: Block 4 (상사가 성과 가로챔), Block 8 (인사위원회 탈락)
대단원 3~4: 30억 → 300억 (건설 프로젝트 성공 + 주식 투자)
  패배: Block 26 (부동산 폭락 시기 역이용 실패), Block 33 (2세의 보복 인사)
대단원 5~6: 300억 → 2,000억 (지분 매집 시작 + 계열사 장악)
  패배: Block 44 (내부 고발 역풍), Block 55 (사모펀드 합류 실패)
대단원 7: 2,000억 → 5,000억 (경영권 장악)
  패배: Block 65 (오너 일가 최후 반격)
```

# 컨셉 기획안 — 회사원물 B: 「회의실의 독심술사」

> 장르: 현대판타지 · 회사원물 · 능력물
> 플랫폼 타겟: 카카오페이지 (1순위), 문피아 (2순위)

---

## 1. 로그라인

**회의 중 상대방의 '진짜 속마음'이 말풍선처럼 보이는 능력을 가진 평범한 대리. 사내 정치, 고객사 협상, 적대적 M&A까지 — 보이는 건 진심이지만, 가장 못 읽는 건 자기 자신의 마음.**

## 2. 1화 후킹

> _"이 프로젝트는 반드시 성공시키겠습니다." — 팀장의 입에서 나오는 말. 머리 위에 뜨는 진짜 속마음: 「이거 터지면 너한테 뒤집어쓰기 딱 좋겠다.」_
> → "… 네, 열심히 하겠습니다." 그날부터 박서준 대리의 '진짜 회사 생활'이 시작됐다.

## 3. 세계관 & 장르 설정

| 항목            | 설정                                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **판타지 능력** | 공식적 대화 시 상대의 **진짜 의도가 말풍선으로 보임**. 비공식(사적 대화)에서는 작동 안 함                                  |
| **능력 제약**   | ① 말풍선은 '의도'만 보여주고 '감정'은 안 보임 ② 자기 자신의 속마음은 절대 안 보임 ③ 3명 이상이면 가장 강한 의도 1개만 보임 |
| **핵심 갈등**   | 남의 속마음을 아는 것이 반드시 유리하지는 않음 — 진심을 알수록 인간 불신이 커짐                                            |
| **기업 배경**   | 한올 그룹 (유통+식품+미디어 복합 대기업, 시총 12조)                                                                        |

### 적대자 3단계

| Phase          | 적대자                       | 방법                                   |
| -------------- | ---------------------------- | -------------------------------------- |
| 1 (대단원 1~2) | 사내 정치꾼 (상무)           | 뒷거래, 성과 가로채기, 파벌 동원       |
| 2 (대단원 3~5) | 경쟁사 CEO + 적대적 M&A      | 영업비밀 탈취, 위조 거래, 인수 공세    |
| 3 (대단원 6~7) | 그룹 총수의 숨겨진 후계 구도 | 가족 내전, 주인공 이용 시도, 최종 선택 |

### NPC 12명 / 복선 8개 / 패배 10개 / deal_type 13종 / 장소 15곳 / 해외 파트너 3곳

### 자본 곡선 (개인 연봉+스톡옵션+승진)

```
대단원 1~2: 연봉 4천만 → 1억2천 (대리→차장, 핵심 인재 발탁)
  패배: Block 4 (상무 뒷거래 발각 시도 실패), Block 8 (협상 독심 오독)
대단원 3~4: 개인자산 5억 → 30억 (핵심 프로젝트 성공 보너스)
  패배: Block 26 (경쟁사 역스파이), Block 33 (M&A 방어 중 정보 누수)
대단원 5~6: 30억 → 200억 (임원 승진 + 스톡옵션 행사)
  패배: Block 44 (능력 의존으로 인한 판단 실수), Block 55 (후계 구도 함정)
대단원 7: 200억 → 500억 (경영 참여 + 최종 선택)
  패배: Block 65 (총수 일가 분열, 양쪽 다 읽히는 속마음)
```
