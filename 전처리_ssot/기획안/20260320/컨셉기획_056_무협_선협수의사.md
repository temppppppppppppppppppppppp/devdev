## 1. 로그라인

**현대 수의대 졸업생 '윤하진'이 교통사고 직후 선협 세계로 전이한다. 영수(靈獸)를 치료하면 영수가 보은하여 수호수가 되고, 치료 과정에서 영기가 체내에 축적되어 수선 경지가 오른다. 전투는 영수에게, 치료는 내가 — 비전투 수의사의 선협 세계 생존기.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 현대 서울, 동물병원 야간 당직.
 → 수의대 갓 졸업한 윤하진, 교통사고로 실려온 유기견을 수술 중.
 → "제발… 버텨." 수술 성공. 하지만 병원 밖으로 나온 순간 —
 → 음주운전 트럭이 돌진. 충돌. 의식 소실.

1화: 낯선 숲. 거대한 나무들. 풀벌레 소리가 아닌 짐승 울음소리.
 → 하진이 눈을 뜬다. 몸이 앳되다. 자기 몸이 아니다. 15세 소년.
 → 숲 속에서 피를 흘리며 쓰러진 짐승 발견 — 새끼 은빛 여우.
   크기는 송아지만 한데, 이마에 은색 문양이 빛난다.
 → 수의사 본능: "개방골절에 내장 출혈… 지금 안 하면 죽어."
 → 주변 약초를 더듬어 찾고, 전생 수술 지식으로 응급 처치.
 → 처치 완료 순간, 여우의 이마 문양에서 은빛 기류가 하진의 몸으로 스며든다.
 → [단전에 한 줄기 영기가 생긴다. 축기 1층.]
 → 새끼 여우가 눈을 뜨고, 하진의 무릎에 머리를 비빈다.
 → 1화 마지막 줄: "…너, 나한테 보은하는 거야?"
```

**후킹 구조**: 현대 감성(공감) → 전이(반전) → 부상 영수 치료(직업 정체성) → 영기 각성(성장 시작) → 영수 보은(동반자 확보). 5단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **전이 방식** | 현대 교통사고 사망 → 선협 세계 15세 고아 소년에게 빙의. 원래 영혼은 이미 소멸 |
| **치료 보은 시스템** | 영수를 치료하면 영수가 '보은각인(報恩刻印)'을 새기고 수호수가 됨. 치료 난이도가 높을수록 더 강한 영수가 보은 |
| **영기 축적 원리** | 치료 과정에서 영수의 영기 일부가 자연 유입. 난이도·위험도에 비례하여 축적량 증가 |
| **제약** | ① 강제 포획/속박 시 보은각인 소멸 ② 한 번에 계약 유지 가능한 수호수 수 제한 (경지에 비례) ③ 치료 실패 시 영기 역류 위험 ④ 영수를 도구로 취급하면 각인 약화 ⑤ 일부 영수는 치료 후에도 보은각인을 맺지 않음 (야생성이 강하거나 과거 트라우마) — 치료=반드시 수호수 획득이 아닌 변주 확보 | [P4 수정]

### 3.2 배경 세계관 체계

| 항목 | 설명 |
|------|------|
| **세계명** | 만령대륙(萬靈大陸) — 영수와 수선자가 공존하는 세계 |
| **수선 경지** | 축기→금단→원영→화신→도합→대승→도극(渡劫)→선인 |
| **영수 등급** | 범수(凡獸)→영수(靈獸)→요수(妖獸)→신수(神獸)→선수(仙獸) |
| **주요 세력** | 4대 수선 종파 + 수수전(獸修殿, 영수 조련 전문) + 영수 사냥꾼 조직 + 요수 왕국 |
| **핵심 갈등** | 수선자들은 영수를 자원(내단·가죽·뼈)으로 취급 ← → 하진은 영수를 생명으로 대함. 이 가치관 충돌이 전체 서사 관통 |

### 3.3 주인공 그룹

| 항목 | 설명 |
|------|------|
| **빙의체** | 만령대륙 변방 마을 고아 '하진'. 영근 미각성, 채약 소년 |
| **초기 조건** | 영근 없음 (치료 보은으로만 영기 획득), 전투력 제로 |
| **전생 지식** | 수의학 전공 지식(해부학·약리학·외과술), 현대 의학 상식 |
| **성장 방향** | 영수 치료 → 보은각인 수호수 확보 → 수호수 전투력으로 위기 극복 → 대륙 영수의사 → 선수 치료로 선계 진입 |

## 6. 경지 성장 곡선 설계

### 6.1 핵심 규칙
- 초기 경지: **영근 미각성** → 최종: **도극 완료, 선계 영수의(靈獸醫) 자격**
- 성장 연료: 치료 보은 영기 축적 (전투 수련 아님)
- 수호수 전력: 경지보다 상위 전투력 보유 (하진 자체 전투력은 항상 부족)
- **최소 7블록에서 성장 정체 또는 역행** 필수
