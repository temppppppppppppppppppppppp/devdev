## 1. 로그라인

**무당파 삼대제자 '서진운'은 산중 수련 중 벼락에 맞고, 머릿속에 현대 물리학 전체 지식이 쏟아져 들어온다. 내공의 흐름은 유체역학, 경공은 역학, 검기는 에너지 보존 법칙 — 무공을 물리로 재해석한 천재는 강호의 상식을 하나씩 부수며 올라간다. "저 자식, 무공을 너무 이상하게 쓰는데… 왜 이기는 거야?"**

## 2. 1화 후킹 시퀀스

```
프롤로그: 무당산 정상. 한밤중 뇌우.
 → 삼대제자 서진운이 좌선(坐禪) 수련 중.
 → 내공 순환이 막힌다. 세 번째 관문(경혈)을 뚫지 못하는 병목.
 → "사형들은 다 뚫었는데… 나만 왜."
 → 번개가 내리친다. 정수리를 관통.
 → 의식이 날아간다. 그리고 — 머릿속에 쏟아지는 수식, 도표, 법칙.
 → F=ma. E=mc². ∇·E=ρ/ε₀.
 → "이건… 뭐지?"

1화: 다음 날 아침. 무당파 의료각.
 → 눈을 뜬다. 사형 '한무결'이 걱정스런 얼굴로 내려다본다.
 → "진운아, 벼락을 맞았다. 사흘을 깨지 못했다."
 → 진운이 몸을 일으킨다. 머릿속이 이상하다.
 → 내공을 돌려본다 — 경맥의 흐름이 보인다. 아니, "유체의 흐름"으로 보인다.
 → "유속이 빨라지면 압력이 낮아진다… 베르누이 정리?"
 → 막혀 있던 세 번째 관문. 유체역학으로 다시 접근.
 → 내공이 뚫린다. 한 번에.
 → 1화 마지막 줄: 한무결이 경악한다. "진운… 네 내공이… 하루 만에 어떻게?"
   서진운은 말없이 손을 내려다본다. 손바닥 위에서 기(氣)가 소용돌이친다.
   — 물리적으로 완벽한 와류(渦流).
```

**후킹 구조**: 수련 병목(공감) → 벼락(사건) → 물리 지식 유입(반전) → 즉시 돌파(카타르시스). 과학+무공 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **물리 지식 유입** | 벼락에 의한 의식 변화. 현대 물리학(역학~양자역학~통일장 이론) 전체가 지식으로 유입 |
| **지식 활용 방식** | 물리 원리를 "무공의 언어"로 번역하여 적용. 수식 자체가 아닌 원리적 이해 |
| **제한** | ① 지식은 있지만 체(體)가 따라가는 데 시간 필요 ② 높은 물리 원리일수록 높은 내공 필요 ③ 설명하면 아무도 이해 못 함 |
| **태극-물리 공명** | 무당의 태극(太極) 원리와 물리학의 대칭(symmetry) 원리가 본질적으로 같다는 세계관 설정 |

### 3.2 배경 타임라인

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 무당파 내부. 삼대제자 수련 시기 | **1화 기폭제** — 벼락 + 물리 각성 |
| ~1년 | 무당파 내 비무대회, 문파 간 교류전 | 물리 무공의 첫 검증 (대단원 1~2) |

| 4~5년 | 마교 부활 + 천지이변 | 물리 원리로 천재지변 대응 (대단원 5~6) |
| 6년 | 최종 결전 + 만물귀일 경지 | 물리와 무공의 완전 통합 (대단원 7) |

## 6. 경지/내공/무공 성장 곡선 설계

### 6.1 핵심 규칙
- 물리 원리 적용 7단계: 역학기초(力學基礎) → 유체내공(流體內功) → 파동검기(波動劍氣) → 상대진기(相對眞氣) → 양자경지(量子境地) → 통일장(統一場) → 만물귀일(萬物歸一)
- 무당파 전통 경지: 연환초식 → 태극 운용 → 혼원 내공 → 진무 경지 → 현무 경지 (물리 경지와 병행 성장)
- **물리 원리가 높을수록 이해는 가능하나 체(體)가 못 따라감** — 이론과 실전의 괴리가 갈등축
- **최소 7블록에서 좌절/하락** 필수 (물리 오적용, 부작용, 내상)
- 액션 60% : 탐구/학습 30% : 일상 10% 비율

### 6.2 경지 곡선 개요 (70블록)

```
대단원 1 (Block 1~10): 각성기 — 물리의 눈이 열리다
  물리 경지: 역학기초(力學基礎) 완성
  무당 경지: 기본 내공 → 연환초식 완성
  패턴: 병목 돌파 → 내공에 역학 적용 → 동료들의 경악
  좌절 블록: Block 4 (물리 과신으로 내공 폭주. 경맥 3개 손상)

  물리 경지: 유체내공(流體內功) 완성
  무당 경지: 태극 운용 단계

  물리 경지: 상대진기(相對眞氣) 성장 (상대성 원리 적용)
  무당 경지: 혼원 내공 완성 → 진무 경지 초입

  물리 경지: 양자경지(量子境地) 성장
```

## 11. 회귀/빙의 전용 설정

**해당 없음** — 본 작품은 회귀/빙의가 아닌 "벼락에 의한 지식 유입" 구조. 현대인의 빙의가 아니며, 원래 무당파 제자의 인격이 유지되면서 물리 지식만 추가된 설정.

단, 물리 지식 유입에 관한 전용 설정:

| 필드 | 설정 |
|------|------|
| **유입 방식** | 벼락 → 무당산 지맥 반응 → 태극 원리가 물리학을 '소환' |
| **지식 범위** | 고전역학 → 유체역학 → 전자기학 → 열역학 → 상대성이론 → 양자역학 → 통일장이론 (순차 해금) |
| **제한** | 경지가 올라야 상위 물리 이해 가능. 체가 못 따라가면 오히려 부작용 |
| **소멸 가능성** | Block 3에서 심기. 물리 지식이 영구적이지 않을 수 있다는 위기감 (최종 복선) |

## 13. 킬링포인트 요약 (5개)

1. **"F=ma로 내공을 뚫었다"** — 물리 공식이 무공이 되는 순간의 쾌감. 독자가 물리를 '아는 것'처럼 느끼는 쾌감
2. **"이상한 방식으로 무공을 쓰는데… 왜 이기는 거야?"** — 주변인의 반응이 곧 코미디+카타르시스
3. **마교에도 물리를 아는 자가 있다** — 유일한 무기가 적에게도 있다는 공포. "너만 아는 게 아니야"
4. **태극 = 대칭 = 물리법칙** — 무당 태극과 현대 물리의 공명. 동양 철학+서양 과학의 합일이 주는 지적 쾌감
5. **7단계 물리 경지의 스케일** — 역학→유체→파동→상대→양자→통일장→만물귀일. 경지마다 세계의 크기가 달라짐
