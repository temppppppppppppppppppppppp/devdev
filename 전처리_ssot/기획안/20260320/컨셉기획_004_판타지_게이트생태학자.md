> 작성일: 2026-03-20
> 장르: 현대판타지 · 헌터물 · 학술/테이머
> 플랫폼 타겟: 카카오페이지 (1순위), 문피아 (2순위)
> 배치: BATCH 01 / #004 / FAN-HNT-04

## 1. 로그라인

**동물행동학 박사 출신 C급 헌터가, 게이트 안의 몬스터를 죽이지 않고 관찰·연구·길들이는 '생태 시스템'을 각성한다. 논문 1편이 스킬 1개 — 연구가 곧 성장이고, 길들인 몬스터가 그의 군단이 된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: C급 던전 레이드.
 → 주인공 서준호(34), 동물행동학 박사, C급 헌터.
 → 파티원들이 보스 몬스터를 사냥한다. 서준호는 후방에서 기록 중.
 → "이 개체의 공격 패턴은 영역 방어 본능이야. 새끼가 있을 거다."
 → 파티장: "박사님, 관찰 말고 좀 싸워요."
 → 보스 사냥 성공. 그 뒤에 새끼 몬스터 3마리가 떨고 있다.
 → 파티원: "저것도 잡자." 서준호: "기다려. 이건 연구 가치가—"

1화: 새끼 몬스터 앞.
 → 서준호가 새끼 몬스터에 손을 뻗는다. 몬스터가 물려고 한다.
 → 행동학적 접근 — 시선을 낮추고, 느리게 접근하고, 울음을 모방한다.
 → 새끼 몬스터가 경계를 풀고 서준호의 손을 핥는다.
 → 시스템창이 뜬다.
 → [생태 시스템 활성화]
 → [관찰 대상 등록: 섀도울프 유체(E급)]
 → [관찰 완료 시 해당 종의 행동 패턴 스킬 획득]
 → [길들이기 성공: 충성도 23%]
 → 서준호의 눈이 빛난다. "…논문감이다."
 → 1화 마지막 줄: 새끼 섀도울프가 서준호의 발에 웅크린다. "너 이름은 '알파'다."
```

**후킹 구조**: 비전투 학자(설정) → 새끼 몬스터(감정) → 생태 시스템(반전) → "논문감이다"(유머+지적 쾌감). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **생태 시스템** | 몬스터를 관찰·연구하면 해당 종의 행동 패턴이 스킬로 변환. 길들이면 명령 가능 |
| **성장 축** | 연구 논문 수(=스킬 수) + 길들인 몬스터 수 + 몬스터 충성도·등급 |
| **논문 = 스킬** | 관찰 데이터 축적 → '논문 제출' → 스킬 해금. E급 논문(100회 관찰) ~ SSS급 논문(10,000회+) |
| **제약** | ① 전투 시 몬스터를 직접 죽이면 연구 데이터 소실 ② 길들이기 실패 시 몬스터 폭주 ③ 충성도 관리 필요(방치 시 탈주) ④ 본인 전투력 C급 고정 |
| **테이밍 한계** | 동시 유지 가능 몬스터: 초기 3마리 → 최종 30마리. 등급 합산 제한 |

### 3.2 헌터 세계 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 현재 | 몬스터=사냥 대상이라는 인식 지배 | 서준호의 반대 가치관 |
| 6개월 후 | 게이트 몬스터 생태 보고서 발표 | 학계 충격, 패러다임 전환 시작 |
| 2년 후 | 몬스터 활용 법안 통과 | 테이밍 합법화 |
| 4년 후 | 몬스터 생태계 위기 | 무분별한 사냥으로 생태계 붕괴 |
| 5년 후 | 차원 연결 | 몬스터 고향 차원과의 접촉 |

### 3.3 주인공 그룹

| 항목 | 설명 |
|------|------|
| **소속** | 초기: 1인 연구자 → 중기: '게이트 생태 연구소' → 후기: '테이머 길드' |
| **연구 실적** | 초기 논문 0편 → 최종 100편+ (각각이 스킬) |
| **길들인 몬스터** | 초기 1마리(알파) → 최종 30마리(S급 포함) |
