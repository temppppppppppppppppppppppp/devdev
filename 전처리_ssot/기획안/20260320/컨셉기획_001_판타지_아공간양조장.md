## 1. 로그라인

**F급 판정을 받고 헌터 등록조차 거부당한 전직 양조기능사가, 아공간에서 몬스터 소재로 영약주를 빚으면 마시는 자의 등급이 올라가는 사기 능력을 각성한다. 전투력 0, 그러나 그의 술을 마시면 S급이 된다.**

## 2. 1화 후킹 시퀀스

```
프롤로그: 각성 측정소.
 → "마나 반응 — F. 전투 적성 — 없음."
 → 주인공 강태주(32), 전직 양조장 기능사. 각성자 판정에서 최하등급.
 → 길드 면접 7곳 전멸. "전투 못 하는 헌터는 헌터가 아닙니다."
 → 자포자기로 편의점 술을 사 마신다.

1화: 빈 양조장 지하실.
 → 술에 취해 쓰러진 태주 앞에 시스템창이 뜬다.
 → [아공간 개방: 양조장(1평)]
 → 허름한 지하실이 아닌, 빛나는 양조장이 펼쳐진다. 발효통 1개, 증류기 1대.
 → 주머니에서 꺼낸 게이트 부산물(슬라임 젤) — 호기심에 넣고 발효시킨다.
 → 12시간 후. 풋사과 향의 투명한 술 1병.
 → [영약주 제조 완료: 슬라임 양조주 (E급)]
 → [효과: 음용 시 30분간 마나 총량 +15%]
 → 태주가 한 모금 맛본다. 풋사과와 슬라임의 기묘한 조화.
 → [경고: 음용자 마나 반응 없음. F급 비각성 체질. 각성자 전용 효과.]
 → "…내가 마셔도 안 되는 거야?" 그러나 맛은 놀랍도록 좋다.
 → 1화 마지막 줄: "맛은 내가 보증한다. …이거 팔면 안 되나?"
```

**후킹 구조**: 각성 실패(좌절) → 아공간 발현(반전) → 영약주 제조(호기심) → "팔면 안 되나?"(경제 쾌감 기대). 4단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **각성 방식** | 아공간 양조장 개방. 전투 능력이 아닌 **제작 특화 능력** |
| **아공간 성장** | 양조장 등급이 오르면 공간 확장(1평→10평→100평→…), 발효통·증류기 추가, 숙성실 해금 |
| **영약주 시스템** | 몬스터 소재 + 양조 기법 = 영약주. 등급(E~SSS)은 소재 등급 × 양조 숙련도로 결정 |
| **제약** | ① 양조에 실시간 대기 필요(즉석 대량 생산 불가) ② 같은 영약주 반복 음용 시 내성 ③ 태주 본인은 전투력 F 고정 — 팔 수만 있고 본인이 강해지진 않음 |
| **경제 시스템** | 영약주 가격 = 헌터 시장 수급에 따라 변동. 독점 제조자로서의 가격 결정력이 핵심 갈등 |

### 3.2 헌터 세계 배경

| 시기 | 사건 | 작중 활용 |
|------|------|-----------|
| 각성 원년 | 게이트 최초 출현 | 배경 설정 (10년 전) |
| 현재 | 헌터 포화 시대 | F~D급 헌터 실업률 40% — 태주의 출발점 |
| 6개월 후 | A급 게이트 러시 | 고급 영약주 수요 폭발 — 첫 번째 도약 |
| 2년 후 | SSS급 게이트 출현 | SSS급 영약주 필요 — 독점 지위 확립 |
| 4년 후 | 차원 균열 확대 | 아공간 확장의 부작용 복선 회수 |

### 3.3 주인공 그룹 (태주 양조장 → 양조길드)

| 항목 | 설명 |
|------|------|
| **상호** | 초기: 무허가 개인 양조 → 중기: '천양(天釀)' 양조길드 |
| **주력** | 영약주 제조·유통 |
| **시가** | 초기 0원 → 최종 영약주 시장 독점(시장 규모 2조+) |
| **인원** | 초기 1인 → 최종 30인+ (양조사·유통·보안) |
