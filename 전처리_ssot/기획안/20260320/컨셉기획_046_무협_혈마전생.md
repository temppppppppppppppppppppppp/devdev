## 1. 로그라인

**혈마교의 절대 교주 '혈마(血魔)'. 정사대전에서 무림맹주에게 전사한 그가 눈을 뜨니 — 정파 5대세가 남궁세가의 적자(嫡子) 남궁현(南宮玄)의 몸이었다. 전생의 부하는 현생의 적이고, 전생의 원수는 현생의 가족. 마도의 힘을 쓰면 정파에서 축출당하고, 정파 검법만으론 다가오는 위기를 막을 수 없다. 두 무공 체계의 충돌 속에서 그가 창시하는 전무후무한 경지 — 혈검일체(血劍一體).**

## 2. 1화 후킹 시퀀스

```
프롤로그: 정사대전 최후의 전장. 혈마교 본단.
 → 혈마교주 vs 무림맹주 장천웅의 최종 일전.
 → 혈마교주의 혈마대법(血魔大法)이 하늘을 붉게 물들인다.
 → 그러나 무림맹주의 천검귀일(天劍歸一)이 혈마교주의 가슴을 관통.
 → 쓰러지면서 혈마교주가 웃는다. "다음 생이 있다면... 이번에는 다르게."
 → 의식이 꺼진다.

1화: 남궁세가 본가, 어느 새벽.
 → 소년의 몸에서 눈을 뜬다. 낯선 천장. 비단 이불. 고급 가구.
 → 거울을 본다: 16세 소년의 얼굴.
 → 시녀가 들어온다. "도련님, 가주님께서 아침 문안을 기다리십니다."
 → 도련님? 가주? — 기억을 더듬는다. '남궁현'이라는 이름. 남궁세가 적자.
 → 복도를 걸으며 무의식적으로 혈마보법(血魔步法)을 쓰려다 급히 멈춘다.
 → 남궁세가 가주 남궁천의 앞에 선다. 그 뒤에 서 있는 인물 —
   전생에서 자신을 죽인 무림맹주 장천웅이 아버지의 벗으로 웃고 있다.
 → 1화 마지막 줄: "네가 남궁현이냐. 자라서 아비를 닮겠구나."
   — 원수의 손이 소년의 머리를 쓸어내린다. 핏줄 속 마기(魔氣)가 들끓는다.
```

**후킹 구조**: 프롤로그 전사(충격) → 환생(반전) → 정파 세가 적자(갭) → 전생 원수가 아군(극적 아이러니) → 마기 폭주 위기(긴장). 5단 임팩트.

## 3. 세계관 & 장르 설정

### 3.1 판타지 요소

| 항목 | 설정 |
|------|------|
| **환생 방식** | 전사 직후 의식 전이. 혈마교주 → 남궁세가 적자 남궁현의 몸에 환생 |
| **기억 유지** | 전생 기억 완전 보존. 단, 마공(魔功) 사용 시 전생의 살의(殺意)가 되살아나며 폭주 위험 |
| **환생 제약** | 남궁현의 몸은 정기(正氣)가 강한 체질. 마기(魔氣) 운용 시 경맥 역류 위험 → 두 기운의 융합이 유일한 해결책 |
| **이중 무공** | 혈마대법(마공) + 남궁검법(정공). 두 체계가 충돌하여 내상 발생 → 블록마다 융합 시도 |
| **핵심 갈등** | 마공을 쓰면 강하지만 정체 발각 → 축출/처형. 정공만으론 적을 막을 수 없음 |

## 6. 경지/내공/무공 성장 곡선 설계

### 6.1 핵심 규칙
- 이중 경지 시스템: **마공 경지** + **정공 경지** → 최종 융합
- 경지 체계: 기충(氣衝) → 혈동(血動) → 마각(魔覺) → 혈검합일(血劍合一) → 파마정심(破魔正心) → 혈도검존(血刀劍尊) → 마정일체(魔正一體)
- 시작: 전생 마공 기억은 있으나 **몸이 16세 → 내공 바닥**에서 재시작
- **최소 7블록에서 경지 하락/내상** 필수 (마공-정공 충돌)
- 마공과 정공을 동시 운용할 때마다 경맥 역류 위험

  패턴: 병약 체질 회복 → 남궁검법 기초 수련 → 비정상적 속도의 성장
