## 4. ARC-01~04 완료 요약

### ARC-01 (B01~B10): 장부의 비밀
- 서사 기동: 10년 자금 유출 폭로 → 흑풍방 연결 확정
- 경지: 산원 입문 → 장방
- 핵심 성과: 삼중 정보 체계(장부+홍매+서문경), 검무 호위, 첫 직접 거래, 백란 대면
- 거래 규모: 0 → 1만2천 냥

### ARC-02 (B11~B20): 상전(商戰)
- 서사 기동: 백란 가격 전쟁 + 관부 세금 + 흑풍방 암살
- 경지: 장방 → 대관
- 핵심 성과: 무당파 계약, 거란 교역, 가격 전쟁 승리, 유출 60% 차단
- 거래 규모: 1만2천 → 5만 냥

### ARC-03 (B21~B30): 가문의 균열
- 서사 기동: 큰오빠 추궁 → 가문 내분 → 소림 거부 → 중립 상인 선언
- 경지: 대관 → 재신 입문
- 핵심 성과: 약왕곡 선납, 무기 유통 절반, 사파 거래, 중립 상인 선언
- 거래 규모: 5만 → 10만 냥

### ARC-04 (B31~B40): 상단주의 무게
- 서사 기동: 서역 교역 → 자산 동결 → 아버지 은퇴 → 5대 문파 계약 → 큰오빠 진실
- 경지: 재신 → 상성 입문
- 핵심 성과: 서역 루트, 금맥도 초기형, 5대 문파 일괄 계약, 유출 100% 차단, 큰오빠 화해
- 거래 규모: 10만 → 30만 냥

### ARC-05 진행 중 (B41~B42 완료)
- B41 **무림 대란 서막**: 사파 연합군 정파 총공격. 소연이 장안 무림맹 별원에서 5대 문파 전시 보급 총관리 계약 체결. 독고진 선제 수락. 형제 전시 역할 분담. 거래 규모 30만→80만 냥. 보급로 2/3 사파 영향권 위험 잔존.
- B42 **전쟁의 경제**: 형양성 전시 물가 폭등. 매점매석 상인 곽원보/제인상회 격파(비축 물자 공정가 방출+서문경 은닉 창고 특정). '정파든 사파든' 공정가 선언. 백란 전시 공정가 참여(2대 상단 공동 물가 관리 시작). 배후 자금 관부 출처 정황. 거래 규모 80만→200만 냥.
- **다음: B43 패배 블록(보급로 차단)**
