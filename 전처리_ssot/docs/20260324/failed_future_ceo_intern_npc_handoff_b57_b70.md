# failed_future_ceo_intern NPC 이월 매핑 (Block 57→70)

> 자동 생성: 2026-03-25
> 소스: npc_tracker.md (Block 56 스냅샷) + phase0_design.json (ARC-06/07)
> 목적: Block 57~70 treatment 생산 시 relationship_delta.before 직접 복사용

---

## 사용법

Block N의 `relationship_delta` 작성 시:
1. 해당 NPC의 **이월 before** 값을 그대로 `before` 필드에 복사
2. 해당 블록에서 NPC 상태가 변하면 `after`를 새로 작성
3. 변하지 않는 NPC는 해당 블록의 `relationship_delta`에서 생략 (마지막 등장 블록의 after가 유지됨)
