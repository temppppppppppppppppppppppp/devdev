## 4. 핵심 서사 구조 요약

### 4.1 로그라인

2045년 제국그룹 파산·추락한 재벌 3세 막내 이준서(37)가 2025년으로 회귀. 20년치 미래 데이터를 무기로 코인→반도체→바이오→AI→금융→방산→우주까지, 항상 3개 섹터를 동시에 굴려 0원에서 200조 J제국홀딩스를 혼자 짓고 제국그룹을 통째로 먹는다.

### 4.2 3개 동시 롤링 시스템

- 항상 메인 1 + 서브A + 서브B = 3개 섹터가 동시에 돌아감
- 섹터 하나가 완성(구조화)되면 즉시 다음 섹터가 추가
- 이 리듬이 전 70블록 반복

### 4.3 원 패턴 5스텝 (매 섹터 반복)

1. 진입 — 준서가 섹터에 발을 내딛음
2. 업계 반응 (타자 POV) — 기득권이 뒤늦게 인지
3. 압박 — 기득권이 방해 실행
4. 돌파 (사이다) — 준서가 한 수 앞선 해결
5. 완성 — '다음.'

### 4.4 섹터 순서 (15개)

코인/주식 → 반도체 → 바이오 → 부동산/DC → AI/클라우드 → 이커머스 → 게임/IP → 엔터/OTT → 금융/PE → 패션 → 식품/푸드테크 → 에너지/SMR → 방산/우주 → EV/배터리 → 해운/물류
