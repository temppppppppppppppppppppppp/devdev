## ⑬ 「프로듀서인데 음악을 못 들음」

**힌트**: 천재 PD(#41)/음악천재(#110) → **비틀기: 청각장애 프로듀서**

**로그라인**: 전생에서 K팝 전성기를 만든 S급 프로듀서가 회귀했는데 — 이번 생에서는 50% 난청이다. 소리를 절반밖에 듣지 못하는 상태에서, 전생의 음악 지식과 업계 인맥으로 다시 한번 K팝 제국을 세운다.

**1화 후킹**: _리듬은 들리는데 멜로디가 안 들린다. 왼쪽 귀는 죽었고, 오른쪽 귀는 절반만 산다. 그런데 머릿속에는 2025년부터 2040년까지 차트 1위 곡의 멜로디가 전부 빽빽하게 채워져 있다. "들리지 않는 음악을, 세상에 들려주겠다."_

| 항목       | 설정                                                            |
| ---------- | --------------------------------------------------------------- |
| 비틀기     | 음악 천재인데 **못 들음** → 베토벤 + K팝 웹소설                 |
| 핵심 갈등  | 난청 악화 = 능력 소실. 시간제한 레이스                          |
| 자본곡선   | -5천만→5억→50억→20억(난청 악화)→300억→1,000억                   |
| 적대자     | ①전생에서 빼앗긴 곡을 쓴 작곡가 → ②대형 기획사 → ③글로벌 레이블 |
| **P3**     | ✅ "못 듣는 음악 천재" — 핸디캡 먼치킨의 극단형                  |
| **P4**     | ✅ 감동+사이다+음악 소재 인기 3연타                              |
| **5-Pass** | **PASS**                                                        |

## ⑭ 「엑스트라인줄 알았는데 카메라가 날 찍고 있었다」

**힌트**: 착각 배우(#62,#200)/엑스트라(#167) → **비틀기: 본인만 모름. 이미 찍혀서 편집됨**

**로그라인**: 촬영장 알바생이 실수로 프레임에 잡혔는데, 그 장면이 편집되지 않고 방영됐다. 반응이 폭발적이다. 감독이 일부러 그를 엑스트라로 계속 넣기 시작한다. 본인은 모른다 — 인터넷에선 이미 '유령 배우'로 바이럴 중.

**1화 후킹**: _"야, 너 어제 드라마에 나왔더라." — "뭐? 나 촬영장 의자 정리하는 알바인데?" — "12분 38초에 네 뒤통수가 잡혔는데, 시청자 게시판에 '뒤통수 남' 검색량 1위야."_

| 항목        | 설정                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 비틀기      | 인식하지 못 한 채 스타가 됨. **뒤통수→옆모습→정면→주연** 점진적 노출 |
| 판타지 없음 | 순수 현실물. "운빨+외모+분위기" 연기                                 |
| 자본곡선    | 알바비 80만→CF 3억→조연 20억→주연 100억→300억                        |
| 적대자      | ①정체 파헤치는 기자 → ②선배 배우 견제 → ③소속사 노예계약 시도        |
| **P3**      | ✅ "인지하지 못한 성공" — 수동적 주인공이 웹소설에선 역설적 매력      |
| **P4**      | ✅ 얼떨결 스타 판타지 + 유머 + 로맨스 가능                            |
| **5-Pass**  | **PASS**                                                             |

## ⑮ 「미국 트럭에서 50년 된 편지가 나왔다」

**힌트**: 미국 트럭커(#11,#163) → **비틀기: 골동품이 아니라 "사연 있는 편지"를 배달**

**로그라인**: 미국 대륙 횡단 트럭 안에서 50년 전 부쳐지지 못한 편지 한 다발이 나온다. 편지를 원래 수신인에게 전달할 때마다 — 그 가문이 숨긴 재산·유산·비밀이 쏟아진다. 트럭커가 편지 배달부 겸 보물 사냥꾼이 된다.

**1화 후킹**: _대시보드 뒤 숨겨진 칸에서 마닐라 봉투 32개. 소인 1974년. 전부 '반송불가.' 첫 번째 편지를 열면 — 텍사스 유전 지분 양도 증서. 현시가 200만 달러._

| 항목       | 설정                                                               |
| ---------- | ------------------------------------------------------------------ |
| 비틀기     | 트럭커 → 오래된 편지 배달 → 재산 발굴. **로드무비+보물찾기**       |
| 자본곡선   | $3,000→$200만(유전)→$50만(사기)→$800만→$3,000만→$1억               |
| 적대자     | ①편지 소유권 주장자 → ②유산 노리는 가족 → ③FBI(미해결 사건 연루)   |
| **P3**     | ✅ "편지 배달"이 보물찾기가 되는 구조. 기존 감정+트럭커 장르와 다름 |
| **P4**     | ✅ 미국 로드무비 감성 + 32개 에피소드 자동 생성 구조                |
| **5-Pass** | **PASS**                                                           |

## ⑯ 「스위스 폐호텔에 유령이 경영을 가르침」

**힌트**: 스위스 호텔(#26) → **비틀기: 호텔에 남은 유령 전주인이 멘토**

**로그라인**: 외할머니에게 물려받은 스위스 알프스 폐호텔에 유령이 산다 — 1920년대 호텔 전성기의 전설적 주인장. 유령이 200년 전 스위스 호텔 경영 노하우를 가르쳐주는데, 그 방식이 21세기와 완전히 충돌한다.

**1화 후킹**: _"침대보는 이집트산 600수가 최소야." 유령이 말했다. "그거 장당 50만원인데요." "그래서? 손님이 돈을 안 낸다면 네가 쫓겨나는 거야." — 1922년 파리 리츠 호텔을 '제 돈으로' 거기가서 리모델링한 유령 프리들리히. 이 유령의 기준은 미슐랭 3스타 호텔._

| 항목       | 설정                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 비틀기     | 유령 멘토가 **극도로 비현실적 기준**을 요구 → 좌충우돌 갈등+코미디     |
| 자본곡선   | €-20만→€50만→€200만→€50만(유령 방식 실패)→€1,000만→€5,000만            |
| 적대자     | ①마을 주민(유령 소문) → ②체인 호텔(인수) → ③스위스 문화재청(건물 규제) |
| **P3**     | ✅ "유령 멘토+호텔 경영"은 없음. 시절 갭 코미디 강점                    |
| **P4**     | ✅ 힐링+코미디+해외 감성. 여성 독자층도 흡인                            |
| **5-Pass** | **PASS**                                                               |

## ⑰ 「알래스카에서 곰을 살렸더니 인생이 바뀜」

**힌트**: 알래스카 사냥꾼(#58)/동물(#101) → **비틀기: 사냥 능력이 아니라 동물 구조+소통**

**로그라인**: 알래스카 수렵 가이드가 부상당한 회색곰을 살린 후, 야생동물과 소통하는 능력이 생긴다. 동물들이 가르쳐주는 건 — 금맥 위치, 원유 매장지, 광물 노다지. 이 정보를 독점해서 알래스카의 자원 왕이 된다.

**1화 후킹**: _총구를 내렸다. 피를 흘리는 회색곰의 눈이 나를 봤다. — 수의학 교재에서 배운 봉합을 해줬다. 일주일 후, 곰이 산삼을 물어왔다. 그 다음엔 금 조각을. 그 다음엔 — 석유 냄새가 나는 흙을._

| 항목       | 설정                                                     |
| ---------- | -------------------------------------------------------- |
| 비틀기     | 사냥꾼이 동물을 죽이는 게 아니라 **살려서** 파트너가 됨  |
| 자본곡선   | $2,000→산삼 $5만→금광 $200만→환경단체 갈등→$2,000만→$1억 |
| 적대자     | ①밀렵 조직 → ②석유 기업 → ③알래스카 주정부               |
| **P3**     | ✅ 사냥꾼이 동물 구조자 → 자원 탐사 조합은 완전 신규      |
| **P4**     | ✅ 힐링+동물+모험. 곰 캐릭터 인기 보장                    |
| **5-Pass** | **PASS**                                                 |

## ⑱ 「추방당한 천재인데 미국이 울며 불러요」

**힌트**: 생명공학자 추방(#51)/한인 천재(#13) → **비틀기: 추방 사유가 "능력 숨기기"**

**로그라인**: 미국 연구소에서 해고+추방당한 한국인 AI 연구자. 추방 사유: '연구 성과 미달.' 실제론 연구가 **너무 잘 돼서** 남에게 줄 수 없어 일부러 데이터를 숨기고 한국으로 가져왔다. 자기 회사에서 독점 상용화하자 — 미국 빅테크 5사가 울며 전화한다.

**1화 후킹**: _"Dr. 윤, 당신의 비자가 만료되었습니다." — "네, 알겠습니다." 속으로 웃었다. 인천공항. 캐리어 안에 128TB SSD가 하나. 이 안에 미국이 50조 달러를 들여도 못 만든 알고리즘이 있다. 이건 내 거다._

| 항목       | 설정                                                         |
| ---------- | ------------------------------------------------------------ |
| 비틀기     | 추방이 **자발적 위장** → 도망이 아니라 포석                  |
| 자본곡선   | 0원→정부지원 50억→500억→미국소송→3,000억→1조→5조             |
| 적대자     | ①미국 전 회사 → ②중국 AI 기업 → ③미국 정부+CIA               |
| **P3**     | ✅ "추방" 소재 자체는 있지만 "일부러 숨겨서 추방 유도"는 없음 |
| **P4**     | ✅ 한국인 대리만족 극대화. "미국이 울며 불러"는 킬링 후킹     |
| **5-Pass** | **PASS**                                                     |
