## 2. Findings First

1. **극단적 초반 모욕의 밀도**: ep1 도입부 4줄 만에 고시원+각혈+라면 부족까지 쌓는다. "재벌 3세였다"라는 반전이 먹히려면 바닥이 충분히 깊어야 하는데, 이 작품은 신체적 고통(각혈)까지 동원해 바닥을 극한으로 판다. → 현대 현판 기업물에서 1화 전반 20% 안에 주인공의 처지를 체감시키는 모욕 설계 템플릿으로 쓸 수 있다.

2. **능력치 시스템 = 안목 보정 치트**: 미래 지식이나 초능력이 아니라 '사람을 보는 눈'만 보정한다. 전생의 최대 결함(사람 보는 눈이 없었음)을 정확히 메우는 설계. → 기업물 주인공에게 "왜 매번 옳은 사람을 고르는가"를 납득시키는 최소 장치로 이식 가능하다.

3. **1화 마이크로 사이다(파텍필립 감정)**: ep1에서 하청업체 사장의 가난한 척 연기를 고급 시계 감정 하나로 깨뜨린다. 능력치가 아닌 전생 경험으로 처리해서 치트 의존도를 낮춤. → 1화 안에서 "이 주인공은 수준이 다르다"를 증명하는 마이크로 이벤트 패턴이다.

4. **할아버지-손자 정서 앵커**: 할아버지가 유일한 가족이자 자원 파이프라인이자 지켜야 할 대상. 보호 동기+자원 접근+정서적 연결을 한 관계에 몰아넣는다. → 현대 현판에서 "왜 이 회사를 지키는가"의 감정 근거를 1인 관계로 압축하는 구조.

5. **1→5화 자본 에스컬레이션 속도**: 100만 달러(용돈) → 니케이 하락 수익(1,400억) → 걸프전 2억 달러 베팅. 5화 만에 3단 점프. → 초반부 성장 곡선의 가속도를 어떻게 설계하면 독자가 "빠르다"고 느끼는지의 벤치마크.

6. **글로벌 인맥 = 재벌물 스케일 확장 장치**: 사우디 왕실(5화), 퀀텀펀드 조지(10화)를 10화 안에 확보. 국내 재벌물이 아니라 글로벌 금융 전장으로 무대를 넓히는 장치. → 현대 현판에서 "국내 시장 → 해외 시장" 확장의 트리거 설계에 참조할 수 있다.

## 3. Master Reference Card v1

### opening_humiliation
고시원+각혈+라면 부족+20년간의 추락사. ep1 첫 4줄에서 신체적 고통(피)까지 동원해 바닥을 시각적으로 각인시킨다. "재벌 3세였다(과거형)"로 낙차를 극대화.

### starting_deficit
태우그룹 부도(외환위기) → 추징금 18조 → 할아버지 징역 10년 → 배신한 공신들 → 20년간 고시원 생활 → 사람 보는 눈 부재(자기 진단). 물질+관계+능력 세 축이 전부 결핍.

### protagonist_edge
- **what**: 신상명세서 능력 — 사람의 얼굴을 보면 이름, 소속, 특이사항, 업무 능력치(A~D)가 떠오른다.
- **how**: 회귀 시 자동 부여. 미래 지식이나 전투력이 아닌 '인물 감별' 특화. 전생에서 "사람 보는 눈이 없었던" 결함을 정확히 보정하는 설계.

### ep1_hook
고시원 각혈 → "나는 재벌 3세였다" 반전 → 20년 추락사 압축 → 임종 직전 "2번째 기회를 달라" 기도 → 17살로 회귀. 도입 3분 분량 안에 바닥→반전→회귀 삼박자 완료.

### ep1_first_saida
하청업체 사장이 허름한 옷으로 가난한 척 하면서 납품가 인하를 요구하는 장면. 주인공이 손목의 파텍필립 컴플리케이션(10억 이상)을 감정해 연기를 깨뜨림. 신상명세서가 아닌 전생 경험(명품 구매력)으로 처리해 치트 과의존을 회피.

### ep1_first_recognition
할아버지가 스위스 은행 페이퍼컴퍼니 명의 통장(100만 달러)을 입학 선물로 줌. 재벌가의 스케일 + 할아버지의 편애 + 증여세 회피 꼼수를 한 이벤트에 압축.

### ep1_end_hook
할아버지의 사랑과 신뢰 확보 + 100만 달러 시드머니 확보 + "닥쳐올 미래를 위해 사랑받는 손자가 되어야 한다"는 전략적 동기 공개. 회귀자가 순진한 아이 연기를 한다는 긴장감.

### block1_summary
ep1~10: 회귀(17살) → 할아버지 신뢰 확보 → 100만 달러 시드 → 전담팀 구성(한정훈) → 니케이 하락 수익(1,400억) → 사우디 왕실 인맥(살만·무함마드 빈 살만) → 걸프전 2억 달러 베팅 → SAVE 투자회사 설립 → 퀀텀펀드(조지) 동맹 → 파운드 공매도 60억 달러 투입.

### block1_spike_type
**금융 레버리지 연쇄 베팅**. 니케이 → 걸프전 → 파운드 공매도. 각 베팅이 다음 베팅의 시드가 되는 에스컬레이션 구조. 단순 "미래 지식으로 주식 사기"가 아니라 헤지펀드 동맹·글로벌 금융전쟁 참전 형태로 스케일업.

### first_reward
니케이 지수 30% 하락 수익 → 자본금 1,400억 원 확보(ep5). 주인공이 직접 트레이딩한 게 아니라 한정훈 팀장에게 위임한 구조. 보상의 규모가 "학생의 용돈"에서 "기업 수준 자본"으로 한 번에 점프.

### reward_stay_method
수익을 현금으로 쌓아두지 않고 즉시 다음 베팅(걸프전)에 재투입. 독자에게 "이 돈이 앞으로 더 커진다"는 기대감을 유지. 중간에 소비 씬 없이 전액 재투자로 처리.

### growth_1_10
- **1화**: 회귀 + 신상명세서 능력 + 100만 달러 시드
- **5화**: 니케이 수익 1,400억 + 걸프전 2억 달러 베팅 + 사우디 왕실 인맥
- **10화**: 퀀텀펀드 동맹 + 파운드 공매도 60억 달러 + 하버드 추천서 확보
- **성장 축**: 자본(100만 달러→수백억 달러급) + 인맥(국내→중동왕실→월가) + 학업(SAT 준비→하버드 조기졸업 루트)
- **20화**: 태우그룹 내부 비리 척결 착수 — 검경·국세청·언론 동원, 재벌 3세가 직접 내부고발 기자회견
