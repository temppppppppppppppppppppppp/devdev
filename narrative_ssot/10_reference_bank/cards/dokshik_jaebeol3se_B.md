## 2. Findings First

1. **연쇄 독식 엔진** — 한 부문(금융)을 먹고 그 자금력+권위로 다음 부문(제조)을 먹는 구조가 50화 내내 반복된다. 장편 현판물에서 "어떻게 스케일을 키우나"의 교과서적 체인.

2. **돈→권위 변환 루프** — 해외 투자 수익(SAVE) → 국내 대출 우회(CT은행) → 그룹 내 부채 정리 → 비리 청소로 도덕적 권위 획득. '돈만으로 권력을 사는 것이 아니라, 돈으로 정당성을 산다'는 현판 특유의 패턴. 이 루프가 없으면 주인공이 단순 금수저로 전락한다.

3. **내부 적 제거의 3단 함정** — 감시(강 대위)→ 증거 축적 → 적이 스스로 큰 사고를 치도록 유도한 뒤 역이용(ep50 이노폰 비방 기사). 적이 자멸하게 만드는 구조여서 주인공의 호감도 손실 없이 권력 교체가 가능하다. 기업물 장편의 악역 처리 레퍼런스.

4. **세대 충돌을 성장 기어로 전환** — 할아버지의 "대마불사(양적 팽창)" vs 주인공의 "영업이익률(선택과 집중)" 대립이 ep40에서 폴더폰 지휘권 협상의 동력이 된다. 세대 차이가 단순 갈등이 아니라 사업권 획득의 레버로 작동.

5. **지역 권력 대면으로 스케일 점프** — ep30 명동 사채시장 직접 대면 장면. 주인공이 '해외 자금'이라는 비대칭 무기로 국내 금융 권력을 정면 돌파한다. 현판 기업물에서 "국내 토착 세력"과의 첫 충돌을 어떻게 설계하는지 보여주는 구조.

6. **기술 특허 선점이 제조업 장악의 전제** — ep35의 폴더폰 특허 전쟁이 ep40 사업권 획득의 근거가 된다. "이 기술은 내가 만든 것이니 내가 지휘한다"는 논리 구조. 현대 현판에서 '무엇을 먼저 만들어야 사업부를 달라고 할 수 있는가'의 설계 재료.

## 3. 확장 구조 전용 카드 — Master Reference Card v1

### core_fantasy
회귀한 재벌 3세가 미래 지식과 해외 자금력을 무기로, 망해가는 가문의 그룹을 부문별로 장악하여 글로벌 독식 재벌로 재건하는 총체적 지배 판타지.

### money_flow
- **ep1–10**: 걸프전 유가 선물 → 레버리지 투자 → SAVE 투자회사 설립(100억 달러급) → 파운드화 공매도(퀀텀펀드 동맹, 60억 달러)
- **ep10–20**: 다중 통화 공매도(마르크/프랑/리라) → SAVE 자산 360억 달러 도달
- **ep20–30**: SAVE 주거래 은행 CT은행 지정 → 태우그룹 4천억 원 대출(실제로는 자기 자금)
- **ep30–50**: 이노폰(폴더폰) 개발 → 태우전자 매출 엔진 전환 + 톰슨 멀티미디어 인수 공작(해외 제조업)

### power_flow
- **1단계 (ep1–10)**: 돈 = 월가 자금력으로 태우그룹 외부에 독립 기반 확보
- **2단계 (ep10–20)**: 정화 = 창원 공장 비리 적발 + 기자회견으로 그룹 내 도덕적 권위 확립
- **3단계 (ep20–30)**: 장악 = 감사팀 성과급 제도로 내부 정보망 구축 + 명동 대면으로 외부 위협 무력화
- **4단계 (ep30–50)**: 확장 = 기술 연구소→태우전자 휴대폰 사업 지휘권 → 해외 기업 인수 → 내부 적 함정으로 제거

### deal_types
- 국제 공매도 동맹 (퀀텀펀드)
- 해외 은행 대출 우회 (CT은행)
- 비리 내부 고발 + 언론전 (창원 공장)
- 기술 특허 선점전 (폴더폰 접이식 메커니즘)
- 해외 기업 인수 (톰슨 멀티미디어)
- 거짓 정보 역이용 함정 (이노폰 비방 기사)

### stakeholders
- 김태중 회장 (할아버지) — 최종 권력자, 대마불사 철학, 세대 갈등 상대
- 김택훈 비서실장 — 내부 조력자, 그룹 행정 채널
- 제프리 부사장 — SAVE 투자회사 운영, 해외 자산 관리
- 한정훈 팀장 — S급 분석력, 투자 전문가
- 강 대위 — 정보/감시/증거 확보 전담, 군 출신 실행 부대
- 박진훈 사장 — 태우전자 내 적대자, 사업권 경쟁 상대
- 우성일 부사장 — 박진훈의 충견, 배신 가능 약점 보유
- 광화문 곰(이선일) — 명동 사채시장 4대 큰손, 토착 금융 권력
- 퀀텀펀드(조지) — 국제 금융 동맹, "모든 전쟁의 동맹군"

### growth_11_30
- **ep10–15**: 퀀텀펀드 동맹 체결(파운드 공매도 60억$) + 다중 통화 공매도로 SAVE 자산 급팽창. 월가에서의 입지 확보.
- **ep20**: 창원 부품 공장 비리 적발 → 압수수색 + 기자회견 → "재벌 3세가 직접 내부 고발"이라는 전례 없는 이벤트로 언론 장악 + 그룹 내 '정화자' 이미지 확립.
- **ep25**: 감사팀 성과급 제도(횡령 환수금 10%, 내부 고발 30% + 인사고과 최우수) 도입으로 정보 수집 체계 구축. 기존 부패 세력(정 부장)과의 대립 시작.
- **ep30**: SAVE 자금력(360억$)을 배경으로 CT은행 대출 4천억 원 실행 → 명동 사채의 고리를 끊고 → 광화문 곰(이선일) 직접 대면. "5년 안에 명동의 주인이 되게 해 주겠다"는 제안으로 적대→동맹 전환 시도.

### growth_31_60
- **ep35**: 폴더폰 특허 전쟁 착수 — 접이식 메커니즘/배터리 기술 특허 선점. 미국 로펌(윌머헤일) 통해 한미 동시 출원. 기술 주도권이 후속 사업권 주장의 법적 근거가 됨.
- **ep40**: 할아버지 설득 전 — 영업이익률 vs 대마불사 논쟁. 할아버지에게 폴더폰 시제품 보여주고 박진훈 사장에게는 감추는 이중 정보전. "1년 내 성과 못 내면 손 떼겠다"는 자충수 연기로 박진훈이 자발적으로 사업 자원(인천/부천 공장, 개발팀, 자금)을 넘기도록 유도. 태우전자 휴대폰 사업 실질 지휘권 획득.
- **ep45**: 데이비드의 프랑스 파견 — 톰슨 멀티미디어 임원진 포섭. 해외 기업 인수의 전 단계로 내부 불만 활용한 인적 네트워크 구축.
- **ep50**: 박진훈→우성일 경유 이노폰 비방 기사 유출을 사전 감지·촬영·녹음 완료. 기사를 일부러 막지 않고 '허위 정보 반박'으로 역전시키는 3단계 함정 가동. 적의 공격을 제품 광고로 전환 + 적의 범죄 증거 축적.

## 5. 현대 현판 적용 분해

### 바로 이식 가능
- 연쇄 독식 엔진의 부문별 장악 시퀀스 (금융→감사→기술→제조→해외)
- 돈→정당성 변환 루프 (자금력을 도덕적 권위로 세탁)
- 3단 함정 적 제거 구조 (감시→유도→역이용)
- 감사팀 성과급 같은 "제도 설계로 충성 세력 형성" 패턴
- 세대 충돌(양적 팽창 vs 선택과 집중)을 사업권 획득의 레버로 활용하는 구조

### 변형 후 사용
- "해외 자금"이라는 비대칭 무기 — 시대/맥락에 맞는 비대칭 자원으로 교체 필요 (예: 기술 특허, 데이터 자산, 규제 지식 등)
- "명동 사채시장 대면" — 토착 금융 권력 대면의 구조는 쓸 수 있으나, 명동/사채라는 구체 장소와 업종은 교체 필요
- "폴더폰 특허 선점" — '기술 선점이 사업권 주장의 근거'라는 논리 구조는 이식 가능하나, 구체 기술(접이식 휴대폰)은 교체 필요
- 기자회견 내부 고발 — 여론전 구조는 차용 가능하나 장면의 구체 연출은 변형 필수

### 폐기
- 회귀 + 미래 지식이라는 핵심 치트키 (현대 현판에서 그대로 쓰면 이 작품의 카피)
- 파운드화 공매도 / 외환위기 / 걸프전 유가 등 실제 역사 이벤트 차용 (시대 특정적)
- 퀀텀펀드(조지 소로스 모티프) 동맹 설정 (실존 인물 기반)
- 애플(스티브 잡스) 협업 설정 (실존 기업/인물 기반)

## 6. 마지막 3줄

- **장편 구조를 레퍼런스로 쓰는 이유**: 한 부문의 성공이 다음 부문 진입의 자격증이 되는 '연쇄 독식 엔진'이 50화 내내 일관되게 작동하며, 이 구조 자체가 현대 현판 기업물 장편의 스케일 확장 설계도로 직접 활용 가능하다.
- **가장 강한 거물화 재료**: 돈→정당성 변환 루프 — 해외 자금력을 비리 청소에 투입하여 '도덕적 권위'로 전환하고, 그 권위로 다음 사업부를 장악하는 순환 구조.
- **절대 베끼면 안 되는 확장 요소**: "회귀 + 미래 지식 기반 투자"라는 핵심 치트키 — 이것을 그대로 쓰면 성장 구조가 아니라 이 작품의 외피를 통째로 가져가게 된다.
