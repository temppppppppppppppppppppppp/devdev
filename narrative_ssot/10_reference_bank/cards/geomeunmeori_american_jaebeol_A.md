3. **악당성 선제 공개 + 독자 계약**: ep1부터 "나는 악마가 될 생각이다", "소수를 속이면 사기꾼이지만 만인을 속이면 영웅"을 직접 선언. 주인공의 도덕 경계를 처음부터 명시해 독자가 불의를 응원할 준비를 하게 만드는 구조. → 현대 현판에서 주인공의 이중성을 도입부에서 처리하는 기법.

4. **저비용 정보망 설계**: 구두닦이 소년 길버트를 정보원으로 운영. 마피아 술집 앞 배치 → 내부 인원수 + 동선 실시간 파악. 자본 없이 정보 우위를 만드는 패턴. → 현대 기업물에서 비서·경비·청소부 등을 정보망으로 활용하는 "눈에 안 보이는 인텔 구조" 설계 참조.

5. **플랫폼 쌓기형 성장**: 자본 직접 베팅이 아닌 "사람을 내 밑으로 끌어들이는" 방식. 마크(중간 관리자) → 존 토리오(마피아 최고 보스) → 밀턴(맥아더 인연 사다리). 각 에피소드의 인맥이 다음 인맥의 진입 티켓. → 현대 현판에서 "팀장 → 임원 → 오너"로 이어지는 인맥 교체 설계의 원형.

6. **zero-cost 자원 창출**: 소뼈(도축장 폐기물)로 곰탕, 남는 사탕수수로 슬러시·착즙기 제작, 버려진 공터를 텃밭으로. 돈 없는 상태에서 "문제 해결 능력"으로 공동체 장악. → 현대물에서 초반 시드머니 없이 주인공의 창의성을 증명하는 에피소드 설계 참조.

## 3. Master Reference Card v1

### opening_humiliation
1902년 하와이 항구. 갤릭호에서 내린 102명 조선인 이민 노동자 중 1인. 아버지는 결핵(신체검사 탈락 직전), 어머니는 두 손 모으고 기도. 백인 농장 관리인에게 "원숭이"라고 조롱당하며 채찍 위협 직전. 조선에서도 미국에서도 최하층. 배경: 망해가는 대한제국(4년 후 을사늑약).

### starting_deficit
- 환생 조건: 1902년 하와이 이민 1세대 노동자 가정, 16세 장남
- 아버지: 결핵 — 페니실린 없는 시대(20년 후에야 개발 예정), 사실상 사망 예고
- 초기 자본: 0 (조선인 이민 노동자 평균 월급 15달러)
- 환경: 영어 불통 공동체 100명, 인종차별 일상, 하와이 원주민 충격
- 국적: 망해가는 대한제국 국민 (돌아가도 할 수 있는 것 없음)
- 단, 환생자 어드밴티지: 미래 역사 전체 지식 + 다국어(영어/일본어/중국어) + 전생 격투기 능력

### protagonist_edge
- **핵심 치트**: 환생자 — 미래 역사 지식 전부 (페니실린, 운산 금광, 알 카포네, 맥아더, 2차대전, 임팔 작전 등)
- **언어**: 영어/일본어/중국어 유창 (이민 도착 즉시 활성)
- **전투력**: 전생 프로 격투기 수준 (ep2에서 성인 남성을 돌+무릎으로 제압)
- **본질**: "선한 성향 절대 아님" 자각 + 악마적 실용주의. "만인을 속이면 영웅" 철학. "악마가 되어야 가장 빠르게 성공한다" 선제 선언.

### what
미국을 움직이는 대재벌 건설. 표면: 조선 독립자금 후원자 이미지 활용(국뽕으로 조선인 공동체 결속). 실제: 자기 제국 구축. 1902년 하와이에서 출발해 시카고 → 전미 → 글로벌 스케일.

### how
마피아를 발판 삼아 합법/불법 혼합 사업 확장. 미래 역사 지식으로 선제 투자(운산 금광, 바나나 농장, 낙농 회사). 핵심 인맥 단계적 교체(마크→존 토리오→밀턴→맥아더). 조선인 공동체를 조직화해 노동력+충성 기반으로 활용. 정보망(구두닦이 소년)으로 마피아 내부 동향 선점.

### ep1_hook
하와이 항구 신체검사 장면. 결핵 아버지 탈락 직전 → 소년 피터가 영어로 농장주 마크에게 즉흥 협상 진입 → "저 아저씨들에게 작업 지시할 때 누가 통역합니까?" + "일본인 파업 계획을 제가 먼저 알 수 있습니다" → 아버지 입국 허가 + 50달러 계약 성립. 주변 조선인 102명 전체 기절.

### ep1_first_saida
농장 관리인이 "원숭이"라고 조롱 + 채찍 위협 상황. 피터: "첫날 애를 때리면 저 아저씨들이 일합니까?" 역제압. 마크가 즉각 관리인을 꺾고 피터 편을 들어줌. 힘 없는 상태에서 언어로 완성한 첫 번째 공개 승리.

### ep1_first_recognition
마크: "재밌는 녀석이야" 반복 인정. 월급 55달러(계약+보너스 5달러) 지급 → "돈 쓸 줄 아네 / 사람 부릴 줄 안다" 상호 인식. 조선인 커뮤니티 전체에서 "마귀가 깃들었다"는 소문이 날 정도의 이탈적 존재감.

### ep1_end_hook
"사실 나는 앞으로 악마가 될 생각이다. 그래야 가장 빠르게 성공할 수 있다" 독백. 의친왕 씬 삽입 — 대한제국 멸망의 그림자. 마크와 한 달 후 성과 평가 예약(카지노 사업 제안 성사 여부). 관리인 복수 해결 미완(ep2로 이월).

### block1_summary
- **ep1**: 하와이 도착 → 마크 첫 계약 (50달러) → 악마 선언
- **ep2**: 바나나 농장 + 카지노 사업 제안 → 관리인 해고 주도 → 격투로 보복
- **ep3**: 카지노 성공(월 순수익 3만달러) → 마피아 보스 존 토리오 등장 → 대부 거절 후 역제안으로 존 보스를 대부로 만듦 → 시카고 이동 결정
- **ep5**: 시카고 마피아 내부 편입 → 운산 금광 채굴권 50% 확보 → 구두닦이 정보망 가동
- **ep10**: 피터 팬 낙농 주식회사 설립 → 밀턴(회계사) 납 주사위 속임수로 포섭 → 마피아 내 파워게임(니콜라 vs 마르코) 편입
- **ep20**: 마피아 내 후계 분쟁에서 존 보스의 핵심 중재자 역할. 니콜라·마르코 세력 모두를 움직이며 자기 위치 극대화.

### block1_spike_type
**플랫폼 쌓기형 + 인맥 레버리지형**. 자본 직접 베팅이 아니라 "사람을 내 밑으로 끌어들이는" 방식으로 성장. 각 에피소드가 다음 에피소드의 인맥/자원 진입 티켓. 자본 증식보다 조직 장악이 먼저.

## 5. 현대 현판 적용 분해

### 바로 이식 가능
- **1화 즉각 능력 증명 + 가족 생사 연결 구조** — 능력 시현이 "추상적 자랑"이 아니라 이해관계자의 생존과 직결되게 설계하는 방식. 현대 기업물 첫 보고·회의 씬에서 주인공이 팀 또는 상급자를 "구하는" 형태로 직접 이식 가능.
- **권력자 역제안 구조** — 을의 위치에서 갑의 제안을 거절하고, 오히려 갑을 자기 플랫폼으로 편입시키는 패턴. 현대 현판 "오너가 스카웃 제안 → 주인공이 조건을 거는" 씬 설계 원형으로 직접 활용 가능.
- **악당성 선제 공개 + 독자 계약** — ep1에서 주인공의 도덕 경계를 명시해 독자가 불의를 응원할 심리 계약을 맺는 기법. 현대 현판 주인공의 이중성을 도입부에서 처리하는 방식으로 이식 가능.
- **저비용 정보망 설계** — 구두닦이(하층부·비가시 직군)를 정보원으로 포섭하는 구조. 현대 재벌물에서 청소부·경비·배달 라이더·주차 관리원을 내부 인텔 소스로 활용하는 "눈에 안 보이는 정보망" 설계로 이식 가능.

### 변형 후 사용
- **플랫폼 쌓기형 인맥 교체** — 마크→존 토리오→밀턴의 단계적 인맥 교체 패턴은 현대판 "팀장→임원→오너" 교체 설계로 이식 가능. 단, 마피아 조직 계층 언어(보스·대부·카포·조직 불문율)는 현대 기업 언어로 전량 교체 필수.
- **zero-cost 자원 창출** — 소뼈 곰탕·사탕수수 슬러시·버려진 공터 텃밭 등 "폐기물·유휴 자산 → 수익"의 창의성 증명 패턴은 현대 기업물에서 "유휴 데이터·미활용 인프라·사내 잉여 자원 재가공" 에피소드로 변환 가능. 시대 배경(1902년 하와이)과 소품은 교체 필수.
- **환생자 미래 역사 지식** — 설정 자체는 현대물 이식 불가이나, 구조("남들이 모르는 흐름을 먼저 아는 자")는 현대판 "업계 내부 정보 선점" 또는 "데이터·트렌드 선행 분석" 패턴으로 치환 가능. 치트 의존보다 실행력 강조 구조는 그대로 유지.

### 폐기
- 존 토리오·알 카포네·맥아더·의친왕 등 실존 역사 인물 직접 접점 — 표절+팩션 시비+시대 혼재 3중 위험. 구조만 빌리고 인물은 반드시 픽션으로 교체.
- 1900년대 마피아 조직 구조 언어 (대부·보스·카포·조직 불문율) — 현대 기업물 이식 시 시대 혼재 즉시 발생.
- 조선인 이민 1세대 공동체 서사 전체 (대한제국 멸망·을사늑약·독립운동 구심점) — 시대적 고유 설정이므로 현대물에 직접 이식 불가.
- "검은 머리 미국인" 정체성 갈등 — 이 작품의 핵심 주제 축. 현대물에서 분리된 별도 서사로 처리하지 않는 한 사용 금지.

## 6. 마지막 3줄

**이 초반부를 레퍼런스로 쓸 이유**: "인맥 레버리지 + 제도적 보호막 확보"로 0에서 대재벌까지 성장하는 플랫폼 쌓기 구조를 가장 극단적인 바닥(이민 노동자)에서 출발해 보여주는 현존 유일의 글로벌 스케일 재벌물 — 현대물에서 "왜 이 주인공이 결국 모든 것을 얻는가"의 초반 설계 원형으로 쓸 수 있다.

**가장 강한 Block 1 재료 1개**: **마피아 대부 역제안 구조** (ep3) — "대부가 되어주겠다"는 최고 권력자의 제안을 당당히 거절하고 오히려 상대를 자기 대부로 만드는 역전. 을의 위치에서 갑을 내 플랫폼으로 편입시키는 초반 사이다의 설계 원형. 현대 기업물의 "오너가 스카웃 제안 → 주인공이 조건을 거는" 씬 설계에 직접 이식 가능.

**절대 베끼면 안 되는 초반 요소 1개**: **존 토리오·알 카포네·맥아더 실존 인물 인연 구조** — 이 작품의 핵심 스케일 장치이지만 실존 역사 인물 직접 접점이라 현대물에 그대로 이식하면 표절 + 시대 혼재 + 팩션 시비 세 가지 위험 동시 발생. 구조만 빌리고 인물은 반드시 픽션으로 교체해야 한다.
