## 0. Purpose

material canon (`material_ssot/20_pitch/canon/quiet_chaebol_heir.md`)은 다음 항목을 `later_enrichment_only`로 위임함:

- 누나의 대외 협상 대표 승부 1건의 구체 안건
- 해외 조달선 국가 후보와 각 국가 리스크
- 글로벌 소비재 확장 순서와 JV 후보

ARC-05 진입(Block 41+)은 본문 serialize 시점에서 이 항목들의 treatment-side 해석이 필요하다. 본 문서는 그 해석을 treatment-internal reference로 lock한다.

**적용 정책**: tr 본문 serialize는 역할명 기반으로 진행(`해외 합작 파트너 임원`, `노조 협상 대표`, `정부 규제 담당관`). 본 문서의 이름 lock은 treatment-internal cross-block 일관성을 위한 **참조 테이블**이며, tr 본문의 가시 문자열로는 노출되지 않는다. 이 정책은 `operator_schedule.md` 14th envelope 섹션에 명시되어 있다.

## 1. ARC-05 Master Scenario (누나의 대표 승부 안건 1건)

### 1.1 안건 이름 (internal)
`대륜그룹 ↔ 동남아 생활편의 유통 JV + 그룹 대형 리브랜딩 동시 국면`

### 1.2 JV 상대국
**베트남** (Phase0 ARC-05 해외 조달선 1순위 후보와 일치)

### 1.3 JV 상대사 (internal)
`BINH MINH RETAIL` (가칭, 베트남 중견 생활편의 유통 체인, 전국 약 180개 점포, 현지 푸드코트·편의점·의약품 판매 라인 보유)

### 1.4 3축 동시 압력 구조
- **여론 축**: 해외 자본 유입으로 인한 국내 유통업 공동화 우려 + 리브랜딩 과정에서 기존 브랜드 충성 고객층 이탈 우려가 SNS·경제지에서 동시 폭발
- **정부 규제 축**: 산업통상자원부가 해외 유통사 지분 구조 + 리브랜딩 후 국내 고용 유지 계획에 대한 사전 심사 요구. 합작 심사 + 리브랜딩 과정의 고용영향평가 동시 진행
- **노조 축**: 대륜유통노조 권역연합이 리브랜딩 과정에서 기존 매장 인력 재배치 방안에 대한 사전 협의 권리 주장. 파업 카드는 아직 꺼내지 않음

### 1.5 누나의 승부 수단 (canon `승부 수단: 싸우지 않고 사람과 시장의 마음을 움직인다` 구현)
- 정부: 고용영향평가 선제 제출 + 국내 인력 재배치 계획의 세밀도로 심사를 협상 아닌 `정확한 답변`으로 통과
- 노조: 사전 협의 권리를 공식 절차로 수용 + 권역연합과의 직접 대화 테이블 선제 개설
- 여론: 리브랜딩 방향성을 `국내 생활몰 현장 데이터 기반 재설계`로 프레이밍 — 여기서 서준의 `노조 신뢰 데이터 v0.1` + 권역 본진 데이터가 재료로 들어감

### 1.6 서준 데이터의 역할 (Block 38 구조적 빚 축 존중 방향 작동)
누나 라인은 서준 본인이 먼저 움직이지 않고 기다린 뒤, 본사 기획실장 → 사업부장 **공식 경로**로 요청서를 보낸다. 요청 대상은 `노조 신뢰 데이터 요약본 + 권역 본진 고용 안정 실행 사례`. 요청서 형식은 Block 27 조건부 협정 3조건을 자기 스스로 재확인하는 구조(공식 경로 / 원본 아닌 요약본 / 사용 범위 한정).

## 2. NPCs (Internal Name Lock)

### 2.1 해외 합작 파트너 임원
- **Internal name**: `응우옌 타인` (Nguyễn Thành) 상무급 임원
- **소속**: BINH MINH RETAIL 전략기획본부
- **성격**: 세련되고 정중하지만 협상 테이블에서는 자국 유통망의 장기 이익을 정확히 계산하는 인물. 누나 강민서와 첫 대면에서 `속도`가 아닌 `정확성`을 공통 언어로 확인
- **첫 등장 블록 후보**: Block 42 또는 Block 44 (treatment-side 판단)
- **본문 표기**: `해외 합작 파트너 임원` (역할명)
- **villain dignity**: 정중함 + 정확성. 바보 악역 금지, 음모가 금지. `이 협상은 양쪽 모두의 장기 이익이 걸린 협상이다`라는 태도

### 2.2 노조 협상 대표
- **Internal name**: `박철민` 대륜유통노조 권역연합 대표
- **소속**: 대륜유통 국내 권역연합 노조 (서준의 권역 10개 매장 포함)
- **성격**: 파업 카드를 먼저 꺼내지 않고 대화 테이블을 먼저 요구하는 절차형 리더. 서준의 권역 본진이 ARC-01~04 동안 쌓은 고용 안정 실행 사례를 이미 알고 있음(Block 15 지역본부장 퇴장 이후 판촉팀장 중립자 전환 + Block 34 환율 대응 실행 과정의 협력 라인). 누나의 사전 협의 권리 수용 제안에 `절차는 좋다, 결과가 남는지 보겠다`로 정직한 경계 유지
- **첫 등장 블록 후보**: Block 44
- **본문 표기**: `노조 협상 대표` (역할명)
- **villain dignity**: 절차형 정직 + 결과주의 경계. 형 Block 32 `차갑지만 정직` family의 노조 버전

### 2.3 정부 규제 담당관
- **Internal name**: `윤소희` 산업통상자원부 유통물류과 담당관
- **소속**: 산업통상자원부 유통물류정책과 (과장급 아님, 담당관급)
- **성격**: `정확한 한계를 제시하는 검증자`. 협상가가 아닌 검증가. 누나의 선제 답변에 대해 `답변 자체는 정확하지만 한 가지 추가 확인이 필요하다`로 정중하되 양보 없음
- **첫 등장 블록 후보**: Block 43 (defeat block — 서준의 데이터가 `정확하지만 부족하다`는 반응을 받는 장면의 villain dignity 주역)
- **본문 표기**: `정부 규제 담당관` (역할명)
- **villain dignity**: 정확한 한계 제시. 숫자를 정확히 이해하지만 숫자가 전부가 아니라는 것을 누나와 서준 양쪽에 정직하게 제시

## 3. Existing Cast (ARC-05 등장·비등장 정책)

### 3.1 본문 등장
- **강서준**: POV. 권역 본진에서 data supplier + 대외 위기 실행자 + 누나 사석 대화 상대의 3위치
- **누나 강민서**: Block 41-43 본문 외 주역 위치 → Block 44-45 본문 내 주역 위치. villain dignity: 형 Block 32-35-39-40 family의 누나 버전. `여론·협상·사람`의 결에서 정직한 경쟁자
- **강민서 보좌관**: Block 42에서 공식 요청서 경로상 한 번 언급. Block 38 family 재등장
- **사업부장**: Block 42에서 공식 요청서 경로상 서명자로 등장. 서준의 발언권자 인가서 3조건 범위 안의 경로 보장

### 3.2 본문 비등장 (ARC-05 내내)
- **형 강도윤**: Block 41-45 본문 직접 등장 없음. Block 39·40 ARC-04 출구의 dignity 유지. Block 46+에서 조용한 재등장 가능성만 열어 둠
- **회장**: 본문 직접 등장 없음. 후계 판정자 거리감 정책 유지 (ARC-04와 동일). Block 24 짧은 등장 family 유지
- **사외이사·부회장·대표이사·전무**: guard §8.2 금지, 본인 등장 0

## 4. 서준 발언권자 6개월 재평가 시점 설계

Block 29 발언권자 인가서 3조건(사업부장 재평가 포함)의 6개월 유효기간이 ARC-05 중반~후반에 도래.

- **재평가 배치**: Block 45 또는 Block 46 근처 (누나 사석 조용한 블록 직후 또는 직전)
- **재평가 결과 방향**: `다음 6개월 연장 + 범위 소폭 확대` 권장 (ARC-06 진입 조건 설계)
- **재평가 주체**: 사업부장 라인 + 형 비서실장 라인 참조 (Block 31 family 재소환)
- **Stage 3 지속 장치**: 재평가 직전 블록에서 본인 권역 본진 업데이트 재확인 장면을 배치해야 Stage 3 `경영의 재미`가 의무감·구경꾼으로 축소되지 않음

## 5. Serialize 시 check field 정책

`_tmp_b4x.py` 스크립트의 `canon_lock_checks` / `capital_allocation_guard_check` 필드는 역할명 기반으로 작성한다. 내부 이름은 본 문서에서만 관리. tr 본문의 `content`·`relationship_delta`·`callback` 필드에도 역할명만 사용.

단, treatment-side cross-block 일관성 확인을 위해 serialize 직후 본 문서와 tr 파일의 교차 검토 권장:
- Block 42에서 사업부장 경유 공식 요청서의 서명 구조가 §2.2 노조 협상 대표의 절차 수용 태도와 충돌하지 않는지
- Block 43에서 정부 규제 담당관의 `정확하지만 부족하다` 반응이 §2.3 villain dignity와 일치하는지
- Block 44에서 노조 협상 대표의 `절차는 좋다, 결과가 남는지 보겠다` 태도가 유지되는지
- Block 45에서 누나의 사석 대화가 §1.5 승부 수단과 정합하는지
