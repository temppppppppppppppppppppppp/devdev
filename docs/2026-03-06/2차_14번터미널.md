## P1 패치 상세

### TF-14-01 | genre_hud_manager.py:674-676 | P1

**현재 코드:**
```python
else:
    # [V70] 미매핑 장르 (romance, politics, military 등) → MartialManager 폴백
    logging.warning(f" [V70] 미매핑 장르 '{genre_type}' → MartialManager 폴백")
    return MartialManager(context)
```

**문제:** MartialManager는 wuxia 전용 internal_energy 하한/회복 로직(V60.23) 보유. romance/politics/military 등 비무협 장르 작품이 `update_physical_status()` 호출 시 wuxia 내공 로직 적용됨. TF-45 비무협 무협 오염과 동일 계열.

**패치 방향:** GenericHUDManager(internal_energy 로직 제외) 신설 또는 `update_physical_status()`에 `if canonical_key == "internal_energy" and not self._is_wuxia_genre(): skip` 조건 추가.
