## P1-R: arc_start_state.location 강제 주입 미구현 — 패치 방향 수립

### 현황 확인

**CLAUDE.md 명시**: `"four_phase_arc_generator._generate_prev_context() → 다음 Arc arc_start_state.location 강제 주입 코드는 미구현(P1 잔여)"`

**`_generate_prev_context()` 실제 위치 처리** (L1112, L1126, L1147-1149):
```python
# L1112: 이전 Arc 종료 위치 추출
final_location = arc_end.get("location") or joint.get("final_location", "알 수 없음")
...
# L1126: 텍스트 컨텍스트에 포함 (soft hint)
```

**미구현 확인**: 텍스트 힌트(soft)는 존재. BUT Python이 생성된 Arc dict의 `state_constraints.arc_start_state.location`을 **직접 덮어쓰는** hard enforcement 코드는 없음.

**위험도**: Arc 경계에서 LLM이 위치 힌트를 무시하고 새 장소를 생성할 경우 공간 연속성 파괴. director.yaml에 MAJOR 감점 조항을 추가했지만 사후 처벌이고, 사전 강제가 없음.

### 패치 방향 (0번 터미널 수행)

**위치**: `four_phase_arc_generator.py`의 `generate_arc()` 내 `best_arc` 확정 직후 (현재 L552 `_check_arc_end_state` 호출 직후)

**로직**:
```python
# [P1-R] arc_start_state.location 강제 주입 — 공간 연속성 하드 보장
if prev_arcs:
    _last = prev_arcs[-1]
    _last_end = _last.get("state_constraints", {}).get("arc_end_state", {})
    _last_joint = _last.get("joint_docs", {})
    _forced_loc = (
        _last_end.get("location")
        or _last_joint.get("final_location")
        or ""
    )
    if _forced_loc:
        _sc = best_arc.setdefault("state_constraints", {})
        _as = _sc.setdefault("arc_start_state", {})
        if not _as.get("location"):
            # LLM이 명시한 경우 존중, 누락 시 이전 Arc 종료 위치로 강제
            _as["location"] = _forced_loc
            logging.info("[P1-R] arc_start_state.location 강제 주입: %s", _forced_loc)
```

**대원칙 검토**:
- 대원칙 2(팩트시트 수정 권한은 LLM만): arc_start_state는 다음 Arc 생성을 위한 "계획 입력값"이지 기존 팩트시트 덮어쓰기가 아님. LLM이 arc_start_state.location을 누락했을 때만 Python이 채우는 구조(not-null check 포함) → 대원칙 준수 ✅
- 대원칙 3(Director 주권주의): Arc 생성 단계는 Director 심사 이전 — Director 우회 없음 ✅
- TF-48과 충돌 없음: TF-48은 `_load_execution_state()`에서 WorldState 실제 위치를 텍스트로 주입. P1-R은 생성된 arc dict의 arc_start_state 필드를 채움. 두 패치가 상호 보완적.

**주의사항**:
- `_generate_prev_context()`가 반환하는 텍스트에 이미 `📍 실제 위치` 힌트가 있으므로, LLM이 arc_start_state.location을 직접 명시하는 경우가 많아질 것 → Python 강제 발동 빈도는 낮을 것으로 예상
- 실제 위치(TF-48 execution_state)와 계획 위치(arc_end_state.location)가 다를 경우: 실행 위치 우선 적용 필요 → `_forced_loc = execution_loc or plan_loc` 순서로 조정 권장
