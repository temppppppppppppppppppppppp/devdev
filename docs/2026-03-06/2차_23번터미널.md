| 항목 | 결과 |
|------|------|
| 위치 | `stage4_interview_round.py` L11 — 모듈 상단 독립 함수 |

| 22번 터미널 버전과 구조 일치 여부 | ✅ 완전 동일 (regex 4개, `list(dict.fromkeys())[:5]`) |

**구현 코드 (L11-25):**
```python
def _ns4_extract_time_markers(arc_data: dict) -> list:
    _text = (arc_data.get("tactical_doc") or "") + "\n" + (arc_data.get("beat_sequence") or "")
    _patterns = [
        r"\d{4}년\s*\d{1,2}월(?:\s*\d{1,2}일)?",
        r"\d{1,2}월\s*\d{1,2}일",
        r"\d{1,2}월(?:\s*(?:말|초|중순|하순|상순))?",
        r"\d+(?:일|주|달|개월|년)\s*(?:후|전)",
    ]
```

**GAP 발견 (P2):**

- `"다음날"`, `"이튿날"`, `"며칠 후"` 같은 비숫자 상대 시간 표현 미커버
- 현재 패턴 `r"\d+(?:일|주|달|개월|년)\s*(?:후|전)"` — 앞에 숫자 필수
- CLAUDE.md의 arc_pos==1 prepend 예시에도 `"다음날"` 표현이 등장
- 위험도: ADVISORY 생략만 발생, LLM/원고에 영향 없음 → **P2(낮음)**
