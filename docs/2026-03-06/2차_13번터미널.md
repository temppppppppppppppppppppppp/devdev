**분류**: deprecated API 사용
**설명**: `get_lore_by_db_search()`에서 `self.db.cursor.execute(query, ...)` 직접 사용. `db_manager.py` L62에 `self.cursor = None  # legacy — prefer local cursors in methods`로 명시 deprecated. 기능상 초기화 시 L153에서 `self.cursor = self.conn.cursor()`로 세팅되므로 현재는 동작하나, deprecated 패턴 사용.

**패치 방향**: `self.db.conn.execute(query, ...)` 교체 + fallback 유지 (현재 구조 그대로)

### TF-13-02 | P2 | `character_voice_profiler.py:121,129` | GAP

**분류**: 이중 저장 경로
**설명**: `CharacterVoiceProfiler._load_from_db()/_save_to_db()`가 `save_anchor("character_voice_profiles")` 앵커 방식 사용.
`CharacterVoiceTracker.save_to_db()`는 `character_voice` 테이블 직접 사용 (DB 효율화 패턴 준수).

두 클래스가 동일 "캐릭터 보이스" 데이터를 다른 저장소에 분산 — 조회 시 `CharacterVoiceTracker.load_from_db()`와 `CharacterVoiceProfiler._load_from_db()`가 서로 다른 데이터를 반환할 수 있음.

**패치 방향**: `CharacterVoiceProfiler`도 `character_voice` 테이블 사용으로 통일:
```python
# _load_from_db: save_anchor → character_voice 테이블 SELECT
# _save_to_db: save_anchor → character_voice 테이블 INSERT OR REPLACE
```
