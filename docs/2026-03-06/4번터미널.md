## TF-4T-A: rubric 조기 반환 → TF-G 게이트 우회 [P1]

### 재현 경로

```
apply_self_critique() 진입
  └─ rubric_score = _evaluate_with_rubric(manuscript)  # 4개 기준 평가
  └─ if rubric_score >= 3.5:
       └─ _structural = _self_critique(...)             # 10개 체크 실행
       └─ _medium_plus = [i for i in issues
                          if isinstance(i, dict)
                          and i.get("severity") in ("medium", "high")]
       └─ if not _medium_plus:
            return current_manuscript   ← 여기서 조기 반환
                                           TF-G(L138) 미실행
```

### 문제 원인

`_self_critique` 내 다음 체크들이 **문자열** 또는 **severity 키 없는 dict**를 반환:

| 체크 | 반환 타입 | `_medium_plus` 포함 여부 |
|------|---------|------------------------|
| `_check_ending_hook_presence` | `list[str]` | 제외 (not dict) |
| `_check_writing_directive` | `list[str]` | 제외 (not dict) |
| `_check_expression_freshness` | `list[str]` | 제외 (not dict) |
| `_check_system_term_exposure` | `list[dict]` (severity 키 없음) | 제외 (severity 미매칭) |
| `_check_arithmetic_consistency` | `list[dict]` (severity="high") | **포함** |
| `_check_hud_consistency` | `list[dict]` (severity="medium") | **포함** |

→ 산술 오류·HUD 모순이 없고, ending_hook만 누락된 고품질 원고: `_medium_plus = []` → 조기 반환 → **ending_hook 미수정**

### TF-G 설계 의도와의 충돌

TF-G 주석: `"severity='low' 탈출 방지"`. ending_hook·분량 이슈를 루프 진입 전에 반드시 수정하는 것이 설계 목적이었으나, rubric 조기 반환 경로(L131)가 TF-G(L138)보다 앞에 위치하여 우회됨.

### 수정 방향

TF-G 검사(`_check_ending_hook_presence` + 분량 체크)를 rubric 조기 반환 분기 **이전**에 수행하거나, TF-G가 탐지한 이슈를 `_medium_plus` 필터에서 포함되도록 dict + severity 반환으로 변경.

```python
# 권장 수정: _check_ending_hook_presence 반환값 dict화
# Before: return [f"ending_hook '...' 발견되지 않음"]
# After:
return [{
    "type": "missing_ending_hook",
    "description": f"ending_hook '...' 발견되지 않음",
    "severity": "high",
}]
```

이렇게 하면 ending_hook 누락이 `_medium_plus`에 포함 → rubric 조기 반환 차단 → TF-G 실행.

## TF-4T-B: `_check_system_term_exposure` 장르별 오탐 [P1]

### 문제 패턴

```python
_SYSTEM_TERM_RE = re.compile(
    r"\b(Block\s+\d+|Arc\s+\d+|Stage\s+\d+|Blueprint|treatment)\b",
    re.IGNORECASE,
)
```

### 오탐 확인 시나리오

**`Stage\s+\d+` — 의료물**:
```
원고: "그의 진단명은 Stage 4 간암이었다."
매칭: "Stage 4" (\b·공백·\d+ 모두 성립)
판정: 오탐 — 세계관 표현으로 대체하라는 false positive
```

**`treatment` — 의료/미용물**:
```
원고: "시술명은 Thermage 치료(treatment)였다."
매칭: "treatment" (\b: "t"와 ")" 사이 \w→\W 경계 성립)
판정: 오탐
```

### 수정 방향

장르별 예외 처리 또는 컨텍스트 필터 추가:

```python
# 옵션 A: 장르 파라미터 추가 후 패턴 조건 분기
def _check_system_term_exposure(self, content: str, genre: str = "") -> list:
    _MEDICAL_GENRES = ("의료", "병원", "의학")
    if genre in _MEDICAL_GENRES:
        # Stage\s+\d+ 제외, treatment 제외
        pattern = r"\b(Block\s+\d+|Arc\s+\d+|Blueprint)\b"
    else:
        pattern = r"\b(Block\s+\d+|Arc\s+\d+|Stage\s+\d+|Blueprint|treatment)\b"
    ...

# 옵션 B: 연속 컨텍스트로 필터 (Stage \d+ 뒤 암/병/진단 키워드 있으면 무시)
```

`_self_critique` 호출 시 `genre_name` 이미 전달되므로 옵션 A 적용 가능.
