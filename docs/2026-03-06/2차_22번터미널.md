### [NS2-1] `_ns4_extract_time_markers()` 구현 확인

- **위치**: `four_phase_arc_generator.py:L154-167` — 클래스 외부 독립 모듈 수준 함수 ✅
- **regex 패턴 4종**:
  - `\d{4}년\s*\d{1,2}월(?:\s*\d{1,2}일)?` — 연월일 (2026년 3월, 2026년 3월 15일) ✅
  - `\d{1,2}월\s*\d{1,2}일` — 월일 (3월 15일) ✅
  - `\d{1,2}월(?:\s*(?:말|초|중순|하순|상순))?` — 월+수식어 (3월 말, 3월) ⚠️ 오탐 가능 (TF-22-03)
  - `\d+(?:일|주|달|개월|년)\s*(?:후|전)` — 상대 시간 (3개월 후, 2주 전) ✅
- **미커버 표현**: "다음날", "이틀 후", "사흘 후", "다음 주" 등 숫자 없는 자연어 표현 — INFO 수준, 상위 5개 상한으로 영향 제한됨

### [NS2-3] P1 잔여 — arc_start_state.location 강제 주입 미구현

**현황 확인:**
- `_generate_prev_context()`에서 `final_location`을 계산(`L1112`)하고 lines에 `"✅ 위치: {final_location}"` 텍스트로 추가 → LLM 컨텍스트에는 위치 정보 포함
- 그러나 다음 Arc의 `arc_start_state.location` dict 필드를 직접 강제 설정하는 코드 **미존재** (grep 결과 `arc_start_state` 0건)
- `analyst.py:L1026-1028`에서 `auto_corrections["location"]` 기반 사후 보정은 존재하나, 이는 FourPhaseArcGenerator 내부가 아닌 Analyst 레이어

**위험도:**
- LLM에게 위치 텍스트 컨텍스트는 전달됨 → LLM이 arc_start_state를 올바르게 설정할 가능성 높음
- Analyst auto_corrections가 2차 안전망으로 작동
- 단, LLM이 컨텍스트를 무시하면 위치 단절 발생 가능 → Arc 경계 공간연속성 MAJOR 감점 조항(director.yaml)이 3차 안전망

**패치 방향 (0번 터미널 수행용):**
```python
# four_phase_arc_generator.py generate() 메서드에서
# best_arc 확정 후 (Phase 3 Validate 통과 직후) 아래 post-process 추가

if prev_arcs:
    # TF-48 execution_state 우선, 없으면 arc_end_state 폴백
    _exec_state = self._load_execution_state(prev_arcs[-1])
    _exec_loc = (
        _exec_state.get("protagonist_location")
        or _exec_state.get("last_episode_state", {}).get("location")
    )
    _plan_loc = (
        prev_arcs[-1]
        .get("state_constraints", {})
        .get("arc_end_state", {})
        .get("location")
    ) or prev_arcs[-1].get("joint_docs", {}).get("final_location")
    _inherit_location = _exec_loc or _plan_loc
    if _inherit_location:
        sc = best_arc.setdefault("state_constraints", {})
        sc.setdefault("arc_start_state", {})["location"] = _inherit_location
        logging.info(
            "[P1-location] arc_start_state.location 강제 계승: %s",
            _inherit_location,
        )
```

**주입 위치 후보**: `generate()` 메서드에서 `pipeline_result["final_verdict"] == "PASS"` 분기 직후, `return best_arc, pipeline_result` 직전.
