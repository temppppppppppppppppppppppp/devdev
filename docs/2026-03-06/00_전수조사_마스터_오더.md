## 공통 작업 수칙 (전 터미널 필수)

### 작업 순서 (반드시 이 순서대로)

```
1단계. TF 구성하며 조사
   → 체크 항목을 읽으면서 즉시 TF 초안 작성
   → 형식: TF-[터미널번호]-[순번] | 등급 | 파일:줄번호 | 설명
   → OK 판정도 근거 1줄 기록

2단계. 감리 1회 — 오탐 1차 제거
   → CLAUDE.md 명시 의도적 설계 제거

3단계. 감리 2회 — 오탐 2차 제거
   → 대원칙 1~4 준수 여부 재확인

4단계. 감리 3회 — 오탐 3차 제거
   → 기존 테스트 커버 여부 확인, 최종 등급 확정

5단계. 문서화 후 0번 터미널에 보고
   → 저장: docs/2026-03-06/2차_N번터미널.md
```

> **코드 수정은 0번 터미널(Claude)만 수행.** 1~10번 터미널은 조사·TF 구성·문서화만.

### 출력 규격

**TF 항목 형식:**
```
TF-[터미널]-[번호] | P0/P1/P2 | 파일:줄번호 | BUG/GAP | 설명 1줄 | 패치 방향 1줄
```

**오탐 처리 형식:**
```
[오탐] 체크항목번호 | 근거 1줄
```

**등급 기준**
- P0: 실전 장애·데이터 오염·대원칙 위반 (즉시 처리)
- P1: 기능 저하·silent 실패·schema 불일치 (차기 처리)
- P2: 로직 불일치·감사 오도·dead code (정기 정리)

**오탐 판정 기준**
- 의도적 설계임이 주석/CLAUDE.md에 명시된 경우
- 대원칙(1~4)을 준수하는 경우
- 기존 테스트가 이미 커버하는 경우
