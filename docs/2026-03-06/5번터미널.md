## 3. TF 구성

### TF-HRC (High Res Context Hybrid Gap)

**우선순위**: P2
**범위**: `retrieve_high_res_context()` 직접 호출 2곳 hybrid 적용

#### 수정 방향 (두 가지 선택지)

**Option A — 함수 내부 분기 추가** (권장, 호출자 변경 없음):

`vec_memory.py:480` `retrieve_high_res_context()` 내부에서 `retrieval_mode` 읽어 hybrid/sparse 분기 추가.

```python
def retrieve_high_res_context(self, query, current_ep: int, n_results: int = 3) -> str:
    if not self.has_valid_memory:
        return ""
    query_text = json.dumps(query, ...) if isinstance(query, dict | list) else str(query)

    _mode = _threshold("smart_retrieval.retrieval_mode", "dense")
    if _mode == "hybrid" and hasattr(self, "retrieve_hybrid_context"):
        return self.retrieve_hybrid_context(
            query=query_text, current_ep=current_ep, max_results=n_results
        )

    emb = self._embed_text(query_text)
    if emb is None:
        return self._keyword_fallback_search(query_text, current_ep, n_results)
    return self._knn_search(emb, current_ep, n_results)
```

**Option B — 호출자별 직접 교체**:
- `stage2_preflight.py:810`: `retrieve_high_res_context` → `retrieve_hybrid_context`
- `stage4_interview_round.py:2333`: 동일 교체

#### 영향 테스트

- `test_vec_memory_hybrid.py` 또는 기존 hybrid 관련 테스트에서 `retrieve_high_res_context` hybrid 경로 검증 1개 추가
- 기존 테스트 회귀 없음 (Option A는 내부 분기 추가이므로 API 변경 없음)
