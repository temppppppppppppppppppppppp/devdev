## 2. TF 구성 (감리 전)

### TF-DIR-1 (P2 후보): `_pre_firewall_score` 초기화 위치 불일치

**발견 경위:** 항목 5 조사

**현상:**
```python
# L833
score = _safe_int(result.get("score", 50), 50)          # LLM 원점수
# L834  ← 문제 위치
_pre_firewall_score = score                              # NC-3B 교정 전 저장

# L836-846: NC-3B 교정 (score 변경 가능)
# L848-850: v60_97_swap (score = 50 가능)
# L852-856: SCM 보정 (score ≥ 95 → 90)
# L858-886: Contradiction Firewall
#   미작동 시: _pre_firewall_score = LLM 원점수 (교정 전) 그대로
#   작동 시:   _pre_firewall_score = score  (L879 재설정 — 교정 후)
```

**불일치 케이스:**
- Firewall 미작동 + NC-3B 교정 발생 시
  - `score` = NC-3B 교정 후 값 (예: 87)
  - `_pre_firewall_score` = LLM 원점수 (예: 92)
  - 반환 dict에서 `score: 87`, `pre_firewall_score: 92` 불일치

**수정 방향:** L834를 NC-3B 블록(L846) 이후, Firewall(L858) 이전으로 이동
