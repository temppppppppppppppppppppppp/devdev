## 8. P1 근본 원인 분석

### 수치 관련 P1 (4건): Arc 설계 → Blueprint 전이

P1-2, P1-3, P1-4, P1-6은 **Arc 자체의 수치 설계가 모호하거나 과대한 것이 Blueprint에 그대로 전이**된 패턴. Blueprint 생성기(Stage 3)는 Arc 설계를 충실히 반영하므로, 근본 수정은 Stage 2(Arc) 레벨에서 이루어져야 함.

→ **Stage 2 수치 자기검증(NS-3-B) 강화 또는 Arc 수치 교차검증 Python 체크 추가** 검토 대상.

### POV 불일치 (1건): LLM 생성 비결정성

Ep.13 Blueprint만 1인칭으로 생성된 것은 LLM의 비결정적 출력. Stage 3 Director가 POV 일관성을 검사하지 않은 것이 원인.

→ **Stage 3 Director 프롬프트에 POV 일관성 체크 항목 추가** 검토 대상.

### ending_hook 부재 (1건): Blueprint 구조 검증 갭

Ep.11만 scene_4가 resolution 타입으로 hook이 없음. Stage 3 검증에서 ending_hook 존재를 강제하지 않음.

→ **Stage 3 Python 사전검증에 ending_hook 필수 체크 추가** 검토 대상.

### 소지품 갭 (1건): Stage 2 PATCH-B 한계

Arc 경계에서 소지품 소멸 시 `items_consumed`에 처분 사유가 기재되지 않아 누적 경고.

→ **PATCH-B 소지품 처분 사유 기재 강화** 검토 대상.
