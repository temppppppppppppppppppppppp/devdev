뭘 쓸지 - 재료 사이드(리서치 -> 기획안 -> Stage 0 preprocess -> Phase 0 design -> TR 생성 -> BI 생성)

기본적으로 카카오/네이버/유튜브/NAS를 뒤져서 소설의 엔진을 찾아. 뭘 쓸지에 대해 대략적으로 가져오게 되어 있어.
대충 설정된 하네스를 따라 규격화 과정을 통해서 기본적으로 70 이야기 블록을 생성해 줘. 블록당 이야기는 2-6화니까 짧으면 140화, 길면 420화야.

현재는 현대판타지 위주로 구성되어 있어. 딱히 머리를 쓴다기보다, 그냥 설정된 하네스 따라서 llm이랑 상담하면 되는 거야.
