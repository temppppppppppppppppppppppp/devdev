### P2-4. Entity Registry LRU 캐시 전환

**현재 문제**:
- `StateTracker.entity_name_registry` 최대 20개 제한
- NPC 100명 이상 시 80개 누락 → 명칭 일관성 체크 무력화

**수정안**:
```python
from collections import OrderedDict

class LRUEntityRegistry:
    """최대 N개, LRU 방식 NPC 보존"""
    def __init__(self, max_size=100):
        self._data = OrderedDict()
        self.max_size = max_size

    def register(self, name, info, arc_no):
        if name in self._data:
            self._data.move_to_end(name)
        self._data[name] = {**info, "last_seen_arc": arc_no}
        if len(self._data) > self.max_size:
            # 가장 오래된 것 삭제 (단, status=="dead"는 보존)
            for key in list(self._data.keys()):
                if self._data[key].get("status") != "dead":
                    del self._data[key]
                    break
```
