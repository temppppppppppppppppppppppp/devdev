# 글로벌 웹소설 플랫폼 — 진입장벽 전수조사

> 조사일: 2026-03-24
> 목적: 각 플랫폼별 실제 진입 난이도, 제출 프로세스, 외국인 제한, 수익 조건 파악
> 분류 기준:
> - **OPEN**: 누구나 업로드, 승인 불필요
> - **EASY**: 제출 후 빠르게 승인, 낮은 허들
> - **MODERATE**: 지원 필요, 일정 심사 있으나 배타적이지 않음
> - **HARD**: 선정/초대 필요, 경쟁적 프로세스
> - **GATEKEEPER**: 플랫폼이 선택, 초대/관계 기반

### 1.1 피코마 (Piccoma) — via 카카오 CP 계약

| 항목 | 내용 |
|------|------|
| **진입등급** | **GATEKEEPER** |
| **누가 올릴 수 있나** | 개인 불가. 카카오엔터테인먼트 CP 계약 또는 제3자 CP(Insight Breeze, Story Lab 등)를 통해서만 가능 |
| **제출 프로세스** | 카카오페이지 기존 작품 → 피코마 자동 파이프라인. 또는 CP 중개사에 작품 피칭 |
| **최소 요건** | 카카오페이지 연재 이력 또는 CP 중개사 심사 통과 |
| **승인 기간** | CP 계약 체결 시점에 따라 다름 (수주~수개월) |
| **외국인 제한** | 일본 법인 불필요하나, 한국 CP 계약이 전제 |
| **수익 조건** | 플랫폼 ~50% + CP 30-50% → **저자 수취 총매출의 ~25-35%** |
| **신규 vs 기존** | 카카오페이지 인기작 우선. 신규 작가는 CP 중개사 루트 |

**핵심**: 문피아처럼 자유 업로드 불가. 카카오 생태계 내 검증된 IP만 유통. 한국에서 먼저 성과를 낸 뒤 파이프라인 탑승이 현실적.

### 1.3 Amazon KDP Japan

| 항목 | 내용 |
|------|------|
| **진입등급** | **OPEN** |
| **누구나 업로드 가능** | **YES** — 전 세계 누구나 |
| **제출 프로세스** | KDP 계정 생성 → 원고 업로드(EPUB/MOBI/DOCX) → 메타데이터 입력 → 출판 |
| **최소 요건** | 없음. 단 일본어 콘텐츠여야 일본 독자에게 노출 |
| **승인 기간** | 24-72시간 자동 심사 |
| **외국인 제한** | **없음**. W-8BEN 제출로 원천징수 10% (한일 조세조약). 일본 법인/은행 불필요 |

| **신규 vs 기존** | 차이 없음. 동일 조건 |
| **지원 포맷** | EPUB, HTML, MOBI, Word, RTF, Plain Text |

### 1.4 카쿠요무 (Kakuyomu)

| 항목 | 내용 |
|------|------|
| **진입등급** | **OPEN** |
| **누구나 업로드 가능** | **YES** — 계정 생성 후 즉시 투고 가능 |
| **제출 프로세스** | 계정 생성 → 작품 생성 → 에피소드 투고. 별도 심사 없음 |
| **최소 요건** | 없음. 일본어 작성 필수 |
| **승인 기간** | 즉시 공개 |
| **외국인 제한** | 투고는 가능하나, **수익 수령에 일본 은행계좌 필요** |

**핵심**: KADOKAWA 직영 → 성공 시 라이트노벨 출판 + 애니화 파이프라인 직행. 단, 일본어 필수 + 일본 은행계좌 수익화 제한.

### 1.5 소설가되자 (小説家になろう / Syosetsuka ni Narou)

| 항목 | 내용 |
|------|------|
| **진입등급** | **OPEN** |
| **누구나 업로드 가능** | **YES** — 무료, 제한 없음 |
| **제출 프로세스** | 계정 생성 → 작품 등록 → 에피소드 투고. 심사 없음 |
| **최소 요건** | 없음 |
| **승인 기간** | 즉시 공개 |
| **외국인 제한** | 공식 제한 없으나 일본어 작성 필수 (비일본어 콘텐츠는 사실상 무시됨) |
| **수익 조건** | **직접 수익화 불가**. 인기작 → 출판사 픽업 → 서적화가 유일한 수익 경로 |
| **규모** | 110만+ 작품, 270만 유저, 월 10억+ PV |
| **신규 vs 기존** | 순수 실력주의. 랭킹 진입 시 출판사 에디터 직접 연락 |

**핵심**: 일본 웹소설의 근원지. 수익화 자체는 불가하지만, "나로우 랭킹 진입 → 출판사 픽업 → 라노벨 출판 → 코믹스화 → 애니화" 파이프라인의 시작점. 이세계 판타지 경쟁 극심.
