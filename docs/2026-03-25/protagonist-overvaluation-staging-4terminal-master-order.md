## 1. Intent

Survey how to stage protagonist high-evaluation (`주인공 고평가`) in a way that is not reducible to simple number-size praise.

The target problem is:
- current evaluation tends to collapse into `big number -> wow`
- in upper-class / chaebol / business-power fiction, this becomes thin or awkward
- we need to understand where the authoritative owner of this staging should live:
  - bible
  - arc
  - blueprint
  - manuscript

This survey is about design ownership and staging layers.
It is not a code execution order.
It is not an implementation SSOT.

## 4. Lane Map

### T1. Bible / Worldview Layer

Save to:
- `docs/2026-03-25/opus-protagonist-overvaluation/t1-bible-owner-mapping.md`

Investigate:
- where `주인공 고평가` should be defined at the worldview / rule level
- what forms of praise should be encouraged vs banned
- how class context changes the meaning of admiration

Focus questions:
- In chaebol / business-power fiction, what should count as admiration if raw money size is not enough?
- Should the bible explicitly define praise axes like:
  - judgment
  - risk tolerance
  - structural thinking
  - information asymmetry
  - social shock / ripple
- What should the bible forbid as low-quality praise?

### T2. Arc Distribution Layer

Save to:
- `docs/2026-03-25/opus-protagonist-overvaluation/t2-arc-distribution.md`

Investigate:
- how overvaluation beats should be distributed across episodes/arcs
- whether admiration modes should rotate by arc

Focus questions:
- Which parts belong at arc planning rather than per-episode improvisation?
- Should arcs pre-assign different admiration modes:
  - “small money, impossible method”
  - “underestimated starting point, outsized leverage”
  - “social hierarchy shock”
  - “quiet fear from informed observers”
- How much should arc docs pre-plan reveal timing and reaction placement?

### T3. Blueprint Staging Layer

Save to:
- `docs/2026-03-25/opus-protagonist-overvaluation/t3-blueprint-staging.md`

Investigate:
- blueprint as the live staging owner
- scene devices for making the protagonist feel highly rated without numeric praise

Focus questions:
- Should blueprint own:
  - POV switch timing
  - observer reaction allocation
  - information gap design
  - “only one informed character realizes the danger/value” setups
  - reveal ordering
- What blueprint fields or staging concepts would carry this best?
- Is blueprint the real authoritative owner of execution even if bible defines the principles?

### T4. Manuscript / POV / Information-Gap Execution Layer

Save to:
- `docs/2026-03-25/opus-protagonist-overvaluation/t4-manuscript-pov-info-gap.md`

Investigate:
- what manuscript can do well
- what manuscript is already too late to fix if upstream design is weak

Focus questions:
- How much of high-evaluation is really manuscript-level tone versus blueprint-level staging?
- What role do:
  - POV switching
  - selective information release
  - reaction-shot pacing
  - dialogue understatement
  - “few characters understand, many misread” structures
  play at the final prose layer?
- What is too late to solve in manuscript if bible/arc/blueprint did not set it up?

## 5. Desired Merge Outcome

- whether a future narrative-design SSOT should start at bible, arc, blueprint, or manuscript level

The likely target is not “add hype,” but “design differentiated admiration modes.”
