# 공유 가능 / 공유 제외 자료

이 문서는 AX팀 검토를 위해 어떤 자료를 공유할 수 있고, 어떤 자료는 기본 공유 범위에서 제외하는지 정리합니다.

## 기본 공유 가능

| 자료 | 공유 가능 여부 | 비고 |
| --- | --- | --- |
| 시스템 구성도 | 가능 | 단계, 역할, 저장소, 관측 지점 설명 |
| 단계별 확대 구성도 PDF | 가능 | S0/S2/S3/S4 확대 설명 |
| 모델/역할별 호출 집계 | 가능 | 원문 프롬프트 없이 집계값만 |
| 입력/출력/캐시 토큰 집계 | 가능 | 회차/역할/모델 단위 |
| 추정 비용 집계 | 가능 | 실제 청구액은 AX팀 확인 필요 |
| 회차별 시도 수 | 가능 | 원고 내용 없이 가능 |
| 실패 범주 집계 | 가능 | 예: 제약 위반, 선택 후 충돌, 논리 오류 |
| 캐시 생성/적중/건너뜀/오류 집계 | 가능 | 캐시 이름은 필요 시 비식별화 |
| 최종 승인 맥락 상태 | 가능 | 본문 없이 상태와 해시 중심 |
| 설계도 계보 해시/출처 상태 | 가능 | 내용 전문 없이 가능 |
| 비식별 진단 패킷 | 가능 | 원고/프롬프트 전문 제외 |

## 기본 공유 제외

| 자료 | 기본 공유 여부 | 이유 |
| --- | --- | --- |
| 원고 전문 | 제외 | 작품 원문 보호 |
| 원문 프롬프트 | 제외 | 파이프라인 지식재산 및 운영 세부 보호 |
| LLM 원문 응답 전체 | 제외 | 원고/프롬프트 재노출 가능 |
| 원본 로컬 DB | 제외 | 원고, 로그, 설정, 운영 흔적 포함 가능 |
| 비식별화되지 않은 LLM 입출력 로그 | 제외 | 원문 프롬프트/응답 포함 가능 |
| 로컬 환경 설정 | 제외 | 운영 환경 정보 포함 가능 |
| 인증 정보, 키, 계정 관련 정보 | 제외 | 보안상 공유 불가 |

## 제한적으로 공유 가능한 후보

| 자료 | 조건 |
| --- | --- |
| 짧은 문제 유형 예시 | 원문 문장 대신 유형 설명 또는 비식별 재작성 예시 |
| 산출물 해시 | 원문 없이 해시만 공유 |
| 호출 단위 trace | 프롬프트/응답 snippet 제거 후 공유 |
| 에러 메시지 | 계정/경로/원문 포함 여부 확인 후 공유 |
| 캐시 이름 | 제공사 리소스명이 민감하면 비식별화 후 공유 |

## AX팀에 확인받고 싶은 점

- 위 공유 범위로 비용/응답 지연 진단이 가능한가?
- 추가로 필요한 최소 필드는 무엇인가?
- 원고 전문을 제외한 상태에서도 병목 분석이 가능한 trace 형식은 무엇인가?
- 실제 청구 대조를 위해 필요한 기간, 프로젝트, 모델, 호출 식별 기준은 무엇인가?
