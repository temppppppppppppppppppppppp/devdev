# AX팀 전달 자료 안내

이 폴더는 AX개발팀에 전달할 글도비 LLM 파이프라인 검토 자료입니다.

현재 정본은 Markdown 문서입니다. `5_PDF판/`의 PDF 문서는 이 Markdown 기준으로 다시 생성한 전달용 판본입니다.

이번 검토의 핵심 요청은 두 가지입니다.

1. S4, 즉 실제 원고 생성/검토/정착 단계의 연속성 문제를 어떻게 더 낮은 비용으로 조기에 탐지할지에 대한 최적화 검토
2. 현재 상태를 기준으로 개발 로드맵, 적정 예산, 실전 테스트 규모, 계속 투자/축소/전환 기준을 어떻게 잡을지에 대한 판단 기준 제안

나머지 자료는 위 두 요청을 판단하기 위한 구조, 비용, 캐시, 관측 데이터, 로드맵 판단 자료입니다.

## 권장 검토 경로

### 초기 전달

시간이 제한적이면 아래 세 개만 먼저 보셔도 됩니다.

1. `1_필수문서/00_한장_요약.md`
2. `1_필수문서/01_검토_요청서.md`
3. `5_PDF판/1_필수문서/03_시스템_구성도.pdf`

회의 질문을 미리 공유해야 하면 `4_추가자료/31_회의용_질문_리스트.md`를 함께 전달합니다.

### 요청 시 추가 제공

S4 연속성, 비용, 캐시, 모델 라우팅을 보실 때는 아래 자료가 우선입니다.

1. `1_필수문서/06_현재_상태_주요_장애물_지원_요청.md`
2. `1_필수문서/04_주요_데이터_흐름.md`
3. `1_필수문서/05_모델_비용_토큰_표면.md`
4. `4_추가자료/30_비식별_진단_패킷_예시.md`
5. `4_추가자료/33_Vertex_청구_대조_요청표.md`

운영 단계 판단, 예산, 개발 기간, 실전 테스트 규모를 보실 때는 아래 자료가 우선입니다.

1. `4_추가자료/36_운영기획_의사결정_지원_요청.md`
2. `4_추가자료/35_원본자료_전체공개_전달_가이드.md`

`2_구성도/`와 `3_단계별_확대/`의 기존 도식 PDF는 2026-04-30 산출물입니다. 구조 설명이 필요할 때만 참고용으로 사용하고, 최신 문구 기준 전달본은 `5_PDF판/`을 우선합니다.

## 원본 자료 공유 방향

기본 방향은 AX팀 내부 검토에 필요한 자료를 최대한 열어 전달하는 것입니다. 원고, 원본 DB, LLM 호출 장부, 캐시 장부, 로그는 비용/지연/연속성 병목을 보는 데 중요하므로 공유 후보에 포함합니다.

다만 실제 비용이 나가거나 외부 계정에 접근할 수 있는 정보는 제외합니다. 예를 들면 `.env`, API key, OAuth token, service account JSON, billing console 접근 정보, 개인 계정 비밀번호, 배포/클라우드 인증 정보입니다.

## 검토 요청 핵심

| 체크 항목 | 확인하고 싶은 답 | 우선 자료 |
| --- | --- | --- |
| S4 연속성 | 연속성 오류와 선택 후 충돌이 어디서 생기며, 어떤 검증을 원고 생성 전으로 옮길 수 있는가 | `06`, `04` |
| 비용/응답 지연 | 작가 에이전트, 검토 에이전트, 재시도 루프 중 비용과 지연이 가장 크게 쌓이는 구간은 어디인가 | `05`, `33` |
| 캐시/세션 메모리 | 맥락 캐시와 세션 메모리가 실제로 비용/지연/품질을 개선하는지, 오래된 맥락을 막는 기준은 무엇인가 | `04`, `05` |
| 진단 자료 | 원고 전문 없이도 비용, 토큰, 응답 지연을 볼 수 있는 최소 관측 패킷은 무엇인가 | `30`, `32` |
| 로드맵/예산 | 현재 단계를 어떻게 분류하고, 다음 4주/8주/12주 목표와 예산 상한을 어떻게 잡을 것인가 | `36`, `31` |
| 카나리아 테스트 | 장르 약속, 스타일, 장기기억, 회차별 보상 구조를 어떤 기준으로 통과 처리할 것인가 | `06`, `34` |
