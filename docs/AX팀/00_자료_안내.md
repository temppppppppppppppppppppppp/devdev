# AX팀 전달 자료 안내

이 폴더는 AX개발팀에 전달할 글도비 LLM 파이프라인 검토 자료입니다.

Markdown 문서를 바로 보기 어려운 경우에는 `5_PDF판/` 폴더의 PDF 문서부터 보시면 됩니다. 같은 번호의 Markdown 문서와 PDF 문서는 같은 내용을 담고 있습니다.

검토 목적은 다음 세 가지입니다.

- LLM 파이프라인 구조 검토
- 비용 및 응답 지연 절감 가능 지점 검토
- 토큰 사용량 및 맥락 캐시 최적화 검토

## 먼저 읽을 순서

1. `1_필수문서/00_한장_요약.md`
2. `1_필수문서/01_검토_요청서.md`
3. `1_필수문서/02_글도비_목적_및_전제.md`
4. `1_필수문서/06_현재_상태_주요_장애물_지원_요청.md`
5. `2_구성도/10_구성도_요약.pdf`
6. `1_필수문서/04_주요_데이터_흐름.md`
7. `1_필수문서/05_모델_비용_토큰_표면.md`

PDF로 전달해야 하는 경우에는 위 순서와 같은 파일을 `5_PDF판/` 폴더에서 열면 됩니다.

## 필요할 때 여는 자료

- `1_필수문서/00_한장_요약.md`: 전체 검토 맥락을 한 장으로 요약한 진입 문서입니다.
- `1_필수문서/03_시스템_구성도.md`: 구성도와 권한/장기기억 설명의 문서판입니다.
- `1_필수문서/06_현재_상태_주요_장애물_지원_요청.md`: 현재 상태, 방향, 주요 장애물, AX팀 지원 요청 요약입니다.
- `2_구성도/11_구성도_상세.pdf`: S0 -> S2 -> S3 -> S4 전체 상세 구성도입니다.
- `3_단계별_확대/*.pdf`: S0, S2, S3, S4 각 단계별 확대 구성도입니다.

## 분석에 바로 도움이 되는 추가 자료

- `4_추가자료/30_비식별_진단_패킷_예시.md`: 한 회차가 실제로 어떻게 비용과 시간을 쓰는지 보여주는 비식별 집계 예시입니다.
- `4_추가자료/31_회의용_질문_리스트.md`: 미팅에서 바로 확인하고 싶은 질문 목록입니다.
- `4_추가자료/32_공유_가능_불가_자료.md`: 공유 가능 자료와 기본 공유 제외 자료를 정리한 표입니다.
- `4_추가자료/33_Vertex_청구_대조_요청표.md`: 로컬 추정 비용과 실제 Vertex 청구액 대조를 위한 요청표입니다.
- `4_추가자료/34_초안_최종후보본_품질_간극.md`: Stage4 통과 초안과 독자용 최종 후보본 사이의 품질 간극 설명입니다.

## 기본 공유 범위에서 제외한 것

- 원문 프롬프트
- 원고 전문
- 원본 로컬 DB
- 비식별화되지 않은 LLM 입출력 로그
- 로컬 환경 설정 또는 인증 정보

## 검토 요청 핵심

- Stage4의 작가 에이전트 + 검토 에이전트 + 재시도 루프 비용/응답지연
- 최종 승인 맥락, 설계도 계보, 정착 상태의 권한 분리
- 맥락 캐시의 단순 적중률이 아니라 최신성 검증 기준
- 원고 전문 없이도 비용/토큰/응답지연을 분석할 수 있는 최소 관측 패킷
