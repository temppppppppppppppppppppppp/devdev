## 4. 개선 기회 목록 (우선순위순)

### [HIGH] 벡터 메모리 요약 밀도 부족
- 현재: `modules/core/stage4_post_processor.py:118`, `modules/core/vec_memory.py:217`
- 문제: 제목/짧은 요약 위주 저장으로 retrieval 품질 저하.
- 수정안: 저장 summary를 `핵심사건+상태변화+인과링크` 400~800자로 구성.
- 수정 파일: `modules/core/stage4_post_processor.py`, `modules/core/vec_memory.py`
- 영향 범위: Stage2/4 벡터 검색 recall/precision 개선.
- 위험도: LOW

### [HIGH] `use_summary` 파라미터 실질 미동작
- 현재: `modules/domain/agents/director_continuity.py:343`, `modules/domain/agents/director_continuity.py:376`
- 문제: `use_summary=True/False`가 history 구성 분기에 반영되지 않음.
- 수정안: `use_summary` true 시 summary 우선, false 시 text 우선으로 분기.
- 수정 파일: `modules/domain/agents/director_continuity.py`
- 영향 범위: 연속성 검사 비용/정확도 제어 가능.
- 위험도: LOW
