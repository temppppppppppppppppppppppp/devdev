# 컨셉 기획안 — 유럽 대체역사 A: 「나폴레옹의 참모가 되었다」

> 장르: 대체역사물 · 유럽 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 네이버시리즈 (2순위)

---

## 1. 로그라인

**군사학 교수가 1805년 아우스터리츠 전투 직전, 나폴레옹의 참모장 베르티에에 빙의한다. 역사는 나폴레옹의 승리를 기록했지만 — 워털루를 막고, 러시아 원정을 바꾸면 유럽은 어떻게 달라지는가?**

## 2. 1화 후킹

> _1805년 12월 1일, 아우스터리츠 전야. 나폴레옹이 지도 위에 손가락을 짚는다. "내일 해가 뜨면 프라첸 고지에서 끝낸다." 그 옆에 선 루이 알렉상드르 베르티에 — 내가 깨어난 곳은 이 남자의 몸이다._
> → 한국 육군사관학교 군사전략 교수 손영훈은 안다: 아우스터리츠는 이긴다. 문제는 그 다음이다. 트라팔가르, 반도전쟁, 러시아, 워털루 — 나폴레옹은 반드시 진다. "내가 바꿀 수 있을까?"

## 3. 세계관 & 장르 설정

| 항목          | 설정                                                            |
| ------------- | --------------------------------------------------------------- |
| **빙의 대상** | 베르티에(Berthier), 나폴레옹의 참모총장                         |
| **시대**      | 1805년 ~ 1825년대                                               |
| **분기점**    | 러시아 원정 회피/변형 + 영국과의 조기 강화                      |
| **핵심 갈등** | 나폴레옹의 천재성과 자만심 — 참모가 황제를 바꿀 수 있는가?      |
| **현대 지식** | 군사 전략뿐 아니라 산업혁명 기술, 의학(소독/마취), 통신(전신기) |

### 적대자 3단계

| Phase          | 적대자                                         |

| 3 (대단원 6~7) | 나폴레옹 자신의 야망 (주인공과 황제의 대립)    |

# 컨셉 기획안 — 유럽 대체역사 B: 「로마는 멸망하지 않았다」

> 장르: 대체역사물 · 유럽 · 빙의물
> 플랫폼 타겟: 문피아 (1순위), 카카오페이지 (2순위)

---

## 1. 로그라인

**토목공학 교수가 서로마 멸망 직전(475년)의 군사령관 오도아케르에 빙의한다. 역사를 따르면 서로마를 멸망시키는 장본인이 되지만 — 이번에는 로마를 살려서, 암흑기를 건너뛴 유럽을 만든다.**

## 2. 1화 후킹

> _475년, 라벤나 궁전. 소년 황제 로물루스 아우구스툴루스가 왕좌에 앉아 있다. 12살, 아버지가 앉힌 허수아비다. 게르만 용병대장 오도아케르 — 내가 된 이 남자는 6개월 뒤 이 소년을 폐위하고 서로마를 끝낸다._
> → 이주성 교수는 안다: 로마가 멸망하면 유럽은 1,000년의 암흑기에 들어간다. "만약 이 제국을 살릴 수 있다면?"

## 3. 세계관 & 장르 설정

| 항목          | 설정                                                                          |
| ------------- | ----------------------------------------------------------------------------- |
| **빙의 대상** | 오도아케르, 게르만 용병대장 (역사적 서로마 멸망자)                            |
| **시대**      | 475년 ~ 510년대                                                               |
| **분기점**    | 오도아케르가 서로마를 멸망시키지 않고 **개혁하여 존속**                       |
| **핵심 갈등** | 게르만 전사들은 약탈을 원하고, 로마 귀족은 개혁을 거부하고, 동로마는 간섭한다 |
| **현대 지식** | 토목(도로·수도·요새), 의학(전염병 대응), 행정(세금 체계), 농업(윤작)          |

### 적대자 3단계

| Phase          | 적대자                                         |
| -------------- | ---------------------------------------------- |
| 1 (대단원 1~2) | 로마 원로원 보수파 + 게르만 약탈파 (양면 반대) |
| 2 (대단원 3~5) | 동로마 제국 제논 황제 (서로마 흡수 시도)       |
| 3 (대단원 6~7) | 훈족 잔존 세력 + 반달족 + 동고트 테오도리크    |
