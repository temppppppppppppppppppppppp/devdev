# 비틀기 기획안 — 배치 2: 회사원/전문직 (6개)

> 5-Pass: P0~P2(하네스) + P3(차별화) + P4(시장성/대리만족)

## ⑦ 「내가 사표를 내면 회사가 망한다」

**힌트**: 건물주 회사원(#8)/퇴사(#103) → **비틀기: 퇴사가 무기가 되는 상황**

**로그라인**: 만년 과장이 사직서를 쓰려는 순간, 미래가 보인다 — 자기가 퇴사하면 회사가 3개월 내 부도난다. 반대로 남아있으면 회사는 살지만 자기 인생은 갈린다. 사표를 '카드'로 쓰기 시작한 남자의 역전극.

**1화 후킹**: _"사표를 내겠습니다." 팀장이 비웃는다. 그 순간 비전이 뜬다: 6월 14일, 이 회사 상장폐지 뉴스. 모든 장면에서 빠져있는 사람이 나다. "잠깐, 그러면 제가 없으면 이 회사가 망하는 건가요?"_

| 항목       | 설정                                                          |
| ---------- | ------------------------------------------------------------- |
| 비틀기     | 퇴사가 **핵 버튼**. 사표=회사 존망 → 역대급 협상 레버리지     |
| 능력 제약  | "사표를 진심으로 쓸 때만" 미래가 보임 / 거짓 사표엔 반응 X    |
| 자본곡선   | 연봉4천만→임원대우→지분5%→경영참여→CEO 대행→30% 지분(2,000억) |
| 적대자     | ①꼰대 임원 → ②경쟁사 스카우트(진짜 빼려는) → ③오너 일가       |
| **P3**     | ✅ "퇴사 무기화"는 파격. 사표=예지 능력의 트리거는 유일        |
| **P4**     | ✅ 직장인 판타지 직격. "내가 없으면 너희 망해" 대리만족 극강   |
| **5-Pass** | **PASS**                                                      |

## ⑧ 「신입인데 30년치 야근을 했습니다」

**힌트**: 회사원 회귀(#103)/능력 회사원(#142) → **비틀기: 야근 시간이 경험으로 스택됨**

**로그라인**: 야근 1시간 = 해당 업무 1년치 경험이 쌓이는 능력. 3일 밤새면 3년차가 된다. 대신 체력이 실제 노화처럼 닳는다. 25살 신입이 1년 만에 몸은 35살, 경력은 30년차.

**1화 후킹**: _첫 야근이 6시간이었다. 다음 날 아침, 엑셀 피벗테이블이 보이기 시작했다. 숫자가 읽혔다. 6년차 대리가 반나절 걸리는 보고서를 30분에 끝냈다. "박 사원, 너 이거 어디서 배웠어?" — 야근이요._

| 항목       | 설정                                                         |
| ---------- | ------------------------------------------------------------ |
| 비틀기     | 야근이 **물리적 레벨업** → 직장인 최강 먼치킨. 대가=노화     |
| 제약       | 월 40시간 야근 = 신체 나이 +5세. 실나이 25 → 외모 35         |
| 자본곡선   | 신입→핵인재→팀장→이사→CEO후보(몸은 50대)                     |
| 감정갈등   | 젊음을 잃는 공포 vs 성공의 쾌감 — 멈출 수 있을까?            |
| **P3**     | ✅ "야근=레벨업"은 직장인 특유의 비틀기. 노화 대가는 웹소설적 |
| **P4**     | ✅ 직장인 공감 극대화. "야근이 실력이 되면 좋겠다" 판타지     |
| **5-Pass** | **PASS**                                                     |

## ⑨ 「의뢰인이 거짓말하면 내 심장이 뛴다」

**힌트**: 천재 변호사(#67,#190) → **비틀기: 거짓말 감지가 자기 의뢰인에게만 작동**

**로그라인**: 변호사에게 각성한 능력 — 의뢰인이 거짓말하면 심장 박동이 올라간다. **내 의뢰인**의 거짓말을 전부 파악한 뒤, 그 약점을 레버리지로 수임료를 올린다. 진실을 아는 변호사는 의뢰인을 지배한다.

**1화 후킹**: _"저는 죽이지 않았습니다." 의뢰인이 말하는 순간, 심장이 BPM 180을 찍었다. — 거짓말이다. "알겠습니다. 수임료 2억 추가요. 제가 알고 있는 것을 검찰이 알게 되면 곤란하시잖아요."_

| 항목       | 설정                                                              |
| ---------- | ----------------------------------------------------------------- |
| 비틀기     | 거짓말 탐지인데 **상대편이 아니라 아군의 거짓말** → 도덕적 딜레마 |
| 제약       | 의뢰 수임 후에만 작동 / 재판 중엔 OFF / 사적 대화에서만 ON        |
| 자본곡선   | 개업 -2억→10억→50억→패소(의뢰인 진실 폭로)→200억→500억            |
| 적대자     | ①검찰 출신 라이벌 → ②로펌 내부 정치 → ③거대 기업 범죄 은폐        |
| **P3**     | ✅ 거짓말 탐지 + 변호사 조합은 있지만 "아군만 읽힘"은 없음         |
| **P4**     | ✅ 법정 드라마 + 도덕적 선택 + 사이다 판결                         |
| **5-Pass** | **PASS**                                                          |

## ⑩ 「갈비 냄새로 부동산을 잡다」

**힌트**: 갈비집 변호사(#10) → **비틀기: 요식업+부동산을 음식 능력으로 연결**

**로그라인**: 회귀한 요리사의 능력 — 음식을 먹으면 그 식재료가 자란 **땅의 가치**가 보인다. 한우를 먹으면 목장 부지의 미래 시세가, 쌀밥을 먹으면 논의 개발 정보가. 갈비집을 하면서 부동산 투자를 하는 기괴한 투자물.

**1화 후킹**: _아버지 갈비집에서 국산 한우를 씹는 순간, 머릿속에 지도가 펼쳐졌다. 횡성군 안흥면 산23-7. '3년 후 KTX 신설역 예정지. 현재 평당 12만 → 3년 후 평당 340만.' — "아빠, 이 소 어디서 사 왔어?"_

| 항목       | 설정                                                           |
| ---------- | -------------------------------------------------------------- |
| 비틀기     | 미식+부동산. **식재료 원산지 = 부동산 투자처** — 유일무이 조합 |
| 제약       | 국산 식재료만 / 본인이 요리해야 / 하루 1지역                   |
| 자본곡선   | 갈비집 3억→부동산 20억→100억→-30억(가짜 원산지)→500억→2,000억  |
| 적대자     | ①부동산 투기꾼 → ②토건 재벌 → ③국토부 조사                     |
| **P3**     | ✅ "음식 먹으면 땅값이 보인다" — 존재하지 않는 장르 믹스        |
| **P4**     | ✅ 먹방+부동산+성장. 3중 대리만족                               |
| **5-Pass** | **PASS**                                                       |

## ⑪ 「수술하면 그 사람의 미래가 보임」

**힌트**: 마취과 회귀(#37)/의학물 → **비틀기: 수술 능력이 아니라 수술 대상의 미래 예지**

**로그라인**: 외과의사가 환자를 수술하면 그 환자의 10년 후 **재산과 지위**가 보인다. 미래에 재벌이 될 환자에겐 최선을 다하고 그 인연을 투자한다. 수술대가 인맥 투자의 현장이 된다.

**1화 후킹**: _교통사고 응급 환자. 수술 시작 3초 후, 비전이 떴다. 이 남자 — 10년 후 시총 3조 IT기업 CEO. 수술에 모든 걸 쏟았다. 퇴원 날 명함을 건넸다. "언제든 연락 주세요." 3년 후, 그 회사 IPO. 내 스톡옵션 가치: 120억._

| 항목       | 설정                                                             |
| ---------- | ---------------------------------------------------------------- |
| 비틀기     | 수술 실력이 아니라 **"살릴 자격"의 판단** → 의학물+트롤리 딜레마 |
| 제약       | 응급 수술에서만 / 예정 수술엔 안 뜸 / 선택 결과는 바뀌지 않음    |
| 자본곡선   | 레지 월급→전문의→교수→병원장→의료재단(500억)                     |
| 적대자     | ①교수 파벌 → ②환자 가족의 복수 → ③능력을 아는 정보기관           |
| **P3**     | ✅ 의학물에서 "기술 먼치킨"이 아닌 "도덕적 먼치킨" → 유일         |
| **P4**     | ✅ 매 수술이 생사+윤리 판단 → 텐션 극강                           |
| **5-Pass** | **PASS**                                                         |

## ⑫ 「순경인데 범인이 보임」

**힌트**: 고졸순경(#152)/정치인(#100) → **비틀기: 범인을 아는 게 아니라 "범행 30초 전"이 보임**

**로그라인**: 범행 30초 전에 범인의 시점이 보이는 순경. 현장에 도착하면 이미 아는 건 — 범인의 얼굴, 동기, 도주 경로. 그런데 30초로는 막을 수 없는 범죄가 있다. 막으면 영웅, 못 막으면 — "어떻게 알았습니까?" 라는 질문이 돌아온다.

**1화 후킹**: _112 신고를 받고 출동 중, 갑자기 시야가 바뀌었다. 칼을 든 손이 보인다. 내 손이 아니다. 범인의 눈으로 세상을 보고 있다. 아파트 603호 문이 열린다. 여성이 "오빠" 하고 웃는다. 30초 후 이 여성은 — 사이렌을 켰다._

| 항목           | 설정                                                         |
| -------------- | ------------------------------------------------------------ |
| 비틀기         | 30초 예지. 막기엔 너무 짧고 모르기엔 너무 긴 시간            |
| 제약           | 30초만. 연장 불가. 본인 관할 사건만. 범행 취소되면 X         |
| 자본곡선(직급) | 순경→경장→경사→경위→경감→총경→경무관                         |
| 적대자         | ①부패 상사 → ②조직범죄 → ③능력을 노리는 정보기관             |
| **P3**         | ✅ "30초"라는 제약이 핵심. 너무 짧아서 만들어내는 서사적 긴장 |
| **P4**         | ✅ 사건마다 30초 카운트다운 → 매화 후킹 보장                  |
| **5-Pass**     | **PASS**                                                     |
