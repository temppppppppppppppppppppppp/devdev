## ㉕ 「회귀했는데 레벨이 0이 아니라 -10임」

**힌트**: 회귀 헌터(#17)/초월급(#184) → **비틀기: 마이너스 레벨에서 시작**

**로그라인**: S급 헌터가 회귀했는데 레벨이 0이 아니라 **-10**이다. 마이너스 레벨은 일반인보다 약하다. 스탯이 역전되어있어 힘을 쓸수록 약해진다. -10에서 0까지 올려야 비로소 '각성'이 시작되는 역전의 회귀물.

**1화 후킹**: _눈을 떴다. 상태창이 뜬다. [레벨: -10] [힘: -15] [민첩: -8] [지능: 120(전생 기억)] "마이너스가 뭐야!?" 주먹을 쥐자 손에 경련이 왔다. 전생에서 S급 레이드 보스를 원펀치하던 이 손이._

| 항목       | 설정                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 비틀기     | **마이너스 레벨** → 레벨 0이 첫 번째 목표. 각성 전 생존이 더 어려움          |
| 제약       | 전생 전투 지식은 있지만 몸이 안 따름 / -10→0 과정에서 스탯 당 고통           |
| 자본곡선   | 레벨 -10→-5→0(각성)→C→A→S→SS                                                 |
| 적대자     | ①E급 몬스터(마이너스 레벨에겐 보스급) → ②헌터 협회(낙인 시도) → ③전생 배신자 |
| **P3**     | ✅ "마이너스 레벨" 설정은 없음. 약체 스타트의 극단형                          |
| **P4**     | ✅ 밑바닥 역전 대리만족. -10→SS까지의 카타르시스 극대화                       |
| **5-Pass** | **PASS**                                                                     |

## ㉖ 「아포칼립스인데 건축왕이 됨」

**힌트**: 만능셸터(#23)/아포 건설(#124) → **비틀기: 전투 0, 건축 MAX**

**로그라인**: 전투 능력이 전혀 없는 건축기사가 아포칼립스에서 살아남는 방법 — 몬스터가 절대 들어올 수 없는 요새를 짓는다. 시스템이 주는 보상이 '전투 스킬'이 아니라 '건축 스킬'인 유일한 각성자. 벽 하나로 S급 몬스터를 막는 남자.

**1화 후킹**: _빨간 게이트가 열렸다. 모두가 검을 들었다. 나만 삽을 들었다. [스킬 각성: 지반 강화 Lv.1] — "이거 왜 건축 스킬이야!?" 몬스터가 달려온다. 내가 할 수 있는 건 — "벽을 세운다!"_
_[흙벽(Lv.1) — 내구도: 50,000. 몬스터 공격력: 12] — 400번을 쳐야 부서진다!?_

| 항목       | 설정                                                          |
| ---------- | ------------------------------------------------------------- |
| 비틀기     | 전투 불가 건축가. **벽+함정+구조물**이 유일한 전투 수단       |
| 제약       | 직접 공격 불가 / 구조물만 설치 / 재료 필요 / 건설 시간 있음   |
| 자본곡선   | 흙벽→벽돌성→강철요새→마나요새→도시→국가                       |
| 적대자     | ①인간 약탈 세력 → ②지능형 몬스터(요새 공략) → ③시스템 관리자  |
| **P3**     | ✅ "건축형 아포칼립스 주인공"은 메인 스트림에 없음             |
| **P4**     | ✅ 방어형 쾌감 + 점점 커지는 요새 대리만족 + 마인크래프트 감성 |
| **5-Pass** | **PASS**                                                      |

## ㉗ 「던전 보스인데 헌터를 고용함」

**힌트**: B급 헌터(#25)/탑 공략(#29) → **비틀기: 주인공이 보스, NPC가 헌터**

**로그라인**: 던전 보스로 빙의했다. 죽으면 끝이다. 매일 헌터들이 공략하러 온다. 살아남는 방법 — 약한 헌터를 고용해서 내 던전의 '가짜 보스'로 세운다. 헌터를 고용하는 보스. 던전 경영 시뮬레이션.

**1화 후킹**: _[당신은 '7층 보스: 그림자 늑대 왕'입니다.] [오늘 공략단 도착 예정: 12시간 후. 인원: 24명. 예상 전투력: A+] 나의 체력은 A-. 진다. — [보스 특수 권한: 몬스터 고용 — 인간 고용 가능(신규)] "인간을 고용할 수 있다고?"_

| 항목       | 설정                                                          |
| ---------- | ------------------------------------------------------------- |
| 비틀기     | **보스 시점 + 헌터 고용 + 던전 경영**. 시점 완전 역전         |
| 자본곡선   | 7층 보스→10층→20층→보스 연합→던전 왕                          |
| 적대자     | ①S급 헌터 공략단 → ②상위 보스(보스 간 패권) → ③시스템 관리 AI |
| **P3**     | ✅ "보스 빙의"는 있지만 "헌터를 고용하는 보스"는 없음          |
| **P4**     | ✅ 던전 경영+전략+생존. 매회 헌터 vs 보스 두뇌전               |
| **5-Pass** | **PASS**                                                      |

## ㉘ 「마법사인데 마나가 0이라 과학으로 함」

**힌트**: 마법사(#33,#44,#181) → **비틀기: 마나 없는 마법사 = 과학 마법**

**로그라인**: 마법 아카데미에 입학했는데 마나가 선천적으로 0이다. 퇴학 직전, 화학·물리학 지식으로 마법과 같은 효과를 만든다. 화약으로 화염 마법을, 전기로 번개 마법을. "마법사님, 그건 과학입니다." "결과가 같으면 마법이야."

**1화 후킹**: _마나 측정치: 0. 역대 최저. "퇴학 대상입니다." — 시험 과목: 화염구 시전. 다른 학생들이 마나로 불을 만들 때, 나는 주머니에서 성냥과 알코올 솜을 꺼냈다. [결과: 화염구 위력 측정 — A등급] "…이게 왜 A야?" "불이 났으니까요."_

| 항목           | 설정                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 비틀기         | 마나 0 → **과학이 마법을 대체**. 이세계에서 과학 혁명                    |
| 자본곡선(랭크) | 최하위→C급(화약)→B급(전기)→A급(화학병기)→S급(핵분열?)                    |
| 적대자         | ①마법 순수주의 교수 → ②마법사 길드 규탄 → ③마왕(과학이 마법보다 강한가?) |
| **P3**         | ✅ "과학으로 마법 대체"는 라이트노벨에 소수 있지만 한국 웹소설엔 비어있음 |
| **P4**         | ✅ 약체→역전 쾌감 + 과학 교양 재미 + 코미디                               |
| **5-Pass**     | **PASS**                                                                 |

## ㉙ 「귀환했는데 지구에 마나가 없어서 일반인이 됨」

**힌트**: 귀환 마신(#173)/귀환 만렙(#84) → **비틀기: 귀환했지만 능력 0**

**로그라인**: 이세계에서 마왕을 처치한 SSS급 영웅이 지구로 귀환. 그런데 지구엔 마나가 없다. 능력이 전부 OFF. 100레벨 전사가 일반인으로 취직해야 한다. 유일하게 남은 건 — **판단력, 리더십, 전투 지식**. 능력 없이 먹고사는 전직 영웅의 현대 생활기.

**1화 후킹**: _마왕의 심장에 검을 꽂았다. 빛이 감싸고 — 눈을 떴다. 서울 강남 길바닥. 손을 펴봤다. [마나: 0. 스킬: 사용불가. 인벤토리: 접근불가] "하…" 주머니를 뒤졌다. 2017년에 만든 주민등록증. 나이: 28세. 빈 통장 하나._
_옆 가판대에 '알바 구합니다'가 붙어있었다._

| 항목       | 설정                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 비틀기     | 귀환인데 **능력 못 씀** → 현대 사회 적응기. 힐링+성장                    |
| 자본곡선   | 알바→편의점 점장→중소기업→이세계 지식으로 컨설팅→사업→대기업             |
| 적대자     | ①사회 부적응 → ②이세계 기억을 노리는 조직 → ③이세계 잔존 세력(지구 침입) |
| **P3**     | ✅ "귀환=능력 OFF"는 거의 없음. 만렙이 알바를 하는 역설                   |
| **P4**     | ✅ 힐링+코미디+약체 시작 역전                                             |
| **5-Pass** | **PASS**                                                                 |

## ㉚ 「아포칼립스 유일 생존자인데, 다 나 때문이었다」

**힌트**: 아포칼립스 회귀(#23)/재앙급(#56) → **비틀기: 아포칼립스의 원인이 주인공**

**로그라인**: 아포칼립스에서 회귀한 유일한 생존자. 그런데 회귀 후 알게 된 진실 — 아포칼립스의 트리거가 **본인의 각성**이었다. 그가 각성하면 세계가 멸망한다. 각성하지 않으면 약체인 채로 아포칼립스를 막아야 한다. 최강이 되면 세계가 끝나는 딜레마.

**1화 후킹**: _전생에서 SSS급 각성 후 혼자 살아남았다. 모두가 죽었다. "왜 나만 살았지?" 회귀 후, 시스템 메시지가 떴다: [경고: 당신의 각성이 '재앙 프로토콜'을 활성화합니다. 각성 시 세계 멸망 확률: 99.97%] — "내가 강해지면 세상이 끝나?"_

| 항목             | 설정                                                               |
| ---------------- | ------------------------------------------------------------------ |
| 비틀기           | **강해지면 세계 멸망** → 먼치킨의 완전한 역전. 약체 유지가 의무    |
| 핵심 갈등        | 각성 없이 어떻게 아포칼립스를 막을 것인가 → 두뇌전+타인 육성       |
| 자본곡선(전투력) | 의도적 E급 유지 → 파티원 육성 → 전략 사령관 역할                   |
| 적대자           | ①각성 강요 세력 → ②아포칼립스 원흉(시스템) → ③자기 자신(각성 충동) |
| **P3**           | ✅ "강해지면 망한다" = 먼치킨 장르의 근본적 전복                    |
| **P4**           | ✅ 매순간 "각성할까 말까" 서스펜스. 약체 전략가 쾌감                |
| **5-Pass**       | **PASS**                                                           |
