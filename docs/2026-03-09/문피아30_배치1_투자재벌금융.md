## ① 「숏 치면 죽는 남자」

**레퍼런스 힌트**: 공매도 (#14) → **비틀기: 공매도를 치면 성공하지만 수명이 줄어드는 저주**

**로그라인**: 전직 증권사 리서처가 각성한 능력 — 기업의 부실이 '냄새'로 보인다. 그 냄새를 따라 공매도를 치면 반드시 성공하지만, 숏 포지션 하나당 수명이 6개월씩 줄어든다. 남은 수명 8년. 이 안에 충분히 벌어서 "수명을 되돌리는 방법"까지 사야 한다.

**1화 후킹**: _"네 코에서 피 냄새가 났어." 전 직장 후배가 말했다. 다음 날 그 회사가 분식회계로 상장폐지됐다. 세 번째 숏을 친 날, 거울 속 내 머리카락이 하얗게 변해 있었다._

| 항목          | 설정                                                                              |
| ------------- | --------------------------------------------------------------------------------- |
| 비틀기 포인트 | 숏은 무조건 성공 → 대가는 수명. **얼마나 벌 것인가 vs 얼마나 살 것인가**          |
| 판타지 요소   | 부패 기업에서 '썩은 냄새'가 남. 숏 성공=수명 6개월 감소                           |
| 제약          | 숏만 가능(롱은 불가). 냄새 없는 기업에 숏 치면 자기가 파산                        |
| 도덕적 갈등   | 그 기업이 망하면 수천 명이 직장을 잃는다 → 정의인가 탐욕인가                      |
| 자본곡선      | 5천만→80억→300억→50억(수명 보존 선택)→500억→"마지막 숏"                           |
| 적대자        | ①부패 기업 보복 → ②금융당국(비정상 숏 패턴 추적) → ③능력을 탐내는 그림자 조직     |
| NPC 12명      | 전 후배(파트너), 종양 전문의(수명 카운터), 금감원 조사관, "같은 능력" 선행자의 딸 |
| 패배 10블록   | 수명 감소 가속, 파트너 배반, 선행자 사망 원인 추적 실패, 능력 폭주                |
| **P3 차별화** | ✅ "성공하는 공매도"는 많지만 **수명 교환**은 없음. death_clock 긴장감             |
| **P4 시장성** | ✅ 매 숏이 목숨 건 도박 → 극강 텐션. 수명 회복 복선 → 후반 사이다                  |
| **5-Pass**    | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                                                    |

## ② 「로또 2등이라 말하고 다니련다」

**레퍼런스 힌트**: 비트코인 은퇴 (#43) / 로또 (#72) → **비틀기: 1등이 아니라 2등이라고 거짓말하는 이유**

**로그라인**: 로또 1등 578억에 당첨된 택배 기사. 1등이라 하면 세금+소송+친척이 몰려오니까 — "2등이요, 5억이요"라고 거짓말한다. 5억짜리 인생을 연기하면서 578억을 은밀하게 굴린다.

**1화 후킹**: _"준호야, 아빠가 로또 2등 당첨됐다." — 이건 거짓말이다. 578억이다. 하지만 1등이라 말한 순간, 인생이 끝나는 걸 나는 안다. 전생에서 당첨 사실을 공개하고, 3년 만에 자살했으니까._

| 항목           | 설정                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| 비틀기 포인트  | **회귀 + 자산 은닉 + 칩거형 투자**. 전생에서 "1등 공개 → 파멸" 경험 → 이번엔 숨기기    |
| regression_ext | 회귀, death_flag="전생 로또 공개 후 자살"                                              |
| 핵심 갈등      | 578억을 5억인 척 쓰면서도 가족에게 좋은 아빠이고 싶다                                  |
| 자본곡선       | 578억(숨김)→외관 5억→비밀투자 100억→300억→유출 위기→700억→1,200억                      |
| 적대자         | ①의심하는 전처 변호사 → ②국세청 자금추적 → ③전생에서 자살로 몬 사채업자(이번에도 등장) |
| **P3 차별화**  | ✅ "부자 숨기기"는 있지만 "회귀+명확한 이유(전생 파멸)" 조합은 없음                     |
| **P4 시장성**  | ✅ 독자 대리만족(578억) + 스릴(들키면 끝) + 가족 감동선                                 |
| **5-Pass**     | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                                                         |

## ③ 「고양이가 종목을 골라줌」

**레퍼런스 힌트**: 위기감지(#50)+고양이투자(#116) → **비틀기: 능력자는 고양이. 인간은 집사이자 실행자**

**로그라인**: 길고양이를 주워 키웠는데, 이 고양이가 신문 위에 앉으면 그 기사 속 기업의 주가가 폭등한다. 6개월간 전부 적중. 단, 고양이가 '히잉' 하고 울면 — 폭락한다. 증권가에서 '고양이 펀드' 전설이 시작된다.

**1화 후킹**: _"야옹이가 삼성전자 위에 앉았습니다." 다음 날 +12%. "오늘은 카카오 위에 앉았습니다." +22%. "오늘은… 신문도 안 보고 내 무릎 위에 앉았습니다." 그날 코스피가 300포인트 빠졌다. 야옹아, 너 설마 알고 있었니?_

| 항목          | 설정                                                                               |
| ------------- | ---------------------------------------------------------------------------------- |
| 비틀기 포인트 | **능력 주체가 인간이 아니라 고양이**. 주인공은 "통역"과 "실행" 역할                |
| 제약          | 고양이는 매일 1개만 고름 / 강제시 도망감 / 아프면 능력 X / 수명 15년               |
| 핵심 갈등     | 고양이의 건강 = 주인공의 사업. 돈 vs 고양이 행복                                   |
| 자본곡선      | 50만→3억→100억→20억(고양이 아픔, 판단 오류)→500억→1,000억                          |
| 적대자        | ①증권사 퀀트팀(패턴 분석) → ②경쟁 펀드(고양이 납치 시도) → ③금감원(이상 수익 조사) |
| **P3 차별화** | ✅ "동물 능력자" 웹소설은 드물고, 고양이=펀드매니저 컨셉은 유일무이                 |
| **P4 시장성** | ✅ 코미디+힐링+투자 스릴. 고양이 캐릭터 상품 潜力                                   |
| **5-Pass**    | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                                                     |

## ④ 「재벌 3세인데 용돈이 0원」

**레퍼런스 힌트**: 재벌집 막내(#112)/금수저(#38) → **비틀기: 재벌인데 돈을 못 쓰는 구조**

**로그라인**: 회귀한 재벌 3세. 그룹 시총 50조의 상속자이지만 — 할아버지의 유언장에 "30세까지 자기 힘으로 100억을 벌지 못하면 상속 자격 박탈"이라 쓰여있다. 가문의 돈을 단 1원도 쓸 수 없는 상태에서, 재벌의 인맥과 정보력만으로 100억을 만들어야 한다.

**1화 후킹**: _"현우야, 네 통장을 확인해봐라." 할아버지 장례식 다음 날, 변호사가 내민 잔액: ₩0. 그리고 유언장 조항 제7항: '30세 생일 전까지 순자산 100억 미달 시, 전 지분을 장학재단에 기부한다.' 남은 기간: 4년._

| 항목           | 설정                                                         |
| -------------- | ------------------------------------------------------------ |
| 비틀기         | 재벌이 **맨몸으로** 돈을 버는 역설. 정보력은 있되 자본은 0   |
| regression_ext | 회귀. 전생에서 100억 실패→상속 박탈→파멸→회귀                |
| 핵심 갈등      | 가문 이름을 쓸 수 없음(유언장 조건). 형제들은 방해           |
| 자본곡선       | 0원→500만(알바)→3억→-2억(사기)→30억→100억(데드라인)          |
| 적대자         | ①형(방해 공작) → ②가문 법무팀(감시) → ③경쟁 재벌(인수 시도)  |
| **P3**         | ✅ "돈 있는 재벌"이 아니라 "돈 없는 재벌" — 완전 역전         |
| **P4**         | ✅ 데드라인 긴장감 + 0원 스타트 대리만족 + 재벌 정보력 사이다 |
| **5-Pass**     | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                               |

## ⑤ 「채무자의 감정 능력은 돈 냄새가 난다」

**레퍼런스 힌트**: 감정사(#4,#9,#85) → **비틀기: 감정 능력의 대가가 빚**

**로그라인**: 빚 9억의 신용불량자에게 각성한 능력 — 물건의 '진짜 가치'가 보인다. 1,000원짜리 도자기가 실은 3억짜리 고려청자. 단, 감정할 때마다 **자기 빚이 감정가의 10%만큼 늘어난다**. 빚을 갚으려고 감정하는데, 감정할수록 빚이 늘어나는 지옥의 굴레.

**1화 후킹**: _잔고 -9억 2,400만 원. 명동 사채업자 문자가 38개. 그런데 오늘 아침부터 물건 위에 숫자가 뜬다. 편의점 라면 위에 '823원'. 옆집 아저씨 시계 위에 '2억 3천만 원'. 지하철 역사 벽에 걸린 액자 위에 '47억 원'. — "47억? 저거 프린트 아닌데?"_

| 항목       | 설정                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| 비틀기     | 감정 능력=빚 증가. **돈을 벌수록 빚도 늘어남** → 영원히 빚쟁이?         |
| 제약       | 감정가의 10%가 빚에 추가 / 하루 3개 한도 / 이미 감정한 물건 재감정 불가 |
| 탈출 조건  | 복선: "최초의 빚 9억을 완제하면 패널티 해제" (40블록 뒤 밝혀짐)         |
| 자본곡선   | -9억→-12억(감정하며 빚 증가)→+5억→-15억(실수)→+50억→빚 청산             |
| 적대자     | ①사채업자(빚 독촉) → ②위작 갤러리(감정 방해) → ③능력 탐내는 골동 재벌   |
| **P3**     | ✅ "감정사" 수백 개지만 "감정=빚 증가" 패널티는 유일                     |
| **P4**     | ✅ 빚 청산 과정=극한 카타르시스. 매 감정이 도박                          |
| **5-Pass** | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                                          |

## ⑥ 「전 아내에게 양육비를 보내려고 주식을 합니다」

**레퍼런스 힌트**: 이혼+비트코인(#76)/딸가진이혼남(#125) → **비틀기: 돈을 버는 이유가 자기가 아니라 양육비**

**로그라인**: 이혼 후 양육권을 잃은 아빠. 월 300만 원 양육비를 보내야 딸을 만날 수 있다. 실직 상태에서 주식 한 종목이 10배가 뜨면서 투자에 눈을 뜬다. 그의 투자 목표는 재벌이 아니다 — "딸이 대학 갈 때까지, 매달 300만 원을 끊기지 않는 것."

**1화 후킹**: _법원 판결문. '양육비 3개월 이상 미납 시 면접교섭권 정지.' 통장 잔고: 42만 원. 다음 달 양육비 납기: 22일 후. 그날 밤, 유일하게 남은 500만 원짜리 주식이 장 마감 후 50% 올라 있었다._
_"마르지 않는 우물을 만들어야 한다. 틀리면 수빈이를 못 만난다."_

| 항목        | 설정                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| 비틀기      | 투자 목표가 "부자"가 아니라 **"매달 300만 원 사수"** → 스케일이 작아서 더 긴장 |
| 판타지 없음 | 순수 현실 투자물. InvestmentGuard 완전 활용                                    |
| 핵심 갈등   | 큰 돈을 벌수록 전처 쪽에서 양육비 증액 소송 → 돈이 늘어도 편해지지 않음        |
| 자본곡선    | 500만→3,000만→-800만(실패)→1억→5억→20억→딸 대학 입학                           |
| 적대자      | ①전처 재혼 남편(양육권 변경 시도) → ②리딩방 사기 → ③증권사 불공정거래          |
| 감정선      | 매 블록 마지막에 "딸 카톡" 한 줄 → 독자 감정 앵커                              |
| **P3**      | ✅ 투자물의 목표가 "재벌"이 아닌 "양육비" — 스케일 다운이 비틀기                |
| **P4**      | ✅ 아빠 독자층 직격. 감정 몰입 극강. 대리만족 = "내 아이를 지키는 성공"         |
| **5-Pass**  | **P0✅ P1✅ P2✅ P3✅ P4✅ — PASS**                                                 |
