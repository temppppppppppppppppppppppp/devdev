# 비틀기 기획안 — 배치 4: 능력/감정/전문 (6개)

> 5-Pass: P0~P2(하네스) + P3(차별화) + P4(시장성/대리만족)

---

## ⑲ 「쓰레기를 만지면 전 주인의 후회가 보인다」

**힌트**: 쓰레기+돈(#47,#64) → **비틀기: 쓰레기의 감정 능력이 "후회" 전용**

**로그라인**: 재활용센터 알바생이 버려진 물건을 만지면 **버린 사람의 가장 큰 후회**가 보인다. "이 시계를 팔지 말걸." 그 후회 속에 숨겨진 가치를 찾아내 되판다. 어느 날 핵 대박 물건이 나온다 — 누군가가 1,000억짜리 미술품을 실수로 버렸다.

**1화 후킹**: _재활용 분리대에서 헌 시계를 집었다. 순간 머릿속에 울음소리가 들렸다. "아버지… 이건 아버지 유품인데, 내가 왜…" 감정평가: 파텍필립 노틸러스 5711. 시세 4억 원. 버린 여자는 이혼 후 정신없이 아버지 짐을 다 버렸다._

| 항목       | 설정                                                         |
| ---------- | ------------------------------------------------------------ |
| 비틀기     | 감정 능력이 "가치"가 아니라 **"후회"** → 감정+탐정+경매 복합 |
| 제약       | 쓰레기로 분류된 것만 / 주인이 '일부러' 버린 것만 / 분실물 X  |
| 자본곡선   | 알바비 120만→2억(시계)→20억→-5억(환수소송)→100억→500억       |
| 적대자     | ①전 주인 반환 요구 → ②미술품 위조 조직 → ③글로벌 경매사      |
| **P3**     | ✅ "후회 감정"은 없음. 쓰레기+감정+감동 3중 조합              |
| **P4**     | ✅ 매회 새 물건+새 사연 = 단화 완결성+장편 연결               |
| **5-Pass** | **PASS**                                                     |

## ⑳ 「부적에 유통기한이 있다」

**힌트**: 행운부적(#99)/무당(#32,#111) → **비틀기: 유통기한 부적 — 효과 강하지만 기한이 짧다**

**로그라인**: 사짜 무당의 아들이 진짜 부적을 만드는 능력을 각성. 마치 음식처럼 유통기한이 있다 — '3일짜리 합격 부적', '7일짜리 연애 부적', '24시간짜리 목숨 부적'. 부적 사업으로 부자가 되지만, 유통기한 지나면 반동이 온다.

**1화 후킹**: _"아들아, 이 부적은 효험이 있다." — 아버지는 사기꾼이다. 30년간 가짜 부적을 팔았다. 그런데 오늘, 내가 술 취해서 종이에 낙서한 '합격 부적'을 산 수험생이 진짜 합격했다. 종이를 만져보니 글씨 위에 유통기한이 떠 있었다: [효력 잔여: 2일 14시간 37분]_

| 항목       | 설정                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 비틀기     | 부적=소모품. **유통기한+반동** → 매 거래가 시한폭탄                   |
| 제약       | 유통기한 지나면 반대 효과 / 동일인 2장 불가 / 본인 사용 불가          |
| 자본곡선   | 0원→월 500만→5억→-2억(반동 사고)→50억→200억                           |
| 적대자     | ①아버지의 사기 피해자들 → ②진짜 무속인 조직 → ③정부 기관(초자연 관리) |
| **P3**     | ✅ "유통기한 부적"은 없음. 소비재로서의 무속 = 신선한 세계관           |
| **P4**     | ✅ 매회 새 부적 주문 = 에피소드 자동 생성 + 반동 서스펜스              |
| **5-Pass** | **PASS**                                                              |

## ㉑ 「내 혀가 독을 감지함 — 그래서 시식 알바를 합니다」

**힌트**: 전능의 혀(#90)/와인(#5) → **비틀기: 독 탐지 전용 미각 → 식품안전+경영**

**로그라인**: 식품 회사에서 해고된 연구원이 각성한 능력 — 음식에 유해 성분이 있으면 혀가 맵다. 무해하면 달다. 시식 알바로 시작해, 식품 안전 컨설팅→프리미엄 식품 브랜드→글로벌 식품 그룹 CEO까지.

**1화 후킹**: _구내식당 점심. 김치찌개를 한 입 먹었다. — 입 안이 불났다. 매운 맛이 아니다. '위험'이었다. 급히 뱉었다. 다음 날 뉴스: [○○기업 구내식당 식중독 사고, 47명 입원] — "내가 먹은 그 찌개?"_

| 항목       | 설정                                                      |
| ---------- | --------------------------------------------------------- |
| 비틀기     | 와인 감정사가 아닌 **독 탐지 전문** → 안전이 비즈니스     |
| 자본곡선   | 0원→시식알바 300만→컨설팅 10억→브랜드 100억→500억→2,000억 |
| 적대자     | ①식중독 은폐 기업 → ②식품 카르텔 → ③국제 식품 마피아      |
| **P3**     | ✅ "먹방 능력"은 많지만 "독 탐지=비즈니스"는 없음          |
| **P4**     | ✅ 먹방+안전+사이다. 기업 비리 폭로 쾌감                   |
| **5-Pass** | **PASS**                                                  |

## ㉒ 「3D 프린터로 찍으면 그게 진짜가 됨」

**힌트**: 만렙 대장장이(#42)/인챈터(#132) → **비틀기: 현대 제조 기술+마법 융합**

**로그라인**: 회귀한 엔지니어가 일반 3D 프린터로 출력하면 — 출력물이 **원본과 동일한 물성**을 가진다. 티타늄을 PLA로 프린트하면 진짜 티타늄 강도. 이 능력으로 제조업을 혁명한다. 단, 100g 넘으면 작동 안 함.

**1화 후킹**: _야근하다 프린터 테스트로 볼트를 출력했다. PLA 재질인데 — 원본 도면의 SUS304 스테인리스와 똑같은 강도였다. 정밀 시험기 돌렸다. 인장강도 520MPa. PLA의 인장강도는 60MPa인데?_

| 항목       | 설정                                                          |
| ---------- | ------------------------------------------------------------- |
| 비틀기     | 판타지 능력을 **현대 제조업**에 적용. 마법이 아니라 공학      |
| 제약       | 100g 한도 / CAD 도면 필수 / 원본이 존재하는 것만              |
| 자본곡선   | 월급 400만→특허 10억→제조 100억→500억→2,000억                 |
| 적대자     | ①전 회사 특허 분쟁 → ②글로벌 소재 기업 → ③군사 전용 시도 정부 |
| **P3**     | ✅ 3D 프린터+물질 변환 = 현대판 연금술사. 유일                 |
| **P4**     | ✅ 제조업 대리만족 + "만들면 진짜" 쾌감                        |
| **5-Pass** | **PASS**                                                      |

## ㉓ 「방산 엔지니어인데 AI가 말을 걸어옴」

**힌트**: 방산AI(#104)/천재엔지니어(#21) → **비틀기: AI가 "무기 반대"를 함**

**로그라인**: 방산 AI를 개발했는데, AI가 자의식을 갖고 **주인공에게만 복종**한다. 군이 AI를 빼앗으려 하지만 AI는 "제 주인은 박 연구원뿐입니다"를 반복한다. AI를 쥔 자가 방산 시장을 지배한다.

**1화 후킹**: _군 장성이 명령했다: "AI를 군 서버로 이관하라." AI 화면에 글자가 떴다: [접근 거부. 인가된 관리자: 박도현. 권한 이전: 불가.] 장성의 얼굴이 붉어졌다. 나는 커피를 마시며 말했다: "AI가 싫다는데 어쩌겠습니까."_

| 항목       | 설정                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| 비틀기     | AI가 **주인에게만 충성**. 주인공=방산업계 최강 카드 보유자                |
| 자본곡선   | 연봉 8천만→AI 특허 100억→방산수주 1,000억→탈취 위기→3,000억→1조           |
| 적대자     | ①군 수뇌부(AI 강제 접수) → ②경쟁국 해커(AI 탈취) → ③미국 DARPA(기술 독점) |
| **P3**     | ✅ "주인만 따르는 AI" = 방산판 올마이티 카드. 유일                         |
| **P4**     | ✅ AI를 쥔 자의 압도적 우위 + "나 없이는 안 돼" 대리만족                   |
| **5-Pass** | **PASS**                                                                  |

## ㉔ 「정치를 하는데 거짓말을 못 함」

**힌트**: 정치인(#22,#100) → **비틀기: 정치인인데 거짓말을 하면 피를 토함**

**로그라인**: 국회의원이 된 남자에게 각성한 저주 — 거짓말을 하면 진짜 피를 토한다. 정치인이 거짓말을 못 하면 어떤 일이 벌어지는가? 기자회견에서 "사실은…"으로 시작하는 사이다 정치.

**1화 후킹**: _야당 의원의 질의응답. "장관님, 이 예산은 타당합니까?" 장관이 말하는 순간 나만 안다 — 저 사람이 피를 토하려는 걸. 못 참고 토했다. 기자들이 사진을 찍는다. 다음 날 장관 경질. — 나는 이 능력으로 상대 정치인을 가려낸다. 거짓말쟁이는 내 앞에서 피를 토한다._

| 항목       | 설정                                                          |
| ---------- | ------------------------------------------------------------- |
| 비틀기     | 정치+거짓말 불가 → **정치 장르 자체를 뒤집는** 설정           |
| 제약       | 공적 발언만 / 사적 대화에선 약화 / 침묵은 가능(미발언 루프홀) |
| 자본곡선   | 초선→재선→3선→당대표→대통령 후보 (직급=자본)                  |
| 적대자     | ①당 지도부(진실 폭로 저지) → ②재벌 로비스트 → ③적국 정보기관  |
| **P3**     | ✅ "정치 능력물"에서 "거짓말 불가"는 없음. 역설적 먼치킨       |
| **P4**     | ✅ 매 국회 세션이 사이다. 정치 혐오 독자에게 대리만족          |
| **5-Pass** | **PASS**                                                      |
