# 컨셉 기획안 — 방산물 A: 「설계도면은 거짓말을 하지 않는다」

> 장르: 현대판타지 · 방산물 · 회귀물
> 플랫폼 타겟: 문피아 (1순위), 네이버시리즈 (2순위)

---

## 1. 로그라인

**2040년, 자신이 설계한 차세대 전투기가 결함으로 추락해 100명이 사망한 항공공학자가, 2025년으로 회귀한다. 방산 비리의 증거가 된 설계도면, 이번엔 내가 바로잡는다.**

## 2. 1화 후킹

> _"KF-41 블랙이글의 3호기가 동해 상공에서 추락했다. 조종사 2명 사망, 함재기 탑재 구축함 병사 98명 사망. 그리고 그 전투기의 날개 구조를 설계한 사람이 나, 하준영이다."_
> → 회귀 후 2025년. 입사 첫날, 면접관이 묻는다: "하 박사, KF-21 후속기 날개 설계에 자신 있습니까?"

## 3. 세계관 & 장르 설정

| 항목            | 설정                                                                           |
| --------------- | ------------------------------------------------------------------------------ |
| **회귀 방식**   | 2040년 자살 직후 → 2025년 방산업체 입사일로 회귀                               |
| **기억 유지**   | 15년간 항공·무기체계 설계 경험 + 방산 비리 내부 정보                           |
| **회귀 제약**   | 기술은 알지만 **군 내부 의사결정 구조**를 모름. 기술만으론 비리를 막을 수 없음 |
| **판타지 요소** | 도면을 보면 **구조적 결함이 붉은 선으로 보이는** 능력 (회귀 후 각성)           |
| **기업 배경**   | 한성에어로스페이스 (KAI+한화 모티브, 시총 8조, 재계 30위)                      |
