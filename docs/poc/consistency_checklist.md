# POC 일관성 검사 체크리스트 (25화)

> 원고 완성 후 Claude와 함께 검토. 화별 검사 + 전체 검사 두 단계.

---

## 1. NPC 연속성

| 항목 | 확인 내용 |
|------|-----------|
| 사망 캐릭터 | 사망 처리된 NPC가 이후 화에 행동/대사로 등장하지 않는지 |
| 이름 일관성 | NPC 이름이 화마다 달라지지 않는지 (한자/영문 혼용, 오타) |
| 직책/소속 변화 | 직책 변경이 있었다면 이후 화에서 올바르게 반영되는지 |
| 성격/말투 | 특정 NPC의 성격·말투가 화마다 일관적인지 |
| 관계 변화 | 적→아군, 아군→적 전환이 있었다면 이후 화에서 유지되는지 |

---

## 2. 주인공 성장 곡선

| 항목 | 확인 내용 |
|------|-----------|
| 자산 누적 | 투자 수익/손실이 누적되어 자산이 논리적으로 증가하는지 |
| 정보 비대칭 활용 | 회귀 지식(미래 정보)을 일관되게 활용하는지, 갑자기 모르는 척하지 않는지 |
| 인맥 구축 | 확보한 인맥이 이후 화에서 활용/언급되는지 |
| 능력/스킬 | 습득한 투자 기법·전략이 이후 화에서 축적되어 나타나는지 |
| 실패 학습 | 실패 경험이 이후 행동에 반영되는지 |

---

## 3. 플롯 논리

| 항목 | 확인 내용 |
|------|-----------|
| 인과율 | 사건 A → 결과 B 연결이 자연스러운지 |
| 복선 회수 | 심어둔 복선이 25화 내에서 회수되거나 유효하게 유지되는지 |
| 타임라인 | 날짜/시간 흐름이 앞뒤로 모순되지 않는지 |
| 목표 일관성 | 주인공 단기/중기 목표가 Arc 내에서 유지되는지 |
| 우연 남용 | 위기 탈출이 지나치게 우연에 의존하는 화가 있는지 |

---

## 4. 세계관/설정 일관성

| 항목 | 확인 내용 |
|------|-----------|
| 기업명/기관명 | 회사명, 증권사명이 화마다 동일한지 |
| 금융 수치 | 투자 금액, 수익률, 주가 등 숫자가 앞뒤로 모순되지 않는지 |
| 시대 배경 | 회귀 시점 기준 역사적 사건(IMF, 서브프라임 등)이 올바른 시점에 등장하는지 |
| 투자 규칙 | 실제 금융 시장 규칙(공매도, 지분 공시 5% 룰 등)이 일관되게 적용되는지 |
| 법률/제도 | 언급된 법률·제도가 시대에 맞고 일관적인지 |

---

## 5. 서사 품질

| 항목 | 확인 내용 |
|------|-----------|
| 반복 장면 | 비슷한 장면(회의, 거래, 대결)이 3화 이상 연속으로 반복되는지 |
| 감정선 | 주인공 감정 변화가 사건에 비례하는지 (갑작스러운 감정 폭발/냉정 전환) |
| 대리만족 포인트 | 통쾌한 역전, 성장, 복수 등 독자 만족 요소가 Arc마다 존재하는지 |
| 긴장-이완 리듬 | 고긴장 화 이후 적절한 이완이 있는지 (긴장만 지속되면 피로감) |
| 클리프행어 | Arc 마지막 화에 다음 Arc로 넘어가는 훅이 있는지 |

---

## 6. 투자물 장르 특수 체크

| 항목 | 확인 내용 |
|------|-----------|
| 회귀 지식 농도 | 미래 지식 활용이 매 화 등장하는지, 아니면 특정 화에 몰리는지 |
| 빌런 위협 수위 | 적대 세력의 위협이 점진적으로 증가하는지 |
| 투자 디테일 | 종목명, 매수/매도 타이밍 등 투자 장면이 구체적인지 |
| 주변인 반응 | 주인공 성공에 대한 주변 반응(질투, 경계, 협력)이 현실적인지 |

---

## 검사 방법

### 화별 검사 (빠른 스캔)
각 화 읽으면서 위 항목 중 위반 사항 발견 시 메모:
```
[n화] 항목: 내용
예) [7화] NPC 연속성: 5화에서 해고된 김부장이 출근하는 장면
```

### 전체 검사 (25화 완료 후)
- NPC 등장 횟수 집계 → 소외된 주요 NPC 확인
- 자산 증감 타임라인 정리
- Arc별 대리만족 포인트 목록화
- 복선 심기/회수 대조표

---

## 합격 기준 (POC)

| 등급 | 기준 |
|------|------|
| ✅ PASS | 치명적 모순 없음, NPC 사망 오류 없음, 자산 누적 논리적 |
| ⚠️ CONDITIONAL | 경미한 불일치 3건 이하 (수정 가능 수준) |
| ❌ FAIL | 치명적 플롯 모순, NPC 부활, 자산 역행 등 |

**POC 목표**: PASS 또는 CONDITIONAL
