## §0. 목적

이 문서는 실패한 `02_chaebol_allowance_zero` TR과 재작업 TR을 **1:1 비교**하기 위한 실행 가능한 재생산 오더다.

- 어떤 항목이 FAIL이었는지 (실측 수치)
- 재작업에서 어떤 수치를 달성해야 PASS인지 (TF-BH1 R27~R33 기준)
- 아크별 재설계 방향 (opponent/weakness/solution 차별화)

## §1. 실패 TR 결함 요약표 (TF-BH1 §0.1 실측 재인용)

### 1.1 5대 결함

| # | 결함 | 실측 수치 | 심각도 | TF-BH1 규칙 |
|---|------|-----------|--------|-------------|
| F-1 | opponent 4명 무한 반복 | 고유 4명: 노현주(5), 서도윤(29/41%), 윤석진(28/40%), 백도현(8). 현재 골든은 31명 / 최대 점유율 24.3%. | **P0** | R29 |
| F-2 | weakness 아크 내 100% 동일 | 7개 아크 전부 아크 내 weakness 1종. 총 7종. | **P0** | R30 |
| F-3 | solution 구조 템플릿 × 70 | "주도권을 자기 쪽으로 당긴다" 70블록 전량 동일 | **P0** | R31 |
| F-4 | content ~268자 | 4필드 평균(context+villain+solution+reward) 268.14자. 현재 골든은 4필드 평균 853.71자, 5필드 평균(+stakes) 972.93자. | **P1** | R27 |
| F-5 | sector 키 이름 불일치 | `business_sector` 7종 70블록 존재. 필드 자체는 있음. | **P2** | R28 |

### 1.2 validate_v3 적용 결과 요약

| 패턴 | 탐지 결과 | 심각도 |
|------|-----------|--------|
| Q' (350자 미만) | 70/70 블록 FAIL (268자) | P1 |
| R (고유 opponent 8명 미만) | FAIL (4명) | P0 |
| R' (점유율 30% 초과) | FAIL (서도윤 41%, 윤석진 40%) | P0 |
| S (아크 내 weakness 3종 미만) | 7/7 아크 FAIL (각 1종) | P0 |
| T (R31-Hard) | FAIL (`tail-20 최다 14` + `1문장 70/70` + `avg 86.50`) | P0 |
| T' (R31-Soft) | N/A | P1 |
| Q+T 복합 | FAIL (밀도 P1 + 템플릿 P0 동시) | **P0** |
| U (sector 10블록+ 연속) | 0건 (7종 × 10블록 — 정확히 10블록이므로 초과 아님) | PASS |

**총 P0 위반: 4건 (R, R', S, T) + 복합 1건 = 5건**

### 1.3 핵심 발견

실패 TR의 `content 268자`는 여전히 핵심 결함이지만, 현재 골든 TR은 4필드 평균 853.71자로 이미 크게 벌어져 있다. **진짜 구분자는 opponent 다양성 + solution 템플릿 반복 + weakness 고정 + 실질 밀도**다.

### 5.3 배치별 검증 체크

각 배치 완료 후:

1. **validate_v3 실행** (누적 블록 전체 대상)
2. P0 위반 확인:
   - P0 위반 0건 → 다음 배치 진행
   - P0 위반 1건+ → **같은 배치 재작업** (다음 배치 진입 금지)
3. P1 위반 확인:
   - P1 위반 3건 미만 → 다음 배치 진행 (P1은 누적 관리)
   - P1 위반 3건+ → 보강 후 재검증

중요 단서:

- R29/R30의 **70블록 전체 기준**은 블록 70개 완성 후 최종 판정한다.
- 중간 배치 검증에서는 아크 단위 기준을 우선 본다.
  - opponent: 대단원 내 ≥2명(P0), ≥3명(P1)
  - weakness: 대단원 내 ≥3종(P0)

### 5.4 1턴 1배치 규칙

- 1턴에 1배치(최대 10블록)만 생산한다.
- 배치 생산 → validate_v3 검증 → 판정을 1턴 내에 완료한다.
- 이전 턴의 P0 위반을 해소하지 않고 다음 배치로 넘어가지 않는다.

- 현재 골든 TR은 R27, R29에서는 PASS다.
- 현재 골든 TR은 현행 단일 R31에서는 FAIL이지만, `R31-Hard / R31-Soft` 분리 기준으로 보면 Hard FAIL은 아니다.
