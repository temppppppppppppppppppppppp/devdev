## 1. 로그라인

**20년간 회사에 충성했지만 구조조정으로 해고당한 54세 과장이, 입사 첫날(24세)로 회귀한다. 이번 생에서는 회사를 위해 일하지 않는다 — 회사를 통째로 삼킨다.**

> 핵심: 복수가 아니다. **투자**다. 회사의 모든 내부 정보를 30년치 알고 있는 남자가, 밖에서 사는 게 아니라 안에서 먹는다.

## 6. 적대자 변천사

### Phase 1 (대단원 1~2): 꼰대 상사 + 학연 파벌
- 차민식(성과 도둑) + 오상현(학연 보스)
- 도영 전략: 전생 30년치 내부 비리 증거로 하나씩 제거. **"네가 횡령한 거 나는 다 안다"**

### Phase 2 (대단원 3~5): 오너 2세 강준혁 + 사모펀드
- 무능한 2세가 회사를 망치려 하고, 외부 자본이 노린다
- 도영 전략: **2세를 조종하여 실책 유도 → 이사회 퇴출 → 도영이 경영 실권 장악**

### Phase 3 (대단원 6~7): 오너 일가 분열 + 경영권 전쟁
- 회장 은퇴 후 일가 내전 → 사모펀드 합류
- 도영 전략: 모든 지분을 확보한 상태에서 **경영권 최종 인수**
