## 1. 로그라인 (수정)

**대한민국 시총 1위 기업을 말아먹은 CEO가, 13년 전 같은 회사의 첫날 인턴으로 빙의했다. 이번엔 회사를 위해서가 아니라 — 회사를 이용해서 자기 제국을 만든다.**

> **핵심 수정**: 원본의 "직원을 도구로 써서 후회 → 이번엔 사람을 살리며" → **"이번엔 더 효율적으로 이용한다. 단, 전생의 실수는 반복하지 않는다."**
> 도덕적 갈등 제거. 죄책감 제거. 남은 것은 **냉철한 재도전의 쾌감**뿐.

## 2. 1화 후킹 시퀀스

```
프롤로그: 2040년, 한라테크 본사 56층 회장실.
 → 뉴스: "한라테크, 반도체 전량 손실… 시총 90조 증발"
 → 이수혁 CEO, 빈 회장실에서.
 → 독백: "전부 내 결정이었다. 그리고 전부 틀렸다."
 → 하지만 후회는 없다. "다시 할 수 있다면 — 다르게 틀리겠다."
 → 의식이 사라진다.

1화: 2027년 3월 2일, 한라테크 강남 사옥 로비.
 → 눈을 뜬다. '신입 인턴 교육 안내문'.
 → 22살의 몸. 2000년생 인턴들 사이.
 → 엘리베이터에서 내려오는 사람 — 정태준 부사장.
   전생에서 수혁을 CEO로 밀어주고, 마지막에 버린 남자.
 → 정태준이 인턴들을 스치며 지나간다. 눈도 안 마주친다.
 → 수혁 독백: "부사장님, 당신이 나를 버린 건 알고 있습니다."
 → 1화 마지막 줄: "하지만 이번엔 — 내가 당신을 먼저 버립니다."
```

## 3. 주인공 — 이수혁 (자기이득 중심 수정)

| 항목          | 원본                                 | opus 수정                                            |
| ------------- | ------------------------------------ | ---------------------------------------------------- |
| 핵심 동기     | "직원을 소중히 하며 회사를 살리겠다" | **"이번엔 회사를 발판으로 내 제국을 만든다"**        |
| 내적 갈등     | "직원을 도구로 썼다"는 죄책감        | **죄책감 없음. "더 효율적으로 이용하겠다"**          |
| 인간관        | "사람을 살리며 회사를 살린다"        | **"쓸모있는 사람은 살리고, 없는 사람은 비켜라"**     |
| 도덕적 딜레마 | "내가 망하게 한 결정을 의심"         | **의심이 아닌 확신: "전생과 다른 선택을 하면 된다"** |
| 자기 의심     | 핵심 콘플릭트                        | **자기 의심 제거. 남은 건 냉철한 계산능력뿐**        |

> **먼치킨 포인트**: 13년간의 경영 브리핑, 이사회, 전략회의 내용을 기억. 핵심 기밀·특허·경쟁사 동향·내부 비리를 전부 앎.
> **제약**: 인턴이라 의사결정권 零. "맞는 답을 어떻게 권한 없이 실현시키는가?" = 매 블록 핵심 텐션.

## 4. 세계관 & 기업 배경 (원본 유지)

| 항목          | 설정                                                   |
| ------------- | ------------------------------------------------------ |
| **빙의 방식** | 의식 전이. 2040 CEO → 2027 인턴                        |
| **기억 유지** | 13년간 경영 경험+인맥+기밀 완전 보존. 타인 행동은 흐릿 |
| **기업**      | 한라테크 (반도체 소재·장비 → AI → 배터리, 시총 15조)   |

### "인턴"이 만드는 서사 구조 = 대리만족 엔진

| 일반 재벌 빙의물        | 이 작품                              |
| ----------------------- | ------------------------------------ |
| 재벌 2세 → 즉시 실행    | 인턴 → 아무 권한 없음                |
| "이 주식 사라" → 실행됨 | "이 주식 사세요" → "인턴이 뭘 알아?" |
| 정보 + 권한 = 쉬운 성공 | 정보 + 0 권한 = **우회 전략의 쾌감** |

**대리만족 핵심**: 답을 알면서 못하는 답답함 → 우회로 성공하는 사이다. 이 구조가 70블록 반복.

## 6. 적대자 변천사

### Phase 1 (대단원 1~2): 내부 정치 — 오승재 + 보수파
- 한예린 경영 승계 차단, 인턴/사원급 인사 조작
- 수혁 전략: 횡령 증거 선점 → 카드로 보관 → Block 20에서 사용

### Phase 2 (대단원 3~5): 외부 자본 — 사라 밀러 행동주의 펀드
- 한라테크 사업 분할 요구, 주주제안, 위임장 대결
- 수혁 전략: **사라를 역이용하여 내부 적 제거 후, 사라도 밀어낸다**

### Phase 3 (대단원 6~7): 정태준 배신 + 복합 위기
- 전생과 같은 배신. 하지만 이번엔 수혁이 **먼저 준비했다**
- 수혁 전략: 정태준의 배신 시점을 알고 있으므로, 핵심 인력·기술·지분을 사전 확보 후 역공

## 11. 킬링포인트 (대리만족 특화)

3. 🗡️ **"이번엔 내가 먼저 버린다"** — 배신자를 미리 알고 역이용하는 사이다
4. 💰 **0원→5,000억** — 인턴 월급에서 시작해 지분 5,000억
5. 🏢 **반도체/AI 2027년 시의성** — 독자가 이미 아는 산업 트렌드 위의 먼치킨
