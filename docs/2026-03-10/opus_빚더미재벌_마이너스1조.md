## 1. 로그라인 (수정)

**2035년, 아버지의 1조 2천억 부채로 파산한 재벌 2세가 2008년 서브프라임 위기 직전으로 회귀한다. 이번에는 아버지의 실수를 막는 게 아니라 — 아버지보다 먼저 그룹을 삼킨다.**

> **핵심 수정: 원본의 "아버지를 구하겠다"는 동기 → "내가 먼저 차지하겠다"로 변경.**
> 전생에서 "아버지의 그늘에서 벗어나지 못해 망했다"는 교훈 → 이번에는 자기 제국을 만든다.
> 아버지는 구하되, 구하는 이유는 **"아버지 살아있어야 그룹이 유지되고, 유지되어야 내가 빼먹을 수 있으니까"**.

## 2. 1화 후킹 시퀀스

```
프롤로그: 2035년, 파산 선고 법정.
 → "피고인 진서하, 대표이사 배임 혐의 유죄."
 → 서하의 독백: "내가 잘못한 게 뭔데. 아버지가 만든 빚을 내가 갚다가 이 꼴이 됐잖아."
 → 법원 옥상. 발 아래 서울.
 → "다시 할 수 있다면… 이번엔 **나를 위해서** 한다."
 → 의식이 사라진다.

1화: 2008년 9월 14일(일), 서울 성북동 본가.
 → 눈을 뜬다. 리먼 브라더스 파산 뉴스 아침 신문.
 → 아버지(진현태)가 살아있다. "오늘 이사회 간다."
 → 서하는 안다: 내일 리먼이 터지고, 아버지의 레버리지가 그룹을 삼킬 것이다.
 → 서하의 독백: "먼저 빚부터 막고, 그 다음엔 내가 주인이 된다."
 → 1화 마지막 줄: "아버지, 이사회 전에 드릴 말씀이 있습니다. — 달러 숏 치세요."
```

## 3. 주인공 성격 (자기이득 중심 수정)

| 항목          | 원본                          | opus 수정                                               |
| ------------- | ----------------------------- | ------------------------------------------------------- |
| 핵심 동기     | "아버지를 살리고 싶다"        | **"나를 위한 제국을 만든다. 아버지는 도구."**           |
| 내적 갈등     | "사람을 숫자로만 봤다"는 후회 | **후회 없음. "숫자로 봐서 살아남았다"가 신조.**         |
| 도덕적 딜레마 | 존재 (빚 탕감 vs 직원 해고)   | **불필요. 돈이 되면 하고, 안 되면 안 한다.**            |
| 인간관계      | "이번엔 사람을 소중히"        | **"이번엔 이용할 사람과 버릴 사람을 정확히 구분한다."** |
| 감정 코어     | 아버지에 대한 속죄            | **"두 번 다시 남 때문에 망하지 않겠다"는 냉철한 결의**  |

> **독자 대리만족 포인트**: 현실에서 남 좋은 일만 하다가 잘린 경험을 가진 30-60 남성 독자가 "이번엔 나를 위해 산다"에 공감.

## 6. 적대자 변천사 (원본 유지)

### Phase 1 (대단원 1~2): 삼촌 진현철 + 이사회 보수파

- 진성 지분 매집 → 서하가 역이용하여 주가 조작카드로 활용

### Phase 3 (대단원 5~7): 글로벌 IB "리버티 캐피털" + 윤재성 재합류
- 최종 결전. 서하가 **27년치 미래 지식의 마지막 카드**를 쓴다

## 12. 킬링포인트 (대리만족 특화)

1. ⚡ **마이너스에서 시작** — 빚 1.2조 청산 과정 자체가 카타르시스
2. 🧠 **리먼/코로나/AI붐** — "나도 그때 알았으면" 독자 판타지 직격
3. 💰 **자기를 위한 제국 건설** — 남 좋은 일 하다 망한 전생 vs 이번엔 내가 주인
4. 🗡️ **이용하고 버리는 쾌감** — 삼촌/배신자를 역이용하는 사이다
5. 📊 **경제사 실화 기반** — 매 블록이 실제 경제 이벤트와 연동되어 공부 없이 몰입
