## 1. 로그라인

**로또 1등 578억에 당첨된 택배 기사. 전생에서 당첨금을 공개했다가 모든 것을 잃고 자살했다. 회귀한 이번 생에서는 "2등 5억"이라 거짓말하고, 578억을 은밀하게 굴린다.**

> 핵심: **거짓말 자체가 생존 전략.** 도덕적 고민이 아니라 합리적 선택.
> "들키면 끝"이라는 단순한 구조가 매 블록 텐션을 자동 생성한다.

```
프롤로그: 전생, 당첨 공개 3년 후.
 → 어머니가 사기꾼에게 3억을 뜯겼다.
 → 전처가 양육비 55억 소송을 걸었다.
 → 고향 친구 7명이 "인생이 힘든데 좀 빌려줘"라고 한다.
 → 국세청 세무조사. 기부 강요. 언론 노출.
 → 아파트 옥상. "578억짜리 인생이 이거밖에 안 되나."
 → 눈을 감는다.

1화: 회귀. 로또 추첨 30분 전.
 → 손에 든 로또 용지. 번호도 기억한다.
 → 추첨 결과: 1등 당첨.
 → 은행 방문. 직원이 묻는다: "1등이시네요! 축하드립니다. 공개하시—"
 → "아뇨. 2등이요. 5억이요."
 → 직원: "네? 아, 네… 2등 5억 원이요."
 → 은행을 나오며 독백: "이 돈은 아무도 모르게 쓴다. 아무도."
 → 1화 마지막 줄: "578억. 세후 413억. 이건 내 거다. 내 것."
```

## 6. 적대자 변천사

### Phase 1 (대단원 1~2): 개인적 위협
- 전처 재혼남(양육권 변경) + 전생 사기꾼(어머니 접근)
- 준호 전략: 법적 대응(양육비 선제 납부) + 사기꾼 역이용(증거 확보 후 경찰 신고)

### Phase 2 (대단원 3~5): 시스템적 위협
- 국세청 장세라(비정상 자금 추적) + 고액 자산 신고 의무
- 준호 전략: 자산 분산(법인 설립+해외 투자+사모펀드 편입)으로 흔적 최소화

### Phase 3 (대단원 6~7): 정체 노출 위기
- PB 한태민이 정보를 흘림(최대 배신) + 언론 노출 위기 + 전처 소송
- 준호 전략: 노출 직전에 **"자수적 공개"** — 하지만 이미 413억은 1,200억이 되어 있다
