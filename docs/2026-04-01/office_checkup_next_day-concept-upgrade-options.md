# office_checkup_next_day Concept Upgrade Options

Date: 2026-04-01  
Target: `office_checkup_next_day`  
Scope: concept-strengthening note for existing `phase0 + TR + BI`

## 1. Current Truth

현재 작품의 코어는 이미 살아 있다.

- 말단 사원 + 조직 병목 읽기
- 굴욕 -> 각성 -> 첫 사이다 -> 전사급 간판 폭발
- 숫자 은닉 / 결재 병목 / 프로젝트 붕괴 지점
- `Block 7` 대표 스파이크 + `Block 8` 보상 4종

즉, 지금 이 작품의 약점은 `엔진 부재`가 아니라 `간판 스케일과 산업 질감의 추가 강화 여지`다.

## 2. What Must Stay

아래는 갈아엎지 않는 편이 좋다.

- `건강검진 다음 날부터 읽힌다`는 발현 트리거
- `조직 역학 조감 감각`이라는 능력 정의
- `말단 -> 배석 -> TF 간사 -> 상신권` 상승 리듬
- `숫자를 숨기는 적대자`와 `결재선 우회` 구조
- `정보를 읽고 행동으로 바꾸는` execution doctrine
- 남성향 / no-romance / 현실밀착형 능력물 톤

## 3. What Feels Slightly Small Right Now

지금 버전은 완성도는 괜찮지만, 다음 부분이 조금 더 커질 수 있다.

### 3-1. Exterior scale

- 현재 전장은 `중견 유통사 내부 권력전`으로 잘 작동한다.
- 하지만 플랫폼 감각상 `재벌 외피`가 조금만 더 붙으면 제목 인지와 판돈 체감이 커진다.

### 3-2. Sector edge

- `유통 / SCM / MD`는 실무 질감이 좋다.
- 다만 초반 제목감이나 한 줄 피치에서 독자가 즉시 놀랄 정도의 `산업 간판`은 약간 덜하다.

### 3-3. Endgame promise

- 현재는 `조직 핵심 노드`로 올라가는 그림이 좋다.
- 여기에 `그룹 레벨 구조를 바꾸는 사람`이라는 promise가 더 노골적으로 보이면 더 강해진다.

## 4. Recommended Direction

원픽은 `유통사 코어는 유지 + 재벌 외피만 추가`다.

한 줄 요약:

> 유통사 내부 오피스 파워물의 손맛은 그대로 두고, 한일유통을 독립 중견사가 아니라 `그룹 주력 계열사`로 재규정해 판돈을 키운다.

이 방향이 좋은 이유:

- 현재 재료를 거의 버리지 않는다
- 물류/MD/예산/결재선 디테일이 이미 살아 있다
- `재벌물 스케일`만 덧입히면 플랫폼 포장력이 세진다
- 반도체/제약으로 갈아타는 것보다 재작성 비용이 훨씬 낮다

## 5. Upgrade Paths

## Option A. Keep Current Sector, Add Group Exterior  **Recommended**

핵심 변경:

- `한일유통`을 독립 중견사가 아니라 `한일그룹 유통 핵심 계열사`로 재정의
- 물류센터 통합안이 단순 내부 프로젝트가 아니라 `그룹 전체 비용절감 시그널 사업`이 되게 만듦
- 전무/대표의 의미를 `계열사 임원`에서 `차기 그룹 구조조정 / 승계 실무`와 연결
- 후반부 `계열사 자원 최적화 TF`가 진짜 그룹 레벨 플레이가 되도록 강화

얻는 것:

- 기존 오피스 파워 손맛 유지
- 재벌 외피 추가
- `그 사원이 왜 그룹급 안건을 건드리지?`라는 긴장감 상승

적용 포인트:

- `group_background`
- `starter_company`
- `grand_objective`
- 후반부 status_end / HUD

## Option B. Shift To Semi-Chaebol Strategy Room

핵심 변경:

- 주인공 시작점을 `유통사 경영기획팀 사원`에서 `그룹 전략실 파견 3년차`로 변경
- 프로젝트 전장을 `유통 계열사 하나`가 아니라 여러 계열사 사이의 자원 배분으로 확장

장점:

- 재벌물 스케일은 제일 크게 오른다

단점:

- 현재 BI/TR의 현장성 상당수를 다시 손봐야 한다
- 초반 말단 사원 감각이 희석될 수 있다

판정:

- 지금 시점에서는 비용 대비 효율이 떨어진다

## Option C. Keep Engine, Retarget Sector

후보:

- 반도체
- 제약
- OTT / 미디어
- 데이터센터 / 전력

장점:

- 한 줄 피치가 더 화려해질 수 있다

단점:

- 현재 유통사 디테일 재료를 많이 버리게 된다
- 사실상 `부분 재기획`에 가깝다

판정:

- 새 작품이면 추천 가능
- `office_checkup_next_day`에는 지금 굳이 할 필요 없음

## 6. Concrete Strengthening Suggestions

### 6-1. Logline sharpen

현재 logline:

> 전사 최대 프로젝트를 멈춘 건 3년차 말단 사원이었다. 건강검진 다음 날부터 어떤 프로젝트가 터질지, 누가 숫자를 숨기는지, 결재가 어디서 막히는지가 먼저 읽히기 시작한다.

추천 보강안:

> 그룹 핵심 계열사의 최대 투자 프로젝트를 멈춘 건 3년차 말단 사원이었다. 건강검진 다음 날부터 어떤 프로젝트가 터질지, 누가 숫자를 숨기는지, 결재가 어느 임원 선에서 막히는지가 먼저 읽히기 시작한다.

포인트:

- `전사` -> `그룹 핵심 계열사`
- `어디서` -> `어느 임원 선에서`
- 판돈과 결재선 감각을 더 또렷하게 함

### 6-2. Group frame wording

현재 `한일유통`은 중견 유통사처럼 읽힌다.

보강 권장:

- `한일그룹 산하 유통 핵심 계열사`
- `그룹 내 현금흐름과 재고 회전을 책임지는 주력 축`
- `승계전 직전, 가장 먼저 손보려는 비용 구조 계열사`

### 6-3. Endgame promise sharpen

현재:

- 의사결정 구조를 바꿀 수 있는 위치

보강:

- 유통 계열사의 의사결정 구조를 바꾸는 것을 넘어
- `계열사 간 예산/프로젝트/자원 배분의 기준선`을 쥐는 위치

즉:

- `잘하는 사원`이 아니라
- `그룹에서 누구를 살리고 누구를 자를지 숫자로 결정하는 사람`

## 7. Best Minimal-Change Patch Set

실제 수정은 아래 정도면 충분하다.

1. `MetaInfo.logline` 강화
2. `group_background`를 그룹 외피 쪽으로 확장
3. `grand_objective`를 그룹 구조 변경 쪽으로 상향
4. `status_end` / `FinanceHUD` 최종 상태를 그룹 레벨 표현으로 강화
5. 후반 적대축 설명에 `계열사 / 그룹 전략 라인` 연결 문장 추가

## 8. Recommendation

다음 실제 작업은 `Option A`로 간다.

즉:

- 작품 엔진은 유지
- 유통 / SCM / MD 전장도 유지
- 재벌 외피와 그룹 판돈만 강화

이 방향이면 현재 pair를 거의 살리면서도,
카카오/네이버/문피아에서 더 익숙하게 읽히는 `오피스 파워 + 재벌 외피` 결로 당길 수 있다.
