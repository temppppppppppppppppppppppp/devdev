# 글도비 6개월·52종 기준 구독형 vs API 1페이지 비교

- 작성일: 2026-04-07
- 상태: final (1-page decision memo)
- 문서 경로: `docs/2026-04-07/geuldobi-6month-52title-subscription-vs-api-onepage.md`

## 1. 비교 전제

- 운영 기간: 6개월
- 제작 목표: 52종
- 평균 매출: 종당 500만원
- 총매출 가정: 52 × 500만원 = **2억 6,000만원**
- API 제작원가: 종당 100만원
- API 총제작비: 52 × 100만원 = **5,200만원**
- 구독형 제작비: 월정액 좌석형이므로 **직접 AI비가 매우 낮은 구조**
- 구독형 비교 기준: **예시값으로 6개월 총 360만원** 사용
  - 예시: 월 30만원 × 2석 × 6개월
  - 주의: 이 값은 벤더 실가격 인용이 아니라 비교용 모델 입력값이다

## 2. 숫자 비교

| 항목 | 구독형 | API |
|---|---:|---:|
| 총매출 | 2억 6,000만원 | 2억 6,000만원 |
| 총제작비 | 360만원 | 5,200만원 |
| 종당 제작비 | 약 6.9만원 | 100만원 |
| 총매출총이익 | **2억 5,640만원** | **2억 800만원** |
| 매출총이익률 | **98.6%** | **80.0%** |
| API 대비 비용 차이 | - | **+4,840만원** |

## 3. 숫자만 보면 누가 유리한가

**같은 52종을 만들고, 같은 종당 500만원을 벌 수 있다는 가정이 사실이라면 구독형이 현금성 손익에서 압도적으로 유리하다.**

- API는 6개월 기준 구독형 대비 **추가 비용 4,840만원**이 든다
- 따라서 API가 경제적으로 맞으려면 아래 셋 중 하나를 만들어야 한다
  - 추가 매출 **4,840만원 이상**
  - 인건비/검수비/운영비 절감 **4,840만원 이상**
  - 실패율 감소/완주율 상승으로 그에 준하는 가치 회수

## 4. API가 손익상 정당화되는 기준선

API 추가비 4,840만원을 회수하려면:

- 종당 평균 매출이 **약 93만원씩 더 올라가야** 한다
  - 4,840만원 ÷ 52종 = 약 93만원
- 또는 **약 10종을 추가 완주**해야 한다
  - 4,840만원 ÷ 500만원 = 9.68종
- 또는 그만큼의 인력/재작업/QA 비용을 줄여야 한다

즉, **구독형이 실제로 52종을 안정적으로 완주할 수 있다면 API는 단기 손익에서 불리하다.**  
반대로 **구독형으로는 42종 수준이 한계이고 API로 52종 완주가 가능하다면 API는 손익상 따라잡을 수 있다.**

## 5. 효용 가치 비교

| 항목 | 구독형 | API |
|---|---|---|
| 단기 현금 효율 | 매우 높음 | 낮음 |
| 제작 단가 예측성 | 높음 | 중간 |
| 52종 완주 가능성 | 사람 역량 의존 큼 | 시스템화 시 높음 |
| 품질 편차 통제 | 낮음 | 높음 |
| 재현성/로그/감사 | 낮음 | 매우 높음 |
| 자동화/배치 확장 | 낮음 | 매우 높음 |
| 핵심 인력 의존도 | 높음 | 중간 |
| 6개월 이후 자산 축적 | 낮음 | 높음 |

## 6. 한 줄 결론

### 경영 숫자만 보면

**구독형 우세**  
동일 매출, 동일 완주량이 성립하면 API는 6개월 손익상 불리하다.

### 운영 현실까지 보면

**API는 "비싸지만 규모화 가능한 생산 시스템"에 가깝다.**  
52종을 6개월 안에 안정적으로 뽑아야 하고, 품질 편차/재작업/운영 리스크를 줄여야 한다면 API의 추가비 4,840만원은 보험료이자 생산 인프라 비용으로 해석할 수 있다.

## 7. 최종 권고

- **보수적 재무 판단:** 구독형 우선
- **생산 시스템 판단:** API 우선
- **실무적 최적안:** `탐색/초안/실험은 구독형`, `권한 있는 대량 생산 라인은 API`

즉, 이 6개월 비교의 핵심 질문은  
**"무엇이 더 싸냐"가 아니라 "구독형으로도 정말 52종을 같은 품질과 속도로 완주할 수 있느냐"** 이다.
