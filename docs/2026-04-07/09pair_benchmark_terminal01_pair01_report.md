## 6. Top 3 Repair Units or Alias Note

Grade is `GREEN`. Alias note and residual risk instead of repair units.

**Alias note**: 투자물_골든 remains a valid `GREEN` reference pair for the market-power benchmark lane. Domain texture and repeatable loop are exemplary within the `blockguide` family.

**Residual risk 1 — asset-only early reward (GREEN ceiling cause)**:
Blocks 2-6 deliver capital growth (20→70억) and PB-level trust only. No family reevaluation, no industry seat, no authority or approval token inside the first block. The first meaningful status-weight shift (마이클 첸 reevaluation, global CDS access) arrives in Block 7, one block late. If a future repair wave targets `GREENPLUS` promotion, the repair unit is: pull one concrete status/authority token into the first block boundary (Blocks 2-6).

**Residual risk 2 — BI amplification ceiling**:
BI organizes the 60-block arc well (FinanceHUD tracking, 6-arc opponent_transition_plan, KarmaMatrix) but reads more as structured TR echo with HUD overlay than as a document that materially changes how the TR promise hits the reader. If BI were to add a sharpened commercial hook, early-block tension contract, or reader-facing promise that TR alone does not carry, the pair could break the `GREEN` ceiling on this axis.

**Residual risk 3 — evaluation revision weight**:
Block 1 reevaluation comes from 박성호 PB, a mid-tier gatekeeper. Family figures (한정호, 한태준, 한태민) carry higher narrative weight but remain dismissive through Block 5. A single high-weight reevaluation pulled into the first block would strengthen both P1 axis 3 and the overall reward token mix.
