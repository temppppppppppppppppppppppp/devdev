## 절대 수칙

1. **각 라운드는 반드시 소스 코드를 Read 도구로 직접 읽은 후 진행한다**
   셸 자동 탐색 도구(`grep`, `find`, `rg`) 금지. Read만 허용.

2. **pytest 통과 = 완료가 아니다**
   코드를 읽지 않은 라운드는 무효다.

3. **근거 필수**
   모든 이슈는 `파일명:줄번호 + 코드 스니펫`을 첨부한다.
   "가능성 있음" 수준의 주관적 판단은 이슈로 등록하지 않는다.

4. **감사 단계(Round A~I)에서는 코드 변경 없다**
   수정은 Round K에서만 한다.

5. **각 라운드 완료 즉시 findings 파일의 "현재 위치" 섹션을 업데이트한다**
   이것이 컨텍스트 컴팩트 복구의 유일한 기준점이다.
