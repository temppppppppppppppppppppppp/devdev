### 1. 추진 목적

「글도비」를 현재의 `비정식 혼합 운영 단계`에서 `회사 운영 체계`로 전환하기 위한 1단계 예산 승인을 요청한다.

글도비는 소설 집필 AI가 아니라, **장르·설정·캐릭터 조합을 빠르게 돌려보고 시장성 있는 IP를 선별하기 위한 LLM 기반 IP 대량 테스트 생산 인프라**다.

사업적 목적은 다음 네 가지다.

1. 선인세 없는 구조
2. Revenue Share(RS) 없는 구조
3. IP 통제 가능 구조
4. 지속 생산 시스템 확보

### 4. 재무적 판단 근거

#### 4-1. 핵심 숫자

| 지표 | 값 |
|------|---:|
| 기본 총원가 | 약 2,200~2,900만원 + α |
| 작품당 총원가 | 약 80.7~106.7만원 |
| 27작품 포트폴리오 P25 (보수적 하한선) | **약 4,503만원** |
| 총원가 2,200만원 초과 확률 | 91.0% |
| 총원가 2,900만원 초과 확률 | 86.1% |

#### 4-2. 산출 근거

- 자료: 자사 내부 남성향 60개월 실매출 추적 원자료 (2021-02~2026-01)
- 모집단: 포텐·올나이트노벨·프로무림, 12개월 관측 완료 **1,699작품**
- 방법: 27작품 비복원 무작위추출 × 20,000회 몬테카를로 시뮬레이션
- 승인 판단 기준: P25 (보수적 하한 분위수)

#### 4-3. 포트폴리오 분포

| 분위수 | 27작품 포트폴리오 12개월 누적 순매출 |
|:------:|---:|
| P10 | 약 2,335만원 |
| P25 | 약 4,503만원 |
| P50 | 약 9,085만원 |
| P75 | 약 1억 7,929만원 |

#### 4-4. 해석

이 문서는 `작품 1개가 바로 돈이 되느냐`를 묻는 문서가 아니라, **27작품 포트폴리오 기준 총원가가 내부 시장 기준선 대비 완전히 무리한 숫자인가**를 판단하는 승인서다. 보수적 하한선(P25) 약 4,503만원은 총원가 밴드 2,200~2,900만원을 상회한다.

### 5. 손익 시나리오

```
작품당 Vertex 비용 (기본)   = 70 arc × 6,300원 = 약 44만원
작품당 Vertex 비용 (reject) = 약 70만원
작품당 총원가              = 약 80.7~106.7만원

27작품 총원가              = 약 2,178~2,880만원 + α
27작품 P25 순매출          = 약 4,503만원
```

| 비교 항목 | 금액 | 비고 |

※ 즉시 현금회수 보장이 아니라, 포트폴리오 회수 가능성 기준선 확인 용도.
