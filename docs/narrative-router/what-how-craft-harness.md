# What-How 웹소설 작법 하네스

> 작성일: 2026-03-28
> Status: active
> Scope: 소재 → 캐릭터 → 장면 → 회차 설계의 what-how 분리 체크리스트
> 근거: 스토리튠즈(샤이나크/사도연/김달인) 교육 프레임워크 + 한국 웹소설 작법 생태계 표준
> 목적: **작품 기획~회차 집필 전 단계에서 "무엇을 보여줄 것인가"와 "어떻게 보여줄 것인가"를 분리하여 점검하는 하네스**

---

## 0. 핵심 원칙

웹소설의 모든 단위(작품·아크·회차·장면)는 두 질문으로 분해된다.

| 축 | 질문 | 실패 시 증상 |
|----|------|-------------|
| **WHAT** | 이 단위에서 독자에게 **무엇**을 전달/보여줄 것인가? | 목적 없는 장면, 흐름 없는 전개, "그래서 뭐?" |
| **HOW** | 그것을 **어떻게** 전달/보여줄 것인가? | 설명충, 가독성 붕괴, 몰입 이탈, "재미없음" |

WHAT 없이 HOW만 있으면 기교 과잉.
HOW 없이 WHAT만 있으면 설정집.
**둘 다 답할 수 없는 장면은 쓰지 않는다.**

## 1. WHAT 계층 — 무엇을 보여줄 것인가

### 1-1. 작품 단위 (기획 시점)

| 항목 | 체크 질문 | 판정 기준 |
|------|----------|----------|
| **소재** | 이 작품의 핵심 소재(키워드)는? | 메이저+마이너 키워드 조합, 한 줄 피치 가능 |
| **주인공 내적 욕망** | 주인공이 최종적으로 도달하고 싶은 상태는? | 작품 전체에서 불변, 이야기의 종착지 |
| **주인공 외적 욕망** | 내적 욕망을 위해 지금 추구하는 구체적 목표는? | 아크마다 변할 수 있음, 행동으로 드러남 |
| **테마** | 이 작품이 독자에게 남길 감정/메시지는? | 한 문장으로 요약 가능 |
| **장르 독자** | 타겟 독자층은 누구인가? | 남성향/여성향, 연령대, 플랫폼 특성 |

> **목적성 체크**: "주인공이 뭘 하는 인물인지"가 1화 안에 보여야 한다.
> 내적 욕망은 절대 변하지 않는다. 외적 욕망은 아크 전환 시 갱신된다.

### 1-2. 아크 단위

| 항목 | 체크 질문 |
|------|----------|
| **아크 목표** | 이 아크가 끝났을 때 주인공/세계에 어떤 변화가 생기는가? |
| **핵심 갈등** | 목표 달성을 가로막는 장애물은? |
| **떡밥 설치** | 이 아크에서 새로 까는 복선은? (설치 위치 명시) |
| **떡밥 회수** | 이전 아크에서 설치한 복선 중 이번에 회수할 것은? |
| **사이다 포인트** | 독자의 카타르시스를 줄 핵심 해소 장면은? |

### 1-3. 회차 단위

| 항목 | 체크 질문 |
|------|----------|
| **회차 목적** | 이 회차가 존재하는 이유는? (한 문장) |
| **핵심 사건** | 이 회차의 중심 씬은? (1~3개) |
| **감정 변화** | 독자가 느낄 감정의 시작점 → 끝점은? |
| **다음 화 연결** | 이 회차 끝에서 독자가 품을 궁금증은? |

### 1-4. 캐릭터 단위

| 항목 | 체크 질문 |
|------|----------|
| **겉목표** | 이 캐릭터가 표면적으로 추구하는 것은? |
| **속목표** | 본인도 모르거나 숨기는 진짜 욕망은? |
| **GAP** | 겉모습과 실제 사이의 갭은? (갭 모에) |
| **동기 → 목표 → 기대 → 보상** | 이 체인이 논리적으로 연결되는가? |
| **악역 개연성** | 악역이 악역인 이유가 설득력 있는가? |

## 2. HOW 계층 — 어떻게 보여줄 것인가

### 2-1. 연출 원칙 (Show → Tell 금지)

| 등급 | 방식 | 예시 |
|------|------|------|
| **Best** | 들려주기 (대사) | "네 따위가 감히." 그가 검을 뽑았다. |
| **Good** | 보여주기 (행동·묘사) | 그의 손이 검병으로 갔다. 눈이 가늘어졌다. |
| **Avoid** | 설명하기 (서술) | 그는 분노했다. 상대를 죽이고 싶었다. |

> 지문 5줄 연속 시 대사 또는 행동 삽입 필수.
> 세계관 설명은 사건 안에 녹여야 한다. 독립 설명 단락 금지.

### 2-2. 문장·가독성

| 규칙 | 기준 |
|------|------|
| **대사 비중** | 50% 이상 |
| **문장 길이** | 단문 기본, 중문·장문은 리듬 변주용 |
| **줄바꿈** | 대사 직전 행동/태도/발화를 하나의 흐름으로 |
| **감각 디테일** | 시각만 쓰지 말 것 — 소리, 냄새, 촉감 혼합 |
| **모바일 최적화** | 한 문단 3줄 이내 (모바일 화면 기준) |

### 2-3. 클리프행어 (절단신공)

| 조건 | 판정 |
|------|------|
| 갈등 미해결 또는 심화 시점에서 끊는가? | PASS |
| 다음 화 초반에 이전 궁금증을 해소하는가? | PASS |
| 답이 뻔한 질문으로 끊는가? | **FAIL** — 긴장감 없음 |
| 작위적·억지스러운가? | **FAIL** — 역효과 |

### 2-4. 사이다/고구마 밸런스

```
[고구마] ──── [고구마] ──── [소사이다] ── [고구마] ──── [대사이다]
 갈등 축적      갈등 심화      작은 해소     최고조         폭발적 해소
```

- 고구마 구간이 3회차 이상 지속되면 소소한 사이다라도 투입
- 사이다 직후 바로 다음 갈등의 씨앗을 뿌릴 것

### 2-5. 복선(떡밥) 관리

| 단계 | 체크 |
|------|------|
| **설치** | 자연스러운 맥락 안에서 심었는가? (노골적이면 FAIL) |
| **추적** | 아크별 설치/진행/회수 상태를 기록하고 있는가? |
| **회수** | 설치한 복선을 방치하지 않았는가? (체호프의 총 원칙) |
| **미회수 허용** | 의도적 장기 떡밥이면 진행 상태 표시 후 유보 |

### 2-6. 1화 특수 규칙

| 규칙 | 근거 |
|------|------|
| 가장 흥미로운 장면부터 시작 | 2화 조회수가 반토막 → 1화 실패 |
| 세계관 독립 설명 금지 | 사건과 혼합해서만 노출 |
| 조연 동시 다수 등장 금지 | 독자 혼란 |
| 주인공 분량 70% 이상 | 주인공 목적성이 1화에서 보여야 함 |
| 5,500자 내외 | 4,500자부터 엔딩 의식 |

## 3. WHAT-HOW 매트릭스 — 회차 설계 체크시트

회차 집필 전 아래를 한 줄씩 채운다. 빈 칸이 있으면 집필하지 않는다.

```
회차 번호: ___
───────────────────────────────────
WHAT
  회차 목적 (한 문장):
  핵심 씬 (1~3):
  감정 변화 (시작→끝):
  떡밥 설치/회수:
  사이다/고구마 위치:

HOW
  오프닝 후킹:
  Show/Tell 비율 계획:
  클리프행어 설계:
  대사 핵심 라인:
  감각 디테일 (시각 외):
───────────────────────────────────
```

## 4. 판정 게이트

이 하네스를 적용하는 시점은 **집필 전 설계 단계**이다.

| 게이트 | 조건 | 불합격 시 |
|--------|------|----------|
| **G-1 작품 기획** | 1-1 전항목 답변 완료 | 시놉시스 진입 금지 |
| **G-2 아크 설계** | 1-2 전항목 + 떡밥 대장 초안 | 회차 분배 금지 |
| **G-3 회차 설계** | 섹션 3 매트릭스 빈 칸 없음 | 집필 금지 |
| **G-4 회차 완료** | 2-1~2-5 규칙 위반 0건 | 다음 회차 진입 금지 |
