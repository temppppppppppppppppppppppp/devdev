## A. 기존 하네스 오류 수정 (즉시 반영 필요)

### A-1. G-0 게이트 과잉 — 히로인/소품교체가 게이트에 들어가 있음

**현재 문제:**
```
G-0 대리만족 계약: ... + 히로인(0.5-5) + 소품 교체(0.5-6) + 정보격차(0.5-7)
```

**왜 문제인가:**
- 히로인(§0.5-5)은 "여성 캐릭터가 나올 때" 적용하는 조건부 규칙이다. 히로인이 안 나오는 작품도 있다. 게이트 블로커가 아님.
- 소품 교체(§0.5-6)는 진단 도구이지 통과/불통과 게이트가 아님. HOW 확정(G-2) 단계에서 §2-2로 이미 재확인하고 있음.

**수정안:**
```
G-0 대리만족 계약: 둥기둥기(0.5-1) + 보상 체류(0.5-2) + 고통 미학(0.5-3) + 벡터 방향(0.5-4) + 정보격차(0.5-7)
```
- 히로인(0.5-5): 게이트에서 제거. "여성 캐릭터 등장 시 참조" 조건부 규칙으로 유지
- 소품 교체(0.5-6): 게이트에서 제거. G-2(HOW 확정)의 §2-2에서만 체크

### A-2. §4 매트릭스 히로인 체크란 — 조건부로 변경

**현재:**
```
히로인: 여성 캐릭터 등장 시 호감 방향 확인, 로맨스 라인 없음 확인:
```

**수정안:**
```
히로인 (해당 시에만): 여성 캐릭터 등장 시 호감 방향 확인, 로맨스 라인 없음 확인:
```

## B. 웹서치 기반 추가 법칙 제안 (검토 후 결정)

### B-1. [높음] 고구마-사이다 비례 법칙

**근거:** 나무위키 웹소설/특징/서술 + 업계 컨센서스
**내용:** 고구마 구간이 길수록 뒤따르는 사이다 강도가 비례적으로 커야 한다. 2블록 고구마 후 소사이다는 OK지만, 2블록 고구마 후 대사이다가 더 좋다.

**반영 위치:** §3-4 사이다/고구마 밸런스에 1줄 추가
**제안 문구:**
```
- 고구마-사이다 비례: 고구마 구간이 길거나 강할수록, 뒤따르는 사이다도 비례적으로 강해야 한다. 강한 고구마 + 약한 사이다 = 불만족
```

### B-1.5. [높음] 회귀/빙의/환생 정체 의심 금지

**근거:** pantech_cyworld_reborn BI 폐기 사유 — "이 사람이 미래에서 온 게 아닌가?" 류의 의심은 서사적으로 무의미하고 장르 클리셰 중 가장 식상한 축에 해당
**내용:** NPC가 주인공의 회귀/빙의/환생 자체를 의심하는 전개는 금지. "정보 출처가 뭐냐"는 현실적 의심은 허용하되, "혹시 미래에서 왔냐", "전생이 있냐" 등 초자연적 정체를 의심하는 방향으로 가면 REJECT.

**반영 위치:** §0.5 대리만족 계약에 신규 법칙 추가
**제안 문구:**
```
### 0.5-9. 회귀/빙의/환생 정체 의심 금지

NPC는 주인공의 회귀·빙의·환생을 의심하지 않는다.

| 허용 | 금지 |
|------|------|
| "자료 출처가 뭐냐" (현실적 의심) | "미래에서 온 거 아니냐" (초자연적 의심) |
| "누가 알려줬냐" (내부자 의심) | "전생 기억이 있는 거냐" (정체 의심) |
| "너무 정확한데 찍은 거냐" (운/실력 의심) | "회귀자냐" (장르 메타 의심) |

> 회귀/빙의/환생 정체 의심은 독자에게 긴장감이 아니라 짜증을 준다.
> suspicion_count 같은 누적 메커니즘은 BI에서 삭제한다.
```

### B-2. [높음] 장르 드리프트 금지

**근거:** 나무위키 장르 이탈/웹소설 — 남성향에서 가장 치명적인 독자 이탈 원인
**내용:** 1화에서 설정한 장르적 약속(노맨스, 성장물, 먼치킨 등)을 아크 중간에 변경하면 REJECT. 장르적 약속은 독자와의 계약이다.

**반영 위치:** §0.5 대리만족 계약에 신규 법칙 추가 (§0.5-8)
**제안 문구:**
```
### 0.5-8. 장르 계약 고정 법칙

1화에서 설정한 장르적 약속은 작품 전체에서 유지해야 한다.

| 장르 약속 | 변경 시 결과 |
|-----------|-------------|
| 노맨스로 시작 | 중간에 로맨스 라인 추가 → REJECT |
| 성장물로 시작 | 중간에 일상물로 전환 → REJECT |
| 먼치킨으로 시작 | 중간에 약해지는 전개 → REJECT |
| NL로 시작 | 중간에 BL 뉘앙스 → REJECT |

> 장르 드리프트는 "독자 배신"으로 간주된다.
> 장르 전환이 필요하면 새 작품을 쓰는 것이 맞다.
```

### B-3. [높음] 1화 판타지 제시 의무

**근거:** 브런치 작법 시리즈 + 플랫폼 데이터 (2화 조회수 반토막 법칙)
**내용:** 1화에서 독자가 원하는 대리만족의 맛보기가 반드시 와야 한다. 정보격차 제시 + 첫 사이다.

**반영 위치:** §3-6 1화 특수 규칙에 1줄 추가
**제안 문구:**
```
| 첫 사이다 필수 | 1화 안에 소규모라도 사이다(성취+인정) 장면이 있어야 함. 고구마만으로 1화를 끝내면 REJECT |
```

### B-4. [중간] 주인공 최소 등장 비율

**근거:** 업계 컨센서스 — 10회차(2주) 이상 주인공 미등장 시 이탈 급증
**내용:** 블록 단위 환산 시, 연속 3블록 이상 주인공 미등장이면 경고.

**반영 위치:** §1-3 블록 단위에 1줄 추가
**제안 문구:**
```
> 주인공 등장 최소 기준: 연속 3블록 이상 주인공이 중심이 아닌 전개는 경고. 조연 에피소드가 필요하면 주인공 시점을 병렬로 유지할 것.
```

### B-5. [중간] 정보격차 시대적 감쇠 경고

**근거:** 회귀물/한국 나무위키 — 비트코인 선점 등 식상해진 정보격차 패턴
**내용:** 같은 정보격차 패턴이 장르 내에서 반복 사용되면 신선도가 떨어진다.

**반영 위치:** §0.5-7 정보격차 법칙에 경고 추가
**제안 문구:**
```
> **시대적 감쇠 경고**: 같은 유형의 정보격차가 장르 내에서 이미 수십 작품에 쓰였다면, 그 정보격차의 사이다 생산력은 감쇠한다. "회귀해서 비트코인 산다"는 2018년에는 사이다였지만 2025년에는 식상하다. 정보격차의 형태보다 **활용의 참신함**이 차별화를 만든다.
```

### B-6. [중간] 억지 사이다 경고

**근거:** 나무위키 사이다(클리셰) — "억사(억지 사이다)" 역풍
**내용:** 사이다에도 개연성이 필요하다. 만능 먼치킨이 긴장감 없이 모든 것을 해결하면 역효과.

**반영 위치:** §3-4 사이다/고구마 밸런스에 경고 추가
**제안 문구:**
```
- 억지 사이다 경고: 사이다에도 개연성이 필요하다. "주인공이 갑자기 숨겨진 능력을 발현해서 해결"은 사이다가 아니라 데우스 엑스 마키나. 사이다의 씨앗(정보격차, 복선, 준비 과정)이 사전에 깔려 있어야 한다.
```
