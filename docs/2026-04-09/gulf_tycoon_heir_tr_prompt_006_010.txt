## NPC 연속성 규칙
- 반복 등장 NPC는 relationship_delta에 `anchor_before` / `anchor_after`를 우선 기입하라.
- `before` / `after` 자연어 문장은 바뀌어도 되지만, anchor는 직전 anchor_after를 잇는다.
- anchor를 안 쓰면 하네스는 `before` / `after` 문장 자체를 continuity truth로 본다.

## Harness Digest
- family: blockguide
- stage: tr_batch

### Hard Prohibitions
- 70블록 단일 출력 금지
- 영문 템플릿 문장 사용 금지
- code-like 값(plan_01, type_1, _B01) 사용 금지
- callback을 generic 한 문장으로 때우는 것 금지
- no-cider block 금지: 모든 블록은 same-block 사이다 영수증을 지급해야 함
- pain-only exit 금지: 실패/굴욕/지연만 남기고 블록 종료 금지

### Continuity Equalities
- capital_before == 직전 capital_after
- relationship_delta.before == 직전 relationship_delta.after

### Family Axis Requirements
- 이번 배치의 각 블록은 사업축, 상대 구도, 감정 비트 중 최소 하나에서 직전과 차이를 만들어야 한다
- deal_type, location, leverage_used는 반복 신호 없이 재탕하지 않는다
- reward는 단순 수익이 아니라 승인권, 신용, 정보 우위 중 최소 하나의 이동을 보여야 한다
- 각 블록은 genre_ext.block_cider.has_cider=true, receipt_line 1문장, pain_only_exit=false를 포함해야 한다

### Lexicon Bans
- 영문 프롬프트 문장
- placeholder 식 문구
- 한국어 서사 대신 schema 설명문

### Output Contract

- JSON 배열
- 차이 행렬
- 복선 원장 업데이트

### Acceptance Gates

- callback debt 방치 금지
- capital continuity 보존
- relationship carry-over 보존
- block_cider_missing_blocks = 0

- pain_only_exit_blocks = 0

## 절대 금지
- 70블록 단일 출력 금지
- 한국어 대신 영문 템플릿 사용 금지
- `plan_01`, `type_1`, `_B01` 같은 코드형 값 금지
- 각 블록은 `genre_ext.block_cider.has_cider=true`, `receipt_line` 1줄, `pain_only_exit=false`를 반드시 포함할 것
- quiet/setup/recovery/political block이라도 same-block 영수증 없이 닫지 말 것
- callback을 `직전 블록의 성과가 발판` 한 문장으로 때우는 것 금지
- `Block 3`, `B12`, `블록 7`, `ARC-01`, `Phase 1`, `Stage 4` 같은 메타 표기는 자연어 필드 전면 금지
- 복선/회수 타깃 블록은 `foreshadow_targets` / `callback_sources`에만 적고, `foreshadow` / `callback`에는 자연어 의미만 적을 것
- `section_rotation`에는 `ARC-01 - ...` 같은 번호 메타 금지. 자연어 라벨만 허용
- deal_type 3블록 이내 재등장 금지
- emotional_beat.type 2연속 동일 금지
- location 15블록 이내 재등장 금지
- 같은 장소를 연속 쓸 때는 deal_type / opponent / stakes / 관계 타깃 / 세부 장소 중 2개 이상 바꿀 것
- `capital_before != 직전 capital_after` 금지
- `relationship_delta.before != 직전 after` 금지
- leverage_used 동일 세트 3회 반복 금지
