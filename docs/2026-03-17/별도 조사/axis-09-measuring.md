## 3. 갭 식별

### G9-1: "재미있는가"의 측정 간극 — `critical`

**유형**: 부분 구현

**현황**: "재미"와 관련된 측정 차원은 분산되어 있음:
- Emotion Arc(Art.4, 20점): 감정 곡선 + 긴장 관리 + 카타르시스
- Commercial Appeal(Art.6, 20점): 오프닝 훅 + 클리프행어 + 보상 타이밍
- Reader Satisfaction(10점): 성취감 + 유능함 + 좌절-보상 균형

**갭**:
- 세 차원의 합산(50/100점)이 "재미"에 가장 가깝지만, **"재미"라는 단일 판단이 어디에도 명시적으로 존재하지 않음**
- 각 차원은 요소 분해 방식("훅 요소 몇 개?", "감정 상태 몇 개?")으로 측정 — **"읽고 싶어지는가?"라는 통합적 질문에 직접 답하지 않음**
- "모순 없음 ≠ 재미있음" — character_consistency(15점) + continuity 검증이 높은 점수를 보장하지만, 이는 "깨지지 않음"이지 "재미있음"이 아님
- **축 7+8 교차 발견 반영**: 시스템의 "방어적 편향"이 측정에서도 재현됨. 100점 중 ~35점이 "결함 부재" 측정(character_consistency 15 + continuity 계층 + pattern consistency)에 배분되는 반면, "적극적 매력"은 commercial_appeal 20점에 집중

**증거 경로**: Quality Constitution 7조에 "재미" 또는 "engagement"를 직접 측정하는 조항 없음; 가장 가까운 Art.6 commercial_appeal도 구조적 요소(훅, 클리프행어) 수를 세는 방식

### G9-2: "독자가 다음 화를 클릭하는가" 관점의 메트릭 부재 — `critical`

**유형**: 완전 부재

**현황**: 클리프행어(Art.6.2)가 유일하게 "다음 화 유도"를 측정하지만, 7점/100점에 불과.

**갭**:
- 웹소설의 핵심 KPI인 "다음 화 클릭률(retention)"에 대한 직접 메트릭 없음
- 클리프행어 효과가 "마지막 500자에 질문/폭로/위기 요소가 있는가?"로만 측정 — **에피소드 전체의 서사 추진력(momentum)**은 미측정
- 보상 타이밍(Art.6.3)이 3화 이내 보상을 권장하지만, "독자가 3화까지 읽고 있을 것이다"는 가정에 기반 — 1화 내 이탈 방지 메트릭 부재
- **외부 신호 부재**: 실제 독자 반응 데이터가 시스템에 유입되는 경로 없음 (축 15 alignment과 교차하나, 측정 설계 자체의 문제)

### G9-3: 점수 차원 간 상관관계/충돌 미관리 — `significant`

**유형**: 완전 부재

**현황**: 6차원(+Constitution 7조)이 독립적으로 채점됨. 차원 간 상호작용이 정의되지 않음.

**갭**:
- **잠재적 충돌 쌍**:
  - `commercial_appeal` ↔ `character_consistency`: 극적 반전(상업적 매력)이 캐릭터 일관성을 위반할 수 있음
  - `emotion_arc` ↔ `dialogue_quality`: 감정 고조 장면에서 대화 자연스러움이 훼손될 수 있음
  - `pattern_diversity` ↔ `reader_satisfaction`: 새로운 패턴 시도가 독자 기대(성취감, 보상)를 지연시킬 수 있음
- 차원별 독립 채점이므로, **A 차원을 높이려다 B 차원이 낮아지는 트레이드오프**를 시스템이 인식하지 못함
- "전체 최적"이 아닌 "차원별 합산 최대화"가 목표 — 로컬 옵티마에 빠질 수 있음
- Director가 이 트레이드오프를 암묵적으로 처리할 수 있으나, 명시적 가이드라인 없음

### G9-4: 장르별 "좋다"의 의미 차이 반영 부족 — `significant`

**유형**: 부분 구현

**현황**: M4의 장르별 가중치(e.g., hunter: action_weight 1.3)가 차원별 가중치를 조정. Reader Satisfaction의 장르별 성취 예시(무협: 경지돌파, 헌터: 각성)가 장르 맥락을 제공.

**갭**:
- 가중치 조정은 **양적 차이**(action이 더 중요)만 표현하고, **질적 차이**(무협의 "좋은 전투"와 요리의 "좋은 조리 장면"은 본질적으로 다른 것)를 반영하지 않음
- Quality Constitution이 **장르 불문 단일 헌법** — 장르별 "헌법 부칙"이 없음
- Negative Example Injector에 장르별 오버라이드가 있지만, **Positive Example Injector**가 부재하여 "이 장르에서 좋은 것"의 구체적 기준 미제공
- 임계값 차이(68~72)가 **장르 난이도 보정**인지 **장르별 품질 기대 차이**인지 의미론적으로 불명확

### G9-5: 절대 점수 vs 상대 품질 관점의 편향 — `significant`

**유형**: 완전 부재

**현황**: 모든 채점이 **절대 점수**(0~100) 기반. "이 에피소드가 이전 화 대비/장르 평균 대비 어떤 수준인가?"라는 상대 평가 없음.

**갭**:
- 프로젝트 초반의 72점과 후반의 72점이 동일하게 취급됨 — 시스템 성숙에 따른 기대 수준 상승 없음
- **축 8 교차 발견**: G8-1의 "충분히 좋다 판단 부재"가 여기서 측정 차원에서도 재현됨. 상대 점수가 없으면 "전보다 나아졌는지" 판단 불가
- 동일 Arc 내 에피소드 간 점수 흐름(상승/하락 추이)이 품질 판단에 반영되지 않음
- "이 장르의 최근 10화 평균 대비"와 같은 기준선(baseline) 개념 부재
- 축 7 교차 발견: 학습 데이터(G7-2)에 장르/위치별 분화가 없는 것과 동일한 근본 원인 — **맥락 없는 절대값**

### G9-6: Positive 예시 부재 — `significant`

**유형**: 완전 부재

**현황**: M10의 Negative Example Injector가 40+ 부정 예시를 제공("이렇게 쓰지 마"). Positive Example Injector 또는 동등한 구성요소 없음.

**갭**:
- "이렇게 쓰면 좋다"의 구체적 예시가 시스템적으로 제공되지 않음
- Revision guide의 before/after(M14)가 부분적으로 이 역할을 하지만, **수정 맥락**에서만 작동하고 **생성 맥락**에서는 미작동
- 부정 예시만의 학습은 **회피 행동**을 유도하고, 능동적 품질 추구를 유도하지 않음 — 축 7+8에서 발견한 "방어적 편향"의 측정 계층 근원
- 장르별 "좋은 원고" 샘플이 프롬프트에 주입되지 않음

**증거 경로**: `negative_example_injector.py` (406줄, 40+ 예시) 존재; `positive_example_injector.py` 또는 유사 파일 부재; `top_success_patterns()`(축 7 L5)이 유일한 성공 패턴 소스이나 이는 자체 생산물 기반이지 외부 고품질 샘플이 아님

### G9-7: 1점 단위 점수의 유의미성 미검증 — `nice-to-have`

**유형**: 형식적 존재

**현황**: 6차원 각각에서 정수 점수를 산출하여 합산. 72점과 73점의 차이가 판정에 영향(임계값 72 장르의 경우).

**갭**:
- LLM이 매긴 정성 점수의 **재현성(reproducibility)**이 검증되지 않음 — 같은 원고를 재채점하면 ±3~5점 편차가 일반적
- **축 8 교차 발견**: G8-4의 비용-품질 한계효용 판단이 1점 단위에 의존하는데, 측정 자체의 노이즈가 이를 무의미하게 만들 수 있음
- Self-consistency voting(S8)이 50~60점 구간에만 적용 — 임계값 부근(68~72)에서도 필요할 수 있음
- 채점자 간 합의(inter-rater agreement) 메트릭 없음

**시스템 천장 분석 — 묶음 A 종합**:

축 7+8+9를 관통하는 **근본 패턴**이 도출됨: **"방어적 시스템" 편향**.

1. **측정(축 9)**: "좋다" = "결함 없다"로 수렴하는 측정 체계 (G9-1, G9-6)
2. **학습(축 7)**: 실패에서만 배우고 성공에서 배우지 않음 (G7-1, G7-3)
3. **멈춤(축 8)**: "실패 없음 = 충분"으로 멈춤 (G8-1, G8-2)

이 3개 축의 방어적 편향은 서로를 **강화**: 측정이 결함 중심 → 학습이 결함 회피 중심 → 멈춤이 결함 없음 기준 → 측정이 이를 "좋다"로 확인 → **자기 확인적 루프(self-confirming loop)**.

## 6. 묶음 내 교차 발견

### 축 7 → 축 9 교차

- **G7-1 → G9-6 연결**: 성공 학습 비대칭(G7-1)과 Positive 예시 부재(G9-6)는 **동일한 시스템적 공백의 서로 다른 계층 표현**. 학습 계층에서는 "성공에서 안 배움", 측정 계층에서는 "좋은 것의 기준을 안 보여줌"
- **G7-2 → G9-4 연결**: 학습의 장르 분화 부재(G7-2)와 측정의 장르 질적 차이 미반영(G9-4)은 동일 근본 원인 — **장르를 양적 파라미터(가중치)로만 다루고 질적 차이를 무시**

### 축 8 → 축 9 교차

- **G8-1 → G9-5 연결**: "충분히 좋다" 판단 부재(G8-1)와 절대 점수 편향(G9-5)은 직결. 상대 점수가 없으면 "전보다 나아졌으니 충분"이라는 판단 자체가 불가
- **G8-4 → G9-7 연결**: 비용-품질 한계효용(G8-4)이 유의미하려면 1점 단위 점수가 신뢰할 수 있어야 함(G9-7). 점수 노이즈 ±5점이면 한계효용 계산 무의미

### 묶음 A 관통 발견: "방어적 시스템" 편향

| 계층 | 방어적(현재) | 공격적(부재) |
|------|------------|------------|
| 측정(축 9) | 결함 감지 + 부정 예시 | 매력 측정 + 긍정 예시 |
| 학습(축 7) | 실패 학습 + 실패 제약 주입 | 성공 학습 + 성공 패턴 주입 |
| 멈춤(축 8) | 실패 없으면 멈춤 | 개선 가능하면 계속 |

이 편향은 **각 축의 가장 높은 등급 갭**(G9-1 critical, G7-1 significant, G8-1 critical)에 공통으로 반영되며, 단일 축 수정보다 **3축 횡단적 접근**(예: Positive 측정 + 성공 학습 + Stretch round를 함께 도입)이 효과적일 가능성이 높음.
