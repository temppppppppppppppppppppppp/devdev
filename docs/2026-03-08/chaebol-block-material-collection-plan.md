## 2. 수집 전략 — 멀티 터미널 최대 병렬 리서치

### 2-A. 병렬화 원칙

```
핵심: Phase 1과 Phase 2는 서로 의존성 없음 → 동시 실행 가능
     Phase 3만 Phase 1+2 결과 필요 → 유일한 동기화 지점
     Phase 4(팩트체크)도 Phase 1+2와 동시 가능
```

### 2-B. Wave 1 — 동시 투입 (터미널 15개, 전부 병렬)

**시간축 리서치 (Sonnet 4개)** — 연도별 사건 + 투자 기회
```
터미널 T1: 2006~2008 (유가 급등 → 금융위기 전야)
터미널 T2: 2008~2012 (금융위기 → 회복기 → 모바일 혁명)
터미널 T3: 2013~2018 (한류/바이오/암호화폐/반도체 슈퍼사이클)
터미널 T4: 2019~2025 (코로나/미중전쟁/전기차/AI 혁명)
```

**섹터 심층 리서치 (Sonnet 5개)** — 섹터별 투자 전략 + 인수 대상 + Block 재료
```
터미널 S1: 에너지/원유 + 철강/소재 + 조선/해운 (원자재 클러스터)
터미널 S2: 금융/은행 + 부동산/건설 + 암호화폐 (금융 클러스터)
터미널 S3: IT/소프트웨어 + 반도체 + 통신/플랫폼 (테크 클러스터)
터미널 S4: 바이오/제약 + 자동차/모빌리티 + 항공/방산 (산업 클러스터)
터미널 S5: 엔터/미디어 + 유통/이커머스 + 식품/소비재 (소비 클러스터)
```

**서사 구조 리서치 (Sonnet/Opus 3개)** — Phase 1/2와 독립적으로 병렬 가능
```
터미널 N1: [인물 설계] 주인공 + 적대자(형들/라이벌) + 조력자(PB/전문가) 인물 아키타입
           → 15개 섹터별 핵심 NPC 후보 (실존 인물 모델링)
           → 가문 내 권력 구조 + 갈등 축 설계

터미널 N2: [위기/실패 설계] 주인공이 맞을 수 있는 위기 유형 전수 조사
           → 세무조사, 검찰 수사, 주가조작 혐의, 내부자거래 조사
           → 배신(측근/가족), 시장 예측 실패, 정치적 압박
           → 각 위기의 실제 사례 + 극복 방법 + 서사 긴장도
           → Block 간 "실패 Block" 배치 권장안

터미널 N3: [섹터 체인 설계] 15개 섹터 간 시너지 맵
           → 어떤 순서로 진출해야 경제적으로 현실적인지
           → 섹터 A의 인프라가 섹터 B 진출에 어떻게 쓰이는지
           → 실제 재벌 그룹(삼성/현대/SK) 확장 경로 분석
           → "그룹이 되는 과정" 로드맵
```

**팩트체크 (코덱스 2~3개)** — Wave 1과 동시 실행
```
코덱스 F1: 유가 차트 2006~2025 (월별 WTI/브렌트 가격, 주요 변곡점 날짜)
코덱스 F2: 환율/금리/주가지수 차트 (원달러, KOSPI, S&P500, 비트코인 월별)
코덱스 F3: 한국 주요 M&A/IPO 목록 2006~2025 (날짜, 금액, 기업명)
```

**총 Wave 1: 터미널 12~15개 동시 투입, 대기 시간 0**

### 2-C. Wave 2 — 교차 검증 + 보강 (Wave 1 완료 후, 터미널 5개)

Wave 1 결과물을 취합한 뒤, 갭 보강:

```
터미널 X1: [교차 대조] T1~T4 시간축 결과 vs S1~S5 섹터 결과
           → 빠진 사건 식별, 날짜 불일치 교정, 중복 제거
           → 통합 사건 DB (JSON) 생성

터미널 X2: [자본 시뮬레이션] 20억에서 시작, Block별 수익/손실 적용
           → 자본 성장 곡선 현실성 검증
           → "이 베팅에 자본이 부족한 시점" 식별 → 대출/투자유치 Block 추가

터미널 X3: [NPC 배치] N1의 인물 설계 + S1~S5의 섹터 재료 결합
           → 섹터별 핵심 NPC 확정 (이름, 역할, 첫 등장 Block)
           → 적대자 등장 스케줄 (가문 충돌 Block 배치)

터미널 X4: [위기 배치] N2의 위기 목록 + T1~T4의 시간축 결합
           → 투자 성공 3~4개마다 위기 1개 삽입
           → 위기 Block의 시기/유형/해결 방식 확정

터미널 X5: [팩트 교정] F1~F3 결과로 T/S 결과물의 수치/날짜 일괄 교정

#### T1~T4: 시간축 리서치

```
## 역할
너는 금융 전문 리서치 애널리스트다. 회귀 재벌물 소설의 재료 수집을 돕는다.

## 과제
다음 기간의 한국 및 세계 주요 사건을 조사해줘: [2006~2008]
주인공은 2006년에 20억으로 시작해 2025년에 세계 최고 그룹을 만드는 인물이다.

## 15대 섹터 (참고)
에너지/원유, 금융/은행, 부동산/건설, IT/소프트웨어, 반도체,
바이오/제약, 엔터/미디어, 유통/이커머스, 자동차/모빌리티,
조선/해운, 철강/소재, 통신/플랫폼, 식품/소비재, 암호화폐/블록체인, 항공/방산

## 출력 형식 (사건당 1항목, JSON 배열)

```json
[
  {
    "id": "T1-001",
    "date": "2006-01",
    "event": "이란 핵 위기 고조, UN 안보리 제재안 논의",
    "category": ["INTL", "ECON"],
    "sectors": ["에너지/원유"],
    "opportunity": "이란 제재 → 유가 급등 예상. WTI 선물 롱 포지션",
    "return_estimate": "3개월 내 +40% (60달러→84달러)",
    "capital_needed": "최소 5억 (레버리지 3배 시 15억 효과)",
    "risk": "제재 완화 시 유가 급락, 2006.03 일시 하락 구간",
    "narrative_use": "모두가 이란을 모를 때 홀로 원유에 베팅하는 신입 투자자",
    "tension": "가족이 '한량이 무슨 투자'라며 비웃는 상황에서 확신을 지키는 갈등",
    "connected_events": ["T1-003 유가 147달러 피크", "T1-005 금융위기"]
  }
]
```

## 요구사항
- **최소 30개 사건**, 40개 이상 권장
- 한국 사건 40% + 세계 사건 60% 균형
- 투자/사업 기회가 명확한 사건 우선
- 날짜순 정렬
- JSON 형식 엄수 (후처리 자동화용)
- **connected_events로 사건 간 인과관계 표시** (같은 터미널 내)
- 각 사건의 risk 필드에 "중간에 흔들리는 구간"을 반드시 포함
```

## 4. 수집 시 주의사항

### 4-A. 팩트 정확도
- **날짜/수치는 반드시 교차 검증** — LLM이 날짜를 혼동하는 경우 빈번
- 코덱스로 핵심 사건의 정확한 날짜/수치 별도 확인 권장
- 특히 유가·환율·주가 수치는 실제 차트 데이터와 대조

### 4-B. 서사적 현실성
- 한 사람이 모든 섹터를 정복하는 건 비현실적 → **전문 인력 인수/영입** 서사 필요
- 자본 성장 곡선이 너무 가파르면 독자 이탈 → **실패/손실 Block도 배치**
- 정치 리스크(세무조사, 국회 청문회 등) Block도 필요

### 4-C. 섹터 간 시너지
- 단순히 "돈 벌고 → 다음 섹터"가 아닌, **섹터 간 연결고리** 설계
  - 에너지 → 조선(LNG선) → 해운 → 물류 → 이커머스
  - 반도체 → IT → AI → 자율주행 → 모빌리티
  - 금융 → 부동산 → 건설 → 인프라
- 이런 체인이 "그룹"이 되는 과정

## 5. 권장 실행 순서

```
Step 1. Phase 1 (3 터미널, 각 30분)
  → 연도별 사건 목록 90건+ 수집

Step 2. Phase 2 (5 터미널, 각 40분)

Step 3. 수동 정리 (1시간)
  → 중복 제거, 팩트 교정, 서사 우선순위 매기기

Step 4. Phase 3 (Opus 1 터미널, 1시간)
  → Block 배치표 + 섹터 정복 로드맵 생성

Step 5. Block Treatment JSON 변환 (Codex 또는 수동)
  → 30~50개 Block treatment 파일 생성

Step 6. 글도비 파이프라인 투입
  → Stage 0 → 2 → 3 → 4 순차 실행
```
