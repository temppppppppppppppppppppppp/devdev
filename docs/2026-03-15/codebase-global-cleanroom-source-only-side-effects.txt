1. File writes and artifact generation
- SessionLogger writes llm_io.jsonl, decisions.jsonl, state_changes.jsonl, ui_events.jsonl
- AuditService writes runtime_audit.jsonl and runtime_audit_summary.json
- stage4 flows append episode_production.jsonl
- desktop main process writes settings, imports material files, saves project config surfaces

2. DB writes, schema touchpoints, transaction boundaries
- DBManager owns anchors, stage_attempts, director_selections, ui_events, quality observations, and many other tables
- write authority is spread across main_a.py, stage2/3/4 orchestrators, base_agent, and project services
- commit and rollback surfaces are not isolated to one service boundary

3. JSONL, log, audit sinks
- runtime_audit.jsonl
- runtime_audit_summary.json
- pass_rate_monitor.json touchpoints via runtime pipeline callbacks
- session JSONL categories via SessionLogger
- desktop transport path depends on bridge stdout/stderr and websocket events

4. Console, UI, and operator-visible output
- main_a.py raw input prompts
- UIService prompt wrapper and get_int_input
- StudioVisualizer log/menu/prompt/selection rendering
- bridge_server prompt_request and prompt_resolved events
- Electron IPC and renderer-facing bridge endpoints

5. Rollback, recovery, retry, compensation
- DBManager local rollback paths
- ProcessRunner stop/terminate/kill lifecycle
- PromptBroker timeout applies defaults
- project_service rewind/reset/wipe flows mutate downstream surfaces

6. Cache, singleton, global state
- main_a.py keeps current_project, runtime_audit, services, and app-level callbacks
- ProcessRunner keeps internal state machine and runtime tails
- PromptBroker keeps in-memory prompt and run registries

7. Bootstrap fallback, config, and env mutation
- ProcessRunner resolves engine root, project root, python executable, GEULDOBI_ENGINE_EXE, GEULDOBI_PYTHON_PATH
- desktop main process switches between packaged and dev roots for settings, material, projects, and work guard templates
- UIService falls back to raw input() when richer UI prompt surface is absent

8. Source-text hygiene
- Active source still contains mojibake-like text in operator-facing strings and comments in core Python and desktop JS
- check_utf8_hygiene.py remains action-bearing because it now flags both genuine corruption and at least some legitimate question prompts
