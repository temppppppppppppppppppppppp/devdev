# 파공검제 회차 간 연결 패턴 전수 분석

## 1. 개요

### 분석 대상
- **작품**: 파공검제 (무협 웹소설)
- **분석 범위**: 전 100화, 총 99개 전환점
- **분석 방법**: 5개 독립 분석 에이전트가 각 전환점의 연결 방식을 개별 판정한 뒤, 교차 검증을 거쳐 합의 결과를 도출

### 목적
화(에피소드) 간 연결 패턴의 유형을 분류하고, 빈도·구간별 경향·서사 구조적 특징을 도출하여 무협 장르 웹소설의 회차 전환 메커니즘에 대한 정량적 레퍼런스를 구축한다.

## 2. 전환 패턴 유형 분류

| 유형 코드 | 유형명 | 정의 |
|---|---|---|
| **A** | 즉각연속 (직접이어짐) | 직전 화의 마지막 장면이 다음 화 첫 장면으로 끊김 없이 이어짐. 동일 시간·공간 내에서 행동이 계속됨 |
| **B** | 시간경과 | 명시적 시간 도약("보름이 흘렀다", "다음 날" 등)을 통해 새로운 시점으로 진입 |
| **C** | 시점/장소전환 (병렬) | 시간 축은 유지하되 시점 인물이나 공간이 전환됨. 교차편집·병렬 서사 포함 |
| **D** | 시점전환+즉각연속 복합 | 직접 이어지면서 동시에 시점 인물이나 관찰 각도가 바뀜 |
| **E** | 공간교차 (동시사건 병치) | 두 개 이상의 공간에서 동시 진행되는 사건을 교차 배치 |
| **F** | 감정/내면 연속 | 외적 행동보다 인물의 내면 반응·감정 여진이 연결 축이 됨 |
| **G** | 서사블록 전환 | 하나의 서사 단위(수련, 대회, 음모 등)가 종결되고 다른 블록으로 넘어감 |
| **H** | 시간역행/회상 삽입 | 현재 시점에서 과거로 돌아가 기원 서사를 제시 |

- **특징**: 시간경과(B)와 복합 시점전환(D)의 비율이 작품 전체 평균보다 높다. 캐릭터 소개와 세계관 확립을 위해 의도적으로 시간을 건너뛰며 수련 성과를 요약하거나, 동일 사건을 복수 시점으로 재조망하는 기법이 집중 사용된다.

## 6. 핵심 발견사항

### 6.1 즉각연속(A) 편향 구조
전체 전환의 48.5%가 즉각연속이다. 이는 파공검제가 **화 단위 클리프행어→즉시 해소** 패턴을 기본 리듬으로 삼고 있음을 의미한다. 독자가 다음 화를 클릭했을 때 직전 긴장이 바로 이어지는 구조로, 웹소설 연재 환경의 "다음 화 클릭 유도" 전략과 직결된다.

### 6.2 감정연속(F)의 집중 배치
감정/내면 연속 5건이 모두 EP66→EP78 사이(무연회 본선)에 몰려 있다. 비무 결과를 단순히 승패로 넘기지 않고, 관중→상대→제3자→본인 순으로 시점을 릴레이하며 감정적 파장을 증폭시킨다. 이 기법은 액션 장르에서 "전투 후 여운"을 극대화하는 고급 연출로 평가할 수 있다.

### 6.3 공간교차(E)의 전략적 배치
공간교차 8건 중 5건이 "음모 라인"과 "주인공 라인"을 병치하는 데 사용된다(EP04→05, EP47→48, EP88→89, EP90→91, EP92→93). 특히 목란산 편(EP88→93)에서 4연속 공간교차가 등장하는 것은 작품 전체에서 가장 밀도 높은 교차편집 시퀀스이다.

### 6.4 시간경과(B)의 감소 추세
- 도입기(EP01→15): 14개 전환 중 4건 (28.6%)
- 원정기(EP15→30): 15개 전환 중 2건 (13.3%)
- 무연회 전반(EP30→50): 20개 전환 중 3건 (15.0%)
- 무연회 본선(EP50→75): 25개 전환 중 2건 (8.0%)
- 최종 결전(EP75→99): 24개 전환 중 2건 (8.3%)

서사가 진행될수록 시간경과 비율이 하락하며, 이는 작품이 후반부로 갈수록 **시간 압축(사건 밀도 증가)**을 지향함을 보여준다.

### 6.5 서사블록 전환(G)의 기능
서사블록 전환 8건은 모두 "대회 진행 중 일상/음모 삽입" 또는 "하나의 시퀀스 종결 후 다른 시퀀스 개시"에 해당한다. 이 유형은 EP31 이후에만 등장하며, 무연회라는 거시 구조가 복수의 소서사를 포함하게 되면서 발생하는 구조적 필연이다.

### 6.6 시간역행(H)의 희소성
99개 전환 중 단 1건(EP84→85)만이 시간역행이다. 파공검제는 **철저한 시간 순행 서사**를 유지하며, 유일한 역행은 음모의 기원을 밝히는 극적 필요에 의해서만 허용된다. 이는 무협 웹소설에서 회상 남용을 피하고 전진적 서사 추진력을 유지하려는 장르적 관습과 일치한다.

### 6.7 글도비 시스템 적용 시사점
- **기본 전환 생성 시**: 즉각연속(A)을 약 50% 비율로 생성하되, 3회 이상 연속 사용 후에는 시점전환(C) 또는 시간경과(B)를 삽입하여 단조로움을 방지해야 한다.
- **비무/전투 시퀀스 시**: 감정연속(F)을 의식적으로 배치하여 "관전 서사 릴레이"를 구현할 것.
- **음모+본선 병행 시**: 공간교차(E)를 2~4회 연속 사용하는 밀집 배치가 효과적.
- **도입부 설계 시**: 시간경과(B) 비율을 20~30%로 높여 세계관 조성 속도를 확보할 것.
