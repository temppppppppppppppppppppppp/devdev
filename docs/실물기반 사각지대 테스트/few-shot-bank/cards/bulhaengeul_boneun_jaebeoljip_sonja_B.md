## Findings First

1. **"능력 → 예측 → 선점"의 3단계 돈 루프**
   강동 개발구역 예측(ep10)이 바로 자산 선점으로 이어진다. 초능력 없는 현대 현판에서도 "정보 우위 → 선제 투자 → 사후 검증"의 구조로 이식하면 독자가 주인공의 격을 즉각 체감한다.

2. **재벌 내부 약자 포지션이 성장 엔진이다**
   승계서열 최하위(5남의 아들)라는 설정이 모든 성장에 정당성을 부여한다. 삼촌들이 견제할수록, 할아버지가 지분을 희석시키려 할수록 주인공의 저항이 독자 감정을 끌어올린다. 현대 현판에서 "약자 출발 + 내부 적대" 구조를 설계할 때 사용하기 좋다.

3. **거물화 루트가 기술 혁신 축으로 수렴한다**
   부동산 → 금융상품 → 반도체 → 스마트폰(316화 티폰)으로 이어지는 섹터 이동이 자연스럽다. 각 섹터 전환마다 주인공이 기존 판을 흔드는 혁신 아이디어를 선보인다. 장편 설계 시 "섹터 업그레이드" 루트의 교과서.

4. **할아버지가 견제와 인정 사이를 오가는 보스 캐릭터**
   김대환 회장이 주인공을 누르려다 결국 가장 신뢰하는 패로 쓰는 구조. 적대적 후원자 관계가 서사 내내 긴장을 유지시킨다. 현대 현판에서 그룹 총수나 선배 실력자를 이 포지션에 배치할 수 있다.

5. **언론전 + 정치 레버리지가 중반 거물화 축**
   석공그룹 언론전(ep50)과 외환위기 예측(ep200)이 주인공을 "돈만 많은 재벌 손자"에서 "판을 바꾸는 플레이어"로 격상시킨다. 단순 투자 승리가 아닌 정치·미디어 레버리지를 쓰는 거물화 구조를 쓸 때 참고.

6. **엔드게임이 제품 발표 무대 장악이다**
   316화에서 전 세계 1,000명 앞에 스마트폰을 직접 시연하는 장면이 최종 거물화 이미지를 완성한다. 단순 "사업 성공"이 아닌 "대중 앞 퍼포먼스"로 거물 이미지를 확정짓는 방식은 현대 현판에서 강한 마무리 클리셰로 쓸 수 있다.

- **언론전 + 정치 레버리지**: 경쟁자 언론 압박, 정치권 연계 타격 장면

### 변형 후 사용
- **검은 기운 시각화 → 정보 분석 우위**: 능력을 "시장 데이터 독해 능력" 또는 "사람 관찰 직관"으로 치환
- **회귀 지식 → 전문가 컨설팅/정보 선점**: 위기 예측 장면을 "업계 내부 정보 활용"으로 변환
- **티폰 발표 → 현대 제품 발표회 장면**: 스마트폰 대신 현재 시점 첨단 제품/서비스 발표로 치환
- **손자 포지션 → 낙하산 의심 받는 임원**: 약자 포지션 재설계 필요

### 폐기
- 1980년대 강동 개발 / 올림픽 배경 (시대 배경 특수성)
- 검은 기운 시각화 초능력 자체 (현대 현판 초능력 외피로는 과도)
- 55세 노숙자 회귀 구체 설정 (회귀물 전용)

## 마지막 3줄

장편 거물화 설계에서 이 작품의 가장 큰 자산은 "예측 선점 → 섹터 이동 → 위기 전환"이 316화 내내 반복되는 리듬감이다. 각 사이클마다 주인공이 더 큰 판에서 놀고 있음을 독자가 실감하게 만드는 구조 공식으로 재사용할 수 있다.

가장 강한 거물화 재료: **구조조정본부장 자리에서 외환위기 1,500원 환율을 맞히는 장면(ep200)** — 예측 능력이 단순 투자를 넘어 국가급 위기를 다루는 수준으로 확장된 순간. 주인공의 리그가 확 바뀌었음을 독자가 체감하는 가장 강한 거물화 스파이크.

절대 베끼면 안 되는 확장 요소: **티폰 발표 장면 전체** — 스티브 잡스 아이폰 발표를 의도적으로 오마주한 구조이므로 현대 현판에서 직접 복제하면 두 겹의 2차 창작이 된다. 구조(무대 장악 + 실시간 시연 + 즉시 판매 선언)만 차용하고 소재는 완전히 교체해야 한다.
