## 2. Findings First

1. **"과세권 = 무기" 구조**: 주인공이 총이나 주먹이 아니라 과세권이라는 제도적 권한으로 상대를 제압한다. 현대 현판 기업물에서 "법과 제도 안에서 싸우는 맛"을 설계할 때 직접 이식 가능한 골격.

2. **공개 굴욕 → 권위 획득 루프**: ep5 임성물산 사장실, ep20 검사실 — 상대의 안방에 쳐들어가 목격자가 지켜보는 앞에서 증거를 들이밀고 무너뜨린다. "주인공이 위상을 얻는 장면"의 가장 강력한 패턴.

3. **통장/숫자 기반 반박 불가 증거**: 감정이나 추론이 아니라 통장 내역, 재무제표, 계약서 같은 숫자 증거로 상대를 몰아넣는다. 사업물에서 "주인공의 말에 무게가 실리는 이유"를 설계할 때 가장 현실적인 방식.

4. **멘토 체인 구조**: ep1 한강변 중년 남자 → ep5 함선호 재산세과장 → ep10 조사과장. 각 단계마다 주인공의 실력을 시험하고 인정하는 멘토가 교체된다. "혼자 천재"가 아니라 "인정받아 올라가는 구조"를 만들 때 유용.

5. **제도권 내부의 적**: ep5 소득세과 과장+계장(유착), ep20 하성필 검사(뇌물). 외부 악당이 아니라 같은 시스템 안의 부패한 사람이 적. 기업물에서 "내부 권력 투쟁"을 설계할 때 직접 전용 가능.

6. **극빈 출발 + 어머니 보호 동기**: ep1의 건강보험료 체납, 어머니의 "네 앞길 안 막을 거다" — 주인공의 동기가 단순한 출세가 아니라 가족 보호. 독자가 주인공 편에 서게 만드는 초반 설계의 핵심 장치.

## 3. Master Reference Card v1

### opening_humiliation
7급 세무직 시험 합격 직후, 어머니 응급실 이송 + 건강보험료 6회 체납으로 보험 적용 제외 통보. 형(신우현)에게 SOS 전화했으나 "그 노친네 안 아픈 적이 있긴 했어?", "발목 좀 그만 잡으라고" 거절당함. 3중 타격으로 바닥 찍기.

### starting_deficit
극빈(카드 한도 턱밑, 현금서비스 감당 불가), 부재 아버지, 병환 어머니(대학병원 처방 필수), 가출한 형. 대학 포기하고 취직한 과거.

### protagonist_edge

- **what**: 세법 지식 + 숫자 기반 분석력 + 불의에 대한 분노
- **how**: 통장/재무제표를 읽고 즉석에서 탈세 구조를 역산. 함선호 과장이 "1년 차 맞나? 업계인이었어?"라고 할 정도의 속도. 세무사 사무실 알바 1개월이 전부인데 과장급 분석을 해냄.

### ep1_hook
7급 시험 막 끝난 직후, 핸드폰 켜자마자 어머니 응급실 이송 문자 2통. 합격의 기쁨이 1초 만에 절망으로 전환.

### ep1_first_saida
한강 잠수교에서 수험서 던지려는 순간, 중년 남자가 손목을 잡고 "공무원 하겠다는 사람이 한강에 쓰레기를 버리면 안 됩니다." — 절망의 밑바닥에서 문이 열리는 전환점.

### ep1_first_recognition
택시 기사: "국세청 그거? 좋은 데로 보셨네!" + 어머니의 대견한 눈빛. 아직 합격도 확정 안 됐는데 이미 인정의 씨앗이 심어짐.

### ep1_end_hook
중년 남자가 "사정을 들어나 봅시다"라고 하며 주인공의 운명이 바뀔 가능성 암시.

### block1_summary
극빈 7급 합격자 → 세무서 배치 → 소득세과 내부 유착 적발(ep5) → 조사과 이동(ep10) → 검사 과세(ep20). 매 에피소드 "제도적 권한으로 상대를 찍어 누르는" 사이다 1개 이상 배치.

### block1_spike_type
권위 행사형 — 과세 통지서를 직접 들고 가서 상대 안방(사장실/검사실)에서 증거를 펼치고 공개 굴욕. 상대가 겁먹는 구조의 핵심은 "숫자가 거짓말을 못 하기 때문".

### first_reward

### reward_stay_method
과세 성공 → 조사과 발탁 → 더 큰 건 배정. 보상이 "다음 싸움의 입장권"이 되는 구조. 머무르지 않고 계속 상승하게 만드는 엔진.

### growth_1_10

## 5. 현대 현판 적용 분해

### 바로 이식 가능
- "제도적 권한을 무기로 쓰는" 사이다 구조 — 총이나 주먹이 아니라 법적 권한으로 상대를 제압하는 골격
- "상대 안방 진입 + 숫자 증거 공개 + 목격자 앞 공개 굴욕" 3단 콤보 패턴
- 멘토 체인 성장 구조 — 각 단계마다 실력을 시험하고 인정하는 멘토가 교체되며 상승
- "보상 = 다음 싸움의 입장권" 엔진 — 과세 성공이 조사과 발탁으로 이어지는 보상 체류 구조
- 극빈 출발 + 가족 보호 동기로 독자를 주인공 편에 세우는 초반 설계

### 변형 후 사용
- "과세권"이라는 구체적 무기 → 현판 기업물에서는 감사권·인허가권·규제 조사권 등 다른 제도적 권한으로 교체 필요
- "세무 조사 → 공개 굴욕 → 위상 상승" 3단 구조 → 업종(세무)과 무기(과세 통지서)를 교체하면 권위물 전반에 이식 가능
- 제도권 내부의 적(소득세과 유착 과장, 뇌물 검사) → "같은 시스템 안의 부패한 사람이 적"이라는 구조는 차용 가능하나, 세무서/검찰이라는 구체 조직은 변형 필요

- "국세청 7급 세무직"이라는 직업 설정 자체 — 이 작품의 정체성이 과세권에 묶여 있음
- 부담부증여·비상장주식 상장 전 매입 등 구체적 세무 기법

## 6. 마지막 3줄

- **초반부를 레퍼런스로 쓸 이유**: "제도적 권한으로 상대를 찍어 누르는 맛"의 설계도가 ep1~20에 완성형으로 들어 있다. 권위물의 초반 사이다 구조를 역설계할 때 가장 깨끗한 샘플.
- **가장 강한 Block 1 재료 1개**: "상대 안방 진입 + 숫자 증거 공개 + 목격자 앞 공개 굴욕" 3단 콤보 — ep5 사장실과 ep20 검사실에서 동일 패턴이 반복되며 매번 사이다 강도가 올라간다.
- **절대 베끼면 안 되는 초반 요소 1개**: "과세권"이라는 구체적 무기 자체. 이 작품의 정체성이 과세권에 묶여 있으므로, 동일 무기를 쓰면 아류작이 된다. 반드시 다른 제도적 권한으로 교체해야 한다.
