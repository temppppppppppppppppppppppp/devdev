## 5. 현대 현판 적용 분해

**바로 이식 가능**
- **이중 성장 병렬 구조 (신체 × 재력)**: 신체 수치와 자산 수치를 동시에 진행하는 보상 이중화 구조. 소재(체중·주식)를 바꿔도 "두 축이 함께 움직인다"는 독자 보상 회로 설계 자체는 어떤 현대 기업물에도 그대로 이식 가능. 현재 시장에서 단일 성장 축 대비 클릭감 밀도 차별화 효과가 검증된 패턴.
- **Block 1 고속 완결 구조**: ep5 한 화 안에 투자 결정 → 상사 저지 → 돌파 → 당일 결과 확정. 첫 사이다 보상을 ep1~5 내에 배치하는 타이밍 설계 자체가 이식 가능. 장르와 소재 무관하게 "독자 이탈 방지 첫 보상" 배치 로직으로 활용.
- **협박형 인센티브 협상 시퀀스**: 주인공의 수익을 레버리지로 삼아 상사를 굴복시키는 권력 역전 패턴. "싫으면 매도할게요" 구조의 핵심은 '주인공이 거래 파기 버튼을 쥐고 있다'는 설정. 상사 제압 에피소드를 쓸 때 협상 논리형으로 구현하는 방식으로 이식 가능.

**변형 후 사용**
- **미션-보상 체계 구조**: 워포라 앱 고유명·설정은 복제 금지. 단 "목표 수치 달성 → 정보·능력치 티어업"이라는 게임화 보상 루프 구조는 앱·아이템·인물·조직으로 교체 후 이식 가능. 매 화 말미에 다음 보상을 예고하는 훅 패턴도 동일 방식으로 활용 가능.
- **외형 열세 + 실력 고수 조합**: 160kg이라는 구체 수치와 초고도비만 외형 자체는 복제 금지(원작 즉시 연상). 단 '사회적으로 가시화된 외형 열세가 왕따의 근거로 작동한다'는 구조적 패턴은 다른 외형 열세(나이·외모·장애 등)로 대체해 이식 가능.
- **몸-자산 교차 은유 서술**: 웨이트(바벨 눌림)↔주가 눌림 교차편집이라는 구체 소재 조합은 변형 필요. 두 개의 성장 언어를 교차편집으로 동시에 서술하는 밀도 기법 자체는 소재 교체 후 사용 가능 (예: 신체 훈련↔사업 확장, 기술 연마↔조직 장악 등).

**폐기**
- **워포라(WoFora) 앱 고유명 및 체중 감량 × 미래 주식 정보 연동 미션 체계**: 직접 복제 시 원작 특정 오염. 유사 앱 이름·동일 미션 구조 사용 금지.
- **실제 종목명 직접 사용** (레인보우 로보틱스, HMM, 노아해운, DS단석 등): 법적 리스크 + 원작 특정 오염. 허구 종목명으로만 사용할 것.
- **실제 경제 이벤트 직접 인용** (연준 금리 동결 날짜·수치, 홍해 봉쇄, 헝다 파산): 시기 특정 오염. 현실 이벤트를 허구화하거나 추상화해서만 사용 가능.
- **160kg 초고도비만 외형**: 유사 수치·외형 설정 시 독자가 원작 즉시 연상. 극단적 신체 수치를 직접 복제하는 방식 폐기.
