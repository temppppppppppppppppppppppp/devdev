# 대체역사 화간 연결(전환) 패턴 분석 (2작품 100화)

## 1. 개요

본 문서는 대체역사 웹소설 2작품 — **고려천조국** 50화 + **갑신정변** 50화 — 의 98개 전환 지점(각 작품 49개)을 분석한 결과이다.

### 분석 대상
- 총 100화, 98개 전환 지점
- 각 전환 지점에서 이전 화의 말미(~300자)와 다음 화의 도입부(~300자)를 비교

### 핵심 발견
대체역사 2작품은 무협과 달리 **"다시점 교차"와 "시간 점프"** 비중이 높다. 이는 국가 단위 서사가 개인 서사와 병행되어야 하기 때문이다. 또한 **에피소드 타이틀이 arc를 표지**하는 구조가 양 작품에 공통되어, 독자의 서사 위치 인식을 돕는다.

## 2. 전환 패턴 유형 분류

### 유형 A: 직접 연결 (장면 이어짐)
**설명**: 이전 화 마지막 장면이 시간 단절 없이 다음 화 첫 장면으로 이어짐. 동일 장소, 동일 시점.

**예시 — 고려천조국**:
- 3화→4화: "속전속결" 선언 → 기철 숙청 현장으로 직접 이어짐
- 14화→15화: "태후 유폐" 선언 → 태후와의 실제 담판 시작
- 21화→22화: 최영 군대 출발 → 전투 현장 도착 직결

**예시 — 갑신정변**:
- 1화→2화: "거사를 막는다" 결심 → 반란군 내 이탈 행동 시작
- 8화→9화: 일본군 접근 → 전투 개시 직결
- 13화→14화: 급조화포 준비 → 화포 발사 장면 직결

### 유형 B: 반응 전환형 (리액션 전환)
**설명**: 이전 화 말미의 충격적 사건 직후, 다음 화가 당사자 또는 제3자의 반응으로 시작.

**예시 — 고려천조국**:
- 4화→5화: 기철 숙청 완료 → 이제현과의 심야 문답 (사건 후 정리)
- 22화→23화: 최영의 김용 사살 → "개경에서의 위험이 끝났다" 확인
- 32화→33화: 최무선 등장 → 화약 기술 논의 반응

**예시 — 갑신정변**:
- 3화→4화: "역모입니다" 선언 → 우정총국의 김옥균 시점 반응
- 14화→15화: 화포 폭발 → 전투 결과에 대한 반응
- 29화→30화: 다케조에 협상 → 여론전 실행 반응

### 유형 C: 시점 전환형
**설명**: 이전 화의 주시점에서 다른 인물/세력의 시점으로 전환.

**예시 — 고려천조국**:
- 13화→14화: 이제현 시점 → 공민왕 시점으로 복귀
- 33화→34화: 공민왕 시점 → 원 조정(토크토아) 시점
- 45화→46화: 이제현/최영 시점 → 소녀 제비 시점

**예시 — 갑신정변**:
- 6화→7화: 김덕령 시점 → 우정총국 시점 (동시간대 다른 장소)
- 16화→17화: 민영목 시점 → 김덕령 시점 복귀
- 34화→35화: 외세 시점 → 조정 내부 시점

### 유형 D: 시간 점프형
**설명**: 이전 화와 다음 화 사이에 명시적 시간 경과. "며칠 뒤", "보름 후", "수개월 뒤" 등의 시간 표지.

**예시 — 고려천조국**:
- 5화→6화: 심야 문답 후 → 다음날 아침 군사 회의
- 23화→24화: 반란 진압 완료 → 시간 경과 후 개혁 논의
- 44화→45화: 태후와의 차 → 다음날 출발

**예시 — 갑신정변**:
- 18화→19화: 왕 면전 장면 → 유배지로 시간 점프 (수일)
- 22화→23화: 건어물 사업 시작 → 사업 안정화 후 (수주)
- 36화→37화: 협력자 발견 → 실행 준비 완료 (수일)

### 유형 E: 클리프행어 후속형
**설명**: 이전 화의 극적 긴장이 다음 화 도입부에서 해소 또는 설명.

**예시 — 고려천조국**:
- 7화→8화: "요동을 병략한다" 선언 → 구체적 군사 계획 논의
- 28화→29화: 이성계/쌍성총관부 언급 → 공략 계획 수립
- 34화→35화: "원의 시선이 고려를 향했다" → 원 사신 도착 소식

**예시 — 갑신정변**:
- 2화→3화: 반란 진행 → 주인공의 이탈 결행
- 41화→42화: 러시아 카드 제시 → 영국의 반응과 협상 진행
- 47화→48화: 이완용 등장 충격 → 이완용에 대한 대응 모색

### 유형 F: 배경/해설 전환형
**설명**: 다음 화가 세계관 설명, 역사적 배경, 국제정세 해설로 시작.

**예시 — 고려천조국**:
- 8화→9화: 전쟁 계획 논의 → 대운하 체계 및 원의 약점 해설
- 29화→30화: 상공업 진흥 선언 → 군기감의 현실적 상황 설명
- 38화→39화: 카마 활용 결심 → 해상 교역 구조 배경 설명

**예시 — 갑신정변**:
- 4화→5화: 외국 공사 대화 → 갑신정변 후 국제정세 배경 해설
- 24화→25화: 원세개의 등장 → 청·조선 관계 구조 설명
- 40화→41화: 이인임 등장 → 조정 내 권력 지형도 설명

## 4. 패턴 분포 특징

### 4.1 직접 연결(A)이 최다이나 무협보다 낮음

무협(곤륜마협)의 직접 연결 비율 33.3% 대비 대체역사 30.6%로 유사하나, **시점 전환(C)이 대폭 높음** (무협 17.2% vs 대체역사 19.4%). 이는 국가 단위 서사에서 적국/동맹국/민간의 시점을 교차해야 하기 때문.

### 4.2 시간 점프(D)의 장르적 차이

무협 8.1% vs 대체역사 13.3%. 대체역사는 군사 준비, 외교 교섭, 경제 사업 등 수주~수개월 단위의 시간 경과가 빈번하여 시간 점프가 자주 발생. 특히 갑신정변(16.3%)이 높은데, 주인공의 유배/사업 기간에 시간 압축이 필수적이기 때문.

### 4.3 배경/해설 전환(F)의 일정한 비율

양 작품 모두 8.2%로 동일. 이는 대체역사 장르에서 **역사적 맥락 제공이 필수**이며, 에피소드 도입부에 배경 설명을 배치하는 것이 장르적 관습임을 시사.

### 4.4 Arc 구조와 전환 패턴의 관계

| Arc 위치 | 주요 전환 패턴 | 이유 |
|----------|---------------|------|
| Arc 시작 | F(배경 해설) + D(시간 점프) | 새로운 무대/시기 설정 |
| Arc 중반 | A(직접 연결) + B(반응 전환) | 사건 전개의 긴밀한 연결 |
| Arc 클라이맥스 | A(직접 연결) + E(클리프행어 후속) | 긴장 유지 + 즉시 해소 |
| Arc 전환 | C(시점 전환) + D(시간 점프) | 시야 이동 + 시간 경과 |

### 4.5 에피소드 타이틀의 Arc 표지 기능

- **고려천조국**: 4화 단위 연작 구조 (예: "눈을 뜨다(1)~(4)", "대물을 낚기 위해서는(1)~(4)")
- **갑신정변**: 구어체 감탄문 형식 (예: "성공하면 생존! 실패하면 패망 아닙니까!", "맛을 보여주마!")
- 양 작품 모두 타이틀이 독자에게 현재 서사 위치와 톤을 즉시 전달
