# TF-E: Manuscript Contradiction Audit Report

**Auditor**: TF-E (Claude Opus 4.6)
**Date**: 2026-03-16
**Scope**: 8 project DBs x 4 episodes each = 32 manuscripts
**Method**: Full sequential reading of every episode, cross-episode fact tracking within each project

---

## Contradiction Type Key

| Code | Type |
|------|------|
| M-1 | Character (name, age, appearance, personality, background) |
| M-2 | Timeline (dates, sequence of events, time durations) |
| M-3 | Location (place names, geography, spatial layout) |
| M-4 | Asset/Ability (money, possessions, skills, resources) |
| M-5 | Relationship (family ties, alliances, interpersonal dynamics) |
| M-6 | Event continuity (plot events, cause-and-effect chains) |

**Severity**: CRITICAL = breaks plot logic, IMPORTANT = noticeable inconsistency, MINOR = subtle discrepancy

**M-1-001** | **IMPORTANT** | 김 비서 vs 김 집사 호칭 불일치
- **Ep1**: "김 비서의 목소리. 10년 뒤 위암으로 세상을 떠났던, 나를 친아들처럼 아껴주던 그 사람" — '김 비서'로 지칭
- **Ep2**: 별도 등장 없음
- **설명**: Ep1에서 '김 비서'로 호칭하지만 역할 묘사(아침 식사 준비 안내)는 집사에 가까움. DB0에서는 동일 역할이 '김 집사'로 지칭됨. 같은 프로젝트 내에서는 일관되게 '김 비서'로 사용되므로 내부 모순은 아님.

**M-4-001** | **MINOR** | 자산 총액 차이
- **Ep1**: 계좌 잔고 "2,078,451,200원" (약 20억 7천만 원) — 이것은 매각 전 계좌 잔고
- **Ep3**: 매각 목표 "20억" — 이는 목표 금액
- **Ep4**: SW인베스트먼트 계좌 "2,000,000,000원" — 초기 비용 차감 후
- **설명**: 금액 차이가 발생하나, 자산 처분 비용/세금/법인 설립비 등으로 설명 가능.

**M-3-001** | **MINOR** | 사무실 위치
- **Ep4**: 여의도의 낡은 상가 건물 **5층** (PC방에서 부동산 사이트로 검색)
- **설명**: 프로젝트 내에서 층수가 한 번만 언급되므로 자체 모순은 아님.

**M-6-001** | **IMPORTANT** | 법인 설립 경로 변경
- **Ep1**: 홍콩 기반 금융 컨설턴트를 통한 페이퍼 컴퍼니/해외 선물 거래용 유한회사 설립 계획
- **Ep3**: 김형준 변호사(세경 로펌)에게 "페이퍼컴퍼니가 아닌, 실제 해외 선물 거래를 위한 유한회사" 설립 의뢰 + 법인명 'SW인베스트먼트'
- **Ep4**: SW인베스트먼트 법인이 설립되어 있고, 한미증권 VVIP 전담팀 박성호 차장과 해외 선물 거래 계약
- **설명**: Ep1에서 홍콩 컨설턴트에 전화하려던 순간 아버지가 등장하여 중단. Ep3에서 김형준 변호사로 전환. 이것은 줄거리 흐름상 자연스러운 계획 변경으로 볼 수 있으나, 홍콩 법인 계획이 완전히 사라진 것은 아쉬운 연결.

**M-1-002** | **MINOR** | 아버지 문진 재질 명칭
- **Ep2**: "묵직한 크리스탈 문진" — 크리스탈로 지칭
- **Ep3**: "크리스탈 문진" — 일관됨
- **설명**: 내부 일관성 유지됨. DB0에서는 '수정 문진'으로 지칭하나, 이는 다른 프로젝트.

**결론**: CRITICAL 모순 없음. 법인 설립 경로 변경(홍콩 → 국내 김형준 변호사)이 가장 눈에 띄는 불연속이나, 아버지 등장으로 인한 계획 수정으로 해석 가능.

**M-6-001** | **MINOR** | 형의 투자 제안 내용
- **Ep2**: 아버지가 "네 형, 태준이도 신사업 투자 건을 올려놨더군"이라 했으나 구체적 내용 없음
- **Ep4**: 한태준이 회의에서 "해외 원유 선물 트레이딩"이라며 시우의 계획을 묘사 → 자기 제안이 아닌 시우 것에 대한 반대 논리를 폄
