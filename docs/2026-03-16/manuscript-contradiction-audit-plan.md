## 3. 검사 항목 (6대 모순 유형)

| # | 유형 | 설명 | 예시 |
|---|------|------|------|
| M-1 | **인물 설정 모순** | 이름/나이/외모/성격이 화별로 달라짐 | ep3에서 30대 → ep7에서 20대 |
| M-2 | **타임라인 모순** | 시간 순서 불일치 | "3일 전"이 다른 화에서 "1주 전"으로 |
| M-3 | **공간/장소 모순** | 장소 명칭이나 위치 설명 불일치 | 사무실이 3층 → 5층으로 변경 |
| M-4 | **능력/자산 모순** | 보유 자금, 기술, 무공 수준 불일치 | 전 화에서 빈털터리 → 갑자기 자금 보유 |
| M-5 | **관계 모순** | 인물 간 관계가 설명 없이 변동 | 적대 관계 → 갑자기 동맹 |
| M-6 | **사건 연속성 모순** | 해결된 사건이 미해결로, 미발생 사건이 기정사실로 | ep4에서 해결한 문제가 ep6에서 미해결 |

## 4. 각 TF 작업 흐름

```
Step 1. DB에서 manuscripts.content 전문 추출 (ep_num ASC)
Step 2. 에피소드별 순차 정독
Step 3. 핵심 팩트 추적표 작성
        - 인물: 이름, 나이, 직업, 외모, 성격
        - 장소: 명칭, 위치, 설명
        - 시간: 절대/상대 시간 표현
        - 자산: 금액, 보유물, 기술/능력
        - 관계: 인물 간 관계 (방향+성격)
        - 사건: 발생/해결 상태
Step 4. 화간 팩트 불일치 탐지
Step 5. 모순 리포트 작성 (심각도 분류)
```

## 5. 모순 심각도 분류

| 등급 | 기준 | 조치 |
|------|------|------|
| **CRITICAL** | 독자가 즉시 인지할 수 있는 명백한 모순 | 즉시 수정 필요 |
| **IMPORTANT** | 주의 깊은 독자가 발견할 수 있는 불일치 | 수정 권장 |
| **MINOR** | 해석 여지가 있거나 사소한 불일치 | 참고 기록 |
