### 3. 품질 신호 분석

#### 3.1 AI Slop 분석

전체 에피소드 AI Slop 히트 총 8건:

| 표현 | 출현 횟수 | 비고 |
|------|-----------|------|

| 어느새 | 1 | |
| 순식간에 | 1 | |
| 고개를 끄덕였다 | 1 | |
| 한순간 | 1 | |

에피소드당 AI Slop 지표는 0~2 범위로, 허용 기준 내 통제됨.
'입을 열었다'가 전체의 50%를 차지하므로, 향후 금지표현 목록 추가를 권장한다.

#### 3.2 압축률/복잡도 분석

| 지표 | 범위 | 평가 |
|------|------|------|
| Compression (압축률) | 0.43 ~ 0.46 | 안정적. 과도한 반복이나 희박한 서술 없음 |
| Burstiness (문장 변동성) | 17 ~ 21 | 양호. 단조로운 문장 길이 반복 없음 |
| Complexity (복잡도) | 41 ~ 46 | 투자물 장르에 적합한 중상위 수준 |
| CED (연속성 편집 거리) | 0.0 (전 에피소드) | 완벽. 연속성 위반 제로 |

모든 수치가 좁은 범위 내에서 일관되어, 생산 파이프라인의 품질 안정성을 입증한다.

#### 3.3 대화 비율 분석

스타일 가이드 목표 대화 비율: **0.0** (서술 중심)

전 에피소드에서 대화 비율 경고(warning)가 지속적으로 발생했다.
이는 스타일 가이드의 대화 비율 목표가 0.0으로 설정되어 있어,
실제 원고에 대화가 포함되는 한 경고가 불가피한 구조적 문제다.

**권장 조치:** 스타일 가이드의 `dialogue_ratio` 목표를 0.0에서 실제 원고 특성에 맞는
현실적 값(예: 0.15~0.25)으로 재조정 필요.

### 4. 다시도 근본 원인 분석

#### 4.1 ep4 (3회 시도)

```
R0 (tension) → REJECT: NPC 이름 혼동
R1 (patch)   → REJECT: 금지표현 미수정
R2 (patch)   → PASS (98점, ASP+MAD 적용)
```

**근본 원인: NPC 이름 혼동 (한진호 vs 한태준)**

- 1차 시도: Contradiction Firewall이 NPC 이름 오류를 탐지.
  '한진호'가 '한태준'으로 잘못 기재됨.
- 2차 시도: inplace_patch로 이름 수정 시도했으나,
  금지표현 '그림자처럼'이 여전히 잔존. 패치가 해당 구간을 건드리지 않음.
- 3차 시도: ASP(Adaptive Strategy Protocol) + MAD(Multi-Agent Debate) 적용.
  이름과 금지표현 모두 수정되어 98점으로 통과.

**교훈:** 패치 전략은 지적된 오류만 수정하므로, 동시에 존재하는 다른 유형의 오류
(금지표현 등)를 놓칠 수 있다. 복합 오류 시 전면 재생성이 더 효율적.

#### 4.2 ep5 (4회 시도) — 최난이도

```
R0 (tension)  → Contradiction Firewall REJECT: 장소 연속성 위반
R1 (patch)    → REJECT: 고유명사 '한미은행' 도입 (정답: '한미증권'), 점수 44점 폭락
R2 (patch)    → REJECT: NPC 직급 불일치, Contradiction Firewall MAJOR 2건
V75-D 발동    → Blueprint 자체 패치 (고유명사 수정)
R3 (tension)  → PASS (90점, 수정된 Blueprint 기반 전면 재앙상블)
```

**근본 원인: Blueprint 레벨의 고유명사 오염**

- **R0:** Director가 90점으로 승인했으나, Contradiction Firewall이 장소 연속성을 포착.
  '낡고 허름한 사무실'로 묘사된 공간이 '신축 오피스'로 변경됨.
  Blueprint 자체에 '신축 오피스' 표현이 포함되어 있었음.
- **R1:** Inplace patch가 상황을 악화시킴. '한미증권'이 '한미은행'으로 변질,
  점수 44점으로 폭락. 패치가 오히려 새로운 오류를 주입한 사례.
- **R2:** 재패치 시도했으나 NPC 직급 drift가 해소되지 않음.
  Contradiction Firewall이 MAJOR 2건 추가 탐지.
- **V75-D 발동:** 3회 연속 실패로 V75-D(Blueprint 수정 프로토콜) 트리거.
  Blueprint 내 고유명사('한미은행'→'한미증권', 장소명)를 직접 수정.
- **R3:** 수정된 Blueprint 기반으로 전면 재앙상블(full re-ensemble) 실행.
  tension 전략으로 깨끗한 원고 생성, 90점 통과.

**교훈:**
1. 패치 전략은 Blueprint 자체의 오류를 수정할 수 없다. 원천 데이터 오염 시
   V75-D(Blueprint 패치)가 필수적이다.
2. Inplace patch는 점수를 악화시킬 수 있다 (90→44). 패치 후 점수가 하락하면
   즉시 전면 재생성으로 전환해야 한다.
3. ep5는 시스템의 최악 시나리오를 보여주지만, 최종적으로 자동 복구에 성공했다.

### 5. 연속성 충돌 패턴

#### NPC Drift (지배적 실패 모드)

가장 빈번하고 심각한 연속성 위반 유형. 6개 에피소드 중 2개(ep4, ep5)에서 발생.

| 유형 | 사례 | 탐지 주체 |
|------|------|-----------|
| 이름 혼동 | 한진호 ↔ 한태준 (ep4) | Contradiction Firewall |
| 고유명사 변질 | 한미증권 → 한미은행 (ep5) | Contradiction Firewall |
| 직급 불일치 | 박성호 직급/직함 drift (ep5) | Contradiction Firewall |

**분석:** NPC 관련 오류가 전체 리젝트 사유의 ~70%를 차지한다.
투자물 장르 특성상 등장인물의 직급/소속/직함이 서사적으로 중요하며,
LLM이 유사한 이름이나 직함을 혼동하는 경향이 두드러진다.

#### Location Continuity

| 유형 | 사례 | 탐지 주체 |
|------|------|-----------|
| 공간 묘사 불일치 | '낡고 허름한 사무실' → '신축 오피스' (ep5) | Contradiction Firewall |

Blueprint 레벨에서 장소 표현이 오염되어 있었던 경우로,
원고 생성 단계의 패치로는 해결 불가능했다.

#### Forbidden Expression

| 유형 | 사례 | 탐지 주체 |
|------|------|-----------|
| 금지표현 잔존 | '그림자처럼' (ep4) | Quality Validator |

패치 전략이 금지표현 검사를 별도로 수행하지 않아 발생.
ASP+MAD 전면 재생성에서 해소됨.

### 8. 종합 평가

#### 강점

1. **품질 안정성:** 전 에피소드 최종 점수 90점 이상. CED 0.0 달성.
2. **자동 복구 능력:** ep5의 4회 시도 → V75-D Blueprint 패치 → 자동 복구 성공.
   인간 개입 없이 최악 시나리오를 해결함.
3. **Contradiction Firewall 유효성:** NPC 이름/장소 연속성 위반을 100% 탐지.
   Director가 승인한 원고도 Firewall이 리젝트하여 품질을 보전함 (ep5 R0).
4. **비용 효율:** 에피소드당 $0.788은 ~2M 토큰 기준으로 합리적.
5. **AI Slop 통제:** 8건의 클리셰가 6개 에피소드에 분산, 에피소드당 1.3건으로 양호.

#### 약점 및 개선 과제

1. **NPC Drift가 지배적 실패 모드:** 전체 리젝트의 ~70%.
   Blueprint/StateTracker 레벨에서 고유명사 강제 검증 필요.
2. **Inplace Patch의 부작용:** ep5에서 패치가 오히려 점수를 폭락시킴 (90→44).
   패치 전략의 안전장치(점수 하락 시 즉시 중단) 필요.
3. **Blueprint 오염 탐지 지연:** ep5의 장소/고유명사 오류가 Blueprint에서 비롯되었으나,
   3회 실패 후에야 V75-D가 발동. 조기 탐지 메커니즘 필요.
4. **대화 비율 경고 노이즈:** 스타일 가이드 설정 문제로 전 에피소드에서 경고 발생.
   실질적 품질 문제가 아닌 설정 오류.
