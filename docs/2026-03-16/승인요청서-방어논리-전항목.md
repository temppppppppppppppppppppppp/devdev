## A. 빠져 있거나 약한 부분 — 방어 논리

### #1 운영 인력/인건비 — "사람 비용 빠져있는데요?"

**방어 핵심**: 신규 채용이 아니라 **기존 인력의 업무 전환**이다.

- 운영자 = 이미 재직 중인 담당자. 추가 인건비 0원.
- 인간 감수도 기존 편집 인력 업무 범위 내 재배치.
- 따라서 총원가에 인건비를 별도 산입하지 않은 것이 아니라, **기존 인건비 내에서 소화되는 구조**다.
- 구두 답변용 공수 추정치 준비 권장: 운영자 주당 N시간, 감수자 작품당 N시간.

**승인서 반영안**: 2.4 비용 구조 하단에 한 문단 추가.

```
운영 인력은 기존 재직 인력의 업무 전환으로 충당하며, 본 승인 범위에 신규 채용 인건비는
포함하지 않는다. 운영자 공수는 주당 약 N시간, 인간 감수 공수는 작품당 약 N시간으로
추정하며, 기존 업무 재배치 범위 내다.
```

---

### #2 현재 reject율·재시도 비용

**방어 핵심**: 10 arc 로그가 이미 있다면 **실측치를 지금 넣는 게 방어력이 올라간다**.

- 현재 "reject 감안 ~70만원"은 추정치. 실측 reject율과 재시도 비용 편차를 로그에서 뽑을 수 있다.
- 넣을 수 있는 수치:
  - Stage 4 Director reject율: N% (10 arc 기준)
  - reject 1회당 추가 비용: 약 N원
  - 평균 재시도 횟수: N회/화
- 실측치가 추정 밴드(44~70만원) 안에 있으면 → "추정 밴드가 실측으로 검증됨"
- 실측치가 밴드를 넘으면 → 밴드를 조정하되, 상한 승인 범위(2,900만원 + a) 안에 있으면 문제없음

**승인서 반영안**: 2.5 손익분기 공식 하단에 실측 보조 표 추가.

```
| 지표 | 실측값 (10 arc 기준) | 비고 |
|------|---:|------|
| Stage 4 reject율 | N% | Director 심사 기준 |
| 평균 재시도 횟수 | N회/화 | reject 후 재생성 |
| reject 감안 실측 작품당 Vertex 비용 | 약 N만원 | 추정 밴드(44~70만원) 내 |
```

### #3 작품 1건 생산 리드타임 — "월 3작품이 정말 되나요?"

**방어 핵심**: 역산 + 실측 + 파도형 배치.

역산 공식:

```
1작품 = 70 arc
10 arc 실측 wall-clock = ?일
→ 70 arc 추정 리드타임 = 실측 × 7
→ Vertex Batch API 병렬 처리 시 단축 폭 적용
→ 월 3작품 = 순차 시 N일, 병렬 시 N일
```

추가 방어선:

- 2.1 차트에서 이미 **파도형 배치**를 깔아놨음: 4월 1작품, 5월 2작품으로 램프업
- 따라서 "4월 첫날부터 월 3작품"이 아니라 "하반기 안정 궤도에서 월 3작품"
- Stage 2/3/4는 파이프라인이므로 **작품 간 병렬 진행** 가능 (작품 A가 Stage 4일 때 작품 B는 Stage 2)

**승인서 반영안**: 3.3 현재 단계 또는 4.5 로드맵에 리드타임 한 문단 추가.

```
10 arc 실측 기준 wall-clock은 약 N일이며, 70 arc 기준 1작품 리드타임은 약 N일로
추정한다. 월 3작품은 파이프라인 병렬 진행(작품 A Stage 4 + 작품 B Stage 2)과
하반기 램프업 배치를 전제로 한 운영 목표다.
```

### #4 플랫폼 유통 전략

**방어 핵심**: 매출 분포 자료의 출처 플랫폼 = 유통 대상 플랫폼.

- 통계 모집단이 포텐/올나이트노벨/프로무림 → 글도비 작품도 동일 채널 유통 전제
- 이미 회사가 운영 중인 유통 채널이므로 신규 채널 개척 비용 없음
- 플랫폼 선택은 작품 장르·타겟에 따라 기존 편집부 판단 기준 적용

**승인서 반영안**: 2.1 또는 4.2에 한 줄 추가.

```
유통 채널은 자사가 기존에 운영 중인 포텐, 올나이트노벨, 프로무림 등 남성향 플랫폼을
기본 경로로 둔다. 통계 모집단과 유통 대상이 동일 채널이므로 매출 분포 비교의 전제가
일관된다.
```

### #5 플랫폼 AI 콘텐츠 정책 리스크

**방어 핵심**: 현재 시점에서 **명시적 금지 정책은 없으며**, 리스크로 인식하고 있다.

- 2026-03 기준 주요 남성향 플랫폼(포텐, 올나이트노벨, 프로무림)에 AI 생성 콘텐츠 전면 금지 약관은 확인되지 않음
- 다만 향후 정책 변경 가능성은 존재 → 리스크 표에 등재
- 대응: 인간 감수를 거친 최종 결과물로 유통하므로, "AI 보조 도구 사용 + 인간 창작자 저작" 구조 유지
- 정책 변경 시: 월 단위 운영이므로 즉시 대응 가능 (생산 중단 → 정책 확인 → 재개 판단)

**승인서 반영안**: 4.3 리스크 표에 행 추가.

```
| 플랫폼 AI 콘텐츠 정책 | 유통 플랫폼이 AI 생성 콘텐츠 제한·표시 의무화할 가능성 | 현재 명시적 금지 없음 확인. 인간 감수 거친 저작물로 유통. 정책 변경 시 월 단위 운영이므로 즉시 대응 가능 |
```

### #6 품질 기준선 정량 지표 — "pass"의 정의

**방어 핵심**: "pass"는 **Stage 4 Director 심사 통과**를 의미한다.

정의:

```
pass = Stage 4 Director 면담에서 5회 이내에 accept 판정을 받은 원고가
       해당 arc의 모든 화차에 대해 존재하는 상태
```

보조 지표 (넣을 수 있으면):

- Director accept 평균 라운드: N회/화
- 품질 게이트(Python 사전 검증) 경고 평균: N건/화
- Advisory 시스템 경보 건수: N건/arc

**승인서 반영안**: 3.3 현재 단계 또는 각주에 "pass" 정의 추가.

```
본 문서에서 "통과(pass)"는 Stage 4 품질 게이트(Director 면담 5회 이내 accept)를
전 화차에서 달성한 상태를 뜻한다.
```

### #7 실패/중단 기준 — "안 되면 어떻게 하나요?"

**방어 핵심**: 매몰비용이 거의 없는 구조 + 명시적 exit criteria.

비용 구조의 가역성:

- 월 단위 구독 (Codex, Claude Code) → 언제든 해지
- Vertex API → 종량제, 계약 잔여분 없음
- 서버/인프라 → 별도 장비 구매 없음
- **"이 예산은 공장 짓는 돈이 아니라 수도꼭지 여는 돈이다. 안 되면 잠그면 된다."**

Exit criteria 제안:

```
| 조건 | 판단 시점 | 액션 |
|------|----------|------|
| 실프로젝트 1건 Stage 4 완주 실패 | 2026-06 | 예산 동결, 원인 분석 후 재판단 |
| reject율 N% 초과 3개월 연속 | 월간 점검 | 생산 속도 하향 또는 일시 중단 |
| 작품당 실원가가 상한(~107만원) 대비 2배 초과 | 분기 점검 | 물량 축소 또는 구조 재검토 |
| 유통 플랫폼 AI 콘텐츠 전면 금지 | 즉시 | 생산 중단, 정책 대응 후 재개 판단 |
```

**승인서 반영안**: 4.4 의사결정 요청 하단 또는 4.5 로드맵 앞에 "중단 기준" 소절 신설.

### #8 브랜드 리스크

**방어 핵심**: 이미 필명 분리 + 인간 감수로 **이중 차단** 구조다.

- AI 생성 작품은 기존 작가 브랜드와 분리된 **별도 필명**으로 유통
- 인간 감수를 거치므로 "AI가 쓴 티"가 나는 품질 사고는 감수 단계에서 차단
- 최악의 경우(독자 반발) → 해당 필명 작품만 영향, 회사 본 브랜드·기존 작가 라인업과 격리

**승인서 반영안**: 4.3 리스크 표에 행 추가.

```
| 브랜드 리스크 | AI 생성 작품의 독자 반발 가능성 | 별도 필명 유통으로 기존 브랜드와 격리. 인간 감수로 품질 사고 사전 차단. 최악 시 해당 필명 라인만 영향 |
```

---

### #9 인간 감수 비용

**방어 핵심**: #1과 동일 논리 — **기존 편집 인력 업무 재배치**.

- 인간 감수 = 기존 편집부 인력이 기존 업무 시간 내에서 수행
- 추가 외주 편집비가 발생하는 구조가 아님
- 만약 물량 증가로 외주가 필요해지면 → 그 시점에 별도 추가 승인 요청

**승인서 반영안**: #1과 합쳐서 2.4에 한 문단으로 처리.
