# AI 웹소설 자동생산 시스템 도입 제안

**작성일**: 2026.02.11 | **작성자**: 웹소설사업팀 | **결재**: 본부장

---

## 1. 왜 지금 해야 하는가

2025년 이후 생성형 AI의 창작 품질이 임계점을 넘었습니다. 현재 주요 플랫폼(카카오페이지, 네이버시리즈, 문피아)은 내부적으로 AI 보조 집필 파이프라인을 연구 중이며, 해외(NovelAI, Sudowrite)는 이미 상용화 단계입니다. **선제 도입사가 콘텐츠 단가와 물량에서 압도적 우위를 점하게 됩니다.** 우리가 안 하면 경쟁사가 먼저 합니다.

## 2. 시스템 역량 — "모순 없는 장기연재"

자체 개발한 AI 생산 파이프라인은 **기획 → 아크 설계 → 회차 설계 → 원고 집필 → 품질 검증** 5단계를 완전 자동으로 수행합니다.

| 항목 | 기존 작가 집필 | AI 자동생산 |
|------|:---:|:---:|
| **서사 정합성** | 작가 기억력 의존 (30화 이후 모순 급증) | 8단계 자동검증 + 세계상태 추적 (200화+ 대응) |
| **NPC/설정 모순** | 수작업 연표 관리 | 자동 생사추적, 관계맵, 팩트원장 |
| **외부 검증 결과** | - | **테스트 15화 기준, 외부 AI 감사 정합성 98%↑** |

> **실증**: 투자 재벌물 15화(약 75,000자)를 생산하여 경쟁 AI(Gemini)로 교차검증한 결과, 지적 4건 중 실제 유효 오류 1건(회계 수치 반올림). 해당 건도 즉시 자동 연쇄수정 완료. **첨부 원고 참조.**

## 3. 생산 단가 및 속도

| 구분 | 작가 외주 | AI 생산 | 절감률 |
|------|:---:|:---:|:---:|
| **원고료/API 비용** (1권 15화 기준) | 150~300만 원 | **7~15만 원** | **95%↓** |
| **생산 소요** | 3~4주 | **4~8시간** (연산+PD 검수) | **90%↓** |
| **인간 개입 비율** | 100% (작가 전담) | **15~20%** (PD 기획·감수) | - |

- **API 비용 내역**: Gemini Pro 기준, 회당 앙상블 3편 생성 + 검증 = 약 5,000~10,000원. 1권(15화) = 7.5~15만 원
- **PD 역할**: 작품 기획(Bible), 톤/방향 설정, 최종 QA. 기존 "작가 관리" 업무가 "AI 감수"로 전환
- **월간 생산량**: PD 1인 기준, 월 4~8권(60~120화) 생산 가능 → 기존 작가 4~8명분

## 4. 리스크 및 대응

| 리스크 | 대응 |
|--------|------|
| 품질 불균일 | 8단계 자동검증 + PD 최종 감수 (이중 안전장치) |
| 저작권 | 자체 시스템으로 생산 → **저작재산권 100% 사내 귀속** |
| 독자 반감 | 단계적 도입. AI 표기 의무 없는 현행법 하에서 품질로 승부 |
| 기술 종속 | 멀티 모델 대응 (Gemini/Claude/GPT 폴백 체인 구축 완료) |

## 5. 요청사항

**파일럿 프로젝트 승인을 요청드립니다.**

- **범위**: 투자 재벌물 1작품, 50화(약 250,000자) 완성
- **기간**: 2주
- **투입**: PD 1인 + API 비용 약 50만 원
- **산출물**: 완성 원고 50화 + 품질 리포트
- **판단 기준**: 사내 편집자 블라인드 평가 (AI 원고 vs 작가 원고 비교)

> **결론**: LLM 시대에 콘텐츠 생산 구조가 바뀌는 것은 시간문제입니다. 먼저 움직이는 쪽이 단가 경쟁력과 IP 물량에서 승리합니다. 첨부된 15화 원고가 현재 도달 가능한 품질의 실증입니다.
