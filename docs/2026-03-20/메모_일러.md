## Midjourney vs Gemini/Nano Banana 메모

- `Nano Banana`는 Google Gemini 이미지 생성 계열 명칭이다.
- `Midjourney`는 공식적으로 자체 `V6 / V7 / V8 Alpha` 계열을 문서화한다.
- 현재 확인 가능한 공식 문서 기준으로 `Midjourney가 Nano Banana 기반`이라는 근거는 없다.

실무적 차이 메모:

- `Midjourney`
  - 강한 첫인상, 미감, 커버 아트 무드, 스타일 밀도가 강점
  - `Style Reference`, `Omni Reference`, `Editor` 기반 아트 디렉션에 유리
- `Gemini/Nano Banana`
  - 대화형 편집, API 자동화, 파이프라인 결합, 반복 리파인에 유리
  - 이미지 생성 단독 품질보다도 `자동화 가능한 편집기`로 보는 편이 맞다

정리:

- 최고 품질 목표라면 `Midjourney로 베이스 무드/원안 확보 -> 로컬/별도 파이프라인으로 리파인 -> 필요 시 Gemini로 심사/편집` 조합이 더 현실적이다.
- Google 단독 스택은 자동화는 편하지만, 현재 실험만 보면 `d.png`급 커버 임팩트를 바로 뽑는 쪽은 아쉽다.
