### 핵심 구조적 결함 5가지

#### 결함 1: 시간선/연대기 완전 부재 — 위험도 ★★★★★

작중 시간 경과가 **어디에도 추적되지 않는다.** `cumulative_bible['time_passed']`가 위치 데이터를 시간 필드에 매핑하는 **버그**도 있음 (stage4_orchestrator.py L994). 3일 거리를 1시간에 이동하거나, 중상에서 다음 화에 완치되어도 탐지 불가.

#### 결함 2: 사망 NPC 표시 상한 (10명) — 위험도 ★★★★☆

`dead_npcs`는 전체 누적이지만, Writer 프롬프트에는 **최대 10명**만 표시 (chief_writer.py future_guard `dead_npcs[:10]`). 100화+ 연재에서 11번째 이후 사망 NPC가 부활할 수 있음. StateTracker의 `check_dead_npc()`는 전체를 검사하지만, LLM이 프롬프트에서 "이 NPC는 살아있다"고 인식하면 자연스럽게 등장시킬 수 있음.

#### 결함 3: state_changes 단일 경로 의존 (9/11 항목 폴백 없음) — 위험도 ★★★★☆

11개 state_changes 필드 중 **NPC 사망과 무공 습득만** regex 폴백이 있음. 나머지 9개 (관계, 부상, 이동, 플롯, 아이템, 금융, 파괴, 성격, NPC-NPC)는 LLM이 state_changes JSON을 생략하면 **추출 자체가 안 됨.** LLM 응답 잘림이나 JSON 파싱 실패 시 해당 Arc의 모든 상태 변화가 소실.

#### 결함 4: 검증 파이프라인의 구조적 허점 — 위험도 ★★★★☆

- ContinuityValidator의 부상/위치 체크가 **항상 WARNING** (REJECT 불가)
- BlockingValidator의 물리적 능력/권위 체크가 **기본 비활성**
- Director LLM이 **직전 1화 + 요약만** 참조 (2화 이전 모순 미검출)
- NPC 프로필 없으면 캐릭터 로직 검증 **자동 PASS**
- retry_count 증가 시 Director 기준 완화 + 적응형 임계값 상승 = **수렴 방향 불일치**

#### 결함 5: 10화 이후 급격한 "망각 절벽" — 위험도 ★★★☆☆

| 거리 | 원고 텍스트 접근 | 구조화 데이터 |
|------|----------------|-------------|
| 1화 전 | 전문 (~5,000자) | 전체 |
| 4-10화 전 | 첫 150자만 | 전체 |
| 11화+ | **없음** | cumulative (최신값만) |
| 100화+ | **없음** | narrative_summary (87.5% 압축) |

서사적 복선, 감정선, 세계관 미세 변화는 10화 이후 급격히 소실. 200화+ 연재 시 mandatory_context 25,000자 상한에서 V66 신규 기능(뒷부분)이 먼저 truncate됨.
