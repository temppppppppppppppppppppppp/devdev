## 7. V50 모듈이란?

V50~V51 시리즈는 원고 품질 향상을 위해 도입된 **보조 분석 모듈**들입니다.
각 모듈은 LLM 호출 없이 Python만으로 원고를 분석하고, 그 결과를 프롬프트에 주입하여 작가 에이전트의 글쓰기 품질을 높이는 역할이었습니다.

### 죽은 모듈 (5개, ~2,896줄) — 어디서도 import 안 됨

| 모듈 | 버전 | 기능 | 줄 수 |
|------|------|------|------:|
| `tension_curve.py` | V50.1 | **긴장도 곡선 관리** — 에피소드별 긴장도(0~100) 수치화, 연속 고조/이완 방지, 클라이맥스 타이밍 최적화 | 677 |
| `dialogue_engine.py` | V50.2 | **대사 품질 엔진** — 캐릭터별 말투 DNA 추출, 대사 일관성 검증, 캐릭터 간 유사도 비교 | 603 |
| `subplot_weaver.py` | V50.3 | **서브플롯 직조기** — 다중 서브플롯 추적, 방치된 서브플롯 감지, 다음 에피소드 비트 제안 | 631 |
| `reader_simulator.py` | V50.4 | **독자 시뮬레이터** — 가상 독자 반응 시뮬레이션, 지루함/예측가능성/혼란 감지, 몰입도 평가 | 546 |
| `pacing_analyzer.py` | V51.1 | **호흡 분석기** — 문장 길이 분포, 긴박/이완 구간 탐지, 대화:서술 비율, 장면 전환 빈도 | 439 |

> **왜 죽었나?** V64 Phase 1에서 `if False:` 비활성화 → Phase 4에서 init 코드 삭제.
> `main_a.py`에서 import 자체가 제거되어 **.py 파일만 남아있는 상태**.
> `prompt_builder.py`에서 `getattr(..., None)`으로 참조하지만, 항상 `None`이므로 **모든 코드가 dead path**.

### 살아있는 모듈 (4개) — main_a.py에서 활발 사용 중

| 모듈 | 버전 | 기능 |
|------|------|------|
| `agent_intelligence.py` | V51.3 | 에이전트 지능 향상 (우수/회피 예시 패턴) |
| `failure_learning.py` | V51.4 | 실패 학습 시스템 (과거 실패에서 제약 학습) |
| `character_voice.py` | V51.5 | 캐릭터 음성 추적 (말투 일관성) |
| `foreshadow_tracker.py` | V51.6 | 복선 회수 추적 (복선 등록/회수 관리) |

> `V50_MODULES_AVAILABLE` 플래그가 이 살아있는 모듈들의 로딩을 제어합니다.
> 이름이 "V50"이지만 실제로는 V51+ 모듈을 게이트하는 역할.

### 처리 옵션

| 옵션 | 설명 | 효과 |
|------|------|------|
| **A. 삭제** | 죽은 5개 파일 삭제 + prompt_builder.py dead path 정리 | **-2,960줄**, 혼란 제거 |
| **B. 재연결** | 죽은 모듈을 다시 import하고 파이프라인에 통합 | 품질 분석 기능 부활, 대공사 필요 |
| **C. 보존** | 현 상태 유지 | 변경 없음, dead code 잔존 |
