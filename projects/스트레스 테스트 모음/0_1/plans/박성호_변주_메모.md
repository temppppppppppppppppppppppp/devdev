# 박성호 캐릭터 변주 메모

## 현황
- 6~15화에 걸쳐 "반론 → 압도 → 복종" 루프 7회 반복
- 감정의 대상이 매번 동일: "시우가 맞을까?" → "맞았다" → "대단하다"

## 원칙
- 1차 반응(6~8화)은 현재 그대로 유지 — 회의 + 충격 + 복종의 기본 세팅
- 9화부터 매 국면마다 **1개씩** 변주 요소 삽입
- 큰 구조 변경 없이, 기존 장면 안에서 박성호의 내면/행동을 바꾸는 수준

## 변주 맵

### 9~10화: 탐욕으로의 전환
- **변주 포인트**: 최 수석이 포지션 청산 압박할 때, 박성호가 시우의 지시가 아니라 **자기 수수료를 지키려고** 최 수석을 막아섬
- **현재**: 시우의 확신에 눌려서 복종한 채 최 수석에게 "고객의 명시적 지시입니다"로 대응
- **변주 후**: 같은 대사여도 내면이 다름 — 경외가 아니라 계산. "이 계좌가 터지면 내 실적도 끝"이라는 이해관계
- **작업 범위**: 내면 독백 교체 + 최 수석 대응 장면의 톤 변경

### 11화: 능동적 움직임
- **변주 포인트**: 시우가 카페로 부르기 **전에**, 박성호가 에콰도르 관련 채널을 선세팅해 와서 보고
- **현재**: 시우가 시키면 움직이는 수동 실행자
- **변주 후**: "지시하신 에콰도르 채널, 어제 밤에 미리 뚫어두었습니다" — 시우가 잠깐 의외라는 반응
- **작업 범위**: 카페 장면 내 대사 2~3줄 추가/수정

### 12~13화: 도덕적 비용
- **변주 포인트**: 에콰도르 숏 스퀴즈 후, 마진콜 당한 동료(김 대리 등)와의 대면 장면
- **현재**: 딜링룸 아수라장은 배경으로만 존재. 박성호는 시우 계좌만 바라봄
- **변주 후**: 김 대리가 "박 팀장님, 혹시 미리 알고 있었던 거 아닙니까?" 한마디. 박성호가 대답 못하고 시선을 피하는 짧은 장면
- **작업 범위**: 딜링룸 장면에 3~5줄 삽입

### 14~15화: 정체성 질문
- **변주 포인트**: 시우가 금 시장 인과관계를 설명할 때, 박성호가 반론이 아니라 "그걸 왜 저한테 설명하시는 겁니까"라고 물음
- **현재**: 로직에 감탄 → 복종
- **변주 후**: "저는 어차피 버튼만 누르는 사람 아닙니까. 설명은 필요 없습니다. 시점만 알려주십시오." — 자조적이지만 동시에 자기 역할을 수용한 프로의 태도
- **작업 범위**: 대사 교체 1~2줄 + 시우의 짧은 반응(의외 또는 무반응)

## 기대 효과
- 동일 구조(지시→실행) 안에서 박성호가 매번 다른 내면을 통과
- 6~8화 복종 → 9~10화 이해관계 → 11화 능동성 → 12~13화 죄책감 → 14~15화 체념적 프로의식
- 시우와의 관계도 "주종"에서 "비대칭적 파트너십"으로 미세하게 이동
